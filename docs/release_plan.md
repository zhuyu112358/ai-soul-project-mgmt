# 应用发布规划

**版本：** v1.0
**创建日期：** 2026-09-05
**维护方：** AI灵魂项目监控任务

> 本文档规划AI灵魂项目各阶段产品的发布策略、渠道、版本节奏和发布标准。基于商业计划书三层产品矩阵。

---

## 一、产品矩阵与发布节奏

### 阶段一：RTS灵魂对战竞技场（0-9个月）

**产品定位：** 宝可梦级智能的RTS对战游戏，玩家指挥AI灵魂进行实时策略对战。

**发布渠道：**
- **Steam（优先）** — PC端核心玩家群体，独立游戏友好
- **itch.io** — 早期测试版发布，收集反馈
- **TapTap（国内）** — 移动端玩家社区，适合测试
- **官网下载** — 独立分发渠道

**版本节奏：**

| 版本 | 时间 | 内容 | 发布渠道 |
|------|------|------|----------|
| v0.1 Alpha | M3 | 核心对战玩法（1v1），3个基础灵魂，本地对战 | itch.io / 内部测试 |
| v0.3 Beta | M5 | 联网对战，6个灵魂，天梯系统，观战模式 | Steam Early Access申请 |
| v0.6 EA | M7 | Steam抢先体验，10个灵魂，赛季系统，皮肤系统 | Steam Early Access |
| v1.0 正式版 | M9 | 完整内容，20+灵魂，剧情模式，成就系统 | Steam正式发布 |

**发布标准（v1.0门槛）：**
- [ ] 核心对战玩法完整，平衡性经过至少3轮测试调整
- [ ] 10个以上可玩灵魂，每个有独特技能树和性格
- [ ] 联网对战稳定（延迟<200ms，掉线率<5%）
- [ ] 天梯/匹配系统正常运行
- [ ] 新手引导完整，新玩家10分钟内可上手
- [ ] 崩溃率<1%，内存占用<2GB
- [ ] 灵魂系统API稳定（SoulArena v1.0）
- [ ] 世界引擎稳定（Seed v1.0）
- [ ] 端到端联调通过（灵魂进入世界→感知→认知→动作→世界反馈闭环）

### 阶段二：养成+直播观察（9-18个月）

**产品定位：** 玩家养成AI灵魂，观察其在虚拟世界中的自主行为，支持直播互动。

**发布渠道：**
- **Steam（续作/DLC）** — 基于阶段一用户基础
- **移动端（iOS/Android）** — 养成类适合移动端
- **直播平台集成** — 抖音/B站/Twitch直播互动插件

**版本节奏：**

| 版本 | 时间 | 内容 |
|------|------|------|
| v2.0 Alpha | M11 | 养成核心玩法，灵魂成长系统，基础世界 |
| v2.0 Beta | M14 | 直播互动功能，多灵魂同居，世界事件系统 |
| v2.0 正式版 | M18 | 完整养成体验，跨平台同步，直播打赏互动 |

### 阶段三：社会模拟+模型评测平台（18-36个月）

**产品定位：** 大规模AI社会模拟，同时作为AI模型评测平台（多智能体基准测试）。

**发布渠道：**
- **Steam（续作）**
- **Web端** — 模型评测平台面向研究者/企业
- **API服务** — 企业级AI灵魂API

## 二、发布前检查清单

### 技术检查
- [ ] 所有P0卡点已解决
- [ ] 端到端联调通过
- [ ] 性能测试达标（帧率/内存/网络）
- [ ] 安全审计通过（无高危漏洞）
- [ ] 数据备份/恢复机制验证
- [ ] 服务器压力测试通过（预期并发量的2倍）

### 内容检查
- [ ] 灵魂数量达标（各阶段目标）
- [ ] 世界内容达标（地图/事件/物品）
- [ ] 新手引导完整
- [ ] 本地化完成（至少中文+英文）
- [ ] 音效/音乐/美术资源齐全

### 合规检查
- [ ] 版号/备案完成（国内发布需要）
- [ ] 隐私政策/用户协议就绪
- [ ] 未成年人保护机制（防沉迷）
- [ ] 内容审核机制（UGC内容）
- [ ] 详见 `legal_compliance.md`

### 运营准备
- [ ] 社区运营计划（Discord/QQ群/Steam社区）
- [ ] 客服渠道建立
- [ ] 反馈收集系统（bug报告/建议）
- [ ] 数据分析埋点完成
- [ ] 发布营销物料（预告片/截图/商店页）

## 三、灰度发布策略

1. **内部测试（Alpha）** — 开发团队+核心测试者，不公开
2. **封闭测试（Closed Beta）** — 邀请制，500-2000人，收集核心反馈
3. **公开测试（Open Beta / EA）** — 公开可玩，持续迭代
4. **正式发布（1.0）** — 全渠道发布

**回滚机制：** 每个版本保留前一稳定版本，重大问题可快速回滚。

## 四、当前发布就绪度评估（2026-09-05）

| 维度 | 状态 | 说明 |
|------|------|------|
| 灵魂系统 | 🟡 进行中 | v4.47，58个认知子系统，持续迭代中 |
