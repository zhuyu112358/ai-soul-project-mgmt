一、执行摘要

核心定位：打造一个跨游戏、跨平台的AI灵魂系统。用户培养的"灵魂"是带有持久记忆和个性的数字伙伴，可以在不同游戏间迁移使用，在对战中成长，在虚拟社会中进化，最终走向实体机器人。

市场机会：AI陪伴/角色互动市场2025年规模超1.2亿美元，Character.AI月活2000万、用户日均使用75分钟，证明用户对"与AI角色深度互动"有强需求。但现有产品均为单平台、单角色、无持久迁移能力。本项目首次提出"灵魂可跨游戏迁移"的概念，将AI角色从"游戏内功能"升级为"跨平台数字资产"。

产品路径：采用三层产品矩阵，共享同一套灵魂引擎：

  • 短期（0-9月）：RTS灵魂对战竞技场——限制地图、指定任务、宝可梦级智能灵魂对战，快速变现
  • 中期（9-18月）：养成+直播观察——灵魂在虚拟小镇中长期生活，大事件驱动叙事，直播围观变现
  • 长期（18-36月）：社会模拟+模型评测平台——万级Agent持久社会，吸引模型厂商入驻，成为具身智能训练基础设施

核心优势：

  • 成本极低：宝可梦级智能无需大模型，小模型+规则系统+记忆检索即可实现，单灵魂月成本¥0.5-2，比人类级AI灵魂低一个数量级
  • 合规友好：游戏化包装（"数字宠物/对战伙伴"）大概率不触发《人工智能拟人化互动服务管理暂行办法》的最严监管
  • 商业闭环清晰：对战门票+皮肤+交易抽成+赛季通行证+游戏接入费，已被宝可梦验证20年
  • 壁垒深厚：UGC生态+跨游戏记忆数据+用户情感绑定，大公司可抄产品但抄不走社区和数据

二、愿景与核心设想

2.1 五层愿景

本项目的终极愿景是推动"智能载体的进化"——智能的本质不依赖于载体，载体是可以迁移的。从游戏代码到虚拟社会，到机器人身体，到生物融合，最终走向星际。每一层都有独立的商业价值，同时为下一层积累技术和数据。

层级愿景时间尺度技术可行性商业价值
第一层基础游戏中灵魂培养现在-3年9/10 已验证游戏对战、养成、交易，直接变现
第二层社会化灵魂的进化3-8年7/10 初步验证社会模拟、模型评测、研究服务
第三层结合机器人走进现实5-15年5/10 研究中具身智能训练基础设施、机器人大脑授权
第四层人机融合与互相转化15-50年2/10 远期脑机接口、意识数字化（研究跟踪）
第五层新物种走向星辰大海50年+1/10 科幻级愿景终点，不纳入商业计划
说明：第四、五层为长期愿景，用于指引方向和激励团队，不纳入本商业计划的财务预测和执行路线图。商业计划严格聚焦前三层，其中第一层和第二层为可执行范围，第三层为技术储备方向。

2.2 核心概念：跨游戏灵魂系统

什么是"灵魂"？灵魂是一个带有持久记忆、个性参数和行为模式的AI实体。它不是绑定在某个游戏里的角色，而是存储在云端、可以被不同游戏调用的"可移植智能体"。

灵魂的构成：

  • 核心身份：唯一ID、名称、外观（可跨游戏映射）、创建者
  • 性格参数：5-10个维度（勇敢/怯懦、激进/保守、友善/敌对、好奇心等），影响行为倾向
  • 记忆库：跨游戏的经历摘要，向量存储，检索后影响当前行为（被火烫过→怕火）
  • 技能/能力：在各游戏中习得的技能，通过"兼容性映射"在不同游戏中转化
  • 关系网络：与其他灵魂/用户的关系值（友好、敌对、师徒等）
  • 成长轨迹：等级、经验、成就，跨游戏累积但战斗数值按游戏独立计算

灵魂的智能级别

本项目的关键设计决策是：灵魂不需要人类级别智力。采用"宝可梦级"智能——条件反射、简单情感、习惯养成、基础战斗决策。这一决策将推理成本降低一个数量级，同时规避了最严的AI陪伴监管。

2.3 跨游戏迁移机制

灵魂的核心价值在于"可迁移"。用户在A游戏中培养的灵魂，可以带到B游戏中使用，其记忆、性格、关系会保留，但战斗数值按B游戏规则重新计算。

类比：类似宝可梦从《红/绿》迁移到《金/银》，但更进一步——不只是同系列跨版本，而是跨不同厂商、不同类型的游戏。你的灵魂伙伴陪你从一个游戏走到另一个游戏。

迁移规则：

  • 保留：性格参数、记忆库、关系网络、外观（通过映射）、成就标签
  • 重算：等级、战斗数值、技能效果（按目标游戏平衡性重新映射）
  • 新增：在目标游戏中获得的新记忆和技能，回流到灵魂核心

三、产品矩阵设计

采用三层产品矩阵，共享同一套灵魂引擎。每层产品有独立的商业模式和用户群，同时形成协同效应：短期产品赚现金流，中期产品攒用户，长期产品建壁垒。

3.1 第一层：RTS灵魂对战竞技场（短期，0-9月）

产品形态

玩家配置1-3个灵魂（性格/技能/装备），投入限定地图（竞技场、迷宫、资源点、生存岛），灵魂自主决策对战，玩家作为"教练"观战和战前配置。单局10-30分钟。赛季制排位。

核心玩法循环

  1. 配置：选择灵魂、调整性格倾向、装备技能/道具
  2. 对战：灵魂在地图中自主移动、战斗、采集、结盟，玩家不可实时操控（可发送有限指令）
  3. 观战：上帝视角观看战局，灵魂的个性导致不同的战术风格
  4. 成长：胜利获得经验和奖励，灵魂记忆中增加战斗经历，影响未来行为
  5. 交易：玩家间可交换/买卖灵魂、技能、装备

差异化设计

  • 个性即战术：勇敢的灵魂主动开团，怯懦的灵魂蹲草偷袭，好奇的灵魂到处探索——性格参数直接影响战局，没有"最优配置"
  • 记忆影响战斗：被某个技能击败过的灵魂，下次会优先躲避该技能；和某个灵魂并肩作战过，再次相遇会优先结盟
  • 观战即娱乐：AI自主对战产生不可预测的"名场面"，天然适合直播和短视频传播

3.2 第二层：养成+直播观察（中期，9-18月）

产品形态

玩家的灵魂进入一个持久运行的虚拟小镇（500-2000个灵魂同时生活），拥有住所、工作、社交关系。系统定期触发大事件（节日、天灾、选举、战争、神秘访客），玩家可以围观、微调自己的灵魂、直播给他人看。

核心体验

  • 养成：灵魂在小镇中工作赚钱、社交、学习、恋爱，玩家引导但不控制
  • 大事件：每1-2周一次世界事件，所有灵魂参与，产生戏剧性剧情
  • 直播围观：玩家可以直播自己的灵魂生活，或围观热门灵魂/事件，打赏
  • 暗中资助：付费为自己的灵魂提供资源、机会、特殊事件触发（差异化氪金点）

3.3 第三层：社会模拟+模型评测平台（长期，18-36月）

产品形态

大规模持久虚拟世界（1万+灵魂），模拟完整社会结构（经济、政治、文化、科技）。模型厂商可入驻驱动灵魂，平台发布"模型社会能力排行榜"，向学术机构和企业提供研究接口和数据服务。

核心价值

  • 活体benchmark：传统模型评测（MMLU/GSM8K）是静态答题，虚拟社会中的长期交互能测出记忆一致性、社交智能、目标坚持度等动态能力
  • 训练数据：万级灵魂的长期社会交互数据，对模型厂商和机器人公司有极高价值
  • 仿真环境：虚拟世界可作为机器人/具身智能的训练环境（Sim2Real的前置环节）

3.4 产品协同效应

三层产品共享同一套灵魂引擎和用户体系，形成正向飞轮：

飞轮效应：RTS对战产生精彩内容→吸引用户→用户培养灵魂→灵魂进入养成世界积累记忆→记忆使灵魂更独特→独特灵魂在RTS中更有价值→更多用户参与对战→数据积累→吸引模型厂商→平台价值提升。
  • 技术共享：灵魂架构、记忆系统、世界引擎一套代码三层复用
  • 用户导流：RTS用户自然流入养成世界，养成用户围观社会模拟
  • 数据累积：每层产品的交互数据都丰富灵魂的记忆库和平台的数据资产
  • 品牌统一：所有产品共用"灵魂"品牌认知，降低获客成本

四、技术可行性分析

4.1 灵魂架构设计

采用"小模型+规则系统+记忆检索"的混合架构，而非纯大模型驱动。这一设计在保证体验的同时将成本降到最低。

架构分层

层级组件技术选型作用
感知层环境状态解析游戏引擎API + 结构化状态将游戏状态转为灵魂可理解的输入
记忆层向量记忆库Milvus / Qdrant / Convex向量检索存储跨游戏经历，语义检索相关记忆
决策层规则引擎 + 小模型行为树/状态机 + 7B模型微调规则处理战斗决策，小模型处理个性表达
个性层性格参数系统多维参数向量（5-10维）影响决策权重和行为倾向
表达层台词/动作生成小模型生成 + 预设模板生成符合个性的台词和动作
成长层经验/记忆写入事件摘要 + 重要性评分将经历压缩为记忆，更新性格参数

记忆系统工作流程

  1. 事件捕获：灵魂在游戏中的关键事件（战斗、社交、获得物品）被捕获
  2. 摘要压缩：用小模型将事件压缩为简短描述（"在竞技场被火焰技能击败"）
  3. 重要性评分：根据事件影响（胜负、情感强度）评分，高分记忆长期保留
  4. 向量存储：摘要转为向量存入记忆库
  5. 检索调用：当前场景触发语义检索（如看到火焰→检索"被火击败"的记忆）
  6. 行为修正：检索到的记忆调整决策参数（怕火→躲避火焰技能）

4.2 跨游戏迁移技术

灵魂跨游戏迁移的核心是"标准接口+兼容性映射"。

标准接口定义

  • 输入接口：游戏向灵魂传入结构化环境状态（位置、敌人、物品、事件）
  • 输出接口：灵魂返回行为指令（移动方向、目标选择、技能使用、台词）
  • 状态同步：游戏定期同步灵魂状态到云端，云端更新记忆和成长

兼容性映射

不同游戏的技能/数值体系不同，通过映射表实现跨游戏兼容：

  • 灵魂的"火焰亲和"属性 → A游戏中映射为"火焰技能伤害+10%"，B游戏中映射为"火系技能解锁"
  • 灵魂的"战斗经验" → 各游戏中独立计算等级，但核心属性（勇敢度等）提供修正系数
  • 灵魂的外观 → 通过美术资源映射表在不同游戏中呈现为对应风格

4.4 规模化与成本优化

推理成本优化策略

  1. 模型分层：战斗决策用规则系统（零成本），个性表达用小模型（低成本），复杂社交用中等模型，人类级反思仅对少数高级灵魂开放
  2. 批量推理：多个灵魂的思考请求批量处理，提高GPU利用率
  3. 休眠机制：48小时无交互的灵魂进入休眠，暂停实时推理，仅保留记忆
  4. 记忆压缩：旧记忆定期摘要合并，减少检索和存储成本
  5. 事件驱动：灵魂不持续思考，仅在关键事件（战斗、社交、移动决策）时触发推理
  6. 缓存复用：相似场景的决策结果缓存，避免重复推理

5.2 游戏化包装的合规优势

关键合规策略：将产品定位为"游戏中的数字宠物/对战伙伴"，而非"AI陪伴/虚拟伴侣"。这一定位差异可能使产品不触发《人工智能拟人化互动服务管理暂行办法》的最严监管。

《拟人化互动服务管理暂行办法》适用于"模拟自然人人格特征、思维模式和沟通风格的持续性的情感互动服务"，典型场景为AI陪伴、虚拟伴侣。本产品的核心是：

  • 灵魂是"宠物/伙伴"定位，不是模拟真人
  • 核心交互是对战和养成，不是情感对话
  • 智能级别为宝可梦级，不具备人类级思维模拟
  • 用户与灵魂是"训练师-宠物"关系，不是"人与人"关系

以上设计降低了被认定为"拟人化情感互动服务"的概率。但最终认定以监管部门意见为准，建议在公测前咨询合规顾问并主动备案。

5.3 各阶段合规要求

阶段一：RTS对战（0-9月）

  • 内测阶段（<500用户，邀请制）：可暂不完成全面备案，但需在用户协议中标注"测试版本"
  • 公测前必须完成：生成式AI服务备案、算法备案、ICP备案
  • AI生成内容（灵魂台词）需添加AI标识
  • 建立内容审核机制（初期可人工审核，用户量增长后加AI审核）
  • 不涉及直播，无需AI直播备案

阶段二：养成+直播（9-18月）

  • 直播功能需完成：主体备案、数字人备案、肖像链路备案、类目资质、真人接管证明、异常应急预案
  • 每场直播至少一名持证主播在线，30秒内可人工介入
  • 建议采用"用户自发直播"模式：用户用自己的账号直播自己的灵魂，平台提供工具，部分合规责任由用户承担
  • 未成年人保护：设置未成年人模式，限制使用时长和付费

阶段三：社会模拟+平台化（18-36月）

  • 大规模面向公众，需通过安全评估
  • 数据服务需注意：用户记忆数据不得直接出售，仅可提供脱敏聚合数据
  • 模型厂商入驻需签署数据处理协议，明确数据归属和使用范围
  • 如使用海外模型，需完成数据出境安全评估（建议优先使用国产模型）

5.4 数据与隐私

  • 灵魂记忆归属：用户创建的灵魂，其记忆数据属于用户个人信息。用户有权查看、导出、删除。平台拥有数据的处理权，但不得未经同意用于其他目的。
  • 数据存储：全部存储在境内服务器，使用国产模型，避免数据出境合规问题。
  • 交易合规：灵魂交易涉及虚拟物品，需明确平台拥有灵魂数据所有权，用户仅有使用权；限制交易价格区间，防止金融化和赌博认定。
  • 人格权保护：禁止用户创建模仿真实人物（名人、逝者、他人）的灵魂，用户协议中明确禁止并建立审核机制。

7.3 核心壁垒构建策略

壁垒一：UGC生态（最优先）

  • 早期就开放灵魂创建工具，让用户创造个性灵魂
  • 建立创作者激励：热门灵魂创作者获得交易分成和流量扶持
  • 促进玩家间关系：组队、敌对、师徒、灵魂联姻，关系链是最强迁移壁垒
  • 社区运营：官方论坛、玩家赛事、灵魂名人堂，让用户有归属感
  • 参考：Character.AI的UGC角色生态、小红书的笔记、B站的UP主

壁垒二：数据资产化

  • 从第一天规范收集和存储多灵魂交互数据
  • 这些数据可用于：模型评测、训练数据销售（脱敏）、研究服务、行为预测
  • 数据是大公司抄不走的，也是他们最想要的
  • 建立数据分级：核心用户数据（不可出售）、脱敏聚合数据（可商业化）、公开统计数据（免费用于建立公信力）

壁垒三：跨游戏网络效应

  • 接入的游戏越多，灵魂的使用场景越丰富，对用户越有价值
  • 用户越多，游戏厂商越有动力接入
  • 形成双边网络效应后，后来者难以复制
  • 先通过自有游戏（RTS+养成）建立用户基础，再向第三方游戏扩展

壁垒四：合规先行

  • 提前完成生成式AI备案、算法备案，形成监管壁垒
  • 在监管趋严环境下，"已经合规"本身就是竞争力
  • 大公司法务更保守，某些创新玩法（如灵魂交易）可能不敢做

壁垒五：多模型适配

  • 不绑定单一模型厂商，支持多家模型驱动灵魂
  • 避免被某家厂商通过断供或涨价控制
  • 同时为后期"模型评测平台"奠定基础

7.4 避免被收购的具体策略

原则：不主动寻求收购，但保持开放。被收购是退出选项之一，不是目标。以下策略旨在保持独立性和议价权。

策略一：保持现金流健康，不被迫融资

  • 阶段一即可微利，用利润支撑研发，减少对外融资依赖
  • 融资只在需要加速扩张时进行，且选择财务投资人而非战略投资人（战略投资人往往附带收购条款）
  • 保持至少12个月的现金储备，避免在资金紧张时被低价收购

策略二：股权结构保护

  • 创始人保持绝对控股权（投票权>50%），融资时使用AB股结构（A股1票，B股10票）
  • 核心团队期权池预留15-20%，绑定团队利益
  • 融资时拒绝"强制出售权"（Drag-along Right）或设置高门槛（需90%以上股东同意）
  • 拒绝"优先购买权"中赋予单一投资人过大的否决权

策略三：构建不可替代性

  • 如果大公司可以轻易复制，就会选择复制而非收购。必须让"收购比复制更划算"
  • 不可替代性来自：UGC生态（用户关系链）、数据资产（跨游戏记忆）、品牌心智（第一认知）、合规资质
  • 当这些壁垒足够厚时，大公司会选择收购而非复制，但此时你也有足够底气拒绝

策略四：与多家厂商保持等距关系

  • 不与任何一家大模型厂商签订独家协议
  • 同时与2-3家厂商合作，让他们互相制衡
  • 接受战略投资时，选择小额、非控股、无排他条款的投资
  • 避免被某一家厂商"绑定"后成为其对抗其他厂商的棋子

策略五：建立独立品牌和社区文化

  • 品牌不依附于任何大公司，保持独立调性
  • 社区有自己的文化、梗、名人，用户对品牌有认同感
  • 如果被收购，社区可能流失——这本身就是收购方的顾虑，也是你的议价筹码

八、实现路径与里程碑

采用渐进式路径，每个阶段有明确的目标、里程碑和决策点。前一阶段的成功是后一阶段启动的前提，避免过早扩张。

阶段零：技术验证期 第0-3月
目标：验证"AI灵魂对战好不好看、用户愿不愿意回来"这两个根本问题。
动作：基于AI Town开源代码搭建极简原型（10个灵魂在一个房间里抢资源/对战）；接入DeepSeek/Qwen-Flash；实现基础记忆系统；找10-20个朋友测bug，再找50-100个陌生人测留存。
团队：创始人1人 + 朋友1-2人（免费/低薪）。
成本：月现金成本¥50以内（免费额度+域名）。
关键指标：次留>30%，用户平均观看时长>5分钟/局，单局推理成本<¥0.2
阶段一：RTS对战上线 第3-9月
目标：正式上线RTS灵魂对战竞技场，实现第一个产品的商业化。
动作：完善对战系统（地图、技能、排位、赛季）；上线灵魂创建和交易系统；完成生成式AI备案和算法备案；接入支付；社群运营+KOL推广；赛季制运营。
团队：扩至3-5人（前端、后端、美术/运营）。
成本：月成本¥4-9万。
关键指标：MAU>1万，月收入>¥5万，付费率>12%，7留>15%
阶段二：养成+直播上线 第9-18月
目标：推出养成虚拟世界，建立直播围观生态，扩大用户规模。
动作：开发持久运行的虚拟小镇（500-2000灵魂）；大事件系统；直播功能（合规：持证主播+30秒接管）；暗中资助付费系统；RTS用户导流到养成世界；开始接触中小游戏厂商谈灵魂接入。
团队：扩至8-12人（增加直播运营、社区、AI工程师）。
成本：月成本¥23-44万。
关键指标：MAU>5万，月收入>¥25万，直播日均观看>1万人次，首个第三方游戏接入
阶段三：社会模拟+平台化 第18-36月
目标：从游戏公司升级为"智能载体平台"，吸引模型厂商和研究机构。
动作：扩展至万级Agent持久社会；上线多模型适配和"模型社会能力排行榜"；推出研究服务和企业沙盘；与2-3家模型厂商达成合作（算力补贴/入驻费）；接入5-10款第三方游戏；探索机器人仿真环境。
团队：扩至15-20人（增加AI研究、商务、合规）。
成本：月成本¥46-81万（厂商补贴后¥41-72万）。
关键指标：MAU>15万，月收入>¥80万，模型厂商合作>2家，整体盈利
阶段四：机器人延伸（技术储备） 第36月+
目标：在虚拟世界跑通、有现金流和数据后，探索向实体机器人延伸。
动作（渐进式）：①先开放虚拟世界作为机器人仿真训练环境（to B，不碰硬件）；②将灵魂架构封装为具身智能中间件，移植到合作方机器人硬件；③针对高价值垂直场景（工业巡检/养老）自研或投资硬件。
原则：成立独立子公司/事业部，核心团队继续守虚拟世界基本盘，不用主营业务利润赌硬件。
启动条件：虚拟世界月收入稳定>¥100万，有机器人公司主动寻求合作

十、融资策略与独立性保障

10.1 融资理念

核心原则：用利润养研发，用融资换速度，不为融资而融资。 由于阶段一即可微利，本项目不需要在早期大额融资稀释股权。融资只在需要加速扩张时进行，且优先选择财务投资人，保持战略独立性。

10.2 融资路径

轮次时间金额估值用途投资人偏好
种子轮第3-6月¥300-800万¥3000-5000万团队扩张+RTS上线+备案天使投资人、游戏行业老兵、AI应用基金
Pre-A第9-12月¥1000-2000万¥1-1.5亿养成产品开发+用户增长财务VC（红杉、高瓴、IDG等消费/科技组）

B轮第30-36月¥8000万-1.5亿¥10-20亿规模化+机器人方向探索成长基金、产业资本（小额）

10.3 融资叙事

对投资人讲三层故事：

  1. 近期（已验证）：AI灵魂对战游戏，6个月上线，宝可梦级智能成本极低，阶段一即可盈利
  2. 中期（路径清晰）：跨游戏灵魂平台，UGC生态+交易经济+直播变现，5万MAU月收¥30万
  3. 远期（想象空间）：具身智能训练基础设施，社会模拟+模型评测+机器人仿真，是"智能载体进化平台"

参考SpaceX和Neuralink的叙事方式：用宏大愿景融资，用近期产品赚钱，两者之间有清晰的技术递进链。

10.4 保持独立性的具体措施

股权与控制权

  • 采用AB股结构：创始人B股1票=10票，确保经济权益稀释后投票权仍>50%
  • 期权池15-20%，由创始人代持投票权
  • 融资协议中拒绝：强制出售权（Drag-along）、领售权、一票否决权（除重大事项外）
  • 董事会席位：创始人占多数（如3席中占2席），投资人仅占1席

投资人选择

  • 优先：纯财务投资人（不附带业务绑定和收购条款）
  • 谨慎：战略投资人（大模型厂商、游戏公司）——如接受，要求小额（<5%）、无排他、无收购优先权
  • 避免：要求独家合作、要求数据共享、要求优先收购权的投资人
  • 与2-3家大模型厂商同时保持合作关系，不被任何一家绑定

业务独立性

  • 技术栈不依赖单一厂商：多模型适配、多云部署、开源组件为主
  • 用户数据完全自有，不与任何投资人共享原始数据
  • 品牌独立，不使用任何投资人品牌背书
  • 核心技术（灵魂架构、记忆系统）申请软件著作权和专利

财务独立性

  • 保持至少12个月现金储备，不在资金紧张时被迫融资或接受收购
  • 阶段一实现微利后，用利润覆盖基础运营，融资仅用于加速
  • 建立成本控制纪律，不盲目扩张

10.5 被收购时的议价框架

如果未来考虑被收购（作为退出选项），以下因素决定议价权：

  • 用户规模：MAU>50万才会被大公司认真考虑
  • 收入健康：有正现金流或清晰盈利路径，比纯烧钱项目估值高
  • 数据壁垒：独有跨游戏灵魂交互数据，是收购方最看重的
  • 团队不可替代：核心团队的AI+游戏复合能力
  • 竞争威胁：如果多家大公司都想要，竞价会推高估值

参考AI应用类收购估值：年收入的10-20倍，或$50-200/用户。做到月收入¥500万、MAU 50万时，估值可能在¥10-30亿区间。

最终目标：独立发展成为"智能载体基础设施"平台，类似Steam之于游戏、AWS之于云计算。被收购始终是选项，但不是目标。保持独立性的关键是：有现金流、有数据壁垒、有用户社区、有控股权。
