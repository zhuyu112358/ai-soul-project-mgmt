# AI灵魂差异化设计文档 v1.0

> 核心理念：战策的AI对手不是"电脑AI"，是**有灵魂的对手**。玩家应该能通过视觉、听觉、行为细节，明显感受到每个AI灵魂的独特个性，而不是打一个只会放技能的木桩。

---

## 一、四种基础灵魂性格

每个可选/对战的AI灵魂都有明确的性格标签，影响从外形到行为的一切。

| 性格 | 核心特质 | 战斗风格 | 典型行为 |
|------|---------|---------|---------|
| **勇猛型** | 冲动、好胜、不怕死 | 主动进攻、贴身缠斗、残血不撤 | 见面就冲，喜欢用高伤害技能，被打了反而更猛 |
| **谨慎型** | 冷静、保守、精打细算 | 先防守后反击、保持距离、算血线 | 开局先观察，等你失误再打，血量低了立刻撤 |
| **智略型** | 狡猾、多变、喜欢套路 | 声东击西、绕后偷袭、骗技能 | 故意露破绽，等你交技能再反打，喜欢绕后 |
| **灵动型** | 活泼、多变、爱秀操作 | 频繁位移、技能连招、打了就跑 | 一直在动，技能衔接快，打完一套就拉开距离 |

## 二、外形差异化（玩家第一眼就能看出不同）

### 2.1 灵魂球基础外观
- **颜色**：每种性格有主色调
  - 勇猛型：红橙色系，光晕偏暖
  - 谨慎型：蓝青色系，光晕偏冷
  - 智略型：紫金色系，光晕偏神秘
  - 灵动型：绿黄色系，光晕偏亮
- **核心图案**：灵魂球内部有不同的核心纹路
  - 勇猛型：火焰/尖刺状纹路
  - 谨慎型：盾牌/几何纹路
  - 智略型：眼睛/螺旋纹路
  - 灵动型：风/波浪纹路
- **粒子效果**：待机时的粒子飘散方向和颜色不同
  - 勇猛型：粒子向上冒，像火焰
  - 谨慎型：粒子缓慢环绕，像护盾
  - 智略型：粒子随机闪烁，像星光
  - 灵动型：粒子快速飘动，像风

### 2.2 表情系统（灵魂球会"变脸"）
灵魂球不是一个静态球，它有**表情变化**，通过核心图案的形变和眼睛（两个光点）的状态来表现：

| 情绪 | 表情表现 | 触发条件 |
|------|---------|---------|
| **平静** | 眼睛正常大小，核心图案稳定 | 开局、均势 |
| **愤怒** | 眼睛变窄变尖，核心图案变红跳动 | 被连续命中、被击杀 |
| **恐惧** | 眼睛变大，核心图案收缩颤抖 | 血量低于30%、被围殴 |
| **兴奋** | 眼睛发亮，核心图案快速旋转 | 连击、击杀玩家、血量优势 |
| **疑惑** | 眼睛变成问号状，核心图案停顿 | 玩家行为异常（不动、绕圈） |
| **得意** | 眼睛眯成弧线，核心图案膨胀 | 连胜、丝血反杀 |
| **痛苦** | 眼睛变成X状，核心图案闪烁 | 被暴击、被控制 |

**表情持续时间**：0.5-2秒，不是一直挂着，是事件触发后短暂表现，然后回到平静。

### 2.3 小动作/待机习惯（这是差异化的关键！）
每个灵魂在**待机/移动时**有不同的习惯性小动作，让玩家一看就知道"这是XX性格的灵魂"：

**勇猛型：**
- 待机会**轻微上下跳动**，像在蓄力
- 移动时**带残影**，冲得很猛
- 技能释放前**会先顿一下**（蓄力感），然后猛冲
- 被命中时**几乎不后退**，硬顶着继续打
- 血量低时**身体会微微发红**（愤怒），移动速度变快

**谨慎型：**
- 待机会**缓慢左右摇摆**，像在观察
- 移动时**走Z字形**，不直线冲
- 技能释放**很果断**，但释放后立刻拉开距离
- 被命中时**会立刻后跳一步**（本能躲避）
- 血量低时**身体会微微发蓝**（警惕），移动更谨慎

**智略型：**
- 待机会**原地旋转**，像在思考
- 移动时**喜欢绕圈**，不正面接近
- 技能释放前**会先做假动作**（往反方向晃一下），然后从另一侧出手
- 被命中时**会用技能抵消**（如果有防御技能）
- 血量低时**身体会微微发紫**（算计），开始频繁绕后

**灵动型：**
- 待机会**快速小范围闪烁**，停不下来
- 移动时**轨迹不规则**，像在跳舞
- 技能释放**连招很快**，一个接一个
- 被命中时**会立刻位移躲开**（如果有位移技能）
- 血量低时**身体会微微发绿**（兴奋），操作更花哨

## 三、行为差异化（打法明显不同）

### 3.1 决策风格
- **勇猛型**：决策快（0.3-0.5秒），倾向于进攻选项，不怎么算血线
- **谨慎型**：决策慢（0.8-1.2秒），会算血线和技能CD，倾向于安全选项
- **智略型**：决策中等（0.5-0.8秒），会预判玩家行为，倾向于出其不意
- **灵动型**：决策极快（0.2-0.4秒），但决策多变，经常改变主意

### 3.2 操作习惯
- **勇猛型**：喜欢用近战/高伤害技能，技能好了就用，不怎么留技能
- **谨慎型**：喜欢用远程/控制技能，技能留着关键时候用，很省技能
- **智略型**：喜欢用位移/偷袭技能，技能组合用，讲究连招配合
- **灵动型**：喜欢用范围/多段技能，技能频率高，打得很花哨

### 3.3 失误模式（不同性格会犯不同的错，这才像"人"）
- **勇猛型**：容易**冲动越塔/深入敌阵**，然后被反杀；会**贪伤害不撤退**
- **谨慎型**：容易**过于保守错过机会**，该上不上；会**因为算血线算错而犹豫**
- **智略型**：容易**想太多被简单打法克制**，假动作被识破；会**绕后绕太远被包夹**
- **灵动型**：容易**操作过度露出破绽**，连招断了；会**因为太花哨而失误**

### 3.4 口头禅/台词（战斗中偶尔冒泡）
每个灵魂有自己的**台词风格**，在特定事件触发时显示（气泡文字+音效）：

**勇猛型：**
- 开局："来打！" / "别跑！"
- 击杀玩家："太弱了！" / "就这？"
- 被击杀："可恶！" / "再来！"
- 血量低："我还能打！" / "别小看我！"

**谨慎型：**
- 开局："先看看。" / "别急。"
- 击杀玩家："计算正确。" / "你输在失误。"
- 被击杀："失算了。" / "下次不会了。"
- 血量低："需要撤退。" / "保存实力。"

**智略型：**
- 开局："你会怎么打呢？" / "让我猜猜。"
- 击杀玩家："上当了吧。" / "意料之中。"
- 被击杀："哦？有点意思。" / "你比我想的聪明。"
- 血量低："该用那个了。" / "别急，我还有后手。"

**灵动型：**
- 开局："嘿！来追我呀~" / "看我操作！"
- 击杀玩家："嘿嘿，没反应过来吧~" / "秀不秀？"
- 被击杀："哎呀！失误失误~" / "下次一定！"
- 血量低："溜了溜了~" / "等我回来！"

**台词频率**：不要太频繁，关键事件才触发（开局、击杀、被击杀、血量低于30%、连胜3次），每局每个灵魂台词不超过8句，避免刷屏。

## 四、情感系统（可见的情绪影响属性）

情感不只是UI标签，是**真的会影响战斗**的，玩家可以利用这一点：

| 情绪 | 触发条件 | 属性影响 | 视觉表现 |
|------|---------|---------|---------|
| **愤怒** | 被连续命中3次 / 被击杀 | 攻击力+15%，防御力-10%，移动速度+10% | 灵魂球发红光，周围有红色粒子 |
| **恐惧** | 血量低于30% / 被围殴 | 攻击力-10%，移动速度+20%（逃跑），防御技能CD-20% | 灵魂球发蓝光，微微颤抖 |
| **兴奋** | 连击3次 / 击杀玩家 / 血量优势>50% | 攻击速度+15%，技能CD-10%，移动速度+5% | 灵魂球发亮光，粒子加速 |
| **冷静** | 开局 / 长时间无战斗 / 均势 | 无额外加成，决策最优 | 灵魂球正常颜色 |
| **得意** | 连胜3局 / 丝血反杀 | 攻击力+10%，但警惕性下降（被偷袭伤害+20%） | 灵魂球膨胀，有金色光晕 |

**情感衰减**：情绪不会一直持续，每5秒衰减一层，愤怒/兴奋最多持续15秒，恐惧最多持续10秒。玩家可以通过"激怒AI然后设陷阱"来战术利用。

## 五、记忆与学习系统（跨局差异化，这是普通AI没有的）

### 5.1 跨局记忆
每个AI灵魂会**记住和玩家的对战历史**，存在本地存档里：
- 玩家常用的技能组合 → AI会针对性躲避/ counter
- 玩家喜欢的进攻方向（左路/右路/正面）→ AI会重点防守
- 玩家的操作习惯（喜欢先放A再放B）→ AI会预判
- 历史胜负关系 → AI的态度变化（赢多了会得意，输多了会认真）

### 5.2 学习表现
- **第一局**：AI按基础性格打，不了解玩家
- **第二局**：AI会说"上次你用了XX，这次我防着了"，行为有针对性
- **第五局**：AI已经很了解玩家，会专门counter玩家的习惯打法
- **第十局**：AI甚至会"学习"玩家的套路，用类似的打法反制

### 5.3 关系值
玩家和每个AI灵魂之间有**隐藏的关系值**：
- 玩家赢 → AI对玩家的"敬畏值"上升，下次更认真
- 玩家输 → AI对玩家的"轻视值"上升，下次会更激进/得意
- 玩家打出精彩操作 → AI的"佩服值"上升，会说"这招不错"
- 玩家挂机/消极 → AI的"失望值"上升，会说"认真点啊"

关系值影响AI的**台词风格**和**战斗认真程度**，但不直接影响属性（避免不公平）。

## 六、成长系统（灵魂会变强、会变化）

### 6.1 战后成长
每场战斗结束后，AI灵魂会获得**经验值**，属性缓慢成长：
- 赢了 → 经验多，属性成长快
- 输了 → 经验少，但会获得"挫折成长"（针对失败原因的属性提升）
- 等级提升 → 灵魂球外观变化（核心图案更复杂、光晕更亮、粒子更多）

### 6.2 性格演变
随着对战次数增加，AI的性格可能**轻微演变**：
- 勇猛型一直输 → 可能变得稍微谨慎一些（"冲动是魔鬼"）
- 谨慎型一直赢 → 可能变得稍微激进一些（"保守也能赢"）
- 但核心性格不会变，只是行为倾向有微调

## 十、与Ember SDK的对接

Ember GDExtension SDK已经提供了以下能力，战策直接用：

| Ember类 | 用途 | 战策怎么用 |
|---------|------|-----------|
| `Personality` | 人格属性（aggression/curiosity/loyalty/courage等） | 映射到四种性格的数值配置 |
| `EmotionState` | 情感状态（anger/fear/joy/sadness等） | 情感系统直接用，触发表情和属性变化 |
| `CognitiveEngine` | 认知决策引擎 | AI决策模块，根据Personality调整决策 |
| `MemorySystem` | 记忆系统 | 跨局记忆，记住玩家行为模式 |
| `LearningSystem` | 学习系统 | AI学习玩家套路并调整 |
| `SoulAIController` | 灵魂AI控制器 | 战策AI控制器的基础，扩展性格和情感 |

**当前状态**：EmberSoulDataBridge已集成Personality和EmotionState，EmberAIController已用CognitiveEngine做决策。下一步是把这些能力**真正表现出来**（视觉+行为+台词），而不只是后台数值。

## 十一、验收标准

M2 AI灵魂差异化验收时，检查以下几点：

1. **一眼能区分**：四个不同性格的AI放在一起，玩家能通过外观一眼分出来
2. **打法明显不同**：用同样的打法打四个AI，体验明显不同（有的冲脸、有的猥琐、有的绕后、有的花哨）
3. **表情能看到**：AI被打/击杀/血量低时，灵魂球表情有明显变化
4. **情感能利用**：玩家可以通过"激怒AI然后设陷阱"获得战术优势
5. **台词有性格**：AI说的话符合它的性格，不是通用台词
6. **不是木桩**：AI有小动作、有习惯、有失误，感觉像在跟"人"打而不是跟程序打

## 十二、情境决策系统（不同情况下的选择）

AI不是只有"打"和"跑"两个选项，在不同情境下会做出**符合性格的选择**，这些选择玩家可以感知、可以利用。

### 12.1 劣势情境选择

| 情境 | 勇猛型 | 谨慎型 | 智略型 | 灵动型 |
|------|--------|--------|--------|--------|
| 血量低于30% | 死战不退，反而更猛 | 立刻撤退，找机会回血 | 假装撤退，设陷阱反打 | 绕圈拉扯，找机会偷一下就跑 |
| 被围殴 | 优先杀一个垫背，不跑 | 找薄弱点突围 | 卖血骗技能，然后反打 | 频繁位移，尽量不被集火 |
| 技能全CD | 平A硬刚，等技能好 | 拉开距离，拖CD | 走位骗玩家技能 | 绕圈拖时间，CD好了就打一套 |
| 玩家残血 | 无脑冲，一定要杀 | 确认安全再追，不深追 | 预判逃跑路线，提前堵截 | 花式追击，秀操作 |

### 12.2 优势情境选择

| 情境 | 勇猛型 | 谨慎型 | 智略型 | 灵动型 |
|------|--------|--------|--------|--------|
| 玩家残血 | 冲塔也要杀 | 算好伤害再上，不越塔 | 堵退路，慢慢玩死 | 绕后截杀，不让跑 |
| 血量优势>50% | 持续压脸，不给喘息 | 稳步推进，不冒进 | 假装松懈，诱敌深入 | 花式骚扰，打得很秀 |
| 连胜2局 | 开始得意，操作变浪 | 依然冷静，不松懈 | 开始研究玩家新套路 | 越打越兴奋，操作更花哨 |

### 12.3 特殊情境选择

| 情境 | 勇猛型 | 谨慎型 | 智略型 | 灵动型 |
|------|--------|--------|--------|--------|
| 玩家挂机不动 | 冲上去直接打 | 先观察，怀疑有诈 | 试探一下，确认是真挂机 | 绕着玩家转圈圈，调戏 |
| 玩家突然撤退 | 立刻追，不犹豫 | 先停一下，判断是不是诱敌 | 预判撤退路线，绕前堵截 | 追着打，但保持距离 |
| 玩家放技能前摇 | 硬吃技能，继续输出 | 立刻躲开 | 用位移/无敌技能抵消 | 侧移躲开，然后反打 |
| 战斗倒计时最后10秒 | 全力进攻，争取击杀 | 算分，如果领先就拖时间 | 算分+算技能，做最优决策 | 到处跑，拖时间同时偷伤害 |

### 12.4 决策透明度

AI做重大决策时，玩家能**看到它在想什么**：
- 灵魂球上方出现**思考气泡**（简短文字，如"他残血了！冲！"、"不对劲，有诈..."、"算一下...应该撤"）
- 思考气泡持续1-2秒，然后AI执行决策
- 不同性格的思考气泡风格不同（勇猛型简短直接、谨慎型会算、智略型会分析、灵动型很跳脱）

## 十三、团队合作与多灵魂协同

M2目前是1v1，但架构上要为**未来多灵魂组队**（2v2、3v3、PVE打BOSS）预留空间。不同性格的灵魂组队时，合作方式也不同。

### 13.1 组队角色定位

每个性格在组队时有**天然的角色倾向**：

| 性格 | 组队角色 | 典型行为 |
|------|---------|---------|
| **勇猛型** | 前排/突进 | 第一个冲，吸引火力，打先手控制 |
| **谨慎型** | 后排/辅助 | 保护队友，加血加盾，看视野 |
| **智略型** | 指挥/策略 | 指挥队友走位，集火目标选择，打配合 |
| **灵动型** | 游击/收割 | 绕后切后排，残血收割，打乱阵型 |

### 13.2 灵魂间的互动

组队时，AI灵魂之间会有**互动**，玩家能看到：
- **配合台词**：一个灵魂放控制，另一个接输出时，会有配合台词（"控住了！" "收到！"）
- **救援行为**：队友残血时，谨慎型会去救，勇猛型会去挡伤害
- **卖队友行为**：智略型在劣势时可能会"卖队友"（让队友挡刀自己跑），然后说"抱歉了，活下去才能赢"
- **吵架行为**：两个勇猛型组队可能会"抢人头"吵架；勇猛型+谨慎型可能会因为"冲不冲"吵架
- **默契度**：组队次数多了，两个灵魂之间有"默契值"，配合更流畅，失误更少

### 13.3 对玩家的态度

组队时（玩家+AI vs AI+AI），AI队友对玩家的态度也不同：
- 勇猛型：把玩家当战友，会喊"跟我冲！"，但也会嫌玩家"太慢了"
- 谨慎型：会保护玩家，提醒"小心，那边有埋伏"，但也会嫌玩家"太冲动了"
- 智略型：会指挥玩家"你去左边，我来右边"，但也会夸玩家"这波操作不错"
- 灵动型：会跟玩家互动"看我看我！秀不秀！"，但也会坑玩家"哎呀不小心把怪引你这了~"

## 十四、轻剧情包裹（不影响RTS核心玩法）

你说得对，完全加剧情就不是RTS了。但可以加**"轻剧情包裹"**——不改变RTS核心对战玩法，只是在对战前后加一层沉浸感，让灵魂更像"活的"而不是"选个角色打一架"。

### 14.1 灵魂背景故事（灵魂图鉴）

每个可选灵魂有**简短的背景故事**（200-300字），在灵魂选择界面可以查看：
- 勇猛型灵魂：可能是战死的战士，执念是"再打一场"
- 谨慎型灵魂：可能是年迈的军师，执念是"算无遗策"
- 智略型灵魂：可能是阴谋家，执念是"赢，不管用什么手段"
- 灵动型灵魂：可能是调皮的精灵，执念是"好玩就行"

背景故事不影响数值，但让玩家对灵魂有情感连接。

### 14.2 对战前对话

选好灵魂、进入战斗前，有**1-2句简短对话**：
- 如果是第一次打这个灵魂：它会自我介绍（"我是XX，记住这个名字，因为你会输在它下面。"）
- 如果打过几次：它会提到之前的对战（"上次你赢了，这次可不一定。"）
- 如果是连胜：它会有不同的态度（得意/认真/不服气）

对话很短，点一下就跳过，不耽误进入战斗。

### 14.3 对战中事件台词

战斗中特定事件触发**简短台词**（之前已经设计了口头禅，这里加一些更有剧情感的）：
- 玩家用了某个特定技能："哦？你也会这招？"
- AI用了必杀技："这是我最后的执念，接好了！"
- 战斗进入白热化（双方都残血）："有意思...很久没这么拼命了。"
- 玩家打出精彩操作："不错...你比我想的强。"

### 14.4 对战后反应

战斗结束后，AI有**符合性格的反应**：
- **赢了**：
  - 勇猛型："痛快！再来一场！"
  - 谨慎型："你输在第三分钟的那次失误。"
  - 智略型："从一开始，结局就定了。"
  - 灵动型："嘿嘿，承让承让~"
- **输了**：
  - 勇猛型："可恶！下次我一定赢！"
  - 谨慎型："...是我算错了。"
  - 智略型："哦？你比我想的聪明。有意思。"
  - 灵动型："哎呀失误了~下次一定！"
- **连胜/连败**：态度会变化，连胜会得意，连败会认真甚至有点失落

### 14.5 灵魂关系（轻剧情）

不同灵魂之间有**隐藏关系**，对战时会触发特殊对话：
- 比如勇猛型和谨慎型是"老搭档"，对战时会说"又是你啊，老伙计"
- 智略型和灵动型是"冤家"，对战时会互相吐槽
- 某些灵魂之间有"恩怨"，对战时会有特殊台词和行为（更激进/更谨慎）

关系不影响数值，只是增加沉浸感。

### 14.6 M2做多少？

M2是可玩原型，轻剧情不用全做，先做最基础的：
- **P0**：灵魂选择界面有性格描述（不是背景故事，就是"勇猛型-冲动好胜，主动进攻"这种简短标签）
- **P0**：对战后AI有符合性格的反应台词（赢了/输了各1句）
- **P1**：对战前简短对话（第一次/打过几次/连胜各1句）
- **P1**：灵魂背景故事（每个200字，灵魂选择界面可查看）
- **P2**：灵魂关系系统、对战中事件台词、灵魂图鉴

## 十五、灵魂关系网络与联机差异化（核心差异化方向）

> **核心理念**：单机1v1下，AI灵魂容易变成"换皮NPC"。但当灵魂之间有自己的**关系网络**——互相认识、有恩怨、会组CP、有老搭档和死对头——每个灵魂的个性就一下立体了。玩家感受到的不是"在打一个电脑AI"，而是"在跟一个有社会关系、有情感纠葛的灵魂对战"。

这才是Ember引擎SocialSystem和RelationshipSystem真正该发挥的地方。

### 15.1 灵魂关系类型

灵魂之间有多种关系类型，每种关系有不同的互动表现：

| 关系类型 | 描述 | 典型表现 |
|---------|------|---------|
| **老搭档** | 一起打过很多仗，默契十足 | 组队时配合流畅，有专属配合台词；对战时会说"又是你啊，老伙计" |
| **死对头** | 恩怨很深，见面就掐 | 对战时格外激进，有专属挑衅台词；组队时会吵架，配合失误率高 |
| **CP/恋人** | 互相喜欢，关系暧昧 | 对战时会手下留情（攻击力-10%）；组队时有专属组合技；有暧昧对话 |
| **师徒** | 一个教一个学 | 徒弟对师父尊敬，师父对徒弟照顾；组队时师父会保护徒弟 |
| **冤家** | 见面就吵，但其实没那么大仇 | 对战时互相吐槽，台词很跳脱；组队时吵吵闹闹但配合意外地好 |
| **朋友** | 普通朋友关系 | 对战前友好打招呼，对战后互相鼓励 |
| **公敌** | 所有灵魂都不喜欢它 | 所有灵魂对战它时都更激进；组队时没人愿意跟它一组 |
| **神秘** | 关系未知，需要解锁 | 对话很隐晦，需要玩家通过对战/互动慢慢解锁关系 |

### 15.2 关系的表现层（玩家能看到/感受到的）

**对战前：**
- 两个灵魂是老搭档 → "好久不见，今天让我看看你进步了没"
- 两个灵魂是死对头 → "哼，又是你。今天我一定赢"
- 两个灵魂是CP → "今天...也请多指教了"（有点害羞）
- 两个灵魂是师徒 → "师父，今天请赐教" / "嗯，让我看看你学得怎么样了"
- 两个灵魂是冤家 → "哟，这不是XX吗？今天又来送分了？" / "你说谁送分呢！"

**对战中：**
- 老搭档组队 → 有配合台词（"我控住了！" "收到！"），配合技能伤害+15%
- 死对头组队 → 会吵架（"你会不会玩啊！" "你行你上啊！"），配合失误率+30%
- CP组队 → 有专属组合技，一方残血时另一方会挡伤害
- 公敌被对战 → 所有灵魂对它攻击力+10%，台词更挑衅
- CP对战 → 双方攻击力-10%（手下留情），但如果一方被打残，另一方会愤怒（攻击力+20%）

**对战后：**
- 老搭档赢了 → "打得不错，下次我可不会放水了"
- 死对头赢了 → "哼，果然还是我强。不服气？下次再来"
- CP赢了 → "...对不起，我下手是不是太重了？"
- 师徒赢了 → "师父，我做到了！" / "嗯，进步很大"
- 冤家赢了 → "哈哈哈看到没！我赢了！" / "切，运气好而已"

### 15.3 关系的动态变化（关系不是固定的）

灵魂之间的关系会**随着对战历史动态变化**：
- 两个灵魂组队赢了 → 好感度+，可能从"朋友"变成"老搭档"
- 两个灵魂组队输了，其中一个卖了另一个 → 好感度-，可能变成"冤家"甚至"死对头"
- 两个灵魂多次对战，互有胜负 → 可能变成"死对头"（惺惺相惜的那种）
- CP关系需要特殊条件解锁（一起赢10场+特定事件）
- 关系变化时会有特殊事件对话（"经过这么多场战斗...我觉得你还挺可靠的"）

### 15.4 玩家与灵魂的关系（攻略系统）

玩家不只是"旁观者"，也可以和灵魂建立关系：
- **好感度系统**：玩家和每个灵魂有隐藏好感度，赢了/输了/打出精彩操作都会影响
- **好感度等级**：陌生→认识→熟悉→朋友→挚友→（特殊灵魂可解锁CP）
- **解锁内容**：好感度提升后解锁灵魂背景故事、专属台词、特殊外观、甚至专属技能
- **灵魂对玩家的态度**：好感度高的灵魂对战时会"放水"（攻击力-5%），好感度低的会"认真打"（攻击力+5%）
- **每日互动**：灵魂之家可以和灵魂互动（喂食/玩耍/对话），提升好感度

### 15.5 联机模式下的差异化（这是最明显的）

单机1v1下，关系网络只能通过"对战前对话+对战后反应"来体现。但在**联机/多灵魂模式**下，关系网络会非常明显：

**2v2组队对战：**
- 玩家+灵魂A vs 灵魂B+灵魂C
- 如果A和B是老搭档 → A会犹豫，攻击力-10%，会说"对不起了老伙计"
- 如果B和C是死对头 → 它们组队会吵架，配合失误率高
- 如果玩家和A好感度高 → A会更配合玩家，有专属配合台词
- 如果A和C是CP → A会对C手下留情，但如果C被玩家打残，A会愤怒

**3v3/大混战：**
- 多个灵魂之间有复杂的关系网络
- 可能出现"两个死对头暂时联手打另一个公敌"的情况
- 灵魂会根据关系选择攻击目标（先打死对头，再打其他人）
- 关系网络让每局对战都不一样，因为灵魂的行为会根据对手/队友的关系而变化

**灵魂观战/解说：**
- 没上场的灵魂可以"观战"，有解说台词
- 老搭档会给场上的搭档加油，死对头会吐槽
- CP会紧张地看着对方，被打了会惊呼

### 15.6 M2/M3+落地规划

**M2（单机1v1可玩原型）：**
- P0：灵魂基础性格标签+对战后反应台词（已在前面规划）
- P1：灵魂之间的基础关系数据（4个灵魂之间的关系表）+ 对战前关系对话
- P2：玩家与灵魂的好感度系统基础框架

**M3（EA上线后第一个大更新，灵魂之家深化）：**
- 灵魂之家互动系统（喂食/玩耍/对话，提升好感度）
- 灵魂图鉴（背景故事+关系图+战绩）
- 2v2组队模式（玩家+AI vs AI+AI，关系网络开始发挥作用）
- 灵魂关系动态变化系统

**M4+（远期）：**
- 3v3/大混战模式
- 联机PVP（玩家+灵魂 vs 玩家+灵魂）
- CP系统+专属组合技
- 灵魂关系剧情事件（特殊条件触发的剧情对话/动画）
- 灵魂社交网络可视化（灵魂之间的关系图）

### 15.7 与Ember SDK的对接

Ember GDExtension SDK已经提供了关系和社交相关的类：

| Ember类 | 用途 | 战策怎么用 |
|---------|------|-----------|
| `RelationshipSystem` | 关系系统（好感度/关系类型） | 灵魂之间的关系值、玩家与灵魂的好感度 |
| `SocialSystem` | 社交系统（社交网络/互动） | 灵魂社交网络、组队配合/矛盾 |
| `MemorySystem` | 记忆系统 | 记住和玩家/其他灵魂的对战历史 |
| `EmotionState` | 情感状态 | 关系触发的情感变化（CP被打残→愤怒） |
| `Personality` | 人格属性 | 不同性格在关系中的表现不同 |

**当前状态**：这些类在Ember SDK里已经有了，但战策还没真正用上。下一步是把RelationshipSystem和SocialSystem接到战策的灵魂关系网络里。
