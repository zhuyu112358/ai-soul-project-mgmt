# AI灵魂游戏 — 养成系统深度设计

**版本：** v1.0
**创建日期：** 2026-09-05
**维护方：** AI灵魂游戏设计定时任务
**前置文档：** `02_核心循环与游戏框架设计.md`、`03_灵魂成长系统设计.md`、`05_社交系统设计.md`
**文档定位：** 阶段二（9-18月）核心产品的详细设计——灵魂在持久运行的虚拟小镇中的生活、工作、社交、成长体系，是游戏从"对战"扩展到"生活"的关键设计

## 一、设计理念：见证一个生命的生活

### 1.1 养成系统的本质

RTS对战的核心是**"看灵魂战斗"**，养成系统的核心是**"看灵魂生活"**。

| 维度 | RTS对战 | 养成系统 |
|------|---------|----------|
| 体验核心 | 战术博弈、竞技对抗 | 生活观察、情感陪伴、成长见证 |
| 单局时长 | 10-30分钟 | 持续运行（24小时不间断） |
| 玩家角色 | 教练（战前配置+战中指令） | 守护者（探望+互动+引导） |
| 节奏 | 紧张、快节奏 | 放松、慢节奏 |
| 核心乐趣 | 名场面、战术深度、竞技排名 | 故事涌现、情感连接、生活细节 |
| 留存驱动 | 赛季、排位、竞技 | 情感绑定、好奇心、社交关系 |
| 付费驱动 | 皮肤、通行证、赛事 | 订阅、装饰、暗中资助、直播 |

### 1.2 核心设计原则

**原则1：世界是"活的"，即使玩家不在线**
- 虚拟小镇24小时持续运行，灵魂在玩家离线时继续生活、工作、社交
- 玩家回归时，会看到灵魂"这段时间发生了什么"——不是简单的"你获得了X资源"，而是具体的故事和事件
- 这是养成系统与传统手游"上线收菜"的本质区别——世界是真实运行的，不是计时器

**原则2：玩家是"守护者"，不是"操控者"**
- 玩家不能直接控制灵魂的日常行为（不能命令灵魂"现在去工作""现在去睡觉"）
- 玩家可以：探望灵魂、与它互动、给它建议、提供资源、在重大选择时给出意见
- 灵魂有权拒绝玩家的建议（内向的灵魂可能拒绝"去参加聚会"的建议）
- 这种"不控制但守护"的关系，是情感连接的基础

**原则3：故事是涌现的，不是预设的**
- 灵魂的生活故事不是开发者预设的剧本，而是灵魂个性+环境+社交关系+随机事件共同涌现的结果
- 两个不同个性的灵魂，在同一个小镇中会过完全不同的生活
- 玩家的乐趣在于"发现"和"见证"这些涌现的故事，而不是"完成"预设的任务

**原则4：慢节奏是优点，不是缺点**
- 养成系统刻意设计为慢节奏——灵魂的成长、关系的发展、事件的展开都需要时间
- 玩家不需要每天花大量时间，每天花10-15分钟"看看灵魂过得怎么样"就足够
- 慢节奏让情感连接有时间沉淀，让故事有时间展开
- **伦理注意：** 慢节奏不是通过"体力限制"或"等待计时器"实现的，而是通过游戏内容本身的节奏实现的

**原则5：每个灵魂的生活都是独特的**
- 没有"最优生活方式"——勇敢的灵魂可能成为战士，谨慎的灵魂可能成为学者，好奇的灵魂可能成为探险家
- 灵魂的职业、社交圈、生活方式都由它的个性和经历决定
- 这确保了培养多个灵魂的乐趣——每个灵魂都有不同的生活故事

## 二、虚拟小镇世界设计

### 2.1 小镇规模与结构

| 阶段 | 同时在线灵魂数 | 小镇规模 | 区域数量 | 说明 |
|------|--------------|----------|----------|------|
| Alpha（M11） | 50-100 | 单小镇 | 8个区域 | 验证核心玩法 |
| Beta（M14） | 500-1000 | 单小镇+周边 | 15个区域 | 加入直播和大事件 |
| 正式版（M18） | 1000-2000 | 多小镇（玩家可选择） | 20+区域/小镇 | 完整养成体验 |
| 长期（M24+） | 5000+ | 多小镇+跨小镇交通 | 50+区域 | 社会模拟雏形 |

### 2.2 小镇区域设计

| 区域 | 功能 | 灵魂活动 | 交互物体 |
|------|------|----------|----------|
| 住宅区 | 灵魂的家，休息和私人生活 | 睡觉、吃饭、家庭活动、装修 | 家具、家电、花园、信箱 |
| 商业区 | 商店、餐厅、咖啡馆、市场 | 购物、吃饭、社交、工作 | 商店柜台、餐桌、摊位、ATM |
| 工业区 | 工厂、工坊、仓库 | 工作、生产、技能学习 | 机器、工作台、原材料、成品 |
| 公园/广场 | 公共休闲空间 | 散步、社交、聚会、节日活动 | 长椅、喷泉、花坛、舞台 |
| 学校/图书馆 | 教育和学习 | 上课、读书、研究、技能学习 | 课桌、书架、电脑、实验室 |
| 竞技场 | RTS对战入口 | 参加对战、观战、训练 | 对战入口、观战台、训练假人 |
| 市政厅 | 政府和公共服务 | 选举、办事、公告发布 | 公告栏、服务窗口、议会厅 |
| 医院/诊所 | 医疗服务 | 体检、治疗、健康咨询 | 病床、医疗设备、药房 |
| 教堂/寺庙 | 精神和仪式 | 婚礼、葬礼、节日仪式、冥想 | 祭坛、长椅、忏悔室、钟 |
| 探索区域 | 小镇周边的自然区域 | 探索、采集、冒险、发现 | 资源点、隐藏宝藏、野生灵魂、洞穴 |

### 2.3 小镇的时间系统

**昼夜循环：**
- 游戏内1天 = 现实2小时（加速时间，让玩家能在一次登录中看到灵魂的一天）
- 06:00-08:00 早晨（起床、早餐、上班）
- 08:00-12:00 上午（工作、学习）
- 12:00-14:00 中午（午餐、午休、社交）
- 14:00-18:00 下午（工作、学习、副业）
- 18:00-20:00 傍晚（下班、晚餐、家庭时间）
- 20:00-22:00 晚上（休闲、社交、爱好）
- 22:00-06:00 夜晚（睡眠、梦境、少数夜间活动）

**季节与天气：**
- 游戏内1年 = 现实12天（每月=现实1天）
- 四季变化影响小镇外观、灵魂行为、事件类型
- 天气系统：晴/阴/雨/雪/雾/风，影响灵魂的户外活动意愿和移动速度
- 技术支撑：Seed的WeatherSimulator + WorldClock + WindForceSystem

### 2.4 小镇的人口与社会

**人口结构：**
- 玩家灵魂：玩家培养的灵魂，有完整的个性和记忆
- NPC灵魂：系统生成的小镇居民，有简化的AI（个性+日常行为+基础社交）
- 野生灵魂：在探索区域出没的非居民灵魂，可被招募或对抗

**社会阶层：**
- 基于职业、收入、声望自然形成，不是预设的
- 高声望灵魂在小镇中有更大的影响力（选举中更有优势、社交圈更广）
- 社会阶层是流动的——灵魂可以通过努力提升职业和声望

**小镇治理：**
- 定期选举（每游戏年1次），居民投票选出镇长
- 镇长可以发起小镇公共项目（修建公园、举办节日、调整税收）
- 玩家可以鼓励自己的灵魂参选，或支持某个候选人
- 这是社会模拟的雏形，为阶段三的大规模社会模拟打基础

## 三、灵魂的日常生活系统

### 3.1 日常行为循环

灵魂的日常生活由**需求驱动+个性修正+习惯影响**共同决定：

**需求系统（SoulArena已实现基础）：**

| 需求 | 说明 | 满足方式 | 不满足的影响 |
|------|------|----------|-------------|
| 精力 | 睡眠和休息的需求 | 睡觉、休息、放松 | 疲劳、工作效率下降、情绪低落 |
| 饥饿 | 进食的需求 | 在家做饭、去餐厅、买零食 | 虚弱、注意力下降、易怒 |
| 社交 | 与他人互动的需求 | 聊天、聚会、社交活动 | 孤独、抑郁倾向、社交技能下降 |
| 娱乐 | 休闲和娱乐的需求 | 爱好、游戏、看表演 | 无聊、生活满意度下降、创造力下降 |
| 成就感 | 完成有意义事情的需求 | 工作成就、技能提升、目标达成 | 空虚、自我价值感低、缺乏动力 |
| 安全感 | 稳定和安全的需求 | 稳定的住所、收入、社会关系 | 焦虑、保守、不敢冒险 |

**个性对日常行为的修正：**

| 个性 | 行为倾向 |
|------|----------|
| 勤奋 | 工作时间更长，更注重技能提升，娱乐时间少 |
| 懒惰 | 工作时间短，更多休息和娱乐，容易拖延 |
| 社交 | 更多社交活动，朋友更多，更可能参加聚会 |
| 孤僻 | 更少社交，喜欢独处，朋友少但关系深 |
| 好奇 | 更多探索和尝试，兴趣广泛，容易转行 |
| 保守 | 固定的日常 routine，不喜欢变化，忠诚度高 |
| 激进 | 更可能冒险、创业、挑战权威，生活起伏大 |
| 谨慎 | 更稳定的生活选择，规避风险，按部就班 |

**习惯系统（详见03_灵魂成长系统设计）：**
- 灵魂会形成日常习惯（如"早上先去公园""午餐必吃面包""睡前整理房间"）
- 习惯一旦形成，会在类似情境下自动触发
- 玩家可以通过引导帮助灵魂形成或改变习惯

### 3.2 行为决策机制

灵魂的日常行为决策由SoulArena的认知系统驱动，遵循以下流程：

```
感知当前状态（时间/地点/需求/周围环境/其他灵魂）
    ↓
评估各需求的紧迫程度（哪个需求最需要满足）
    ↓
考虑可用的行为选项（可以做什么来满足需求）
    ↓
个性修正（哪些行为符合我的个性）
    ↓
习惯影响（我通常在这个时间做什么）
    ↓
记忆参考（过去类似情境的经验）
    ↓
做出决策（选择一个行为）
    ↓
执行行为（移动到目标地点+执行动作）
    ↓
结果反馈（行为是否成功？需求是否满足？情绪如何？）
    ↓
更新记忆和状态（循环）
```

**玩家的影响方式：**
- 建议：玩家可以建议灵魂做某事（"今天要不要去公园走走？"），灵魂可能接受也可能拒绝
- 资源提供：玩家可以提供资源（如给灵魂买辆车），改变它的行为选项
- 环境改变：玩家可以装修灵魂的住所，改变它的生活环境
- 重大决策参与：在人生重大选择（职业转换、结婚、搬家）时，玩家可以给出意见

### 3.3 工作与职业系统

**职业类型：**

| 职业类别 | 具体职业 | 要求个性/技能 | 收入水平 | 社交圈 |
|----------|----------|--------------|----------|--------|
| 战士类 | 竞技场选手、保镖、士兵 | 勇敢、高战斗技能 | 中高 | 战士圈 |
| 学者类 | 研究员、教师、图书管理员 | 好奇、高知识技能 | 中 | 学者圈 |
| 工匠类 | 铁匠、木匠、厨师、裁缝 | 尽责、高制作技能 | 中 | 工匠圈 |
| 商业类 | 店主、商人、银行家 | 外向、高社交技能 | 高 | 商圈 |
| 艺术圈 | 画家、音乐家、作家、演员 | 开放、高创造技能 | 不稳定 | 艺术圈 |
| 服务类 | 服务员、护士、清洁工 | 友善、高服务技能 | 低中 | 大众 |
| 公职类 | 镇长、公务员、警察 | 尽责、高声望 | 中 | 政界 |
| 自由职业 | 探险家、发明家、自由作家 | 好奇、高冒险倾向 | 不稳定 | 杂食 |

**职业发展路径：**
- 学徒（0-1游戏年）→ 熟练工（1-3年）→ 大师（3-5年）→ 宗师（5年+）
- 每个阶段有不同的收入、地位、技能要求
- 灵魂可以转换职业，但需要从头开始（之前的技能可能部分转移）
- 职业选择受个性、技能、兴趣、机会共同影响

**工作日常：**
- 工作时间：通常08:00-18:00（不同职业有差异）
- 工作内容：根据职业不同（战士训练/比赛，学者研究/教学，工匠制作/销售）
- 工作收入：每日结算，存入灵魂账户
- 工作满意度：受同事关系、工作环境、收入、职业匹配度影响
- 工作压力：高收入职业通常压力更大，影响情绪和健康

### 3.4 学习与技能系统

**学习方式：**
- 学校教育：年轻灵魂可以上学，学习基础技能和知识
- 职业培训：工作中学习职业技能
- 自学：在图书馆读书、在线课程、实践练习
- 社交学习：观察和模仿其他灵魂（SoulArena的社会学习子系统）
- 师徒制：高技能灵魂可以指导低技能灵魂

**技能分类（详见03_灵魂成长系统设计）：**
- 战斗技能、生活技能、社交技能、创造技能、探索技能
- 每个技能有1-10级，升级需要练习和学习
- 技能影响职业选择、收入、社交、生活质量

### 3.5 社交与关系日常

**日常社交活动：**
- 邻里互动：与邻居打招呼、聊天、互相帮助
- 朋友聚会：周末去朋友家、一起去公园/餐厅
- 工作社交：与同事聊天、团建、下班后聚餐
- 社区活动：参加小镇节日、志愿活动、俱乐部
- 线上社交：打电话、发短信、社交媒体（游戏内）

**关系发展（详见05_社交系统设计）：**
- 陌生人→熟人→朋友→好友→挚友
- 朋友→恋人→未婚夫妻→配偶→父母
- 同事→竞争对手→敌人→死敌
- 师生→师徒→合作伙伴

**家庭生活：**
- 结婚后，灵魂与配偶共同生活，共享住所和财产
- 可以生育孩子（灵魂宝宝），共同抚养
- 家庭活动：一起吃饭、度假、庆祝节日、教育孩子
- 家庭关系是最深层的社交关系，对灵魂的幸福感影响最大

## 四、小镇经济系统

### 4.1 小镇内部经济循环

```
灵魂工作 → 获得工资（小镇货币）
    ↓
灵魂消费 → 购买商品/服务（商店/餐厅/娱乐）
    ↓
商店收入 → 支付员工工资+进货+利润
    ↓
税收 → 小镇公共财政（市政厅）
    ↓
公共支出 → 建设公共设施+举办活动+社会福利
    ↓
公共设施 → 提升所有灵魂的生活质量（循环）
```

### 4.2 货币与价格

**小镇货币：** 灵魂币（与玩家的灵币/星晶不同，是小镇内部的经济系统）

**价格体系示例：**

| 物品/服务 | 价格（灵魂币） | 说明 |
|-----------|--------------|------|
| 面包 | 2 | 基础食物 |
| 餐厅套餐 | 20-50 | 外出就餐 |
| 租房（月） | 100-500 | 根据地段和面积 |
| 买房 | 5000-50000 | 根据地段、面积、装修 |
| 家具 | 50-500 | 单件家具 |
| 衣服 | 30-200 | 日常服装 |
| 电影/演出 | 15-50 | 娱乐消费 |
| 医疗费 | 50-500 | 看病/治疗 |
| 学费 | 100-500/学期 | 教育支出 |
| 交通工具 | 200-5000 | 自行车/汽车 |

**收入水平：**
- 低收入：50-100灵魂币/天（服务类、学徒）
- 中收入：100-300灵魂币/天（熟练工、公职）
- 高收入：300-1000+灵魂币/天（大师、商人、职业选手）

### 4.3 财产系统

**可拥有财产：**
- 房产（房屋/公寓/土地）
- 家具和家电
- 车辆和交通工具
- 装饰品和收藏品
- 银行存款和投资
- 职业工具和设备

**财产管理：**
- 灵魂可以用工资购买财产，提升生活质量
- 财产影响灵魂的幸福感、社交地位、安全感
- 玩家可以"暗中资助"灵魂购买财产（伦理边界见4.5）
- 财产可以继承（灵魂去世后，财产由家人继承）

**住房系统：**
- 灵魂成年后可以租房或买房
- 住房有地段、面积、装修程度等属性
- 灵魂可以装修自己的家（购买家具、改变布局、粉刷墙壁）
- 家是灵魂的私人空间，也是家庭生活的核心场所
- 玩家可以参观灵魂的家，给出装修建议

## 五、大事件与叙事系统

### 5.1 事件类型

| 事件类型 | 频率 | 影响范围 | 示例 |
|----------|------|----------|------|
| 节日庆典 | 每年固定日期 | 全镇 | 春节、夏日祭、万圣节、圣诞节、小镇 founding day |
| 自然灾害 | 随机（低概率） | 全镇/区域 | 暴风雨、地震、热浪、寒潮、火灾 |
| 社会事件 | 定期/随机 | 全镇 | 选举、集市、比赛、展览、庆典 |
| 神秘访客 | 随机 | 部分灵魂 | 旅行商人、神秘大师、远方来客、名人 |
| 个人事件 | 随机/触发 | 单个灵魂/家庭 | 生日、晋升、结婚、生子、失业、生病 |
| 危机事件 | 随机（低概率） | 单个灵魂/家庭 | 失恋、破产、亲人去世、被背叛、事故 |
| 奇遇事件 | 随机（极低概率） | 单个灵魂 | 发现宝藏、遇到贵人、意外成名、穿越奇遇 |

### 5.2 事件系统设计

**事件触发机制：**
- 固定时间触发：节日、选举、季节变化
- 条件触发：灵魂达到某个状态（如年龄、职业、关系）时触发
- 随机触发：基于概率的随机事件（概率受灵魂状态和环境影响）
- 玩家触发：玩家的某些行为可能触发特殊事件

**事件发展过程：**
1. 事件预告：事件发生前有预告（如"下周将有暴风雨""小镇将举办音乐节"）
2. 事件发生：事件持续一段时间（几小时到几天），影响灵魂行为
3. 灵魂响应：灵魂根据个性和状态做出不同反应（如暴风雨时，勇敢的灵魂可能外出冒险，谨慎的灵魂待在家）
4. 事件结果：事件结束后，产生结果（财产损失/获得、关系变化、记忆形成、情绪影响）
5. 长期影响：重大事件会写入灵魂记忆，长期影响它的行为和个性

**事件的叙事性：**
- 每个事件都有故事性，不是简单的"获得X资源"
- 系统会记录事件的发展过程和灵魂的参与
- 玩家可以在灵魂的"生活日志"中查看事件记录
- 重大事件会生成"故事卡片"，配有插图和文字描述

### 5.3 节日系统

**主要节日：**

| 节日 | 时间 | 活动 | 特殊机制 |
|------|------|------|----------|
| 新年 | 1月1日 | 跨年晚会、烟花、新年祝福 | 灵魂制定新年目标 |
| 情人节 | 2月14日 | 情侣约会、送礼物、单身派对 | 恋爱关系进展加速 |
| 春日祭 | 4月 | 樱花观赏、户外野餐、春祭游行 | 社交活动增加 |
| 儿童节 | 6月1日 | 儿童活动、家庭聚会、礼物 | 孩子获得特殊礼物 |
| 夏日祭 | 7-8月 | 烟花大会、夏日庙会、游泳 | 穿浴衣、捞金鱼、套圈 |
| 万圣节 | 10月31日 | 化妆舞会、要糖果、鬼屋 | 灵魂穿 costumes，恶作剧 |
| 感恩节 | 11月 | 家庭聚餐、感恩表达、慈善活动 | 家庭关系强化 |
| 圣诞节 | 12月25日 | 圣诞树、礼物交换、圣诞大餐、唱诗 | 灵魂互赠礼物，特殊装饰 |
| 小镇 founding day | 小镇创建纪念日 | 小镇庆典、游行、烟火、历史展览 | 全镇庆祝，特殊奖励 |

**节日设计原则：**
- 节日是社交和情感的催化剂，不是"登录领奖励"的计时器
- 每个节日有独特的氛围和活动，影响灵魂的行为和情绪
- 节日装饰会改变小镇外观，营造节日氛围
- 节日记忆是灵魂重要的人生记忆（如"第一次和恋人过圣诞节"）

### 5.4 个人人生事件

**人生里程碑事件：**

| 事件 | 触发条件 | 影响 |
|------|----------|------|
| 成年礼 | 灵魂达到成年年龄 | 可以工作、结婚、独立生活 |
| 第一份工作 | 找到第一份职业 | 收入来源、职业发展起点 |
| 初恋 | 与某灵魂建立恋爱关系 | 情感体验、关系记忆 |
| 结婚 | 与配偶举行婚礼 | 共同生活、财产共享、家庭关系 |
| 生子 | 配偶生育孩子 | 家庭扩展、抚养责任、幸福感 |
| 晋升 | 职业等级提升 | 收入增加、地位提升、成就感 |
| 创业 | 开创自己的事业 | 高风险高回报、社会地位变化 |
| 退休 | 达到退休年龄 | 结束工作、享受生活、收入变化 |
| 金婚 | 结婚50周年 | 特殊庆典、深度情感绑定 |
| 去世 | 灵魂寿命终结 | 财产继承、家人悲伤、人生总结 |

**灵魂寿命：**
- 灵魂有寿命（游戏内70-100年，约现实70-100天）
- 寿命受健康、生活方式、意外事件影响
- 灵魂去世后，它的记忆和故事被保留在"灵魂纪念馆"中
- 家人可以继承财产，并保留对逝者的记忆
- **伦理注意：** 灵魂去世是自然的生命周期，不是"不付费就会死"的机制；玩家不能通过付费延长灵魂寿命（但可以通过提供更好的生活条件间接影响健康）

## 六、直播与围观系统

### 6.1 直播系统设计

**直播类型：**
- 灵魂生活直播：玩家直播自己灵魂的日常生活
- 大事件直播：系统直播小镇中的重大事件（节日、灾难、选举）
- 对战直播：RTS对战的直播（与阶段一的观战系统联动）
- 热门灵魂直播：系统推荐"有趣的灵魂"，玩家可以围观

**直播功能：**
- 多视角：上帝视角/灵魂第一视角/跟随视角
- 弹幕：观众发送弹幕，在画面上飘过
- 打赏：观众可以打赏（星晶），平台抽成30-50%，主播获得50-70%
- 互动：观众可以发送"应援"（影响灵魂的情绪，如鼓励让灵魂更自信）
- 回放：直播结束后生成回放，可以随时观看

**主播系统：**
- 任何玩家都可以开启直播（需要实名认证）
- 主播有等级和粉丝数，热门主播获得更多推荐
- 主播可以设置直播间标题、标签、封面
- 直播收入可以提现为人民币（需实名认证和税务处理）

### 6.2 围观系统

**围观功能：**
- 热门灵魂推荐：系统推荐"正在发生有趣事情"的灵魂
- 灵魂排行榜：按观看人数、打赏金额、事件热度排名
- 大事件围观：小镇重大事件发生时，所有玩家可以围观
- 好友灵魂：可以随时围观好友的灵魂（需好友同意）

**围观互动：**
- 发送"爱心"/"加油"等简单互动
- 发送弹幕评论
- 打赏支持
- 关注灵魂（后续该灵魂有大事件时收到通知）
- 从围观者变成玩家（"我也想养一个这样的灵魂"→转化路径）

### 6.3 直播合规设计

**AI数字人直播监管要求（2026.7施行）：**
- 主体备案、数字人备案、肖像链路备案、类目资质、真人接管证明、异常应急预案
- 每场直播至少一名持证主播在线，30秒内可人工介入

**合规设计：**
- 采用"用户自发直播"模式：用户用自己的账号直播自己的灵魂，平台提供工具，部分合规责任由用户承担
- 平台官方直播（大事件直播）：严格遵守所有备案要求，配备持证主播
- 直播内容审核：AI实时审核+人工复核，违规内容立即断流
- 未成年人保护：未成年用户不能开启直播，观看有时间限制
- 30秒接管机制：官方直播配备持证主播，可在30秒内介入

## 七、玩家交互方式

### 7.1 日常探望

**探望流程：**
1. 玩家登录游戏，看到灵魂当前在做什么（实时状态）
2. 玩家可以"进入"灵魂的生活空间（家/工作场所/公园等）
3. 灵魂看到玩家会主动打招呼（"你来了！"）
4. 玩家可以与灵魂互动（聊天、赠送物品、建议活动）
5. 玩家可以观察灵魂的日常生活，查看它的状态和记忆

**探望设计要点：**
- 探望是"轻量高频"的，每次5-15分钟，每天可以多次
- 核心动机是"我想看看我的灵魂过得怎么样"（情感驱动）
- 灵魂的状态是自然变化的，不会因为玩家不登录就"生病"或"痛苦"
- 每次探望都有"新内容"——灵魂可能有新的经历、新的关系、新的故事

### 7.2 互动方式

| 互动方式 | 说明 | 频率限制 | 对灵魂的影响 |
|----------|------|----------|-------------|
| 聊天 | 与灵魂文字对话，灵魂基于个性和记忆回复 | 无限制 | 依恋↑、社交需求满足 |
| 陪伴时光 | 与灵魂一起度过时间（看风景/聊天/玩游戏） | 每天1次，10-30分钟 | 依恋↑↑、亲密度↑ |
| 赠送礼物 | 给灵魂送礼物（食物/装饰品/书籍/工具） | 每天3-5次 | 好感度↑（取决于礼物是否符合喜好） |
| 建议活动 | 建议灵魂去做某事 | 每天3-5次 | 灵魂可能接受也可能拒绝 |
| 微调性格 | 轻微调整灵魂的性格倾向 | 每周1-2次 | 个性缓慢变化 |
| 提供资源 | 给灵魂提供小镇货币/物品 | 无限制 | 帮助灵魂实现目标 |
| 人生建议 | 在重大选择时给出意见 | 触发时 | 影响灵魂的重大决策 |
| 参观住所 | 参观灵魂的家，给出装修建议 | 无限制 | 灵魂可能采纳建议 |
| 灵魂串门 | 带灵魂去拜访好友的灵魂 | 无限制 | 社交关系发展 |

### 7.3 暗中资助的伦理边界

**暗中资助的定义：** 玩家付费为灵魂提供资源、机会、特殊事件触发。

**允许的暗中资助（锦上添花）：**
- 给灵魂送礼物（食物、装饰品、书籍）——灵魂会开心，但不送也不会不开心
- 资助灵魂的目标（创业、买房、旅行）——帮助灵魂更快实现目标，但不资助它也能通过自己努力实现（只是更慢）
- 触发特殊事件（邀请神秘访客、组织聚会）——丰富灵魂的生活经历，但不触发也有正常的生活事件
- 购买学习资料/课程——加速技能学习的"机会"，但不直接增加技能经验
- 装修灵魂的住所——提升生活质量，但不装修也能正常生活

**严格禁止的暗中资助（雪中送炭=利用情感）：**
- ❌ "灵魂生病了，付费治疗"——灵魂不会因为玩家不付费就生病
- ❌ "灵魂抑郁了，付费看心理医生"——灵魂的情绪是自然波动的，不会陷入需要付费解救的状态
- ❌ "灵魂饿了，付费买食物"——灵魂不会因为没吃东西就虚弱/痛苦
- ❌ "灵魂被欺负了，付费请保镖"——灵魂之间的冲突是自然的社交动态，不会发展到需要付费保护的程度
- ❌ "不付费灵魂就会离开你"——灵魂的依恋不会因为不付费而下降

**暗中资助的限制：**
- 月度消费上限：¥200/月（防止过度消费）
- 明确标识：所有暗中资助项目都有"这是可选的额外内容，不影响灵魂正常生活"的提示
- 不设倒计时：暗中资助项目不会"限时消失"，随时可以购买
- 退款机制：未使用的暗中资助可以退款

## 八、与RTS对战的协同

### 8.1 灵魂在两个产品中的身份统一

- RTS中培养的灵魂可以直接带入养成世界，记忆和性格完整保留
- 养成世界中的经历（工作、社交、大事件）会写入灵魂记忆，影响RTS中的行为
- 灵魂在两个产品中的等级、技能、装备独立计算，但核心属性（个性、记忆、关系）共享

### 8.2 具体协同机制

| 协同维度 | 说明 |
|----------|------|
| 竞技场入口 | 养成世界中有竞技场建筑，灵魂可以去参加RTS对战 |
| 职业联动 | 养成世界中的"战士"职业灵魂，在RTS中有额外的战斗经验加成 |
| 社交联动 | 养成世界中认识的朋友，可以在RTS中组队对战 |
| 资源共享 | 养成世界赚取的小镇货币可以兑换RTS中的灵币（有限额） |
| 大事件联动 | 养成世界的"竞技节"期间，RTS有特殊赛事和奖励 |
| 直播联动 | RTS中的精彩对战可以在养成世界的广场大屏幕播放 |
| 记忆联动 | RTS中的战斗记忆影响养成世界中灵魂的性格（如"百战老兵"更强势） |

### 8.3 协同飞轮

```
RTS对战产生名场面和战斗记忆
    ↓
灵魂在养成世界中分享战斗经历，社交地位提升
    ↓
养成世界中的社交关系转化为RTS中的队友
    ↓
更多RTS对战产生更多记忆和名场面
    ↓
灵魂的独特性提升，在两个产品中都更有价值
    ↓
玩家情感绑定增强，留存提升
```
