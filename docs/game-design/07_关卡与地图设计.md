## 一、设计理念：环境即玩法

### 1.1 传统关卡设计 vs AI灵魂关卡设计

| 维度 | 传统关卡设计 | AI灵魂关卡设计 |
|------|-------------|---------------|
| 设计核心 | 设计玩家要走的路径和要面对的挑战 | 设计一个能激发灵魂有趣行为的环境 |
| 玩家角色 | 执行者（按设计路径操作） | 观察者/引导者（看灵魂如何应对环境） |
| 关卡乐趣 | 挑战玩家的操作和策略能力 | 观察灵魂在环境中的涌现行为和名场面 |
| 重玩价值 | 挑战更高难度/更快通关 | 不同灵魂在同一关卡中有不同行为 |
| 难度来源 | 敌人强度/谜题复杂度/时间限制 | 环境压力/资源稀缺/野生灵魂行为 |
| 关卡线性度 | 通常线性（有明确的起点和终点） | 通常开放（灵魂自由探索，目标是生存/达成条件） |

### 1.2 核心设计原则

**原则1：环境是"第三位玩家"**
- 关卡环境不是被动的背景，而是主动参与游戏的"第三位玩家"
- 环境中的光源、热源、危险区域、资源点、交互物体都会影响灵魂的行为
- 好的关卡设计能让环境与灵魂产生有趣的交互（如灵魂追逐光源、躲避热源、利用掩体）
- 技术支撑：Seed的LightSystem（动态光照）、ThermalSystem（热传导温度）、AcousticPropagation（声学遮挡）、InteractionSystem（交互物体状态机）

**原则2：同一关卡，不同灵魂，不同体验**
- 关卡设计不预设"正确解法"，而是提供一个充满可能性的环境
- 勇敢的灵魂会主动探索危险区域，怯懦的灵魂会躲在安全角落
- 好奇的灵魂会检查每个交互物体，保守的灵魂会避开未知事物
- 这确保了关卡的重玩价值——用不同灵魂玩同一关卡会有完全不同的体验

**原则3：难度是"环境压力"，不是"数值碾压"**
- 关卡难度不通过"敌人血量×10"来实现，而是通过环境压力来实现
- 环境压力包括：资源稀缺、危险区域扩大、视野受限、野生灵魂更活跃、时间限制
- 高难度关卡不是"更难打"，而是"更难生存"——灵魂需要更聪明地利用环境

**原则4：关卡是灵魂成长的"教室"**
- 每个关卡都应该让灵魂学到新东西（新技能、新记忆、新习惯）
- 关卡设计要有明确的"教学目标"——教程关卡教基础操作，进阶关卡教策略思维，挑战关卡教资源管理
- 灵魂在关卡中的经历会写入记忆，永久影响它的未来行为

**原则5：UGC关卡是长期内容的核心**
- 官方只提供基础关卡和地图，长期内容依赖玩家创作
- 关卡编辑器要足够强大，让玩家能创造有挑战性、有趣味性的关卡
- 优质UGC关卡会被官方推荐，创作者获得收益
- 这是内容生态的核心——类似《超级马里奥制造》《魔兽争霸3地图编辑器》

### 2.2 各阶段关卡详细设计

#### 2.2.1 教程阶段（0-2小时）

**目标：** 让新玩家在2小时内理解核心玩法，完成第一局对战，培养第一个灵魂。

| 关卡编号 | 关卡名称 | 教学目标 | 时长 | 解锁内容 |
|----------|----------|----------|------|----------|
| T1 | 灵魂的诞生 | 创建第一个灵魂，理解灵魂的个性和基本行为 | 10分钟 | 灵魂创建功能 |
| T2 | 初识世界 | 引导灵魂在简单地图中移动，观察灵魂的自主行为 | 10分钟 | 自由探索模式 |
| T3 | 感知与反应 | 观察灵魂对光源/热源/交互物体的反应，理解刺激驱动行为 | 15分钟 | 灵魂状态面板 |
| T4 | 第一战 | 1v1对战教程，学习战前配置和战中观战 | 20分钟 | 快速对战模式 |
| T5 | 技能与装备 | 学习技能搭配和装备选择，理解配置对战斗的影响 | 15分钟 | 技能/装备系统 |
| T6 | 记忆的力量 | 体验灵魂记忆对行为的影响（被火击败后怕火） | 15分钟 | 记忆相册 |
| T7 | 成长与进化 | 灵魂升级，学习新技能，体验成长 | 15分钟 | 成长面板 |
| T8 | 社交初体验 | 灵魂串门教程，体验灵魂间交互 | 15分钟 | 好友/串门系统 |

**教程设计要点：**
- 教程不是"看视频+点下一步"，而是"让玩家在实际操作中学习"
- 每个教程关卡都有明确的"观察目标"——引导玩家观察灵魂的某种行为
- 教程有"跳过"选项（老玩家可以直接跳过）
- 教程完成后有"教程回顾"——玩家可以随时重玩任意教程关卡

#### 2.2.2 进阶阶段（2-20小时）

**目标：** 让玩家掌握核心玩法，体验多种地图和模式，开始培养多个灵魂。

**PvE关卡：**

| 关卡类型 | 数量 | 说明 |
|----------|------|------|
| 生存挑战 | 10关 | 灵魂在资源有限的地图中生存指定时间，难度递增 |
| 野生灵魂狩猎 | 8关 | 灵魂在地图中狩猎野生灵魂，收集材料 |
| 探索关卡 | 6关 | 灵魂在大型地图中探索，发现隐藏区域和宝藏 |
| 特殊机制关卡 | 6关 | 每关有独特机制（如黑暗中只有光源可见、热源区域持续伤害、声学迷宫） |
| Boss挑战 | 4关 | 对抗强大的野生Boss灵魂，需要特定策略 |

**PvP地图：**

| 地图名称 | 类型 | 尺寸 | 特色机制 |
|----------|------|------|----------|
| 经典竞技场 | 对称 | 中 | 中央资源点，四周掩体 |
| 迷雾森林 | 非对称 | 大 | 视野受限，隐藏路径，资源分散 |
| 熔岩洞穴 | 对称 | 中 | 熔岩危险区域，需要走位 |
| 天空之桥 | 对称 | 小 | 狭窄通道，竖向位移，掉落即出局 |
| 资源孤岛 | 非对称 | 大 | 多个独立岛屿，资源决定胜负 |
| 镜像迷宫 | 对称 | 中 | 对称迷宫，视野受限，容易伏击 |
| 极地冰原 | 对称 | 大 | 寒冷区域（灵魂会趋近热源），冰面滑行 |
| 废弃工厂 | 非对称 | 中 | 大量交互物体（开关/机关/传送带） |

#### 2.2.3 挑战阶段（20-100小时）

**目标：** 为硬核玩家提供高难度挑战，追求极限操作和策略深度。

| 挑战类型 | 说明 | 奖励 |
|----------|------|------|
| 极限生存 | 资源极度稀缺，危险区域占地图70%，野生灵魂极强 | 限定称号+外观 |
| 无伤通关 | 灵魂在关卡中不受任何伤害 | 星级评价+成就 |
| 速通挑战 | 在限定时间内完成关卡 | 排行榜+限定外观 |
| 单灵魂通关 | 只用一个灵魂完成所有关卡 | 特殊成就+灵魂专属外观 |
| 锦标赛地图 | 官方赛事专用地图，平衡性经过严格测试 | 赛事奖励 |
| 每周挑战 | 每周更新的特殊规则关卡（如"所有灵魂只能用被动技能"） | 周常奖励+排行榜 |

#### 2.2.4 无尽阶段（100小时+）

**目标：** 提供无限重玩价值，依赖UGC内容和程序化生成。

| 模式 | 说明 |
|------|------|
| 无尽生存 | 程序化生成的地图，难度无限递增，看灵魂能生存多久 |
| 随机地图对战 | 每次对战使用程序化生成的随机地图 |
| 每日挑战 | 每天更新一个随机种子的关卡，全服玩家挑战同一关卡，排行榜竞争 |
| UGC关卡浏览器 | 浏览和游玩玩家创作的关卡，按评分/热度/难度分类 |
| 灵魂竞技场 | 玩家的灵魂自动参与离线对战，玩家上线后查看结果 |

## 三、PvE关卡深度设计

### 3.1 生存挑战关卡

**核心玩法：** 灵魂在资源有限、危险四伏的地图中生存指定时间。

**关卡要素：**
- **生存时间：** 5分钟/10分钟/15分钟/20分钟（难度递增）
- **资源点：** 地图中有有限的生命/能量回复点，会被消耗
- **危险区域：** 熔岩/毒雾/深渊等，进入会持续受到伤害
- **野生灵魂：** 地图中有野生灵魂，会攻击玩家灵魂或争夺资源
- **环境变化：** 随时间推移，危险区域扩大，资源点减少，野生灵魂更活跃
- **胜利条件：** 灵魂在指定时间内存活
- **失败条件：** 灵魂生命值归零

**难度设计：**

| 难度 | 生存时间 | 资源数量 | 危险区域占比 | 野生灵魂强度 |
|------|----------|----------|-------------|-------------|
| 简单 | 5分钟 | 充足 | 10% | 弱 |
| 普通 | 10分钟 | 适中 | 25% | 中 |
| 困难 | 15分钟 | 稀缺 | 40% | 强 |
| 极限 | 20分钟 | 极度稀缺 | 60% | 极强 |

**灵魂行为观察点：**
- 勇敢的灵魂会主动狩猎野生灵魂获取资源
- 怯懦的灵魂会躲在安全角落，等待资源刷新
- 好奇的灵魂会探索整个地图，发现隐藏资源
- 保守的灵魂会守在一个资源点附近，不轻易移动
- 社交性高的灵魂会尝试与野生灵魂结盟（如果可能）

### 3.2 探索关卡

**核心玩法：** 灵魂在大型地图中自由探索，发现隐藏区域、宝藏和秘密。

**关卡要素：**
- **大型地图：** 比对战地图大3-5倍，有多个区域
- **隐藏区域：** 需要特定条件才能进入（如需要光源照亮暗门、需要交互物体开启机关）
- **宝藏：** 隐藏区域中有外观/装备/技能书等奖励
- **环境叙事：** 地图中有碎片叙事（如废弃的营地、墙上的涂鸦），暗示地图的背景故事
- **野生灵魂：** 地图中有中立/敌对的野生灵魂
- **完成条件：** 发现所有隐藏区域/收集所有宝藏/击败所有野生灵魂

**探索奖励：**
- 首次发现隐藏区域：灵币+经验
- 收集宝藏：外观/装备/技能书
- 完全探索（100%）：限定称号+灵魂专属外观
- 探索记忆：灵魂会记住探索过的区域，形成认知地图

### 3.3 特殊机制关卡

每关有独特的环境机制，改变灵魂的行为方式：

| 关卡名称 | 特殊机制 | 对灵魂行为的影响 |
|----------|----------|-----------------|
| 黑暗深渊 | 地图完全黑暗，只有光源附近可见 | 灵魂会聚集在光源附近，好奇的灵魂会尝试探索黑暗区域 |
| 灼热沙漠 | 全图高温，灵魂需要不断寻找热源/冷源调节体温 | 灵魂会在冷热区域之间移动，避免过热或过冷 |
| 声学迷宫 | 视野极差，但听觉范围扩大，墙体阻挡声音 | 灵魂会依靠听觉判断敌人位置，利用墙体遮挡声音伏击 |
| 重力异常 | 地图中有多个重力区域，移动方向会改变 | 灵魂需要适应不同重力区域的移动方式 |
| 时间裂隙 | 地图中有时间加速/减速区域 | 灵魂在时间加速区域行动更快，在减速区域行动更慢 |
| 镜像世界 | 地图左右完全对称，左半区和右半区的事件会镜像发生 | 灵魂在左半区的行为会影响右半区的环境 |

### 3.4 Boss挑战关卡

**核心玩法：** 对抗强大的野生Boss灵魂，需要特定策略和配合。

**Boss设计原则：**
- Boss有独特的个性和行为模式（不是简单的"血量高+伤害高"）
- Boss有明显的"弱点"——需要观察其行为模式才能发现
- Boss战有多个阶段，每个阶段行为模式不同
- 击败Boss后，Boss的记忆碎片可以被玩家灵魂吸收（获得特殊记忆）

**Boss示例：**

| Boss名称 | 个性 | 行为模式 | 弱点 |
|----------|------|----------|------|
| 炎魔·雷德 | 狂暴、激进 | 持续追击玩家，发射范围火焰攻击，血量越低越狂暴 | 攻击后有短暂硬直，此时是输出窗口；怕水属性技能 |
| 暗影·维斯 | 狡诈、耐心 | 隐藏在黑暗中，伺机偷袭，会召唤小怪干扰 | 光源可以驱散它的隐身；好奇的灵魂可以发现它的隐藏位置 |
| 冰霜·艾拉 | 冷静、保守 | 保持距离，用远程冰攻击，设置冰陷阱 | 移动速度慢，勇敢的灵魂可以近身压制；怕火属性技能 |
| 雷霆·扎克 | 冲动、好奇 | 随机移动，释放连锁闪电，会被交互物体吸引 | 攻击前有明显蓄力动作，可以躲避；绝缘区域可以免疫闪电 |

## 四、PvP地图设计规范

### 4.1 地图设计的核心原则

**原则1：对称与非对称的选择**
- 排位赛地图必须对称（确保公平性）
- 快速对战和自定义房间可以使用非对称地图（增加趣味性）
- 非对称地图的双方需要有"补偿机制"（如弱势方有额外资源点）

**原则2：资源分布的平衡**
- 中央资源点：高价值，但争夺激烈
- 边缘资源点：低价值，但相对安全
- 资源点数量：2v2地图至少4个资源点，3v3地图至少6个
- 资源刷新间隔：60秒，确保持续争夺

**原则3：视野与掩体的设计**
- 地图中要有明确的"开阔区"和"掩蔽区"
- 开阔区：视野好，但容易被攻击（适合远程/激进灵魂）
- 掩蔽区：视野受限，但相对安全（适合近战/谨慎灵魂）
- 掩体不能完全阻挡移动（灵魂可以绕过），但要阻挡视线和远程攻击
- 高地视野优势：占领高地可以获得更大视野范围

**原则4：地图尺寸与节奏**
- 1v1地图：小型（40×40格），鼓励快速交战
- 2v2地图：中型（60×60格），有战术空间
- 3v3地图：大型（80×80格），有多种战术选择
- 大乱斗地图：超大型（100×100格），有足够空间容纳8个灵魂
- 地图尺寸要确保灵魂在2分钟内必然遭遇（避免"躲猫猫"式无聊对局）

### 4.2 地图元素清单

基于Seed世界引擎已实现的能力，地图可以包含以下元素：

| 元素类别 | 具体元素 | 技术支撑 | 战术意义 |
|----------|----------|----------|----------|
| 地形 | 平地、高地、低地、斜坡、水域、深渊 | PhysicsSystem + Quadtree空间分区 | 影响移动速度和视野 |
| 掩体 | 墙壁、柱子、箱子、岩石 | 碰撞检测+视线遮挡 | 阻挡视线和远程攻击 |
| 资源点 | 生命回复点、能量回复点、经验点 | InteractionSystem | 控制资源点获得持续优势 |
| 视野点 | 高地、瞭望塔、侦察点 | SoulPerceptionSystem | 占领后获得更大视野范围 |
| 光源 | 火把、灯笼、魔法光球 | LightSystem（动态光照） | 照亮黑暗区域，吸引好奇灵魂 |
| 热源 | 篝火、熔炉、熔岩 | ThermalSystem（热传导温度） | 寒冷区域灵魂趋近，过热区域灵魂逃离 |
| 危险区域 | 熔岩、毒雾、深渊、尖刺 | 区域伤害检测 | 进入持续受到伤害，需要走位避开 |
| 交互物体 | 开关、宝箱、机关、门、传送门 | InteractionSystem（状态机） | 可以开启/关闭，改变地图状态 |
| 声学环境 | 隔音墙、回声走廊、噪音源 | AcousticPropagation（遮挡/衰减） | 影响灵魂的听觉感知 |
| 移动装置 | 传送带、弹跳板、滑索 | 物理系统扩展 | 改变灵魂的移动方式 |
| 出生点 | 队伍出生区域 | 实体生成 | 开局保护，防止被蹲守 |

### 4.3 地图平衡性检查清单

每张地图在上线排位赛前，必须通过以下检查：

| 检查项 | 标准 | 检查方式 |
|--------|------|----------|
| 对称性 | 对称地图双方资源/视野/掩体完全对称 | 坐标镜像对比 |
| 资源平衡 | 双方可获取的资源总量差异<5% | 数据模拟 |
| 视野平衡 | 双方出生点视野范围差异<10% | 视野范围计算 |
| 路径平衡 | 从出生点到中央资源点的最短路径长度相同 | 路径计算 |
| 胜率平衡 | 双方胜率在45%-55%之间 | 1000场模拟对战数据 |
| 时长平衡 | 平均对局时长在15-25分钟 | 1000场模拟对战数据 |
| 个性多样性 | 各种性类型的灵魂都有可用战术 | 个性胜率分布检查 |
| 无恶性BUG | 灵魂不会卡住/出图/无限循环 | 自动化测试+人工测试 |

## 五、难度曲线设计

### 5.1 动态难度系统

AI灵魂游戏的难度不是固定的，而是**基于灵魂能力的动态难度**：

**难度调整因素：**

| 因素 | 调整方式 | 说明 |
|------|----------|------|
| 灵魂等级 | 高等级灵魂面对更强的野生灵魂 | 野生灵魂等级=玩家灵魂等级±2 |
| 灵魂胜率 | 高胜率灵魂面对更聪明的野生灵魂 | 野生灵魂AI难度随玩家胜率调整 |
| 关卡进度 | 越往后的关卡难度越高 | 固定的关卡难度递增 |
| 连续失败 | 连续失败3次后，难度临时降低10% | 防止玩家卡关流失 |
| 连续胜利 | 连续胜利5次后，难度临时提升10% | 保持挑战性 |

**难度调整的原则：**
- 难度调整是"隐形"的——玩家不会看到"难度已调整"的提示
- 调整幅度控制在±15%以内，不会让玩家感觉到明显变化
- 难度调整只影响PvE，PvP排位赛难度完全由匹配决定

### 5.2 整体难度曲线

```
难度
  │
  │                          ╭───── 挑战阶段
  │                      ╭──╯
  │                  ╭──╯
  │              ╭──╯  ← 进阶阶段
  │          ╭──╯
  │      ╭──╯  ← 教程阶段
  │  ╭──╯
  │──╯
  └────────────────────────────→ 游戏时间
    0h    2h    10h    30h   100h+
```

**各阶段难度特征：**
- 教程阶段（0-2h）：难度极低，重点是教学，几乎不会失败
- 进阶阶段（2-20h）：难度缓慢递增，玩家逐渐掌握玩法
- 挑战阶段（20-100h）：难度快速递增，需要策略和灵魂培养
- 无尽阶段（100h+）：难度无限递增，追求极限

### 5.3 单关卡难度曲线

每个关卡内部也有难度曲线：

```
难度
  │
  │      ╭──Boss战──╮
  │     ╱            ╲
  │    ╱  ← 中期压力  ╲
  │   ╱                ╲
  │  ╱ ← 初期探索       ╲
  │╱                      ╲── 结局
  └──────────────────────────→ 关卡时间
    0%    30%    60%    100%
```

- 初期（0-30%）：低压力，灵魂探索地图，收集资源
- 中期（30-60%）：压力逐渐增加，野生灵魂更活跃，资源开始稀缺
- 后期（60-90%）：高压力，Boss出现或危险区域扩大
- 结局（90-100%）：压力释放，胜利/失败结算

## 六、奖励机制

### 6.1 关卡奖励结构

| 奖励类型 | 说明 | 示例 |
|----------|------|------|
| 基础奖励 | 完成关卡即获得 | 灵币、经验值 |
| 星级奖励 | 根据关卡表现获得1-3星 | 1星=基础奖励，2星=+50%，3星=+100% |
| 首次通关奖励 | 首次完成关卡获得额外奖励 | 限定外观、技能书、装备 |
| 完全探索奖励 | 100%探索地图获得 | 限定称号、灵魂专属外观 |
| 挑战成就 | 完成特殊挑战条件获得 | 成就点数、特殊外观 |
| 每日首通奖励 | 每天第一次完成关卡获得额外奖励 | 灵币×2、经验×2 |
| 周常任务奖励 | 完成每周任务获得 | 大量灵币、稀有物品 |

### 6.2 星级评价标准

| 关卡类型 | 1星 | 2星 | 3星 |
|----------|-----|-----|-----|
| 生存挑战 | 生存到指定时间 | 剩余生命>50% | 剩余生命>80%且未使用回复道具 |
| 野生灵魂狩猎 | 击败所有野生灵魂 | 用时<标准时间的120% | 用时<标准时间且未受伤 |
| 探索关卡 | 发现所有隐藏区域 | 收集所有宝藏 | 100%探索且用时<标准时间 |
| Boss挑战 | 击败Boss | 剩余生命>50% | 剩余生命>80%且未使用回复道具 |
| 特殊机制关卡 | 完成关卡目标 | 利用特殊机制击败敌人 | 完全利用机制且未受伤 |

### 6.3 奖励的伦理约束

- **不设计"体力限制"** — 玩家可以无限次挑战关卡，不需要等待体力恢复
- **不设计"首通奖励递减"** — 每次完成关卡都获得基础奖励，不会因为重复挑战而减少
- **不设计"限时错过"** — 关卡奖励永久可获得，不会因为活动结束而消失
- **付费不影响奖励** — 付费玩家和免费玩家完成同一关卡获得相同奖励
- **奖励不诱导强迫性游戏** — 每日/周常奖励是"额外奖励"，不是"不领就损失"

## 七、关卡编辑器（UGC）

### 7.1 编辑器定位与价值

关卡编辑器是UGC生态的核心工具，让玩家能够创作自己的关卡和地图。

**价值：**
- 无限内容：玩家创作的关卡远超官方产能
- 社区活跃：创作者和玩家形成内容生态
- 长期留存：玩家为了玩新关卡而持续回归
- 创作者经济：优质关卡创作者获得收益
- 参考：《超级马里奥制造》《魔兽争霸3地图编辑器》《星际争霸2地图编辑器》

### 7.2 编辑器功能模块

| 模块 | 功能 | 难度 |
|------|------|------|
| 地形编辑 | 绘制地形（平地/高地/水域/深渊），调整高度 | 简单 |
| 掩体放置 | 放置墙壁/柱子/箱子等掩体，调整大小和位置 | 简单 |
| 资源点放置 | 放置生命/能量/经验资源点，设置刷新间隔 | 简单 |
| 光源/热源放置 | 放置光源和热源，调整范围和强度 | 中等 |
| 危险区域绘制 | 绘制熔岩/毒雾等危险区域，设置伤害 | 中等 |
| 交互物体放置 | 放置开关/宝箱/机关/门，设置触发条件和效果 | 中等 |
| 野生灵魂放置 | 放置野生灵魂，设置个性/技能/行为模式 | 中等 |
| Boss配置 | 配置Boss的个性/技能/阶段/弱点 | 复杂 |
| 事件系统 | 设置触发事件（如"进入区域X时触发Y"） | 复杂 |
| 胜利/失败条件 | 设置关卡的胜利和失败条件 | 中等 |
| 叙事文本 | 添加关卡介绍/环境叙事/对话文本 | 简单 |
| 测试模式 | 在编辑器中直接测试关卡 | 简单 |
| 发布与分享 | 发布关卡到社区，设置标签和描述 | 简单 |

### 7.3 编辑器使用门槛

**分层设计：**
- **简单模式**：预设模板+拖拽放置，10分钟可以做一个简单关卡
- **高级模式**：完整的事件系统和逻辑编辑，可以做复杂关卡
- **专家模式**：脚本编程接口，可以做几乎任何类型的关卡

**教程与模板：**
- 编辑器内置教程，引导玩家完成第一个关卡
- 提供多种预设模板（生存挑战/对战地图/Boss战/探索关卡）
- 官方定期发布"编辑器教学"视频和文档

### 7.4 UGC关卡的社区机制

| 机制 | 说明 |
|------|------|
| 关卡浏览器 | 按评分/热度/难度/类型浏览关卡，支持搜索和标签筛选 |
| 评分系统 | 玩家完成关卡后可以评分（1-5星）和评论 |
| 排行榜 | 每个关卡有独立排行榜（速通/高分/最少受伤） |
| 创作者等级 | 基于关卡评分和游玩次数，创作者有等级和称号 |
| 创作者收益 | 优质关卡可以设置"付费游玩"（¥1-5），创作者获得70%收益 |
| 官方推荐 | 编辑每周推荐优质关卡，获得首页曝光和流量扶持 |
| 创作比赛 | 定期举办关卡创作比赛，获奖者获得奖金和限定外观 |
| 内容审核 | AI审核+人工复核，确保UGC内容合规 |

### 7.5 UGC关卡的平衡性与质量

- **标签系统**：玩家可以给关卡打标签（"太难""有BUG""创意十足"），帮助其他玩家选择
- 举报系统：玩家可以举报有问题的关卡（BUG/违规内容/恶意设计）
- 质量门槛：发布关卡需要通过基础检查（有明确的胜利条件、没有出图BUG、内容合规）
- 创作者信誉：高信誉创作者的关卡优先推荐，低信誉创作者的关卡需要更严格的审核
