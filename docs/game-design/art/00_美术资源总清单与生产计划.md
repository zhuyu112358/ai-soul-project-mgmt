## 一、资源生产总览

### 1.1 生产原则

| 原则 | 说明 |
|------|------|
| **版权安全** | 所有资源自行生成（AI生成/代码绘制/程序化生成），禁止使用第三方受版权保护的素材 |
| **风格一致** | 所有资源严格遵循v1.1精致像素风美术规范（128×128角色、64色/角色、128色/场景、实时光照、8帧动画） |
| **规格统一** | 同类资源使用统一的画布尺寸、色板、命名规范和导出格式 |
| **优先级驱动** | 按M1（灵魂之家+成长基础）→M2（对战竞技场）→M3（世界探索+社交）的里程碑顺序生产 |
| **可替换** | 早期资源可以是占位符（placeholder），但必须有明确的规格文档，后续可无缝替换为高品质资源 |

## 五、生产方式与工具链

### 5.1 AI图像生成

| 工具 | 用途 | 优势 | 限制 |
|------|------|------|------|
| image_gen（文生图） | 概念图、场景设计、角色设计 | 快速出图，风格多样 | 像素精度不足，需后期处理 |
| image_edit（图生图） | 基于概念图细化、风格转换 | 保持构图，提升品质 | 需参考图，编辑范围有限 |

**AI生成工作流：**
1. 文生图生成概念草图（提示词包含"精致像素风、128×128角色、温暖色调、能量核心"）
2. 人工筛选最佳构图
3. 图生图细化像素细节
4. 人工修图（Aseprite/Photoshop）确保像素完美
5. 导出为PNG（Nearest过滤）

### 5.2 代码绘制/程序化生成

| 工具 | 用途 | 优势 |
|------|------|------|
| Python PIL/Pillow | 瓦片集、UI组件、图标 | 精确像素控制，批量生成 |
| Godot Shader | 粒子特效、后期处理 | 实时渲染，性能优秀 |
| 程序化生成脚本 | 地形瓦片、纹理变体 | 无限变体，一致性好 |

### 5.3 动画制作

| 工具 | 用途 | 输出格式 |
|------|------|----------|
| Aseprite | 像素动画逐帧绘制 | PNG序列 + JSON帧数据 |
| Godot AnimationPlayer | 引擎内动画组装 | .tres动画资源 |
| 程序化动画脚本 | 呼吸、摇摆、闪烁等循环动画 | 代码驱动，无需贴图 |

### 5.4 资源验证清单

每个资源产出后必须验证：

- [ ] 画布尺寸符合规格（128×128角色/48×48瓦片等）
- [ ] 色板符合规范（64色/角色，128色/场景）
- [ ] 像素完美（无半透明像素边缘，无模糊）
- [ ] 风格一致（与v1.1精致像素风规范一致）
- [ ] 命名规范正确（`{类别}_{名称}_{变体}_{帧号}.png`）
- [ ] 版权状态标注（自行生成，无第三方版权）
- [ ] Godot中测试渲染正常（Nearest过滤，像素对齐）
