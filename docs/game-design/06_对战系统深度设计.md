## 一、设计理念：教练式RTS

### 1.1 传统RTS vs AI灵魂RTS

| 维度 | 传统RTS（星际/魔兽） | AI灵魂RTS |
|------|----------------------|-----------|
| 玩家角色 | 指挥官（实时操控所有单位） | 教练（战前配置+战中有限指令+观战） |
| 操作要求 | 极高（APM、微操、多线操作） | 低（策略思考，不需要快速操作） |
| 单位智能 | 低（单位只执行玩家指令，不会自主决策） | 高（灵魂自主决策，个性和记忆影响行为） |
| 战术深度 | 来自操作和战术执行 | 来自灵魂配置和个性组合 |
| 观赏性 | 看玩家操作和战术博弈 | 看灵魂自主决策的不可预测性和名场面 |
| 学习曲线 | 陡峭（需要练习操作） | 平缓（理解灵魂个性和配置即可） |
| 单局时长 | 15-60分钟 | 10-30分钟 |

### 1.2 核心设计原则

**原则1：玩家是教练，不是操控者**
- 玩家在战前配置灵魂（性格倾向、技能、装备、战术）
- 战中灵魂自主决策和行动，玩家只能发送有限的宏观指令
- 这降低了操作门槛，让策略思考成为核心，同时让灵魂的个性得以展现

**原则2：个性即战术**
- 灵魂的性格参数直接影响战斗行为——勇敢的灵魂主动开团，怯懦的灵魂蹲草偷袭，好奇的灵魂到处探索
- 没有"最优配置"，不同个性组合有不同的战术优势和劣势
- 记忆影响战斗——被某个技能击败过的灵魂，下次会优先躲避该技能

**原则3：观战即娱乐**
- 对战过程本身就是娱乐内容——灵魂的自主决策产生不可预测的"名场面"
- 观战系统要提供丰富的视角和数据，让玩家"看懂"灵魂的决策
- 名场面自动录制和分享，是社交传播的核心

**原则4：平衡优先，付费不影响竞技**
- 付费只能购买外观和便利性，不能购买任何影响战斗结果的属性
- 等级压缩机制确保高等级灵魂不会碾压低等级灵魂
- 平衡性是竞技游戏的生命线，每个赛季都要根据数据调整

**原则5：快速上手，深度可研究**
- 新玩家10分钟内完成第一局对战并理解核心玩法
- 高手有足够的深度可以研究（灵魂配置、技能组合、个性协同、记忆利用）
- 配置有"一键推荐"降低门槛，同时有"高级配置"满足深度需求

## 二、对战规则体系

### 2.1 对战模式总览

| 模式 | 人数 | 时长 | 胜利条件 | 解锁条件 |
|------|------|------|----------|----------|
| 新手教程 | 1PvE | 15分钟 | 完成教程任务 | 默认 |
| 快速对战（1v1） | 2人 | 10-20分钟 | 消灭对方所有灵魂/对方投降/时间结束时存活数多 | 教程完成 |
| 快速对战（2v2） | 4人 | 15-25分钟 | 同上 | 等级3 |
| 排位对战（1v1） | 2人 | 15-25分钟 | 同上 | 快速对战5场 |
| 排位对战（2v2） | 4人 | 20-30分钟 | 同上 | 排位段位达到青铜 |
| 排位对战（3v3） | 6人 | 25-35分钟 | 同上 | 排位段位达到白银 |
| 大乱斗 | 4-8人 | 20-30分钟 | 最后存活的灵魂/队伍获胜 | 等级5 |
| 生存挑战 | 1PvE | 20-40分钟 | 在资源有限的地图中生存指定时间/击败所有野生灵魂 | 等级10 |
| 锦标赛 | 多人 | 1-2小时 | 淘汰赛制，最后获胜 | 段位要求/报名 |
| 自定义房间 | 任意 | 任意 | 房主设定 | 等级3 |

### 2.2 核心战斗规则

#### 2.2.1 灵魂状态

每个灵魂在对战中有以下状态属性：

| 属性 | 说明 | 影响 |
|------|------|------|
| 生命值（HP） | 灵魂的健康值，归零时灵魂被击败（出局） | 生存能力 |
| 能量值（EP） | 使用技能消耗能量，随时间恢复 | 技能使用频率 |
| 情绪状态 | 灵魂当前的情绪（平静/兴奋/恐惧/愤怒等） | 影响决策倾向和技能效果 |
| 目标 | 灵魂当前的行动目标（移动到某位置/攻击某目标/采集资源等） | 行为方向 |
| 位置 | 灵魂在地图中的坐标 | 空间关系 |
| 状态效果 | 增益/减益效果（护盾/中毒/减速/眩晕等） | 战斗修正 |

#### 2.2.2 灵魂的战斗行为循环

灵魂在对战中的行为由SoulArena的认知系统驱动，遵循以下循环：

```
感知（Seed SoulPerceptionSystem）
  ↓ 感知到敌人/资源/危险/队友位置
认知（SoulArena 79子系统 + BehaviorArbiter）
  ↓ 基于个性/记忆/情绪/当前状态做决策
决策（BehaviorArbiter仲裁）
  ↓ 选择动作（移动/攻击/技能/采集/交流/回避）
执行（Seed SoulActionSystem）
  ↓ 动作在世界中执行
反馈（ActionResult）
  ↓ 动作结果回传，影响认知状态（成功→满足感，失败→挫败感）
  ↓ 循环
```

**玩家的有限指令：**
- 玩家可以在战中发送宏观指令，每30秒最多发送1次
- 指令类型："集合""撤退""攻击目标X""采集资源""防守位置Y"
- 灵魂有权"不听从"指令——怯懦的灵魂收到"进攻"指令时可能会犹豫或拒绝，这增加了个性的真实感
- 指令不是强制的，而是"建议"——灵魂会参考指令，但最终决策由它自己做出

#### 2.2.3 技能系统

每个灵魂可以携带4-6个技能（战前配置），技能分为以下类型：

| 技能类型 | 说明 | 示例 | 能量消耗 |
|----------|------|------|----------|
| 主动攻击 | 对目标造成伤害 | 火焰冲击、冰霜箭、雷电链 | 中-高 |
| 主动防御 | 为自己/队友提供防护 | 护盾、治疗、净化 | 中 |
| 控制技能 | 限制敌人行动 | 眩晕、减速、冰冻、嘲讽 | 中 |
| 移动技能 | 快速移动/位移 | 冲刺、闪现、跳跃 | 低-中 |
| 被动技能 | 持续生效的增益 | 攻击力提升、生命恢复、抗性 | 无 |
| 终极技能 | 强力技能，需要充能 | 大范围伤害、群体治疗、时间减缓 | 高（需充能） |

**技能的个性修正：**
- 技能的使用方式受灵魂个性影响——激进的灵魂更频繁使用攻击技能，谨慎的灵魂更倾向于防御技能
- 技能的效果可能受情绪影响——愤怒时攻击技能伤害+20%，恐惧时防御技能效果+20%
- 记忆影响技能选择——被某个技能击败过的灵魂，会优先学习/使用克制该技能的技能

**技能学习与升级：**
- 灵魂通过战斗获得技能经验，使用频率高的技能升级更快
- 技能升级提升效果（伤害+10%/级，治疗量+10%/级等），最多5级
- 新技能通过技能书学习（战斗掉落/商店购买/任务奖励）
- **平衡性注意：** 排位赛中技能等级会被压缩到统一水平（见3.1节）

#### 2.2.4 地图机制

每张地图有独特的机制和资源点：

| 地图元素 | 说明 | 战术意义 |
|----------|------|----------|
| 资源点 | 地图中的能量/生命回复点，占领后持续获得资源 | 控制资源点的队伍有持续优势 |
| 视野点 | 高地/瞭望塔，占领后获得更大视野范围 | 视野优势可以提前发现敌人 |
| 掩体 | 墙壁/障碍物，阻挡视线和远程攻击 | 可以利用掩体伏击/躲避 |
| 危险区域 | 熔岩/深渊/毒雾，进入会持续受到伤害 | 走位需要避开危险区域 |
| 交互物体 | 开关/宝箱/机关，灵魂可以主动检查/使用 | 使用交互物体可以获得临时增益/开启新路径 |
| 光源/热源 | 地图中的光源和热源（Seed已支持光照/温度系统） | 灵魂会被光源吸引（好奇）或躲避热源（过热），影响走位 |
| 声学遮挡 | 墙体阻挡声音传播（Seed已支持AcousticPropagation） | 灵魂的"听觉"受地形影响，墙后的敌人不会被听到 |

**地图中的灵魂刺激响应（SoulArena已实现）：**
- 热源过热时灵魂会逃离，寒冷时灵魂会趋近取暖
- 非恐惧状态下灵魂会趋近光源（好奇）
- 威胁性个体灵魂会回避，友好个体灵魂会趋近+3m内主动问候
- 好奇/愉悦时灵魂会主动检查交互物体
- 无强刺激时灵魂会随机方向漫游

### 2.3 战斗节奏设计

```
开局（0-2分钟）          中期（2-10分钟）         后期（10-20分钟）
┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│ 灵魂出生       │      │ 资源争夺       │      │ 决战           │
│ 初始走位       │─────→│ 小规模冲突     │─────→│ 大规模团战     │
│ 探索地图       │      │ 技能升级       │      │ 终极技能释放   │
│ 首次遭遇       │      │ 视野控制       │      │ 最后存活判定   │
└──────────────┘      └──────────────┘      └──────────────┘
  个性展现期             战术博弈期              名场面高发期
```

**节奏控制机制：**
- 开局保护：出生后10秒内无敌，防止被蹲守
- 资源刷新：资源点每60秒刷新一次，鼓励持续争夺
- 缩圈机制（大乱斗/生存模式）：地图可活动范围随时间缩小，迫使玩家交战
- 能量加速：后期能量恢复速度提升，鼓励更多技能使用和团战
- 投降机制：一方灵魂全部出局，或一方玩家主动投降（2v2/3v3需要全队同意）

## 三、平衡性设计

### 3.1 等级压缩与属性归一化

**核心原则：排位赛中，所有灵魂的战斗属性被压缩到统一水平，个性和记忆是唯一的差异化因素。**

| 属性 | 自由模式 | 排位模式 | 说明 |
|------|----------|----------|------|
| 等级 | 实际等级 | 统一为30级 | 高等级灵魂的等级优势被消除 |
| 基础属性（攻击/防御/生命） | 实际值 | 归一化为标准值±5%（由个性微调） | 属性差异极小，个性是主要变量 |
| 技能等级 | 实际等级 | 统一为3级 | 技能等级优势被消除 |
| 装备属性 | 实际值 | 归一化为标准值 | 装备属性优势被消除 |
| 个性参数 | 实际值 | 实际值（保留） | 个性是核心差异化因素 |
| 记忆 | 实际记忆 | 实际记忆（保留） | 记忆影响行为，是核心差异化因素 |
| 技能组合 | 实际配置 | 实际配置（保留） | 技能选择是策略深度的来源 |

**设计理由：**
- 确保竞技公平——付费和时间投入不能转化为战斗优势
- 让个性和记忆成为核心——这是AI灵魂游戏的独特价值，传统游戏没有
- 降低新手门槛——新玩家不会因为等级低而被碾压
- 保留策略深度——技能组合、个性搭配、战术指令仍然有深度

**自由模式（快速对战/自定义）：**
- 保留实际等级和属性，让玩家体验成长的成就感
- 但匹配时会尽量匹配相近等级的玩家（等级差不超过10级）
- 等级差过大时，低等级方获得"新手保护"增益（属性+20%）

### 3.2 灵魂克制关系

灵魂的个性和技能类型之间存在克制关系，增加战术深度：

| 个性/类型 | 克制 | 被克制 | 说明 |
|-----------|------|--------|------|
| 勇敢/激进 | 谨慎/保守 | 灵活/游击 | 激进打法压制保守打法，但被灵活走位克制 |
| 谨慎/保守 | 灵活/游击 | 勇敢/激进 | 保守打法稳扎稳打，克制灵活但输出不足的对手 |
| 灵活/游击 | 勇敢/激进 | 谨慎/保守 | 灵活走位躲避激进攻击，但被保守的持续压制克制 |
| 友善/辅助型 | — | — | 辅助型不直接克制，但在组队中有高价值 |
| 好奇/探索型 | — | — | 探索型在资源控制上有优势，但正面战斗较弱 |

**技能类型克制：**
- 火系技能克制冰系（冰被火融化）
- 冰系技能克制雷系（冰绝缘）
- 雷系技能克制水系（水导电）
- 水系技能克制火系（水灭火）
- 这形成了属性克制循环，增加配置策略深度

**记忆克制（独特机制）：**
- 如果灵魂A曾被灵魂B的某个技能击败过，A会对该技能有"恐惧记忆"，遇到该技能时优先躲避
- 这意味着"复仇之战"有额外的策略深度——B需要变化战术，A可以利用记忆
- 但记忆也可能被利用——B可以假装使用该技能引诱A躲避，然后用其他技能攻击

### 3.3 平衡性监控与调整

**数据监控指标：**
- 各灵魂/技能的胜率（目标45%-55%）
- 各个性类型的出场率和胜率
- 平均对局时长（目标15-25分钟）
- 投降率（目标<10%，过高说明一边倒严重）
- 翻盘率（目标15%-25%，过低说明前期决定胜负，过高说明前期无意义）

**调整机制：**
- 每个赛季开始时，根据上赛季数据进行平衡性调整
- 调整优先修改技能数值（伤害/冷却/能量消耗），不修改灵魂个性（个性是核心体验）
- 重大调整提前在社区公示，收集玩家反馈
- 紧急热修复：如果发现严重失衡（胜率>60%），在24小时内临时调整

## 四、匹配与段位系统

### 4.1 MMR匹配机制

采用**MMR（Matchmaking Rating）**系统进行匹配：

- 每个玩家有一个隐藏的MMR值，基于对战结果动态调整
- 胜利MMR上升，失败MMR下降，上升/下降幅度取决于双方MMR差距
- 匹配时优先匹配MMR相近的玩家（差距<100），最长等待30秒
- 30秒后扩大匹配范围（差距<200），60秒后再次扩大（差距<400）
- 组队玩家的MMR取队伍平均值，适当上调（组队有配合优势）

**MMR调整公式（简化）：**
```
新MMR = 旧MMR + K × (实际结果 - 预期结果)
其中：
- K = 32（基础系数，新玩家前10场K=64加速定位）
- 预期结果 = 1 / (1 + 10^((对手MMR - 自己MMR)/400))
- 实际结果 = 1（胜利）/ 0.5（平局）/ 0（失败）
```

### 4.2 段位系统

段位基于MMR划分，每个赛季重置（保留部分继承）：

| 段位 | MMR范围 | 段位图标 | 玩家占比（目标） |
|------|---------|----------|-----------------|
| 青铜 | 0-800 | 青铜徽章 | 30% |
| 白银 | 800-1200 | 白银徽章 | 30% |
| 黄金 | 1200-1600 | 黄金徽章 | 20% |
| 铂金 | 1600-2000 | 铂金徽章 | 12% |
| 钻石 | 2000-2400 | 钻石徽章 | 5% |
| 大师 | 2400-2800 | 大师徽章 | 2.5% |
| 王者 | 2800+ | 王者徽章（全服前100名） | 0.5% |

**段位晋级/降级：**
- 晋级：MMR达到上段下限，且进行3场晋级赛（赢2场即晋级）
- 降级：MMR跌出本段下限，且连续3场失败即降级
- 段位保护：新晋级的玩家有5场保护期，期间不会降级

### 4.3 赛季系统

**赛季周期：** 每3个月一个赛季

**赛季重置：**
- 赛季结束时，所有玩家的MMR重置为：新MMR = 1000 + (旧MMR - 1000) × 0.5
- 段位重置为青铜，但上赛季最高段位会记录在"历史段位"中
- 赛季奖励根据上赛季最终段位发放

**赛季奖励：**

| 最终段位 | 奖励 |
|----------|------|
| 青铜 | 灵币×500 + 青铜头像框 |
| 白银 | 灵币×1000 + 白银头像框 + 基础皮肤 |
| 黄金 | 灵币×2000 + 黄金头像框 + 高级皮肤 + 赛季表情 |
| 铂金 | 灵币×3000 + 铂金头像框 + 限定皮肤 + 赛季表情 + 击杀特效 |

## 五、观战与回放系统

### 5.1 观战系统

观战是AI灵魂RTS的核心体验之一——玩家不仅自己玩，也喜欢看别人的灵魂对战。

**观战功能：**

| 功能 | 说明 |
|------|------|
| 上帝视角 | 俯视整个地图，看到所有灵魂的位置和状态 |
| 灵魂聚焦视角 | 聚焦单个灵魂，跟随它的移动，看到它的感知范围 |
| 决策可视化 | 显示灵魂当前的决策过程（目标、考虑的选项、最终选择） |
| 内心独白 | 显示灵魂当前的"想法"（如"那个敌人很强，我应该绕开"） |
| 数据面板 | 实时显示各灵魂的状态（HP/EP/情绪/技能冷却/装备） |
| 关系显示 | 显示灵魂间的关系（友好/敌对/中立），组队时显示队伍关系 |
| 慢放 | 关键时刻可以慢放（0.5x/0.25x），仔细观察 |
| 暂停 | 可以暂停（仅自定义房间的观战，实时观战不能暂停） |
| 弹幕 | 观众可以发送弹幕，在画面上飘过（可关闭） |
| 投票预测 | 观众可以投票预测哪方获胜，猜对获得灵币奖励 |

**观战入口：**
- 好友正在对战 → 可以直接观战
- 高段位对战 → 系统推荐的精彩对战
- 锦标赛 → 官方直播的赛事
- 自定义房间 → 房主允许观战的房间
- 灵魂视角 → 选择"看某个灵魂的最近对战"

**观战奖励：**
- 每天观战满10分钟获得灵币×50
- 观看高段位对战（钻石以上）有机会获得"观战宝箱"（随机外观奖励）
- 投票预测猜对获得灵币奖励

### 5.2 回放系统

**回放功能：**
- 每局对战自动保存回放（保存7天，玩家可以永久保存喜欢的回放）
- 回放支持完整的观战功能（上帝视角/灵魂视角/慢放/数据面板）
- 回放可以导出为视频文件（本地保存）
- 回放中可以标记"精彩时刻"，生成短视频分享

**名场面自动剪辑：**
- 系统自动识别每局中的名场面（精彩击杀/极限反杀/神级走位/搞笑失误）
- 自动生成10-30秒的短视频，添加慢放/特写/数据面板
- 玩家可以一键分享到社区/短视频平台
- 名场面会被收录到灵魂的"名场面集"中，永久保存

## 六、锦标赛系统

### 6.1 锦标赛类型

| 类型 | 举办方 | 频率 | 规模 | 报名费 |
|------|--------|------|------|--------|
| 官方周赛 | 官方 | 每周 | 64-128人 | 免费 |
| 官方月赛 | 官方 | 每月 | 128-256人 | ¥10 |
| 赛季总决赛 | 官方 | 每赛季 | 32人（邀请制） | 邀请制 |
| 社区赛 | 玩家/社区 | 不定期 | 任意 | 房主设定（免费/付费） |
| 自定义赛 | 玩家 | 随时 | 任意 | 房主设定 |

### 6.2 赛制

- **淘汰赛制：** 单败淘汰，一局定胜负（决赛BO3）
- **小组赛+淘汰赛：** 先分组循环赛，前两名出线进入淘汰赛
- **瑞士轮制：** 积分制，相同积分的选手配对，最终按积分排名

### 6.3 奖金池

- 官方赛事：官方提供基础奖金+报名费注入（报名费的80%进入奖金池）
- 社区赛事：报名费注入奖金池（平台抽成10%）
- 奖金分配：冠军40%，亚军20%，季军10%，4-8名各5%，9-16名各1.25%
- 奖金以星晶形式发放（可提现为人民币，需实名认证）

### 6.4 观赛与直播

- 官方赛事在游戏内直播，有官方解说
- 玩家可以在直播平台（抖音/B站/Twitch）转播自己参与的赛事
- 观赛有投票预测和弹幕互动
- 赛事中的名场面会被官方剪辑传播

## 七、对战系统的技术实现映射

| 对战功能 | 技术模块 | 当前状态 |
|----------|----------|----------|
| 灵魂感知环境 | Seed SoulPerceptionSystem（光照/温度/声源/其他灵魂/交互物体） | ✅ 已实现 |

| 灵魂动作执行 | Seed SoulActionSystem（7种动作：move/interact/communicate/use/attack/wait/custom） | ✅ 已实现 |
| 物理移动 | Seed MovementController + EntityArrivedEvent（物理移动到达检测） | ✅ 已实现 |
| 动作结果反馈 | SoulArena ActionResult API + Seed SoulBridgeAdapter | ✅ 已实现 |
| 刺激驱动行为 | SoulArena _generateStimulusActions（热源/光源/其他灵魂/交互物体） | ✅ 已实现 |
| 灵魂间交互 | SoulArena社交认知子系统（心智理论/共情/情绪传染/社会学习等） | ✅ 已实现（需多灵魂验证） |
| 声学遮挡 | Seed AcousticPropagation（slab method线段-AABB相交检测） | ✅ 已实现 |
| 多灵魂场景 | Seed多实体 + SoulArena多灵魂API | 🟡 开发中（单灵魂已验证） |
| 战斗规则系统 | 游戏层（HP/EP/伤害计算/胜负判定/状态效果） | ❌ 需实现 |
| 技能系统 | 游戏层（技能定义/效果/冷却/能量消耗） | ❌ 需实现 |
| 匹配系统 | 游戏后端（MMR计算/匹配算法/段位系统） | ❌ 需实现 |
| 观战系统 | 游戏客户端（多视角/数据面板/慢放/弹幕） | ❌ 需实现 |
| 回放系统 | 游戏后端（对战录制/存储/回放播放） | ❌ 需实现 |
| 锦标赛系统 | 游戏后端（报名/赛制/奖金/直播） | ❌ 需实现 |
| 客户端渲染 | 2D/3D渲染 + UI + 动画 | ❌ 需实现 |

**结论：** 对战系统的核心AI能力（感知、决策、执行、反馈、刺激响应、灵魂间交互）在SoulArena和Seed中已经全部实现，且远超"宝可梦级智能"需求。当前缺失的是**游戏规则层**（战斗判定/技能/匹配/段位）和**客户端表现层**（渲染/UI/观战/回放）。多灵魂场景验证是当前的技术卡点，完成后即可进入游戏规则层开发。
