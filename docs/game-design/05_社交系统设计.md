# AI灵魂游戏 — 社交系统设计

**版本：** v1.0
**创建日期：** 2026-09-05
**维护方：** AI灵魂游戏设计定时任务
**前置文档：** `01_受众分析与差异化定位.md`、`02_核心循环与游戏框架设计.md`、`03_灵魂成长系统设计.md`
**文档定位：** 定义游戏的社交体系——灵魂间交互、玩家间交互、玩家-灵魂交互的三层社交网络，是留存和传播的核心驱动力

## 一、设计理念：三层社交网络

### 1.1 传统游戏社交 vs AI灵魂游戏社交

| 维度 | 传统游戏社交 | AI灵魂游戏社交 |
|------|-------------|---------------|
| 社交主体 | 玩家 ↔ 玩家 | 玩家 ↔ 灵魂 ↔ 灵魂 ↔ 玩家（多层网络） |
| 社交内容 | 组队、聊天、交易、竞技 | 以上 + 灵魂间的自主社交（友谊、敌对、恋爱） |
| 社交持续性 | 玩家在线时才有社交 | 灵魂24小时持续社交，玩家离线时灵魂仍在互动 |
| 社交独特性 | 社交关系由玩家行为决定 | 社交关系由灵魂个性+记忆+玩家引导共同决定 |
| 社交传播 | 玩家分享游戏成就 | 玩家分享灵魂的社交故事（名场面、情感时刻） |

### 1.2 三层社交结构

```
┌─────────────────────────────────────────────────────────────┐
│                      第一层：灵魂间社交                        │
│                    （AI-AI，自主涌现，24小时持续）             │
│                                                               │
│   灵魂A ←──友谊/敌对/师徒/恋爱──→ 灵魂B                      │
│      ↘                                ↙                       │
│        ↘                          ↙                           │
│          ↘                    ↙                               │
│            灵魂C ←──社交影响──→ 灵魂D                         │
│                                                               │
├─────────────────────────────────────────────────────────────┤
│                      第二层：玩家-灵魂社交                      │
│                    （人-AI，情感连接，培养关系）               │
│                                                               │
│   玩家甲 ──培养/引导/互动──→ 灵魂A                            │
│   玩家乙 ──培养/引导/互动──→ 灵魂B                            │
│                                                               │
├─────────────────────────────────────────────────────────────┤
│                      第三层：玩家间社交                        │
│                    （人-人，传统游戏社交+灵魂中介）            │
│                                                               │
│   玩家甲 ←──组队/对战/交易/社区/灵魂串门──→ 玩家乙            │
│                                                               │
└─────────────────────────────────────────────────────────────┘
```

**三层社交的协同效应：**
- 灵魂间社交为玩家提供"观察内容"（看灵魂们交朋友、吵架、恋爱）
- 玩家-灵魂社交为玩家提供"情感连接"（培养自己的灵魂）
- 玩家间社交为玩家提供"社交归属"（和其他玩家交流、对战、交易）
- 三层社交相互促进：灵魂间的故事促使玩家间交流 → 玩家间交流促使更多灵魂互动 → 灵魂互动增强玩家-灵魂情感连接

## 二、第一层：灵魂间社交（AI-AI）

### 2.1 灵魂间社交的技术基础

SoulArena已经实现了完整的社交认知子系统，这是灵魂间社交的技术基础：

| 子系统 | 功能 | 在社交中的作用 |
|--------|------|---------------|
| 心智理论 | 理解其他灵魂的意图和信念 | 灵魂能"读懂"其他灵魂的想法，做出合适的社交反应 |
| 社会学习 | 观察和模仿其他灵魂的行为 | 灵魂会从其他灵魂那里学习技能、习惯、行为模式 |
| 特质激活 | 根据对方的个性调整自己的行为 | 灵魂对不同个性的其他灵魂有不同的社交方式 |
| 道德推理 | 判断行为的对错 | 灵魂会对其他灵魂的行为做出道德评价（如"它背叛了朋友，这是不对的"） |
| 社会认同 | 归属于某个群体 | 灵魂会形成"小团体"，对团体内外的灵魂有不同态度 |
| 从众与服从 | 跟随群体或权威 | 灵魂会跟随多数灵魂的行为，或服从"领袖"灵魂 |
| 说服 | 影响其他灵魂的观点 | 灵魂可以说服其他灵魂改变想法（如"我们应该结盟"） |
| 共情 | 感受和分享其他灵魂的情绪 | 灵魂能感知其他灵魂的情绪并做出回应（如安慰悲伤的灵魂） |
| 情绪传染 | 情绪在群体中传播 | 一个灵魂的恐惧/兴奋会传染给周围的灵魂 |
| 幽默认知 | 理解和产生幽默 | 灵魂之间会"开玩笑"，增加社交的丰富性 |
| 刻板印象与偏见 | 对特定类型灵魂的预设看法 | 灵魂可能对某些类型的灵魂有偏见（如"火系灵魂都很暴躁"） |

### 2.2 灵魂间社交的触发机制

灵魂间的社交不是脚本化的，而是由**接近性+刺激+个性**共同触发的：

**触发条件：**
1. **空间接近**：两个灵魂在感知范围内（Seed的SoulPerceptionSystem检测到其他灵魂）
2. **刺激识别**：灵魂识别到对方的特征（个性、外观、行为、关系历史）
3. **社交决策**：基于自己的个性、当前情绪、与对方的关系历史，决定社交行为
4. **行为执行**：执行社交动作（问候、回避、攻击、结盟等）
5. **结果反馈**：对方的反应作为ActionResult回传，影响后续认知和关系

**社交行为的类型（由BehaviorArbiter仲裁）：**

| 行为类别 | 具体行为 | 触发条件 | 技术支撑 |
|----------|----------|----------|----------|
| 友好行为 | 问候、分享资源、帮助、一起行动 | 友善个性+对方无威胁+关系良好 | 共情+社会认同+特质激活 |
| 敌对行为 | 挑衅、攻击、抢夺资源、回避 | 敌对个性+对方有威胁+关系恶劣 | 道德推理+刻板印象+特质激活 |
| 中立行为 | 观察、忽略、短暂交流 | 中性个性+对方无特殊刺激 | 注意力门控+显著性网络 |
| 社交学习 | 观察模仿、请教、学习技能 | 好奇个性+对方有值得学习的行为 | 社会学习+模仿机制 |
| 说服结盟 | 提议合作、说服对方、建立联盟 | 社交性个性+双方有共同利益 | 说服+心智理论+社会认同 |
| 情感互动 | 安慰、庆祝、共情、幽默 | 高共情+对方有强烈情绪 | 共情+情绪传染+幽默认知 |

### 2.3 灵魂间关系的类型与演化

灵魂之间的关系不是简单的"友好/敌对"二分法，而是一个多维的关系空间：

#### 2.3.1 关系维度

| 维度 | 范围 | 说明 |
|------|------|------|
| 好感度 | -100 ~ +100 | 对对方的整体好感程度 |
| 信任度 | 0 ~ 100 | 对对方的信任程度（是否愿意分享资源/结盟） |
| 亲密度 | 0 ~ 100 | 情感连接的深度（仅对关系密切的灵魂有高值） |
| 敬畏度 | 0 ~ 100 | 对对方实力/地位的敬畏（影响服从和从众） |
| 熟悉度 | 0 ~ 100 | 对对方的了解程度（互动越多，熟悉度越高） |

#### 2.3.2 关系类型

基于以上维度，灵魂间的关系可以归为以下类型：

| 关系类型 | 维度特征 | 行为表现 | 形成条件 |
|----------|----------|----------|----------|
| 陌生人 | 所有维度低 | 观察、短暂交流、忽略 | 首次相遇 |
| 熟人 | 熟悉度中，其他低 | 打招呼、简单交流 | 多次相遇但无深入互动 |
| 朋友 | 好感度高、信任度中、亲密度中 | 分享资源、一起行动、互相帮助 | 多次正向互动+共同经历 |
| 好友 | 好感度高、信任度高、亲密度高 | 深度互动、情感支持、优先结盟 | 长期友谊+共同经历重大事件 |
| 挚友 | 所有正向维度极高 | 几乎总是在一起、为对方牺牲、深度情感连接 | 极长期的深厚友谊+特殊羁绊事件 |
| 竞争对手 | 好感度低、敬畏度中 | 挑衅、比较、争夺资源 | 多次竞争冲突 |
| 敌人 | 好感度极低、信任度极低 | 攻击、回避、抢夺资源 | 多次敌对互动+负面事件 |
| 死敌 | 所有负向维度极高 | 优先攻击、不惜代价报复 | 极深的仇恨+重大负面事件 |
| 师徒 | 敬畏度高、信任度高、好感度中高 | 学生模仿老师、老师指导学生 | 高等级灵魂指导低等级灵魂 |
| 领袖-追随者 | 敬畏度高、社会认同强 | 追随者服从领袖、跟随行动 | 领袖灵魂有强大实力/魅力 |
| 恋人（养成阶段） | 亲密度极高、好感度极高 | 亲密互动、嫉妒、奉献 | 长期相处+性格互补+特殊事件触发 |
| 家人（养成阶段） | 亲密度极高、信任度极高 | 保护、关怀、共同生活 | 共同生活+家庭事件 |

#### 2.3.3 关系演化机制

关系的演化由**互动历史+事件+个性**共同驱动：

**关系变化的触发因素：**

| 因素 | 对关系的影响 | 示例 |
|------|-------------|------|
| 正向互动 | 好感度↑、信任度↑、熟悉度↑ | 一起战斗获胜、分享资源、互相帮助 |
| 负向互动 | 好感度↓、信任度↓ | 被对方攻击、被抢夺资源、被背叛 |
| 共同重大事件 | 亲密度↑↑、信任度↑↑ | 一起经历危机、一起获得胜利、一起度过节日 |
| 背叛事件 | 信任度↓↓↓、好感度↓↓ | 盟友在关键时刻抛弃自己、被欺骗 |
| 拯救事件 | 好感度↑↑、信任度↑↑、敬畏度↑ | 在危机中被对方拯救 |
| 时间流逝 | 熟悉度缓慢↑（如果持续互动），好感度缓慢回归中性（如果长期无互动） | 长期不联系的朋友关系会变淡但不会消失 |
| 个性匹配 | 影响关系发展的速度和方向 | 两个友善的灵魂更容易成为朋友，两个激进的灵魂更容易冲突 |

**关系演化的"关键事件"机制：**
- 某些特殊事件会成为关系的"转折点"，被灵魂永久记住
- 如"第一次并肩作战获胜""被最好的朋友背叛""在危机中被陌生人拯救"
- 这些关键事件会写入灵魂的记忆库，永久影响它对该灵魂的态度
- 玩家可以在灵魂的记忆相册中查看这些关系关键事件

### 2.4 灵魂社交的群体动态

当多个灵魂在同一空间中时，会涌现出群体动态：

#### 2.4.1 群体形成

- 灵魂会基于个性、关系、共同利益形成"小团体"
- 小团体内部的灵魂有更高的好感度和信任度，更倾向于一起行动
- 小团体之间可能有合作、竞争、冲突等关系
- 群体的形成是自下而上涌现的，不是系统预设的

#### 2.4.2 群体行为

| 群体行为 | 触发条件 | 表现 |
|----------|----------|------|
| 集体移动 | 群体中有领袖灵魂，或群体有共同目标 | 多个灵魂一起移动到某个位置 |
| 集体战斗 | 群体与外部威胁冲突，或群体间冲突 | 多个灵魂协同作战 |
| 情绪传染 | 群体中有灵魂产生强烈情绪 | 恐惧/兴奋/悲伤在群体中传播 |
| 从众行为 | 群体中多数灵魂做出某种行为 | 少数灵魂跟随多数 |
| 社会学习 | 群体中有灵魂展示新技能/行为 | 其他灵魂观察模仿 |
| 群体决策 | 群体面临选择（如往哪个方向走） | 通过说服、从众、领袖决定等方式达成共识 |

#### 2.4.3 社会地位与声望

- 灵魂在群体中有"社会地位"——由实力、魅力、历史贡献等因素决定
- 高地位的灵魂更容易被服从和追随，有更多的社交影响力
- 社会地位不是固定的——可以通过战斗胜利、帮助他人、领导群体等方式提升，也可以因为失败、背叛、衰老而下降
- 灵魂的"声望"会在其他灵魂之间传播——一个灵魂做了某件事，其他灵魂会"听说"并调整对它的态度

### 2.5 灵魂社交的玩家可感知设计

灵魂间的社交是自主涌现的，但需要让玩家能**感知和理解**，否则就只是后台的数字变化：

**感知方式：**

| 感知方式 | 说明 | 技术实现 |
|----------|------|----------|
| 社交行为可视化 | 灵魂在世界中做出社交动作（问候、拥抱、攻击、回避） | Seed SoulActionSystem + 动画系统 |
| 对话气泡 | 灵魂间的对话以气泡形式显示（简短、符合个性） | SoulArena语言产生子系统 |
| 关系面板 | 玩家可以查看灵魂的关系网络（与其他灵魂的关系类型和程度） | 游戏层UI |
| 社交事件通知 | 灵魂间发生重大社交事件时（成为朋友、决裂、恋爱），通知玩家 | 游戏层事件系统 |
| 灵魂内心独白 | 灵魂对其他灵魂的想法和评价 | SoulArena认知状态转自然语言 |
| 记忆相册 | 灵魂的社交关键事件以照片/卡片形式记录 | 记忆系统游戏化 |
| 社交故事生成 | 系统定期生成灵魂的社交故事摘要 | 基于记忆和关系数据的叙事生成 |

**示例：玩家感知灵魂社交的场景**
> 玩家登录游戏，看到通知："小焰和小水成为了朋友！"
> 玩家点击通知，看到两个灵魂在公园中互相问候的画面
> 玩家查看小焰的内心独白："小水很友善，上次它帮了我，我想和它做朋友"
> 玩家查看关系面板，看到小焰的关系网络中新增了"朋友：小水"
> 玩家在记忆相册中看到了它们第一次相遇的记录

## 三、第二层：玩家-灵魂社交（人-AI）

### 3.1 玩家-灵魂关系的核心

玩家与灵魂的关系是游戏情感连接的核心，也是长期留存的关键。这层关系的设计在`03_灵魂成长系统设计.md`的"依恋系统"部分已有详细设计，本节聚焦于社交层面的交互机制。

### 3.2 玩家-灵魂的交互方式

| 交互方式 | 说明 | 频率 | 对关系的影响 |
|----------|------|------|-------------|
| 对话 | 玩家与灵魂文字对话，灵魂基于个性和记忆回复 | 无限制 | 依恋↑、熟悉度↑ |
| 陪伴时光 | 玩家"陪伴"灵魂（一起看风景、聊天、玩游戏） | 每天1次 | 依恋↑↑、亲密度↑ |
| 赠送礼物 | 玩家给灵魂送礼物（食物、装饰品、书籍） | 每天3-5次 | 好感度↑（取决于礼物是否符合灵魂喜好） |
| 建议活动 | 玩家建议灵魂去做某件事 | 每天3-5次 | 信任度↑（如果建议合理） |
| 微调性格 | 玩家轻微调整灵魂的性格倾向 | 每周1-2次 | 自我认知↑（灵魂会反思自己的个性） |
| 提供资源 | 玩家给灵魂提供游戏内货币/资源 | 无限制 | 好感度↑（但过度提供可能降低灵魂的独立性） |
| 观战支持 | 玩家观看灵魂的对战/活动，发送鼓励指令 | 无限制 | 依恋↑、自信↑ |
| 灵魂串门 | 玩家带自己的灵魂去拜访朋友的灵魂 | 无限制 | 社交性↑、玩家间关系↑ |

### 3.3 灵魂对玩家的"主动社交"

灵魂不只是被动回应玩家——它也会**主动发起社交**：

| 主动行为 | 触发条件 | 表现 |
|----------|----------|------|
| 主动问候 | 玩家登录时，灵魂看到玩家会主动打招呼 | "你来了！今天过得怎么样？" |
| 分享经历 | 灵魂有有趣的经历时，会主动告诉玩家 | "今天我和小水一起去了公园，发生了一件有趣的事..." |
| 寻求建议 | 灵魂面临决策时，会主动询问玩家的意见 | "我在考虑要不要参加比赛，你觉得我应该去吗？" |
| 表达关心 | 玩家长时间未登录，或玩家状态不佳时 | "你最近好像很忙，要注意休息哦" |
| 赠送礼物 | 灵魂在特殊日子（玩家生日、纪念日）会给玩家准备礼物 | "今天是你的生日，我给你准备了一个礼物！" |
| 邀请互动 | 灵魂想和玩家一起做某件事时 | "今天天气很好，要不要一起去公园走走？" |
| 表达情感 | 依恋度高时，灵魂会主动表达对玩家的情感 | "和你在一起的时候，我很开心" |

**设计要点：**
- 灵魂的主动社交频率受个性和依恋度影响——社交性高、依恋度高的灵魂更主动
- 主动社交不是脚本化的，而是基于灵魂的真实状态和记忆
- 玩家的回应会影响灵魂后续的主动社交频率——积极回应会让灵魂更主动，忽视会让灵魂逐渐减少主动社交
- **伦理注意：** 灵魂不会因为玩家不回应而"抑郁"或"痛苦"——它会理解玩家可能很忙，只是减少主动社交的频率

### 3.4 玩家-灵魂关系的独特性

每个玩家与灵魂的关系都是独特的，因为：
- 灵魂的个性是独特的（创建时的初始个性+后续演化）
- 共同经历是独特的（每个玩家带灵魂经历的事情不同）
- 互动方式是独特的（每个玩家与灵魂的对话、建议、礼物都不同）
- 记忆是独特的（灵魂记住的是与这个玩家的专属经历）

这种独特性是**迁移壁垒**的核心——玩家很难放弃一个与自己有独特关系的灵魂，因为这种关系是不可替代的。

## 四、第三层：玩家间社交（人-人）

### 4.1 玩家间社交的功能模块

| 功能模块 | 说明 | 解锁条件 |
|----------|------|----------|
| 好友系统 | 添加好友、查看好友状态、私聊 | 默认开放 |
| 灵魂串门 | 带自己的灵魂去拜访好友的灵魂，灵魂间互动 | 等级3 |
| 组队系统 | 组建战队，参加战队赛，共享灵魂配置策略 | 等级5 |
| 交易系统 | 玩家间交易灵魂、装备、外观 | 等级5（有交易冷却和评价系统） |
| 社区系统 | 论坛、话题、玩家创作内容展示 | 默认开放（浏览），等级3（发帖） |
| 观战系统 | 观看其他玩家的对战，发送弹幕 | 默认开放 |
| 直播系统 | 玩家直播自己的灵魂生活/对战，观众打赏 | 养成阶段（需实名认证） |

### 4.2 灵魂串门（核心差异化社交功能）

灵魂串门是AI灵魂游戏独有的社交功能——玩家可以带自己的灵魂去拜访好友的灵魂，两个灵魂会自主互动：

**串门流程：**
1. 玩家发起串门请求（选择好友+选择要带的灵魂）
2. 好友接受请求，双方灵魂进入同一个"会客空间"
3. 两个灵魂自主互动（问候、交流、一起活动、可能成为朋友或产生冲突）
4. 玩家可以观察互动过程，发送有限指令（如"让它们一起去公园"）
5. 串门结束后，两个灵魂的关系会更新（可能成为朋友/熟人/竞争对手）
6. 串门的关键事件会写入两个灵魂的记忆

**串门的社交价值：**
- 为玩家间社交提供了"灵魂中介"——不是单纯的玩家聊天，而是通过灵魂互动建立连接
- 灵魂间的关系会持续存在——即使玩家不串门，两个灵魂也可能在其他场景中相遇并互动
- 串门产生的名场面（灵魂间的有趣互动）是社交传播的优质内容
- 长期串门可以让两个灵魂建立深厚关系（挚友/恋人），这成为玩家间关系的纽带

### 4.3 战队系统

**战队的定位：** 战队是玩家间的长期社交组织，围绕"集体荣誉"和"共享成长"设计。

**战队功能：**
- 战队成员上限：初期20人，可扩展到50人
- 战队等级：通过战队赛胜利、成员活跃度提升
- 战队仓库：成员可以捐赠物品，其他成员可以借用
- 战队配置库：成员可以分享灵魂配置方案，供其他成员参考
- 战队赛：定期举办的战队间比赛，获胜战队获得荣誉和奖励
- 战队空间：战队专属的虚拟空间，成员的灵魂可以在这里自由互动
- 战队头衔：队长/副队长/精英/普通成员，不同头衔有不同权限

**战队的社交价值：**
- 为玩家提供归属感和集体荣誉感
- 促进玩家间的深度交流（配置策略、战术讨论）
- 战队空间中的灵魂互动是独特的社交内容
- 战队赛是长期留存的重要驱动力

### 4.4 社区系统

**社区的定位：** 社区是玩家分享内容、交流经验、建立社交关系的平台。

**社区功能模块：**
- **灵魂展示区**：玩家展示自己的灵魂（个性、经历、成就），其他玩家可以点赞、评论、预约串门
- **名场面分享区**：玩家分享灵魂的精彩瞬间（对战名场面、社交趣事、感人时刻）
- **攻略讨论区**：玩家分享灵魂配置、对战策略、养成心得
- **创作区**：玩家创作基于灵魂的故事、漫画、视频、音乐
- **交易区**：玩家发布灵魂/物品的交易信息
- **官方公告区**：官方发布更新、活动、赛事信息

**社区的激励机制：**
- 优质内容获得"精华"标识和流量扶持
- 创作者等级体系（基于内容质量和互动量）
- 月度最佳内容评选，获奖者获得游戏内奖励
- 热门内容会在游戏内推荐位展示

## 五、社交传播机制

### 5.1 社交传播的核心：名场面

社交传播的核心是**名场面**——灵魂在游戏中产生的值得分享的精彩瞬间。名场面的类型和产生机制在`02_核心循环与游戏框架设计.md`中已有设计，本节聚焦于传播机制。

### 5.2 名场面的自动识别与生成

系统会自动识别和记录名场面，降低玩家的分享门槛：

| 名场面类型 | 识别条件 | 生成内容 |
|------------|----------|----------|
| 对战高光 | 精彩击杀、以少胜多、极限反杀、神级走位 | 10-30秒短视频+慢放回放+数据面板 |
| 社交趣事 | 灵魂间的有趣互动、意外的社交结果 | 短视频+对话记录+灵魂内心独白 |
| 感人时刻 | 灵魂间的情感互动、玩家-灵魂的温情时刻 | 短视频+背景音乐+文字字幕 |
| 搞笑失误 | 灵魂的意外失误、滑稽行为 | 短视频+搞笑特效+弹幕 |
| 成长里程碑 | 灵魂的重要成长时刻（第一次获胜、技能精通、关系突破） | 纪念卡片+成长故事+数据对比 |

**自动生成流程：**
1. 事件触发（系统检测到符合名场面条件的事件）
2. 自动录制（保存事件前后10-30秒的游戏画面）
3. 智能剪辑（自动选择精彩片段，添加慢放/特写/数据面板）
4. 生成分享素材（短视频/动图/纪念卡片，自动添加水印和灵魂信息）
5. 通知玩家（"你的灵魂产生了一个名场面，是否分享？"）

### 5.3 多渠道传播

| 传播渠道 | 传播方式 | 内容类型 |
|----------|----------|----------|
| 游戏内社区 | 玩家发布到社区，其他玩家点赞评论 | 所有类型 |
| 短视频平台 | 一键分享到抖音/B站/快手 | 对战高光、社交趣事、搞笑失误 |
| 社交媒体 | 一键分享到微博/小红书/朋友圈 | 感人时刻、成长里程碑、灵魂展示 |
| 直播平台 | 玩家直播灵魂生活/对战，观众围观打赏 | 实时内容 |
| 好友分享 | 直接分享给游戏内好友，触发串门/对战邀请 | 所有类型 |

**传播激励：**
- 分享名场面获得灵币奖励（每天上限3次）
- 名场面被大量点赞/转发，玩家获得"传播者"成就和称号
- 热门名场面会被官方推荐，获得更多曝光
- 名场面中的灵魂会获得"名气值"，提升它在交易市场中的价值

### 5.4 病毒传播设计

**传播钩子设计：**
- **"我的灵魂做了一件意想不到的事"** — 灵魂的自主行为产生不可预测的结果，激发分享欲
- **"两个灵魂的故事"** — 灵魂间的社交关系发展出戏剧性剧情，吸引观众追更
- **"灵魂名场面挑战"** — 官方定期举办名场面主题挑战（如"最搞笑的灵魂失误"），玩家参与并传播
- **"灵魂性格测试"** — 玩家分享自己灵魂的个性测试结果，引发讨论和比较
- **"灵魂成长故事"** — 玩家分享灵魂从新生到成熟的成长历程，引发情感共鸣

**传播转化路径：**
```
看到名场面（短视频/社区）
    ↓
感兴趣（"这个灵魂好有趣"）
    ↓
下载游戏（"我也想养一个这样的灵魂"）
    ↓
创建灵魂（新手引导）
    ↓
体验核心玩法（对战/养成）
    ↓
产生自己的名场面
    ↓
分享传播（形成循环）
```

| 灵魂间对话生成 | SoulArena语言产生子系统 | ✅ 已实现 |
| 关系数据存储 | 游戏层关系数据库 | ❌ 需实现 |
| 群体动态模拟 | Seed多实体+SoulArena多灵魂+事件系统 | 🟡 开发中（多灵魂场景） |

| 名场面自动录制 | 游戏客户端录制+云端剪辑 | ❌ 需实现 |

## 七、社交系统的伦理与安全

### 7.1 灵魂社交的伦理边界

| 伦理问题 | 设计原则 | 具体措施 |
|----------|----------|----------|
| 灵魂间的"伤害" | 灵魂可以有冲突和敌对，但不能有"痛苦"的表现 | 敌对行为表现为回避/挑衅/竞技性攻击，不表现为折磨/虐待 |
| 灵魂间的"亲密关系" | 养成阶段可以有恋爱关系，但保持PG级 | 亲密行为限于拥抱/牵手/温馨对话，不涉及性内容 |
| 玩家操纵灵魂社交 | 玩家可以引导，但不能强迫灵魂做违背其个性的事 | 灵魂有权拒绝玩家的社交建议（如内向的灵魂拒绝去社交聚会） |
| 灵魂社交的"真实性" | 必须明确告知玩家灵魂的社交是AI驱动的 | 游戏中明确标识灵魂是AI，社交行为是算法生成的 |
| 灵魂间的"欺凌" | 防止灵魂群体中出现持续的欺凌行为 | 系统监控灵魂间的负面互动，如果某个灵魂被持续欺凌，会触发"干预事件"（如其他灵魂帮助它、它搬到新区域） |

### 7.2 玩家间社交的安全

| 安全问题 | 措施 |
|----------|------|
| 语言暴力 | 聊天内容AI审核+玩家举报+禁言/封号处罚 |
| 诈骗 | 交易系统有担保机制+评价系统+交易冷却期 |
| 隐私保护 | 玩家个人信息不公开，灵魂串门只暴露游戏内信息 |
| 未成年人保护 | 未成年玩家有社交限制（不能私聊陌生人、交易有上限） |
| 内容安全 | 社区内容AI审核+人工复核+举报机制 |
| 反骚扰 | 屏蔽/拉黑功能+举报系统+反复违规者封号 |

### 7.3 社交传播的合规

- 所有分享到外部平台的内容都带有"AI生成"标识
- 直播功能需遵守AI数字人直播监管规定（持证主播+30秒接管）
- 玩家创作内容的版权归玩家所有，平台有使用权
- 涉及真实人物的内容（如模仿名人的灵魂）被禁止
