## 设计风格规范

### 绝对禁止
- ❌ 3D等距视角（isometric）
- ❌ 3D建模渲染
- ❌ 透视、体积光照、3D阴影
- ❌ 高饱和彩虹色、工业软件灰色

### 强制要求
- ✅ 2D像素风格（Pixel Art），清晰像素块边缘
- ✅ RTS竞技场是2D俯视角（top-down / bird's eye view）
- ✅ 角色用像素精灵图（pixel sprite）
- ✅ 配色严格深紫+金色像素奇幻风格
- ✅ 像素分辨率感：角色32x32或64x64，场景瓦片16x16或32x32
