# 战策UI设计资源清单

## 概述
本目录存放战策（Battleplan）视觉提升P0/P1/P2所需的UI设计资源。
所有资源均为AI生成，无版权问题。
设计风格：像素奇幻（Pixel Fantasy），深紫(#1f1a2e) + 金色(#cc9933/#ffd65c)配色。

## 战策集成说明
1. UI皮肤图集：战策开发时将图集切片为各组件，配置9-slice边框，生成.tres样式文件
