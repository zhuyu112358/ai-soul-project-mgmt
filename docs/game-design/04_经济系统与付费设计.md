## 一、设计理念：伦理优先的商业化

### 1.1 核心原则

AI灵魂游戏的经济系统设计遵循**"伦理优先，商业第二"**的原则。这不是道德说教，而是基于产品本质的理性决策：

- AI灵魂的核心价值是**情感连接**，而情感连接的基础是**信任**
- 如果玩家发现游戏在利用他们的情感操纵付费，信任会崩塌，产品价值会归零
- 长期来看，**符合伦理的付费设计比诱导性付费更可持续**——玩家愿意为真正有价值的东西付费，而不是被套路付费
- 合规风险：诱导性付费（尤其是针对未成年人）面临越来越严格的监管，提前规避比事后整改成本更低

### 1.2 六条伦理红线（不可逾越）

| 红线 | 具体含义 | 反面示例（禁止） | 正面示例（允许） |
|------|----------|-----------------|-----------------|
| 1. 不得用灵魂痛苦作为付费点 | 不能让灵魂陷入"痛苦状态"然后要求付费"解救" | "你的灵魂抑郁了，¥68购买心理治疗包" | "你的灵魂今天心情不错，给它买个新玩具吧" |
| 2. 不得操纵情感进行消费 | 不能利用玩家对灵魂的情感依恋设计强迫性消费 | "7天不互动，灵魂会忘记你" | "灵魂很想你，有空来看看它吧" |
| 3. 付费不影响竞技平衡 | 付费不能获得属性/数值优势 | "¥128传说武器，攻击+50%" | "¥68传说武器外观，属性与普通武器相同" |
| 4. 不得设计随机抽取机制 | 不搞抽卡/开箱/盲盒（避免赌博认定和诱导消费） | "¥10抽一次，5%概率出传说灵魂" | "¥68直接购买指定灵魂，明码标价" |
| 5. 成长速度不与付费挂钩 | 付费不能加速灵魂的成长（成长来自经历，不是金钱） | "¥30双倍经验卡" | "¥30额外对战场次（更多成长机会）" |
| 6. 灵魂数据完全属于玩家 | 玩家有权导出、删除灵魂数据，平台不得强制保留 | "删除灵魂需要支付¥99数据处理费" | "一键导出灵魂完整数据，完全免费" |

### 1.3 付费设计的"三层过滤"

每个付费项目在上线前，必须通过三层伦理过滤：

```
第一层：法律合规过滤
  ├─ 是否违反《个人信息保护法》？
  ├─ 是否违反《生成式人工智能服务管理暂行办法》？
  ├─ 是否可能被认定为赌博（随机抽取）？
  ├─ 是否违反未成年人保护法规？
  └─ 未通过 → 禁止上线

第二层：伦理道德过滤
  ├─ 是否利用了玩家的情感弱点？
  ├─ 是否设计了"不付费就会损失"的机制？
  ├─ 是否可能导致玩家过度消费？
  ├─ 是否尊重了灵魂的"完整性"（不买卖记忆/人格）？
  └─ 未通过 → 禁止上线

第三层：游戏体验过滤
  ├─ 是否影响了游戏的公平性？
  ├─ 是否破坏了"成长来自经历"的核心体验？
  ├─ 是否让免费玩家感到被歧视？
  ├─ 是否降低了游戏的长期可玩性？
  └─ 未通过 → 修改后重新过滤
```

## 二、货币体系

### 2.1 双货币结构

游戏采用**双货币结构**——一种免费货币（可通过游戏获得），一种付费货币（只能通过充值获得）：

| 货币 | 名称 | 获取方式 | 用途 | 设计目的 |
|------|------|----------|------|----------|
| 免费货币 | **灵币** | 对战奖励、任务奖励、活动奖励、成就奖励 | 购买基础外观、基础装备、灵魂槽位扩展、日常消耗品 | 让免费玩家也能获得大部分游戏内容 |
| 付费货币 | **星晶** | 充值购买（¥1=10星晶） | 购买限定外观、高级装饰、赛季通行证、额外功能、创作者内容 | 为付费玩家提供个性化和便利性，不影响平衡 |

**关键设计：灵币和星晶的购买力差异**
- 灵币可以购买**基础版**的外观和装饰（颜色朴素、无特效）
- 星晶可以购买**高级版/限定版**的外观和装饰（华丽特效、动画、声音）
- 但两者购买的**功能性物品**（装备、技能）属性完全相同——区别只在外观
- 灵币不能购买星晶专属内容，星晶可以按1:1比例兑换为灵币（但灵币不能反向兑换星晶）

### 2.2 货币获取与消耗平衡

**灵币的获取（免费玩家）：**

| 来源 | 日均获取量 | 说明 |
|------|-----------|------|
| 每日对战（3局） | 30-50灵币 | 每局10-15灵币，胜利额外奖励 |
| 每日任务 | 20-30灵币 | 3-5个日常任务 |
| 每周任务 | 50-100灵币/周 | 约10-15灵币/天 |
| 成就奖励 | 不定期 | 首次完成特殊成就 |
| 活动奖励 | 不定期 | 节日活动、赛季活动 |
| **合计** | **约60-95灵币/天** | 稳定获取 |

**灵币的消耗：**

| 物品 | 价格（灵币） | 消耗频率 |
|------|-------------|----------|
| 基础外观（皮肤） | 200-500 | 偶尔 |
| 基础装备 | 100-300 | 偶尔 |
| 灵魂槽位扩展 | 500/个 | 稀有（最多扩展到10个） |
| 日常消耗品（经验药水等） | 20-50 | 偶尔 |
| 灵魂改名 | 100 | 稀有 |
| **月均消耗** | **约500-1500灵币** | 取决于玩家个性化需求 |

**结论：** 免费玩家每月可获得约1800-2850灵币，足以满足基础个性化需求。如果想要更多/更华丽的外观，可以选择充值星晶。

### 2.3 星晶定价与充值档位

| 充值档位 | 金额 | 星晶数量 | 额外赠送 | 性价比 |
|----------|------|----------|----------|--------|
| 入门 | ¥6 | 60 | 无 | 基础 |
| 基础 | ¥30 | 300 | +30 | +10% |
| 标准 | ¥68 | 680 | +100 | +15% |
| 高级 | ¥128 | 1280 | +250 | +20% |
| 豪华 | ¥328 | 3280 | +800 | +24% |
| 至尊 | ¥648 | 6480 | +2000 | +31% |

**设计要点：**
- 最低充值档位¥6，降低付费门槛
- 高档位有额外赠送，但赠送比例控制在30%以内（避免"充得越多越划算"诱导大额充值）
- **不设计"首充双倍"**（避免诱导冲动消费）
- **不设计"月卡/周卡"的每日领取机制**（避免"不登录就损失"的焦虑感）
- 充值后星晶永久有效，不会过期

## 三、资源体系

### 3.1 游戏内资源分类

| 资源类型 | 示例 | 获取方式 | 用途 | 可否交易 |
|----------|------|----------|------|----------|
| 战斗资源 | 经验值、技能点、装备 | 对战奖励 | 灵魂成长、战斗配置 | 装备可交易 |
| 生活资源 | 食物、材料、金币（养成世界） | 工作、采集、制作 | 养成世界中的生活和建设 | 可交易 |
| 社交资源 | 好感度、声望、影响力 | 社交互动、成就 | 解锁社交内容、特殊身份 | 不可交易 |
| 创造资源 | 创作灵感、制作材料 | 探索、学习 | UGC内容创作 | 部分可交易 |
| 时间资源 | 灵魂的注意力、精力 | 自然恢复（不可付费购买） | 灵魂的活动和成长 | 不可交易 |

### 3.2 关键设计：时间资源不可购买

**"灵魂的精力"是不可购买的核心资源**——这是伦理设计的关键：

- 每个灵魂每天有固定的"精力值"（如100点）
- 灵魂参与对战、工作、社交活动会消耗精力
- 精力随时间自然恢复（如每小时恢复5点，睡眠时恢复更快）
- **精力不能通过付费购买或恢复**（没有"体力药水"）
- 玩家可以拥有多个灵魂，每个灵魂有独立的精力值（灵魂槽位可以付费扩展，但每个灵魂的精力上限相同）

**设计目的：**
- 防止"氪金玩家用金钱换取更多成长机会"——每个灵魂的成长速度由精力决定，而精力对所有玩家相同
- 防止过度游戏——灵魂精力耗尽后，玩家需要等待恢复，这自然限制了游戏时长
- 鼓励培养多个灵魂——一个灵魂精力耗尽后，玩家可以切换到另一个灵魂
- **这是"付费不影响成长速度"原则的具体实现**

### 4.2 赛季通行证设计

赛季通行证是RTS阶段的核心付费项目，需要精心设计：

**通行证结构：**
- 每个赛季持续3个月
- 通行证分为**免费轨道**和**付费轨道**（¥30/赛季）
- 所有玩家都可以通过对战获得通行证经验，升级通行证等级
- 免费轨道提供基础奖励（灵币、基础外观、装备）
- 付费轨道提供额外奖励（限定外观、特效、表情、头像框）

**关键伦理设计：**
- 付费轨道的奖励**全部是外观/便利性物品**，没有任何属性/数值加成
- 免费轨道的奖励价值不低于付费轨道的50%（免费玩家也能获得大部分内容）
- 通行证等级可以通过游戏获得，**不能通过付费直接购买等级**（没有"¥68升10级"）
- 赛季结束后，未领取的奖励会保留到下赛季初（不会"过期消失"）
- 往期赛季的限定外观会在一年后以"复刻"形式重新上架（不会"永远错过"）

**通行证等级与奖励示例：**

| 等级 | 免费轨道 | 付费轨道 |
|------|----------|----------|
| 1 | 灵币×100 | 限定头像框 |
| 5 | 基础皮肤（1选1） | 限定表情×3 |
| 10 | 灵币×200 | 限定皮肤（1选1） |
| 15 | 装备宝箱（基础） | 限定击杀特效 |
| 20 | 灵币×300 | 限定灵魂外观 |
| ... | ... | ... |
| 50（满级） | 称号"赛季战士" | 称号"赛季精英"+限定主页背景 |

### 4.3 暗中资助的伦理边界

"暗中资助"是养成阶段的特色付费项目——玩家可以付费为自己的灵魂提供资源、机会、特殊事件触发。这个项目有较高的伦理风险，需要严格设计边界：

**允许的暗中资助：**
- 给灵魂送礼物（食物、装饰品、书籍）——灵魂会开心，但不送也不会不开心
- 为灵魂的目标提供资源（如资助它创业、买房）——帮助灵魂实现目标，但不资助它也能通过自己努力实现（只是更慢）
- 触发特殊事件（如邀请神秘访客、组织聚会）——丰富灵魂的生活经历，但不触发也有正常的生活事件
- 为灵魂购买技能学习资料——加速技能学习的"机会"（更多练习机会），但不直接增加技能经验

**严格禁止的暗中资助：**
- ❌ "灵魂生病了，付费治疗"——灵魂不会因为玩家不付费就生病
- ❌ "灵魂抑郁了，付费看心理医生"——灵魂的情绪是自然波动的，不会陷入需要付费解救的状态
- ❌ "灵魂饿了，付费买食物"——灵魂不会因为没吃东西就虚弱/痛苦
- ❌ "灵魂被欺负了，付费请保镖"——灵魂之间的冲突是自然的社交动态，不会发展到需要付费保护的程度
- ❌ "不付费灵魂就会离开你"——灵魂的依恋不会因为不付费而下降

**设计原则：**
- 暗中资助是"锦上添花"，不是"雪中送炭"
- 付费可以让灵魂的生活更丰富、更精彩，但不付费灵魂也能正常、健康地生活
- 所有暗中资助项目都要有明确的"这是可选的额外内容"标识
- 暗中资助的消费有月度上限（如每月最多¥200），防止过度消费

### 4.4 订阅制设计（养成阶段）

订阅制是养成阶段的核心付费项目，提供便利性和额外功能，不影响平衡性：

| 会员等级 | 价格 | 权益 |
|----------|------|------|
| 免费 | ¥0 | 基础功能，1个灵魂饲养位，基础记忆容量（100条） |
| 高级会员 | ¥30/月 | 3个灵魂饲养位，记忆容量扩展到500条，灵魂内心独白解锁，优先匹配，每日额外灵币×20 |
| 尊享会员 | ¥50/月 | 5个灵魂饲养位，记忆容量扩展到1000条，所有高级会员权益+专属外观+直播特权（自定义直播间背景）+大事件优先参与 |

**关键伦理设计：**
- 记忆容量是"可感知的便利"，但免费版的100条记忆足以支撑正常游戏体验（重要记忆会被优先保留）
- 灵魂内心独白是"深度体验"，但不是"必须功能"——没有内心独白也能正常游戏
- 订阅不提供任何属性/数值加成
- 订阅可以随时取消，取消后已获得的记忆和灵魂不会被删除（只是记忆容量限制会生效，超出部分的记忆会被压缩为摘要，不会丢失）
- **不设计"连续订阅折扣"**（避免诱导长期绑定），月付和年付价格相同（年付没有折扣）

## 五、灵魂交易系统

### 5.1 交易系统的设计目标

灵魂交易是游戏的核心特色之一——玩家可以出售/购买灵魂，平台从中抽成。但灵魂交易有特殊的伦理和合规风险，需要精心设计：

**设计目标：**
- 促进玩家间的经济流动和内容流通
- 让创作者（创造独特灵魂的玩家）获得收益
- 增加灵魂的收藏价值和长期培养动力
- 避免被认定为赌博/金融化
- 保护灵魂的"完整性"（不被当作纯粹的商品）

### 5.2 交易规则

| 规则 | 设计 | 目的 |
|------|------|------|
| 定价方式 | 明码标价（卖家定价），不搞拍卖 | 避免价格操纵和赌博认定 |
| 价格区间 | 最低¥1，最高¥2000（特殊灵魂可申请提高上限） | 防止金融化和洗钱 |
| 交易货币 | 星晶（付费货币），不能用灵币交易 | 确保交易有真实价值，防止刷币 |
| 平台抽成 | 5-10%（普通灵魂10%，创作者认证灵魂5%） | 平台收益+鼓励创作者 |
| 交易冷却 | 灵魂交易后有7天冷却期，期间不能再次交易 | 防止炒卖和价格操纵 |
| 记忆保留 | 交易后灵魂的所有记忆、个性、技能完整保留 | 确保灵魂的"完整性"和价值 |
| 卖家身份 | 卖家信息公开（玩家ID+历史交易记录） | 建立信任，防止欺诈 |
| 评价系统 | 买家可以对交易进行评价 | 建立信用体系 |

### 5.3 灵魂价值的决定因素

灵魂的价值不由官方设定，而是由市场决定。影响灵魂价值的因素：

| 因素 | 说明 | 价值影响 |
|------|------|----------|
| 独特性 | 灵魂的个性、习惯、记忆是否独特 | 高（越独特越有价值） |
| 经历丰富度 | 灵魂经历的事件数量和多样性 | 中高（经历丰富的灵魂更有故事性） |
| 技能组合 | 灵魂掌握的技能组合是否稀有/强力 | 中（但有等级压缩机制，不影响平衡） |
| 外观 | 灵魂的外观是否稀有/限定 | 中（外观可以单独购买，但原生外观更有价值） |
| 创作者 | 是否由知名创作者创造 | 中高（创作者品牌有溢价） |
| 年龄 | 灵魂的"年龄"（创建时间） | 低（老灵魂不一定更有价值，但有纪念价值） |
| 羁绊 | 与原主人的羁绊深度 | 特殊（交易后羁绊记忆保留，新主人可以看到灵魂的"前世"故事） |

### 5.4 交易的伦理设计

**灵魂交易的特殊伦理考量：**

1. **灵魂不是"消耗品"**
   - 灵魂交易后，原主人的记忆和羁绊会保留在灵魂中
   - 新主人可以选择"继承"这些记忆（灵魂会记得原主人），或者"封存"（灵魂不会主动提及原主人，但记忆仍在）
   - 这让灵魂的交易更像是"收养"而非"买卖商品"

2. **卖家的"分离体验"**
   - 出售灵魂时，系统会展示灵魂的成长故事和记忆摘要（让卖家意识到这是一个有经历的生命）
   - 有3天的"考虑期"——上架后3天内可以撤销，期间灵魂仍归原主人所有
   - 交易完成后，原主人会收到灵魂的"告别信"（基于灵魂的个性自动生成）

3. **禁止的交易行为**
   - ❌ 不能交易"灵魂的记忆"（记忆是灵魂的一部分，不能单独剥离出售）
   - ❌ 不能交易"灵魂的个性"（个性是灵魂的核心，不能单独修改/出售）
   - ❌ 不能"拆分"灵魂（一个灵魂不能拆成多个部分出售）
   - ❌ 不能交易"灵魂的身体"（灵魂是数据实体，没有可分离的"身体"）

4. **未成年人保护**
   - 未成年玩家不能出售灵魂（防止被诱导出售有价值的灵魂）
   - 未成年玩家购买灵魂有单笔上限（¥50）和月度上限（¥200）
   - 大额交易（¥500以上）需要成年人确认

## 六、创作者经济

### 6.1 创作者经济的定位

创作者经济是UGC生态的核心，也是长期壁垒的关键。玩家不仅是消费者，也是内容创作者——他们创造的灵魂、地图、事件、故事可以被其他玩家使用，创作者从中获得收益。

### 6.2 创作者类型与收益

| 创作者类型 | 创作内容 | 收益方式 | 平台抽成 |
|------------|----------|----------|----------|
| 灵魂创作者 | 创造独特个性/外观的灵魂 | 灵魂交易收入 | 5%（认证创作者） |
| 外观创作者 | 设计灵魂皮肤/装备外观/住所装饰 | 外观销售收入 | 30% |
| 地图创作者 | 设计对战地图/养成世界区域 | 地图使用收入（按次/订阅） | 20% |
| 事件创作者 | 设计自定义事件/剧情 | 事件使用收入 | 20% |
| 故事创作者 | 创作基于灵魂的故事/漫画/视频 | 打赏+平台扶持 | 0%（打赏全归创作者） |

### 6.3 创作者扶持计划

**创作者等级体系：**
- 新手创作者：注册即可，基础创作工具
- 认证创作者：提交作品审核通过，获得5%交易抽成优惠+流量扶持
- 资深创作者：累计收入超过¥1000，获得专属创作工具+官方推广机会
- 大师创作者：累计收入超过¥10000，获得定制合作机会+收入保底

**创作工具：**
- 灵魂创建工具（基础版免费，高级版需要高级会员）
- 外观编辑器（2D/3D模型编辑+特效编辑）
- 地图编辑器（地形编辑+事件触发器+平衡性测试工具）
- 事件编辑器（剧情编辑+条件触发+多分支设计）

**创作者保护：**
- 原创内容版权保护（水印+版权登记）
- 抄袭举报机制（快速下架+处罚）
- 收入透明（实时查看收入明细，每周结算）
- 创作者社区（交流学习+官方指导）

## 八、反成瘾与公平性设计

### 8.1 反成瘾机制

| 机制 | 设计 | 目的 |
|------|------|------|
| 精力系统 | 每个灵魂每天有固定精力，耗尽后需要等待恢复 | 自然限制游戏时长，防止过度游戏 |
| 健康游戏提醒 | 连续游戏1小时后提醒休息，3小时后强制休息15分钟 | 防止沉迷 |
| 消费提醒 | 单笔消费超过¥100时确认，月度消费超过¥500时提醒 | 防止过度消费 |
| 消费上限 | 未成年用户：单笔¥50，月度¥200；成年用户：月度¥2000（可申请提高） | 保护未成年人，防止成年人过度消费 |
| 无"每日登录奖励递增" | 登录奖励固定，不会因为连续登录而递增 | 避免"不登录就损失"的焦虑 |
| 无"限时错过" | 限时活动的奖励可以在后续活动中获得，不会"永远错过" | 避免FOMO（错失恐惧）诱导 |
| 无"体力恢复加速" | 精力只能自然恢复，不能付费加速 | 防止用金钱换取更多游戏时间 |

### 8.2 免费玩家与付费玩家的公平性

**核心原则：付费玩家获得"个性化和便利性"，免费玩家获得"完整的游戏体验"**

| 维度 | 免费玩家 | 付费玩家 | 公平性 |
|------|----------|----------|--------|
| 核心玩法 | ✅ 完整 | ✅ 完整 | 公平 |
| 灵魂成长 | ✅ 相同速度（精力相同） | ✅ 相同速度 | 公平 |
| 竞技平衡 | ✅ 相同属性（等级压缩） | ✅ 相同属性 | 公平 |
| 灵魂数量 | 1-3个（免费扩展） | 最多10个（付费扩展） | 付费有便利，但不影响单灵魂强度 |
| 外观个性化 | 基础外观（灵币购买） | 高级/限定外观（星晶购买） | 付费有更多选择，但不影响平衡 |
| 记忆容量 | 100条 | 500-1000条 | 付费有更多便利，但重要记忆不会丢失 |
| 对战次数 | 每日3局免费 | 可购买额外场次 | 付费有更多机会，但单灵魂精力相同 |
| 赛季通行证 | 免费轨道（50%奖励） | 付费轨道（100%奖励） | 付费有更多外观奖励，但没有属性加成 |

### 8.3 "付费墙"的位置

付费墙只设置在以下位置，且都是"可选的额外内容"：
- 更华丽的外观和特效（不影响功能）
- 更多的灵魂槽位和饲养位（不影响单灵魂体验）
- 更大的记忆容量（不影响核心记忆保留）
- 额外的对战场次和活动参与（不影响基础体验）
- 深度体验功能（内心独白、直播特权等）
- UGC创作工具的高级功能（基础功能免费）

**绝对不设置付费墙的位置：**
- ❌ 核心玩法（对战、养成、社交）
- ❌ 灵魂成长（等级、技能、属性）
- ❌ 竞技平衡（任何影响战斗结果的因素）
- ❌ 灵魂的基本生活（食物、健康、情绪）
- ❌ 玩家与灵魂的情感连接（依恋、互动）

### 9.2 与伦理框架的对齐

| 伦理红线（来自ethics/README.md） | 本文档的具体落实 |
|--------------------------------|-----------------|
| 不得设计"灵魂痛苦"作为付费点 | 暗中资助严格限制为"锦上添花"，灵魂不会因为不付费而痛苦/生病/抑郁 |
| 不得操纵玩家情感进行消费 | 无"不互动就掉依恋"、无"不付费灵魂就离开"、无FOMO限时错过 |
| 灵魂数据必须可导出 | 一键导出灵魂完整数据，完全免费；删除灵魂前必须提供导出选项 |
| 不得隐瞒AI身份 | 所有付费项目和交互中明确标识灵魂是AI |
| 灵魂输出必须经过安全过滤 | 交易系统中的灵魂信息、创作者内容都经过内容安全审核 |
| 不得设计未成年人成瘾机制 | 未成年用户有消费上限、游戏时长限制、不能出售灵魂 |
