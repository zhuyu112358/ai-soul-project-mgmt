# 战策 Battleplan 艺术风格指南

> **版本**: v1.0
> **创建日期**: 2026-09-08
> **状态**: 已确认（用户选定）
> **适用范围**: 战策 Battleplan 全部美术资源（UI/角色/场景/特效/图标）

---

## 一、风格定位

### 1.1 核心风格
**2D像素风 + 奇幻魔法主题 + 深紫金色调**

- 整体为2D像素风格（Pixel Art），非3D等距视角
- 主题为灵魂/魔法/奇幻，带有东方神秘元素
- UI采用卡片式布局，金色边框装饰，深紫底色
- 角色为像素精灵图（Sprite Sheet），带多帧动画

### 1.2 参考基准
以下概念图为风格基准，所有新产出需与之保持一致：
- `concept_soul_unit_growth.png` — 灵魂单位成长界面
- `concept_soul_unit_skill_ui_components_upgrade.png` — 技能UI组件
- `concept_soul_unit_sprites.png` — 灵魂单位精灵图
- `concept_soul_unit_talent_tree_ui_components_upgrade.png` — 天赋树UI
- `concept_steam_achievements.png` — Steam成就图标
- `concept_rts_arena_ui_upgrade_v2.png` — RTS竞技场UI（2D像素风版）

### 1.3 禁止风格
- ❌ 3D等距视角（Isometric 3D）
- ❌ 写实风格/照片级渲染
- ❌ 卡通Q版3D渲染
- ❌ 工业软件风/纯数据列表式UI
- ❌ 随意切换配色方案

## 二、配色规范

| 背景底色 | `#1a1428` | 深紫色，所有界面主背景 |
| 背景深色 | `#120e1c` | 更深的紫色，用于面板内层 |
| 金色边框 | `#d4a85c` | 主金色，UI边框/装饰/标题 |
| 金色高亮 | `#f0c878` | 亮金色，悬停/选中/强调 |
| 金色暗部 | `#8b6914` | 暗金色，边框阴影/禁用态 |

### 2.2 功能色

| 用途 | 色值 | 说明 |
|------|------|------|
| 玩家方（蓝） | `#4a9eff` | 玩家灵魂/玩家单位/玩家血条 |
| AI方（红） | `#ff4a4a` | AI灵魂/AI单位/AI血条 |
| 生命值（绿） | `#4ade80` | HP条/治疗/增益 |
| 能量值（蓝） | `#60a5fa` | MP条/能量/法力 |
| 暴击/伤害（橙） | `#f97316` | 暴击飘字/伤害数字 |
| 警告/危险（红） | `#ef4444` | 警告/错误/危险状态 |
| 成功/确认（绿） | `#22c55e` | 成功提示/确认按钮 |

### 2.3 元素色（四元素灵魂）

| 元素 | 色值 | 说明 |
|------|------|------|
| 火 | `#ff6b35` | 火焰橙红色 |
| 水 | `#3b82f6` | 海洋蓝色 |
| 土 | `#a16207` | 大地棕色 |
| 风 | `#22c55e` | 翠绿色 |

### 2.4 渐变规范
- 按钮正常：深紫 `#2a1f3d` → 更深 `#1a1428`，金色边框
- 按钮悬停：稍亮紫 `#3a2f4d` → `#2a1f3d`，亮金色边框+微光
- 按钮按下：深色 `#120e1c` → `#1a1428`，暗金色边框
- 面板：半透明深紫 `rgba(26, 20, 40, 0.9)`，金色1px边框

## 三、分辨率与尺寸规范

### 3.1 基础分辨率
- **游戏内部分辨率**: 1280x720（16:9）
- **UI设计基准**: 1920x1080（设计稿，运行时缩放）
- **像素单位**: 1像素 = 1游戏像素（不缩放像素艺术）

### 3.2 精灵图尺寸

| 资源类型 | 单帧尺寸 | 说明 |
|----------|----------|------|
| 灵魂单位（小） | 32x32 | 战场单位/小型灵魂 |
| 灵魂单位（中） | 48x48 | 主要战斗单位 |
| 灵魂单位（大） | 64x64 | BOSS/大型灵魂 |
| 技能图标 | 32x32 | 技能栏图标 |
| 物品图标 | 32x32 | 背包/物品图标 |
| 状态图标 | 16x16 | buff/debuff小图标 |
| UI按钮 | 可变，最小120x40 | 文字按钮 |

### 3.3 动画帧规范
- 待机动画：4帧循环
- 移动动画：4-6帧循环
- 攻击动画：4-6帧（含前摇/攻击/后摇）
- 受击动画：2-3帧
- 死亡动画：4-6帧
- 特殊技能：6-8帧

## 四、UI设计规范

### 4.1 布局原则
- **卡片式布局**: 所有面板/窗口采用卡片式设计，金色边框
- **圆角**: 4-8px圆角（像素风圆角，非平滑抗锯齿）
- **内边距**: 面板内边距16px，元素间距8-12px
- **层级**: 背景层 → 面板层 → 内容层 → 弹窗层 → 提示层

### 4.2 字体规范
- **标题字体**: 像素风格字体（待确定具体字体文件），字号24-32px，金色
- **正文字体**: 像素风格字体，字号14-16px，浅灰白 `#e0e0e0`
- **数字/数据**: 等宽像素字体，字号14-18px
- **字体颜色**: 标题金色 `#d4a85c`，正文浅灰白 `#e0e0e0`，次要文字灰 `#888888`

### 4.3 按钮规范
- 正常态：深紫渐变背景 + 金色1px边框 + 金色文字
- 悬停态：稍亮背景 + 亮金色边框 + 微光效果
- 按下态：深色背景 + 暗金色边框
- 禁用态：灰紫背景 + 灰色边框 + 灰色文字
- 所有按钮带4px圆角

### 4.4 面板规范
- 背景：半透明深紫 `rgba(26, 20, 40, 0.92)`
- 边框：金色1px `#d4a85c`
- 标题栏：稍深紫背景 + 金色标题文字 + 底部金色分隔线
- 内容区：深紫背景，元素间距8-12px

### 4.5 数据可视化规范
> **核心原则**: 数据以可视化形式表现，不使用纯文本列表

- **生命值**: 球形血条（血球），绿色渐变填充，金色边框
- **能量值**: 球形能量条，蓝色渐变填充，金色边框
- **经验值**: 横向进度条，紫色渐变填充
- **冷却时间**: 技能图标上的扇形遮罩 + 数字倒计时
- **属性数值**: 图标 + 数字，不使用纯文字
- **战斗日志**: 带颜色编码的滚动列表，重要事件高亮

## 五、角色设计规范

### 5.1 灵魂单位
- **形态**: 球形/精灵形灵魂，带元素特征
- **玩家方**: 蓝色系 `#4a9eff`，带蓝色光晕
- **AI方**: 红色系 `#ff4a4a`，带红色光晕
- **元素区分**: 火（橙红火焰）、水（蓝色水波）、土（棕色岩石）、风（绿色气流）
- **动画**: 待机浮动、移动拖尾、攻击前摇/释放、受击闪烁、死亡消散

### 5.2 角色头像
- 尺寸: 64x64 或 96x96
- 风格: 像素风头像，肩部以上
- 边框: 金色边框，选中态亮金色发光

---

## 六、场景设计规范

### 6.1 战斗竞技场
- **视角**: 2D正俯视角（Top-Down），非等距
- **地面**: 石砖/魔法阵纹理，深紫底色 + 金色装饰线条
- **障碍物**: 水晶柱、岩石、魔法封印，像素风
- **边界**: 金色边框/石墙，明确战斗区域
- **氛围**: 粒子光点、魔法阵微光、环境光效

### 6.2 场景背景
- 主菜单: 奇幻战场/灵魂召唤阵，带光影氛围
- 灵魂选择: 灵魂召唤阵，多彩灵魂球漂浮
- 设置: 魔法图书馆/神秘空间
- 战斗结算: 胜利/失败主题背景

---

## 七、特效设计规范

### 7.1 战斗特效
- **技能释放**: 元素色粒子爆发 + 魔法阵光环
- **受击命中**: 闪光 + 粒子飞溅 + 屏幕轻微震动
- **暴击**: 金色闪光 + 放大飘字 + 屏幕震动增强
- **治疗**: 绿色光点上升 + 治愈光环
- **死亡**: 灵魂消散粒子 + 渐隐

### 7.2 UI特效
- **按钮悬停**: 微光 + 轻微放大
- **按钮点击**: 按压反馈 + 波纹
- **面板打开**: 淡入 + 轻微缩放
- **飘字**: 向上浮动 + 渐隐，颜色按类型区分

---

## 八、图标设计规范

### 8.1 通用规范
- 尺寸: 32x32（标准），16x16（小图标）
- 风格: 像素风，带金色边框/底座
- 配色: 功能色区分，保持整体色调统一

### 8.2 图标类型
- 技能图标: 元素色 + 技能特征图形
- 物品图标: 物品形态 + 品质色边框
- 状态图标: buff（绿色向上箭头）/ debuff（红色向下箭头）
- UI图标: 设置/音量/返回/确认等通用符号

---

## 九、资源命名规范

### 9.1 文件命名
- 格式: `{类型}_{名称}_{变体}.png`
- 类型: `ui`/`sprite`/`icon`/`bg`/`effect`/`font`
- 示例:
  - `ui_skill_bar.png`
  - `sprite_soul_fire_idle.png`
  - `icon_skill_fireball.png`
  - `bg_main_menu.png`
  - `effect_hit_flash.png`

### 9.2 目录结构
```
assets/
├── ui/           # UI资源（主题/样式/皮肤）
├── sprites/      # 精灵图（角色/单位/动画）
├── icons/        # 图标（技能/物品/状态/UI）
├── backgrounds/  # 背景图（场景/界面）
├── effects/      # 特效（粒子/纹理/动画帧）
├── fonts/        # 字体文件
└── audio/        # 音频（音效/音乐）
```

## 十、质量检查清单

每批新资源产出后，按以下清单检查：

- [ ] 风格是否为2D像素风（非3D等距）
- [ ] 主色调是否为深紫+金色
- [ ] 配色是否在规范色值范围内
- [ ] 分辨率/尺寸是否符合规范
- [ ] UI是否采用卡片式布局+金色边框
- [ ] 数据是否可视化（非纯文本列表）
- [ ] 角色是否带元素特征和动画帧
- [ ] 场景是否为2D正俯视角
- [ ] 文件命名是否规范
- [ ] 是否与已有资源风格一致
