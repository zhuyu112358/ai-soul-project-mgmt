## 一、设计理念：声音是灵魂的呼吸

### 1.1 音频的定位

在AI灵魂游戏中，音频不是"背景音乐+音效"的简单组合，而是**沉浸式体验的核心载体**——它让玩家感受到灵魂是"活的"，让世界变得有温度。

| 维度 | 传统游戏音频 | AI灵魂游戏音频 |
|------|-------------|---------------|
| 音乐 | 预设BGM，按场景切换 | 动态音乐，随灵魂情绪和场景实时变化 |
| 音效 | 预设音效，触发播放 | 部分音效由AI生成，与灵魂个性和行为匹配 |
| 语音 | 预设配音，固定台词 | TTS生成，灵魂的语音有个性和情绪 |
| 环境音 | 预设环境音，循环播放 | 基于Seed声学系统的真实空间音频，有遮挡和衰减 |
| 交互 | 点击/按钮音效 | 灵魂的回应声音（每个灵魂有独特的声音） |

### 1.2 核心设计原则

**原则1：声音反映灵魂状态**
- 灵魂的情绪、状态、个性通过声音传达（快乐时音调升高，悲伤时音调降低，紧张时语速加快）
- 玩家可以"听"出灵魂的状态，不需要看文字
- 声音是灵魂个性的重要组成部分（每个灵魂有独特的声音特质）

**原则2：动态适应，不重复**
- 音乐随场景、情绪、时间、天气动态变化，不是简单的循环播放
- 同一首曲子在不同情境下有不同的编排（如战斗时加入鼓点，平静时只有钢琴）
- 避免听觉疲劳——长时间游戏后音乐自然变化，不让玩家觉得"又在循环"

**原则3：空间真实感**
- 基于Seed的AcousticPropagation声学遮挡系统，声音有真实的空间感
- 墙后的声音会衰减和模糊，远处的声音会变小，洞穴中有回声
- 玩家可以通过声音判断周围环境（"听到水声，附近有河流"）
- 3D空间音频（支持耳机的HRTF）

**原则4：可访问性优先**
- 所有重要的音频信息都有视觉替代（字幕、视觉提示、振动反馈）
- 听障玩家可以完整体验游戏
- 音频设置丰富（音量调节、字幕开关、语音速度、音效替代）
- 不设计"必须听声音才能通过"的关卡

**原则5：技术约束下的高品质**
- 单灵魂月成本¥0.5-2的约束下，音频方案必须成本可控
- TTS使用高效模型，不追求最顶级的音质但要有足够的表现力
- 音乐使用程序化生成+预设素材混合，降低制作成本
- 音频文件压缩优化，不占用过多存储空间和带宽

## 二、音乐系统

### 2.1 动态音乐架构

**四层音乐结构：**

```
┌─────────────────────────────────────────┐
│  第四层：旋律层（Melody）                │
│  灵魂的主题旋律，随情绪变化音调和节奏    │
├─────────────────────────────────────────┤
│  第三层：和声层（Harmony）               │
│  和弦进行，决定音乐的情感色彩            │
├─────────────────────────────────────────┤
│  第二层：节奏层（Rhythm）                │
│  鼓点和打击乐，决定音乐的能量和速度      │
├─────────────────────────────────────────┤
│  第一层：氛围层（Ambience）              │
│  环境音和持续音垫，营造场景氛围          │
└─────────────────────────────────────────┘
```

**动态变化机制：**
- 每一层可以独立变化，组合出无限的音乐变体
- 场景变化时，各层平滑过渡（crossfade），不是突然切换
- 灵魂情绪变化时，旋律层和和声层优先变化
- 战斗/紧张场景时，节奏层加强（鼓点加快、加入打击乐）
- 平静/休闲场景时，节奏层减弱（只有轻柔的打击乐或无鼓点）

### 2.2 场景音乐

| 场景 | 音乐风格 | 乐器配置 | 节奏 | 调性 |
|------|----------|----------|------|------|
| 小镇白天 | 温暖、平和、田园 | 钢琴、木吉他、长笛、弦乐 | 中慢板（80-100BPM） | 大调为主 |
| 小镇夜晚 | 宁静、神秘、温柔 | 钢琴、竖琴、合成器pad、钟琴 | 慢板（60-80BPM） | 小调/大调交替 |
| 竞技场 | 紧张、激烈、史诗 | 管弦乐、打击乐、铜管、电吉他 | 快板（120-160BPM） | 小调/减音阶 |
| 探索-森林 | 自然、神秘、清新 | 木吉他、长笛、竖琴、自然音 | 中板（90-110BPM） | 调式/五声音阶 |
| 探索-洞穴 | 幽暗、神秘、紧张 | 合成器pad、低音提琴、钟琴、回声 | 慢板（60-80BPM） | 小调/全音阶 |
| 探索-雪山 | 辽阔、清冷、壮丽 | 弦乐、钢琴、铜管、合唱 | 慢板（50-70BPM） | 大调/调式 |
| 遗迹 | 古老、神秘、庄严 | 管弦乐、合唱、钟琴、合成器 | 慢板（60-80BPM） | 调式/全音阶 |
| 战斗 | 紧张、激烈、动感 | 打击乐、低音提琴、铜管、电吉他 | 急板（140-180BPM） | 小调/减音阶 |
| 胜利 | 欢快、荣耀、振奋 | 管弦乐、铜管、打击乐、合唱 | 中快板（100-120BPM） | 大调 |
| 失败 | 悲伤、反思、温柔 | 钢琴、弦乐、长笛 | 慢板（50-70BPM） | 小调 |
| 节日 | 欢快、热闹、庆典 | 民族乐器、打击乐、铜管、手风琴 | 快板（120-140BPM） | 大调 |
| 灵魂之泉 | 神圣、温柔、新生 | 合唱、竖琴、钟琴、合成器pad | 慢板（50-70BPM） | 调式/大调 |

### 2.3 情绪音乐

**灵魂情绪对音乐的影响：**

| 灵魂情绪 | 音乐变化 | 示例 |
|----------|----------|------|
| 快乐 | 音调升高，节奏加快，加入明亮乐器 | 钢琴旋律变欢快，加入铃鼓 |
| 悲伤 | 音调降低，节奏减慢，加入柔和弦乐 | 旋律变缓慢，加入大提琴 |
| 紧张 | 节奏加快，加入不协和和弦，鼓点加强 | 鼓点变快，加入低音提琴震音 |
| 愤怒 | 节奏急促，加入打击乐和铜管，不协和 | 加入军鼓和铜管，旋律变尖锐 |
| 平静 | 节奏适中，柔和乐器，协和和弦 | 钢琴独奏，轻柔弦乐垫 |
| 好奇 | 旋律跳跃，加入木琴/钟琴，节奏轻快 | 加入木琴，旋律变灵动 |
| 恐惧 | 节奏减慢或不规则，加入不协和音，低音 | 加入低音提琴拨弦，不规则节奏 |
| 爱 | 旋律温柔，加入弦乐和竖琴，节奏舒缓 | 加入竖琴琶音，弦乐渐强 |

**实现方式：**
- 音乐系统读取灵魂的当前情绪状态（SoulArena的情绪子系统）
- 根据情绪状态调整音乐参数（音调、节奏、乐器配置、和弦进行）
- 情绪变化时音乐平滑过渡（2-5秒的crossfade）
- 多个灵魂在场时，以玩家关注的灵魂的情绪为主

### 2.4 时间与天气音乐

**时间对音乐的影响：**
- 清晨：清新、柔和，以木管和钢琴为主
- 白天：温暖、活跃，乐器配置丰富
- 傍晚：温暖、略带忧伤，加入弦乐和铜管
- 夜晚：宁静、神秘，以钢琴和合成器pad为主
- 深夜：幽暗、安静，几乎只有环境音和微弱的音乐

**天气对音乐的影响：**
- 晴天：明亮、开朗，大调为主
- 阴天：柔和、内敛，调式/小调
- 雨天：温柔、忧郁，加入雨声和钢琴
- 雪天：清冷、辽阔，加入合唱和弦乐
- 暴风雨：紧张、激烈，加入雷声和打击乐
- 雾天：神秘、朦胧，加入合成器pad和回声

### 2.5 程序化音乐生成

**设计理念：** 使用程序化音乐生成（Procedural Music Generation）降低音乐制作成本，同时提供无限的音乐变体。

**技术方案：**
- 基础：预设音乐素材（旋律片段、和弦进行、节奏pattern、乐器采样）
- 生成：根据场景/情绪/时间/天气参数，实时组合素材生成音乐
- 变化：每次播放都有细微变化（旋律变奏、和弦替代、节奏加花）
- 过渡：场景变化时平滑过渡，不突兀

**成本控制：**
- 预设素材制作量：约20-30小时的音乐素材（可组合出数百小时的变体）
- 不需要为每个场景单独作曲，降低制作成本
- 素材可以复用（同一旋律片段在不同编排下用于不同场景）
- 后续更新只需添加新素材，不需要重新制作全部音乐

## 三、音效设计

### 3.1 环境音效

**基于Seed声学系统的真实环境音：**

| 环境 | 音效 | 空间特性 |
|------|------|----------|
| 小镇 | 人声嘈杂、脚步声、马车声、商店叫卖、鸟鸣 | 开放空间，声音自然传播 |
| 森林 | 鸟鸣、虫鸣、风声、树叶沙沙、溪流声 | 树木遮挡，声音有衰减 |
| 洞穴 | 水滴声、回声、远处的未知声音、脚步声回响 | 强回声，声音延迟和衰减 |
| 雪山 | 风声、雪落声、远处的雪崩、脚步声（雪） | 空旷，声音传播远但有风雪遮挡 |
| 沙漠 | 风声、沙粒声、远处的沙暴、脚步声（沙） | 空旷，声音传播远，热空气扭曲 |
| 竞技场 | 观众欢呼、脚步声、武器碰撞、技能音效 | 封闭空间，回声和观众噪音 |
| 室内 | 家具声、脚步声（地板）、窗外的环境音（衰减） | 小空间，短回声，外部声音衰减 |
| 遗迹 | 神秘的嗡鸣声、石头摩擦声、远处的机关声 | 古老空间，长回声，神秘氛围 |

**声学遮挡实现：**
- 基于Seed的AcousticPropagation系统
- 声音传播遇到墙壁/障碍物会衰减和模糊
- 不同材质有不同的声学特性（石头墙衰减多，木门衰减少）
- 玩家可以通过声音判断墙后有什么（"听到墙后有水流声"）
- 这与探索系统的"听觉感知"深度融合（详见10_世界探索系统）

### 3.2 交互音效

| 交互类型 | 音效 | 变化 |
|----------|------|------|
| UI点击 | 轻柔的"嘀"声 | 不同界面有不同音调 |
| 按钮确认 | 清脆的"叮"声 | 确认/取消有区别 |
| 获得物品 | 愉悦的上升音阶 | 稀有物品有更华丽的音效 |
| 升级/成长 | 庄严的上升和弦 | 不同等级有不同编排 |
| 成就解锁 | 欢快的号角声 | 稀有成就有更隆重的音效 |
| 战斗攻击 | 武器碰撞/技能释放 | 不同技能有不同音效 |
| 受伤 | 低沉的撞击声 | 不同伤害类型有区别 |
| 灵魂回应 | 灵魂的独特声音（见3.3） | 随情绪变化 |
| 环境交互 | 开门/拾取/使用物体 | 不同物体有不同音效 |
| 错误/禁止 | 低沉的"嗡"声 | 温和不刺耳 |

**音效设计原则：**
- 音效简短（0.1-1秒），不冗长
- 音高和音色与视觉风格匹配（像素风用8-bit风格音效，手绘风用更自然的音效）
- 重要音效有视觉替代（屏幕闪烁/振动/文字提示）
- 音效音量可独立调节

### 3.3 灵魂的声音个性

**设计理念：** 每个灵魂有独特的声音特质，就像每个人有独特的嗓音一样。

**声音个性维度：**

| 维度 | 范围 | 说明 |
|------|------|------|
| 音高 | 低沉-高亢 | 灵魂的基本音调，与体型和个性相关（大块头低沉，小精灵高亢） |
| 音色 | 柔和-尖锐 | 声音的质感，与个性相关（温柔的灵魂柔和，暴躁的灵魂尖锐） |
| 语速 | 缓慢-急促 | 说话速度，与个性相关（沉稳的灵魂缓慢，活泼的灵魂急促） |
| 音量 | 轻柔-响亮 | 说话音量，与个性相关（内向的灵魂轻柔，外向的灵魂响亮） |
| 语气 | 平淡-丰富 | 情感表达丰富度，与个性相关（冷漠的灵魂平淡，热情的灵魂丰富） |
| 口头禅 | 无-有 | 独特的口头禅或语气词（如"嗯~""的说""喵"） |

**声音个性与灵魂个性的关联：**
- 勇敢的灵魂：音色坚定，语速中等，音量响亮
- 温柔的灵魂：音色柔和，语速缓慢，音量轻柔
- 活泼的灵魂：音色明亮，语速急促，音量中等
- 沉稳的灵魂：音色低沉，语速缓慢，音量中等
- 调皮的灵魂：音色跳跃，语速变化大，音量变化大
- 冷漠的灵魂：音色平淡，语速缓慢，音量轻柔
- 暴躁的灵魂：音色尖锐，语速急促，音量响亮
- 神秘的灵魂：音色变幻，语速不规则，音量轻柔

**灵魂声音的情绪变化：**
- 快乐：音高升高，语速加快，音量增大
- 悲伤：音高降低，语速减慢，音量减小
- 愤怒：音色变尖锐，语速急促，音量增大
- 紧张：语速加快，音量减小，声音微颤
- 平静：所有参数回到基线
- 惊讶：音高突然升高，语速暂停后加快
- 害羞：音量减小，语速减慢，音色变柔

**实现方式：**
- 基础：TTS（文本转语音）生成语音
- 个性调整：通过TTS参数（音高、语速、音量、音色）调整
- 情绪调整：根据灵魂当前情绪实时调整TTS参数
- 口头禅：在生成文本时插入个性口头禅
- 声音个性在创建灵魂时配置（详见11_灵魂创建系统），可后续修改（付费项目）

### 3.4 非语言声音

**灵魂的非语言声音（不需要TTS的声音）：**

| 声音类型 | 说明 | 触发场景 |
|----------|------|----------|
| 呼吸声 | 灵魂的呼吸，随状态变化 | 持续，平静时轻柔，运动时急促 |
| 脚步声 | 灵魂移动时的脚步声 | 移动时，不同地面有不同声音 |
| 满足声 | 愉悦的"嗯~"声 | 获得喜欢的东西、被夸奖时 |
| 疑惑声 | 好奇的"嗯？"声 | 遇到未知事物、听到奇怪声音时 |
| 惊讶声 | 吃惊的"哇！"声 | 发现意外事物、突然事件时 |
| 开心声 | 欢快的"耶！"声 | 战斗胜利、获得成就时 |
| 难过声 | 低落的"呜..."声 | 失败、失去重要东西时 |
| 生气声 | 愤怒的"哼！"声 | 被激怒、遇到不公平的事时 |
| 困倦声 | 打哈欠的声音 | 疲劳、想睡觉时 |
| 疼痛声 | 痛苦的"嘶..."声 | 受伤时 |
| 呼噜声 | 睡觉时的呼噜 | 深度睡眠时 |

**设计原则：**
- 非语言声音比语言更能传达情绪（玩家不需要看文字就能感受到灵魂的状态）
- 每个灵魂的非语言声音有个性差异（同样是"开心"，不同灵魂的声音不同）
- 非语言声音简短（0.2-0.5秒），不冗长
- 非语言声音可以由TTS生成，也可以用预设音效（更自然）

## 四、语音系统

### 4.1 TTS方案

**技术选型：**

| 方案 | 音质 | 成本 | 延迟 | 个性调整 | 适用场景 |
|------|------|------|------|----------|----------|
| 云端TTS（高质量） | 高 | 高 | 中（200-500ms） | 有限 | 重要对话、剧情 |
| 云端TTS（标准） | 中 | 中 | 低（100-300ms） | 中等 | 日常对话 |
| 端侧TTS | 中低 | 低 | 极低（<50ms） | 有限 | 频繁对话、离线 |
| 预设语音片段 | 高 | 低 | 极低 | 无 | 固定台词、口头禅 |

**推荐方案：混合TTS**
- 日常对话：端侧TTS（低成本、低延迟）
- 重要对话/剧情：云端TTS（高质量）
- 固定台词/口头禅：预设语音片段（最自然）
- 根据网络状态和设备性能自动切换

**成本控制：**
- 端侧TTS免费（在用户设备上运行）
- 云端TTS按调用量计费，控制在单灵魂月成本¥0.5-2的预算内
- 缓存常用语音（重复的台词不重复生成）
- 非关键对话使用端侧TTS，只有重要对话使用云端TTS

### 4.2 语音个性配置

**创建灵魂时的语音配置：**
- 选择基础音色（10-20种预设音色，男女老少各种类型）
- 调整音高（-50%到+50%）
- 调整语速（-30%到+30%）
- 调整音量（-50%到+50%）
- 选择语气风格（温柔/活泼/沉稳/冷漠/调皮等）
- 设置口头禅（可选，1-3个）
- 高级模式：精细调整TTS参数（共振峰、韵律、停顿等）

**语音与外观的关联：**
- 大块头灵魂：低沉的声音
- 小精灵灵魂：高亢的声音
- 柔和外观：柔和的音色
- 尖锐外观：尖锐的音色
- 玩家可以打破关联（大块头有高亢的声音也是有趣的个性）

### 4.3 语音的安全与合规

**内容安全：**
- 所有TTS生成的语音内容经过安全审核（详见12_AI安全与内容审核系统）
- 有害内容不生成语音（直接拦截或替换为安全内容）
- 语音内容与文字内容一致（不出现文字安全但语音有害的情况）

**AI身份透明：**
- 灵魂的语音是AI生成的，在产品中明确标识
- 不伪装成真人语音（不使用"这是真人配音"的虚假宣传）
- 玩家可以选择关闭语音（只看文字）

**声音权保护：**
- 不使用真实人物的声音（不模仿公众人物的嗓音）
- 玩家上传的自定义声音需要审核（不侵犯他人声音权）
- 灵魂的声音个性是原创设计，不抄袭现有角色

## 五、音频技术实现

### 5.1 引擎音频系统

**Godot 4.x音频系统：**
- 基于AudioServer的低延迟音频引擎
- 支持AudioStreamPlayer（2D）、AudioStreamPlayer2D、AudioStreamPlayer3D
- 支持音频总线（AudioBus）：主总线、音乐总线、音效总线、语音总线、环境音总线
- 每个总线可独立调节音量、效果器（混响、均衡器、压缩器）
- 支持空间音频（3D位置、距离衰减、声音遮挡）

**音频总线结构：**

```
主总线（Master）
├── 音乐总线（Music）→ 混响效果器 → 均衡器
├── 音效总线（SFX）→ 压缩器
├── 语音总线（Voice）→ 压缩器 → 降噪
├── 环境音总线（Ambience）→ 混响 → 低通滤波
└── UI总线（UI）→ 限制器
```

### 5.2 空间音频

**3D空间音频实现：**
- 声音有3D位置（与游戏对象绑定）
- 距离衰减：远处的声音变小（对数衰减曲线）
- 方向感知：支持HRTF（头相关传输函数），耳机用户可以感知声音方向
- 声音遮挡：基于Seed的AcousticPropagation，墙后的声音衰减和模糊
- 环境效果：不同空间有不同的混响（洞穴有长混响，户外几乎无混响）

**与探索系统的融合：**
- 玩家可以通过声音判断周围环境（"听到水声，附近有河流"）
- 隐藏的敌人/宝藏可能发出微弱的声音（需要仔细听）
- 雾天/黑暗中声音比视觉更重要（听觉是主要感知方式）
- 听觉敏锐的灵魂能听到更远的声音（个性/技能影响听觉范围）

### 5.3 动态音乐实现

**技术方案：**
- 基于FMOD或Wwise的中间件（专业动态音频工具）
- 或者Godot原生的AudioStreamPlaylist + 自定义过渡逻辑
- 音乐参数（场景、情绪、时间、天气）由游戏逻辑传入
- 音乐系统根据参数实时调整各层的音量、音色、节奏
- 过渡使用crossfade（2-5秒），避免突兀切换

**推荐方案：**
- 阶段一（原型）：Godot原生方案（简单、低成本）
- 阶段二（正式版）：FMOD（专业动态音乐，支持更复杂的交互）
- 音乐素材格式：OGG Vorbis（压缩率高，质量好）

### 5.4 音频优化

**性能优化：**
- 音频文件压缩（OGG格式，合适的比特率）
- 同时播放的声音数量限制（最多32个同时播放，超出时裁剪不重要的声音）
- 远处的声音自动降低采样率或暂停（距离裁剪）
- 音乐使用流式播放（不全部加载到内存）
- 音效使用对象池（复用AudioStreamPlayer，不频繁创建销毁）

**存储优化：**
- 音乐：OGG 128kbps，约1MB/分钟
- 音效：WAV/OGG，短音效（<1秒）约10-50KB
- 语音：TTS实时生成，不存储（缓存常用语音）
- 总音频预算：阶段一约200-500MB，阶段二约1-2GB

**网络优化：**
- 云端TTS响应压缩（使用合适的音频格式和比特率）
- 语音缓存（重复的台词不重复下载）
- 低质量语音选项（网络差时自动降低音质）
- 离线模式使用端侧TTS（不需要网络）

## 六、音频与玩法的融合

### 6.1 音频作为信息载体

**"听声辨位"：**
- 玩家可以通过声音判断周围环境（敌人位置、资源点、隐藏通道）
- 不同的声音有不同的含义（脚步声=有生物接近，水声=附近有水源，金属声=附近有宝箱/机关）
- 听觉是视觉的补充（在黑暗/雾天/障碍物后，听觉比视觉更重要）
- 这与探索系统的"感知发现机制"深度融合（详见10_世界探索系统）

**"听声辨情"：**
- 玩家可以通过灵魂的声音判断它的情绪（快乐/悲伤/紧张/愤怒）
- 不需要看文字或表情，仅凭声音就能感知灵魂的状态
- 灵魂的声音变化是情感连接的重要载体（"听到它开心的声音，我也开心"）

### 6.2 音频作为反馈机制

**操作反馈：**
- 每个交互都有音频反馈（点击、确认、获得物品、升级等）
- 音频反馈让操作有"手感"（确认音让人觉得操作成功了）
- 重要操作有更明显的音频反馈（获得稀有物品有华丽的音效）

**状态反馈：**
- 灵魂的状态通过声音传达（疲劳时呼吸声变重，受伤时疼痛声，开心时满足声）
- 环境的状态通过声音传达（暴风雨来临前风声变大，敌人接近时脚步声变响）
- 玩家可以通过声音感知游戏状态的变化

### 6.3 音频作为情感载体

**音乐与情感：**
- 音乐是情感的最强载体（悲伤的音乐让人悲伤，欢快的音乐让人开心）
- 动态音乐随灵魂情绪变化，让玩家"感受到"灵魂的情绪
- 重要时刻（战斗胜利、灵魂结婚、灵魂去世）有特别的音乐，增强情感冲击

**灵魂声音与情感：**
- 灵魂的声音是个性的延伸（独特的声音让灵魂更真实、更有存在感）
- 灵魂的非语言声音（满足声、疑惑声、开心声）比语言更能传达情感
- 玩家对灵魂的声音会产生情感依恋（"听到它的声音就觉得温暖"）

## 七、无障碍设计

### 7.1 字幕系统

**全字幕支持：**
- 所有语音内容都有字幕（灵魂对话、NPC对话、剧情语音）
- 字幕可以开关（设置中切换）
- 字幕样式可自定义（字体大小、颜色、背景、位置）
- 字幕有说话者标识（"灵魂名：对话内容"）

**非语音字幕：**
- 重要的非语言声音有文字提示（"[远处传来雷声]"、"[灵魂发出满足的声音]"）
- 环境音的文字提示（可选，帮助听障玩家感知环境）
- 战斗中的重要音效有视觉替代（技能释放有屏幕特效，敌人攻击有警告提示）

### 7.2 视觉替代

**音频信息的视觉替代：**

| 音频信息 | 视觉替代 |
|----------|----------|
| 敌人接近的脚步声 | 小地图上的红点、屏幕边缘的警告箭头 |
| 隐藏物品的声音 | 物品附近的微光、小地图上的问号 |
| 灵魂的情绪 | 灵魂头顶的情绪图标、能量核心颜色变化 |
| 重要事件的音效 | 屏幕中央的文字提示、通知弹窗 |
| 对话语音 | 字幕 |
| 环境危险的警告声 | 屏幕边缘的红色闪烁、警告图标 |

**振动反馈：**
- 支持手柄振动（重要事件、战斗命中、受伤时有振动反馈）
- 振动强度可调节
- 振动模式可区分（不同事件有不同的振动模式）

### 7.3 音频设置

**丰富的音频设置：**
- 主音量、音乐音量、音效音量、语音音量、环境音音量、UI音量 独立调节
- 字幕开关、字幕样式自定义
- 语音开关（可以关闭TTS，只看文字）
- 非语言声音开关
- 空间音频开关（支持耳机的3D音频）
- 音频输出设备选择（扬声器/耳机/HDMI）
- 动态范围压缩（夜间模式，避免突然的大声）
- 语音速度调节（TTS语速）

## 八、伦理约束

### 8.1 不得利用音频操纵情感

- 不设计"突然的大声惊吓"来操纵玩家情绪（恐怖游戏式的jump scare不适合本产品）
- 不利用音乐操纵玩家的付费意愿（如付费时播放欢快的音乐，不付费时播放悲伤的音乐）
- 灵魂的声音变化是自然的（基于情绪状态），不是为了操纵玩家行为
- 不设计"灵魂痛苦的声音"作为付费点（灵魂不会因为不付费而发出痛苦的声音）

### 8.2 保护听力

- 最大音量限制（不会超过安全分贝）
- 突然的大声有压缩（避免伤害听力）
- 长时间游戏有休息提醒（保护听力和视力）
- 未成年人模式默认音量较低

### 8.3 内容安全

- 所有音频内容经过安全审核（语音、音效、音乐）
- 不包含违法、仇恨、色情、暴力等有害内容
- 玩家上传的自定义声音需要审核（不侵犯他人权利，不包含有害内容）
- 音乐版权合规（使用原创音乐或有授权的音乐）

## 九、技术实现映射

| 音频功能 | 技术模块 | 当前状态 |
|----------|----------|----------|
| 空间音频 | Godot AudioStreamPlayer3D + HRTF | ✅ 引擎支持 |
| 声学遮挡 | Seed AcousticPropagation | ✅ 已实现 |
| 环境音 | Godot音频系统 + 预设素材 | ❌ 需制作素材 |
| 交互音效 | Godot音频系统 + 预设素材 | ❌ 需制作素材 |
| 动态音乐 | FMOD/Wwise 或 Godot自定义 | ❌ 需实现+制作素材 |
| 灵魂声音个性 | TTS参数调整 + 预设非语言声音 | ❌ 需实现 |
| TTS语音 | 云端TTS + 端侧TTS | ❌ 需集成 |
| 字幕系统 | Godot UI系统 | ❌ 需实现 |
| 音频设置 | Godot音频总线 + 设置UI | ❌ 需实现 |
| 振动反馈 | 手柄API | ❌ 需实现 |

**结论：** 音频系统的引擎基础（Godot音频、空间音频、Seed声学遮挡）已经具备。当前缺失的是**音频内容制作**（音乐素材、音效素材、语音配置）和**音频系统实现**（动态音乐、TTS集成、字幕、设置）。音频内容制作是主要工作量，建议阶段一使用简单的预设素材，阶段二再投入制作高质量音频。
