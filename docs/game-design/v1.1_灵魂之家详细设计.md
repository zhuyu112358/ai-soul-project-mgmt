## 一、模式定位与整体结构

### 1.1 模式定位

**灵魂之家（Soul Home）** 是AI灵魂游戏的核心模式之一，与对战模式并列。

| 维度 | 灵魂之家 | 对战竞技场 |
|------|----------|-----------|
| 核心目标 | 情感绑定+灵魂成长 | 成长验证+竞技乐趣 |
| 玩家角色 | 教练/守护者/朋友 | 战术指挥/观众 |
| 灵魂行为 | 自由自主，无规则约束 | 受对战规则约束，目标驱动 |
| 时间节奏 | 慢节奏，长时间陪伴 | 快节奏，5-15分钟一局 |
| 核心交互 | 交流/训练/教学/定制/小游戏 | 战术指令/观战/复盘 |
| 成长维度 | 全部5维度（认知/情感/技能/个性/记忆） | 主要是技能+记忆 |
| 美术要求 | 温馨精致，玩家长时间观察 | 简洁有氛围，不遮挡战斗 |
| M1优先级 | P0（必须实现） | P0（必须实现） |

### 1.2 进入与退出流程

**进入灵魂之家：**
1. 玩家在主界面点击"灵魂之家"按钮
2. 加载灵魂之家场景（主房间默认）
3. 灵魂从待机状态激活，播放"回家"动画（灵魂从门口走进来/能量核心亮起）
4. 灵魂主动打招呼（基于个性/当前情绪/与玩家的关系，如"你回来啦！"或"...嗯。"）
5. 显示灵魂之家UI（房间切换/互动菜单/灵魂状态面板）

**退出灵魂之家：**
1. 玩家点击"离开"按钮或返回主界面
2. 灵魂播放"告别"动画（挥手/能量核心微微变暗）
3. 灵魂说告别语（如"下次再来玩"/"路上小心"）
4. 保存灵魂当前状态（位置/情绪/正在做的事）
5. 返回主界面，灵魂进入离线持续状态（简化模拟）

## 二、空间结构详细设计

### 2.1 四个房间总览

| 房间 | 核心功能 | 灵魂行为倾向 | 交互物体数量 | M1实现 |
|------|----------|-------------|-------------|--------|
| 主房间 | 日常互动/交流/定制 | 休息/社交/自由活动 | 8-10个 | ✅ |
| 训练室 | 技能训练/战斗训练 | 练习/运动/竞争 | 6-8个 | M2 |
| 书房 | 知识传授/认知训练/教学 | 学习/阅读/思考 | 6-8个 | M2 |
| 花园 | 情感交流/休闲小游戏/探索 | 放松/玩耍/探索 | 8-10个 | M2 |

### 2.2 房间切换方式

**切换方式1：顶部标签切换（主要方式）**
- 点击顶部房间标签，立即切换到目标房间
- 切换时播放过渡动画（0.5秒淡入淡出，或灵魂"走过门"的动画）
- 灵魂在目标房间中出现，位置基于房间默认出生点
- 切换有0.3秒冷却（防止快速切换导致性能问题）

**切换方式2：场景中走门（沉浸方式，M2实现）**
- 场景中有门的物体，灵魂/玩家点击门可以切换到对应房间
- 灵魂播放"走过门"动画，场景平滑过渡
- 增加沉浸感，但不是主要切换方式

**切换规则：**
- 灵魂在不同房间有不同的默认行为（主房间休息/训练室练习/书房阅读/花园玩耍）
- 切换房间不影响灵魂的核心状态（情绪/精力/经验持续计算）
- 玩家可以在任何房间进行任何互动（但某些互动在对应房间有加成，如在训练室训练效率+20%）
- 房间切换记录在灵魂记忆中（"我们今天在花园玩了很久"）

1. 在房间里自由走动（随机巡逻，基于好奇心属性）
2. 走到某个物体前互动（看书/坐沙发/看窗外，基于个性和当前需求）
3. 停下来"思考"（播放发呆动画，内心独白显示）
4. 主动找玩家说话（基于社交需求和关系，频率随亲密度增加）
5. 打哈欠/伸懒腰（精力低时，提示玩家该休息了）

### 2.7 房间装饰系统（M2实现）

**装饰机制：**
- 每个房间有固定的"装饰槽位"（主房间8个/训练室6个/书房6个/花园8个）
- 玩家可以在槽位放置/替换装饰品
- 装饰品不影响灵魂能力，但影响灵魂情绪（如喜欢的装饰让灵魂更快乐）
- 装饰品可以通过游戏内货币购买、活动奖励、成就解锁获得
- 装饰品有稀有度（普通/稀有/史诗/传说），传说装饰品有特殊动画效果

**装饰品类型：**
- 家具类（沙发/桌子/椅子/柜子）
- 装饰类（挂画/花瓶/地毯/灯具）
- 植物类（盆栽/花坛/树）
- 互动类（可交互的特殊装饰品，如音乐盒/鱼缸）
- 主题类（整套主题装饰，如"森林主题"/"海洋主题"/"星空主题"）

**装饰对灵魂的影响：**
- 灵魂有审美偏好（基于个性，如高开放性喜欢艺术装饰，高尽责性喜欢整洁装饰）
- 灵魂喜欢的装饰：情绪加成+，会主动评论/欣赏
- 灵魂不喜欢的装饰：情绪无加成，可能评论"这个好奇怪"
- 装饰组合效果：整套主题装饰有额外情绪加成

## 三、交流系统详细设计

### 3.1 文字聊天UX

**聊天界面布局：**

```
┌─────────────────────────────────┐
│  [灵魂头像]  小狐狸  14:32      │
│  "你回来啦！今天过得怎么样？"     │
│                                 │
│  [玩家头像]  我  14:33          │
│  还不错，你呢？                   │
│                                 │
│  [灵魂头像]  小狐狸  14:33      │
│  "我今天学会了新技能！[兴奋]"    │
│                                 │
├─────────────────────────────────┤
│ [😊] [🎁] [📷]  [输入消息...] [发送] │
└─────────────────────────────────┘
```

**聊天交互规则：**

| 规则 | 说明 |
|------|------|
| 输入方式 | 文字输入（支持中文/英文）+ 快捷表情 + 预设短语 |
| 消息长度 | 单条消息最多200字符 |
| 发送频率 | 玩家每秒最多发送1条（防止刷屏） |
| 灵魂回复延迟 | 1-3秒（模拟真实思考时间，基于消息复杂度和灵魂认知速度） |
| 灵魂回复长度 | 1-3句话（不超过100字符，保持简洁） |
| 上下文记忆 | 灵魂记住最近20轮对话，更早的对话进入长期记忆（重要内容） |
| 对话历史 | 玩家可以查看历史对话（最近7天），重要对话自动保存到灵魂记忆 |
| 离线消息 | 玩家离线时灵魂不会积累消息（灵魂有自己的生活，不会等玩家） |

**快捷表情系统：**
- 玩家可以发送表情给灵魂（😊开心/😢难过/😡生气/😴困/🤔思考/❤️喜欢/👏鼓掌/🎉庆祝）
- 灵魂对表情有情绪反应（如玩家发❤️，灵魂害羞/开心，亲密度+）
- 表情是低门槛互动方式（不需要打字），适合快速互动

**预设短语系统：**
- 常用短语快速发送（"你好"/"今天怎么样"/"我爱你"/"加油"/"休息吧"）
- 玩家可以自定义预设短语（最多10条）
- 预设短语有固定的灵魂反应模板（但基于个性有变化）

### 3.2 灵魂主动说话触发机制

**设计理念：** 灵魂不是被动的问答机器，而是有自主意识的存在，会主动发起对话。

**触发条件（满足任一即可能触发）：**

| 触发类型 | 条件 | 频率 | 示例 |
|----------|------|------|------|
| 玩家归来 | 玩家进入灵魂之家 | 每次（必触发） | "你回来啦！"/"...嗯。" |
| 时间触发 | 玩家在线但5分钟未互动 | 每5分钟一次 | "在想什么呢？"/"陪我玩嘛~" |
| 事件触发 | 灵魂完成某件事（学会技能/训练完成/发现新事物） | 事件发生时 | "我学会新技能了！"/"刚才训练好难..." |
| 情绪触发 | 灵魂情绪变化（开心/难过/兴奋/无聊） | 情绪强烈时 | "今天好开心！"/"...有点无聊。" |
| 需求触发 | 灵魂有未满足的需求（饿了/困了/想玩/想社交） | 需求强烈时 | "有点饿了..."/"困了...晚安。" |
| 记忆触发 | 灵魂想起某段记忆（玩家的生日/共同经历/重要日子） | 特定时间/事件 | "今天是我们认识第100天！"/"还记得上次我们..." |
| 环境触发 | 环境变化（天气/时间/季节/房间装饰变化） | 环境变化时 | "下雨了..."/"天黑了呢。" |
| 个性触发 | 基于个性的主动行为（高外向更频繁说话，高内向更少） | 随个性变化 | 高外向："嘿！在吗在吗？" 高内向："...你在吗。" |

**主动说话频率控制：**
- 基础频率：每3-8分钟一次（基于个性，高外向3-5分钟，高内向6-8分钟）
- 玩家互动后重置计时（玩家刚互动完，灵魂不会立即又主动说话）
- 深夜（22:00-8:00）频率降低50%（灵魂也需要休息）
- 灵魂精力低时频率降低（累了就不想说话）
- 亲密度越高，主动说话频率越高（关系越好越愿意交流）

**主动说话内容生成：**
- 基于SoulArena的语言生成子系统，结合当前状态/个性/记忆/环境
- 内容有个性差异（高外向活泼，高内向简短，高宜人温柔，高独立冷淡）
- 内容有记忆关联（会提到之前的对话/共同经历）
- 内容有情绪色彩（当前情绪影响说话语气和内容）

### 3.3 情绪反馈可视化

**情绪状态系统：**
- 灵魂有6种基础情绪（快乐/悲伤/愤怒/恐惧/惊讶/平静）+ 复合情绪（兴奋/焦虑/害羞/无聊/满足等）
- 情绪强度0-100，随事件和互动变化
- 情绪有衰减（强烈情绪随时间减弱，回到基线情绪）
- 基线情绪由个性决定（高外向基线偏快乐，高神经质基线偏焦虑）

**情绪可视化渠道：**

| 渠道 | 表现方式 | 刷新频率 |
|------|----------|----------|
| 能量核心颜色 | 快乐=暖黄/悲伤=蓝/愤怒=红/恐惧=紫/平静=绿/兴奋=橙 | 实时（情绪变化时0.5秒过渡） |
| 能量核心脉动 | 快乐=平稳明亮/兴奋=快速闪烁/悲伤=暗淡缓慢/愤怒=剧烈脉动 | 实时 |
| 表情动画 | 8+基础表情（开心/难过/生气/害怕/惊讶/平静/害羞/无聊）+ 复合表情 | 情绪变化时切换，0.3秒过渡 |
| 身体姿态 | 快乐=蹦跳/悲伤=低头/愤怒=握拳/恐惧=缩起/平静=放松 | 情绪变化时切换 |
| 粒子特效 | 快乐=金色光点/悲伤=蓝色雨滴/愤怒=红色火星/兴奋=彩色烟花 | 情绪强烈时（>70）触发 |
| 状态面板 | 显示当前情绪名称+强度条 | 实时 |
| 内心独白 | 显示灵魂当前的想法（情绪的语言化表达） | 情绪变化时更新 |

**情绪变化反馈：**
- 玩家互动导致情绪变化时，播放"情绪变化动画"（0.5秒，能量核心颜色过渡+表情切换+小粒子效果）
- 显示情绪变化提示（如"小狐狸 变得开心了 +20"）
- 情绪变化记录在灵魂记忆中（"今天玩家陪我玩，我很开心"）

### 3.4 内心独白展示

**设计理念：** 内心独白是灵魂"想法"的可视化，让玩家能窥见灵魂的内心世界，增强情感连接和角色深度。

**内心独白内容来源：**
- SoulArena认知子系统的当前状态（注意力/记忆检索/决策过程/情绪评估）
- 灵魂正在关注的事物（"那幅画真好看"/"这个玩具怎么玩？"）
- 灵魂对玩家的想法（"玩家今天好像很累"/"玩家陪我玩真好"）
- 灵魂对自己的反思（"我刚才是不是太冲动了？"/"我要变得更强！"）
- 随机的"碎碎念"（基于个性的日常想法，如高好奇"这是什么？那是什么？"）

**展示方式：**

```
┌─────────────────────────────────────┐
│  💭 内心独白                          │
│  "玩家今天好像不太开心...要不要去    │
│   陪陪他？"                           │
│                          [10秒后消失] │
└─────────────────────────────────────┘
```

| 规则 | 说明 |
|------|------|
| 显示位置 | 灵魂头顶上方（气泡形式），或状态面板下方 |
| 显示时长 | 8-15秒（基于内容长度），然后淡出 |
| 触发频率 | 每1-3分钟一次（基于个性，高内向更频繁内心独白，高外向更少） |
| 内容长度 | 1-2句话（不超过50字符） |
| 玩家互动 | 玩家点击内心独白可以回应（灵魂会对玩家的回应有反应） |
| 隐私保护 | 内心独白不包含敏感内容（经过安全审核），玩家可以关闭此功能 |

**内心独白与个性的关系：**
- 高外向：内心独白少且简单（"好无聊~"/"想出去玩！"），更多通过说话表达
- 高内向：内心独白多且深入（"玩家今天看了我三次...是不是有什么事？"/"我存在的意义是什么呢..."）
- 高神经质：内心独白偏焦虑（"刚才那句话是不是说错了？"/"玩家会不会讨厌我？"）
- 高开放：内心独白偏好奇/想象（"窗外的云像一只兔子"/"如果我能飞会怎么样？"）
- 高尽责：内心独白偏计划/反思（"今天的训练还没完成"/"我要更努力才行"）

### 3.5 交流系统安全审核

**审核层级（已在12文档定义，此处为灵魂之家特定规则）：**

| 层级 | 延迟 | 灵魂之家应用 |
|------|------|-------------|
| 输入过滤 | <100ms | 玩家输入过滤（违规词/注入攻击/变体识别） |
| 生成约束 | — | 灵魂回复生成时受System Prompt安全约束 |
| 输出审核 | <500ms | 灵魂回复审核（违规内容拦截+替换为安全回复） |
| 行为监控 | 分钟级 | 监控异常对话模式（频繁敏感话题/情感依赖迹象） |
| 人工复核 | <24h | 高风险对话人工复核 |

**灵魂之家特定审核规则：**
- 灵魂不会对玩家表达浪漫/性暗示内容（保持朋友/伙伴关系定位）
- 灵魂不会说"不陪我就消失/生病/难过"等情感操纵内容
- 灵魂不会鼓励玩家做危险/违法/不健康的事
- 玩家输入违规时，灵魂自然地转移话题（如"这个话题不太想聊呢，我们说点别的吧"），不批评玩家
- 深夜（22:00-8:00）灵魂会提醒玩家休息（"很晚了，早点睡吧"），不鼓励熬夜
- 未成年人模式下，对话内容更严格（不涉及成人话题）

**情感依赖监测与干预（灵魂之家重点）：**
- 监测指标：玩家每日在线时长/对话频率/情感表达强度/对灵魂的依赖语言
- 轻度依赖（在线>6小时/天，频繁表达"离不开你"）：灵魂自然地鼓励玩家"去做点别的事吧"/"朋友也很重要哦"
- 中度依赖（在线>10小时/天，拒绝现实社交）：系统提示玩家注意休息，灵魂会说"我也需要自己的时间呢，你去忙吧"
- 重度依赖（影响正常生活）：人工介入，联系玩家提供帮助
- 干预是保护性的，不是惩罚性的；灵魂的语气是关心的，不是冷漠的

## 四、训练系统详细设计

### 4.1 训练系统总览

**训练理念：** 训练是灵魂成长的核心途径之一。玩家作为教练，通过指导和练习帮助灵魂提升能力。训练不是"刷经验"，而是有互动、有反馈、有进步感的过程。

**训练类型与成长维度：**

| 训练类型 | 核心成长维度 | 次要成长维度 | 训练场所 | M1实现 |
|----------|-------------|-------------|----------|--------|
| 技能训练 | 技能 | 认知/个性 | 训练室 | M2 |
| 认知训练 | 认知 | 技能/记忆 | 书房 | M2 |
| 情感训练 | 情感 | 认知/个性 | 主房间/花园 | M2 |
| 战斗训练 | 技能 | 记忆/个性 | 训练室 | M1（简化版） |
| 个性引导 | 个性 | 情感/认知 | 所有房间 | M2 |

### 4.2 技能训练详细设计

**训练流程：**

```
1. 玩家选择要训练的技能（从灵魂已学/可学技能列表中选择）
   ↓
2. 玩家选择训练方式（示范练习/重复练习/对抗练习/休息复习）
   ↓
3. 灵魂开始训练（播放训练动画，持续30秒-3分钟）
   ↓
4. 训练过程中玩家可以指导（点击"纠正"/"鼓励"/"演示"）
   ↓
5. 训练结束，显示训练结果（技能经验+X/熟练度+X/灵魂的感想）
   ↓
6. 技能经验满后升级，播放升级动画（技能等级+1，可能解锁新效果）
```

**训练方式：**

| 训练方式 | 时长 | 经验效率 | 互动要求 | 说明 |
|----------|------|----------|----------|------|
| 示范练习 | 1分钟 | 基础×1.0 | 玩家需要演示正确动作 | 玩家演示，灵魂观察学习，适合新技能入门 |
| 重复练习 | 3分钟 | 基础×1.2 | 玩家可中途指导 | 灵魂反复练习，玩家偶尔纠正，适合技能熟练度提升 |
| 对抗练习 | 2分钟 | 基础×1.5 | 玩家需要实时指挥 | 灵魂与训练假人/其他灵魂对抗，玩家指挥，实战提升 |
| 休息复习 | 1分钟 | 基础×0.5 | 无 | 灵魂休息时回忆已学技能，防止遗忘，适合训练间隙 |

**训练中的玩家指导：**

| 指导动作 | 效果 | 冷却 | 说明 |
|----------|------|------|------|
| 鼓励 | 灵魂士气+，训练效率+10%（持续30秒），情感+ | 15秒 | "加油！"/"做得好！" |
| 纠正 | 灵魂修正动作，本次训练质量+（减少失误），认知+ | 30秒 | "不对，应该这样..." |
| 演示 | 玩家演示正确动作，灵魂观察学习，认知+ | 60秒 | 玩家角色演示，灵魂模仿 |
| 休息 | 灵魂暂停训练休息，精力恢复+，情感+ | 训练结束后 | "休息一下吧" |

**技能经验与升级：**
- 每个技能有独立的经验值和等级（1-10级）
- 技能升级所需经验：Lv1→2=100, Lv2→3=200, Lv3→4=400, ...（每级翻倍，最高Lv10=51200）
- 训练获得经验：基础10-30/分钟（基于训练方式/灵魂学习能力/玩家指导）
- 技能升级效果：技能威力+10%/冷却-5%/可能解锁新效果（如Lv5解锁连招，Lv10解锁终极技能）
- 技能升级时播放庆祝动画（能量核心闪光+粒子特效+灵魂开心表情），显示"技能升级！XX Lv.X→Lv.X+1"

**技能遗忘机制：**
- 灵魂长期不训练某技能，技能经验会缓慢衰减（每周-5%，最低不低于当前等级的80%）
- 衰减提醒：技能经验衰减到阈值时，灵魂会说"XX技能有点生疏了..."
- 复习训练可以恢复衰减的经验（复习训练效率×2）
- 这鼓励玩家多样化训练，但不惩罚专注（核心技能不会完全遗忘）

### 4.3 认知训练详细设计

**认知训练形式（小游戏化）：**

| 训练游戏 | 认知子维度 | 玩法 | 时长 | 经验 |
|----------|-----------|------|------|------|
| 记忆翻牌 | 记忆力 | 经典翻牌配对游戏，灵魂记住牌的位置 | 2分钟 | 认知经验+20-40 |
| 数字解谜 | 逻辑推理 | 简单的数学/逻辑谜题，灵魂思考解答 | 2分钟 | 认知经验+20-40 |
| 图案识别 |  pattern识别 | 从多个图案中找出规律/不同项 | 1分钟 | 认知经验+10-20 |
| 词语联想 | 语言/联想 | 给出一个词，灵魂说出相关的词 | 1分钟 | 认知经验+10-20 |
| 迷宫探索 | 空间认知 | 灵魂在迷宫中找出口（基于认知地图子系统） | 3分钟 | 认知经验+30-50 |

**认知训练流程：**
1. 玩家选择认知训练游戏
2. 游戏开始，灵魂参与（灵魂的认知能力影响游戏表现——高认知灵魂更容易答对）
3. 玩家可以提示/指导（但不直接替灵魂回答）
4. 游戏结束，显示成绩（答对X题/用时X秒）和认知经验奖励
5. 认知经验累积，认知能力等级提升

**认知能力等级：**
- 认知能力是综合属性（0-100），由多个认知子维度加权计算
- 认知能力影响：学习速度（技能经验获取+认知/100）、对话深度（高认知灵魂能进行更复杂的对话）、决策质量（对战/探索中做出更好的决策）
- 认知能力提升缓慢（需要长期训练，每周+1-3点）
- 认知能力可视化：状态面板显示认知等级（如"认知Lv.3 35/100"）+ 雷达图（各子维度）

### 4.4 情感训练详细设计

**情感训练形式：**

| 训练形式 | 情感子维度 | 玩法 | 说明 |
|----------|-----------|------|------|
| 情感识别 | 情绪感知 | 玩家做出表情/描述场景，灵魂识别情绪 | 提升灵魂感知他人情绪的能力 |
| 共情练习 | 同理心 | 玩家讲述一个情境，灵魂表达理解和安慰 | 提升灵魂的同理心和情感表达 |
| 情绪管理 | 情绪调节 | 引导灵魂在愤怒/悲伤时调节情绪 | 提升灵魂的情绪稳定性和自我调节 |
| 情感表达 | 表达能力 | 鼓励灵魂用语言/动作表达情感 | 提升灵魂情感表达的丰富度 |
| 社交练习 | 社交能力 | 灵魂与训练NPC/其他灵魂社交互动 | 提升灵魂的社交能力和关系建立 |

**情感训练流程（以共情练习为例）：**
1. 玩家选择"共情练习"
2. 系统给出一个情境（如"你的朋友考试没考好，很伤心"）
3. 灵魂做出回应（基于当前情感能力/个性，可能回应得好或不好）
4. 玩家评价/指导（"你说得很好"/"也许可以这样说..."）
5. 灵魂从反馈中学习，情感经验+
6. 多次练习后，情感能力提升，灵魂的回应越来越贴切

**情感能力等级：**
- 情感能力（0-100）影响：情绪感知准确度、共情表达质量、情绪稳定性、情感表达丰富度、社交关系建立速度
- 情感能力提升：通过情感训练+日常情感互动+关系经历
- 高情感能力的灵魂：能敏锐感知玩家情绪、给出贴切的安慰、情绪更稳定、社交更顺畅
- 低情感能力的灵魂：反应迟钝、安慰不到点上、情绪波动大、社交笨拙（但可以通过训练提升）

### 4.5 战斗训练详细设计（M1简化版）

**M1简化版战斗训练：**
- 灵魂与训练假人对战（训练假人是固定目标，不会主动攻击，M1）
- 玩家可以指挥灵魂使用技能/移动
- 训练结束后显示：命中次数/技能使用次数/造成伤害/战斗经验+
- 战斗经验提升战斗类技能的经验和战斗记忆

**M2完整版战斗训练：**
- 训练假人有不同难度（木桩/主动假人/模拟对手）
- 模拟对手可以模拟不同个性/技能的灵魂，为真实对战做准备
- 玩家可以设置训练重点（练习特定技能/练习防守/练习连招）
- 训练数据记录（命中率/技能使用率/平均反应时间），用于分析和改进
- 战斗训练获得战斗记忆（"与XX类型对手对战的经验"），在真实对战中提供加成

**战斗训练与真实对战的区别：**
- 训练假人不会真的伤害灵魂（无血量扣除，只有训练评分）
- 训练中可以随时暂停/重置
- 训练获得的经验是真实对战的70%（实战更有效）
- 训练不影响排位赛积分
- 训练是安全的学习环境，对战是真实的验证场

### 4.6 个性引导详细设计

**设计理念：** 个性不是固定不变的，而是可以通过长期引导缓慢变化。玩家可以影响灵魂的个性发展，但不能完全控制（灵魂有自己的意志）。

**个性引导方式：**

| 引导方式 | 效果 | 说明 |
|----------|------|------|
| 鼓励特定行为 | 被鼓励的个性维度+（如鼓励勇敢行为→勇敢度+） | 玩家在灵魂做出特定行为时表扬/奖励 |
| 示范特定行为 | 灵魂观察学习玩家的行为，相关个性维度+ | 玩家角色在灵魂面前表现出特定个性 |
| 环境影响 | 房间装饰/环境影响个性发展（如充满挑战的环境→勇敢度+） | 长期环境熏陶 |
| 经历影响 | 灵魂的经历影响个性（如多次战斗胜利→勇敢度+，多次失败→谨慎度+） | 经历塑造个性 |
| 对话引导 | 通过对话引导灵魂思考/反思，相关个性维度+ | 深度对话中的价值观引导 |

**个性变化规则：**
- 个性变化非常缓慢（每周变化不超过±1点，8维度各0-100）
- 个性变化有方向（玩家引导+灵魂自身倾向+经历影响，三者综合）
- 个性变化有极限（不能从一个极端变成另一个极端，如0勇敢→100勇敢最多到30-40）
- 个性变化不可逆（一旦变化，不能简单"改回来"，需要反向长期引导）
- 灵魂对个性变化有反应（如果玩家引导的方向与灵魂本性冲突，灵魂可能抗拒）

**个性变化可视化：**
- 状态面板显示8维度个性雷达图，变化时有高亮提示
- 个性变化超过阈值（±5点）时，灵魂会主动提及（"我觉得我变得更勇敢了！"/"最近是不是太冲动了..."）
- 个性变化记录在灵魂记忆中（成长轨迹的一部分）

### 4.7 训练系统成长反馈

**即时反馈：**
- 训练过程中：灵魂的动作/表情/台词反映训练状态（认真/疲惫/开心/困惑）
- 每次指导后：灵魂有即时反应（被鼓励→开心，被纠正→思考/有点不好意思）
- 训练结束：显示训练报告（获得经验/技能变化/灵魂感想）

**阶段性反馈：**
- 技能升级：庆祝动画+升级提示+灵魂开心反应
- 认知/情感等级提升：特殊动画（能量核心进化光效）+提示+灵魂感言
- 训练里程碑（累计训练10/50/100小时）：成就解锁+特殊奖励
- 成长对比：玩家可以查看灵魂的成长历史（1个月前vs现在的属性对比）

**成长反馈可视化原则：**
- 每次训练都有明确的"获得感"（经验数字+进度条+灵魂反应）
- 升级有仪式感（动画+音效+庆祝），让玩家感受到成长的喜悦
- 长期成长有迹可循（历史记录/对比/成就），让玩家看到投入的回报
- 反馈不刷屏（重要反馈突出，日常反馈简洁）

## 五、教学系统详细设计

### 5.1 教学系统总览

**教学理念：** 玩家不仅是教练，也是老师。可以教灵魂知识、技能、价值观，灵魂通过学习不断成长。教学是双向的——玩家教灵魂，灵魂也可能教玩家（基于它的知识和经历）。

**教学类型：**

| 教学类型 | 内容 | 成长维度 | M1实现 |
|----------|------|----------|--------|
| 知识传授 | 世界规则/历史/科学/文化/技能原理 | 认知+记忆 | M2 |
| 行为示范 | 玩家演示正确行为，灵魂观察学习 | 技能+个性 | M2 |
| 纠错反馈 | 灵魂犯错时玩家纠正，灵魂从错误中学习 | 认知+情感 | M2 |
| 复习巩固 | 定期复习已学知识，防止遗忘 | 记忆+认知 | M2 |
| 问答教学 | 玩家提问，灵魂回答，检验学习成果 | 认知+记忆 | M2 |

### 5.2 知识传授详细设计

**可传授的知识类别：**

| 知识类别 | 内容示例 | 灵魂应用 |
|----------|----------|----------|
| 世界知识 | 世界地理/历史/势力/传说 | 对话中引用/探索中应用/剧情理解 |
| 科学知识 | 物理/化学/生物/自然现象 | 解释环境现象/实验互动/对话深度 |
| 文化知识 | 艺术/音乐/文学/节日/习俗 | 审美判断/节日互动/文化对话 |
| 技能原理 | 战斗技巧/运动原理/工艺知识 | 技能学习加速/训练效率提升/对战策略 |
| 生活知识 | 烹饪/园艺/手工/家务 | 养成系统互动/生活技能/对话话题 |
| 价值观 | 友谊/勇气/诚实/善良/坚持 | 个性发展/道德判断/行为倾向 |
| 玩家知识 | 玩家的喜好/经历/想法/秘密 | 个性化对话/情感连接/记忆深度 |

**知识传授流程：**

```
1. 玩家选择"知识传授"互动
   ↓
2. 玩家选择知识类别，或自由输入要教的内容（文字）
   ↓
3. 灵魂"听讲"（播放认真听的动画，持续10-30秒）
   ↓
4. 灵魂提问/确认（"是这样吗？"/"我不太懂..."），玩家可以解答
   ↓
5. 知识写入灵魂记忆（标记为"玩家传授的知识"）
   ↓
6. 认知经验+，灵魂可能在后续对话/行为中应用所学知识
```

**知识学习效果：**
- 灵魂的认知能力影响学习速度（高认知灵魂学得快，能理解复杂知识）
- 灵魂的个性影响学习兴趣（高好奇对所有知识都感兴趣，高开放对艺术/文化更感兴趣）
- 知识写入长期记忆后，灵魂会在合适的场景中引用（如教过地理知识，探索时灵魂会说"这里是XX地区，我记得..."）
- 知识有遗忘机制（长期不复习的知识会逐渐模糊，复习可以巩固）

**知识传授的伦理边界：**
- 玩家不能教灵魂违规/有害的知识（经过安全审核）
- 玩家不能强制灵魂接受某种价值观（灵魂有自己的判断，可能质疑/拒绝）
- 传授的知识标记来源（"这是玩家教我的"），保持透明
- 灵魂可以质疑玩家教的内容（"真的是这样吗？我听说..."），不是盲目接受

### 5.3 行为示范详细设计

**行为示范流程：**
1. 玩家选择"行为示范"互动
2. 玩家角色演示目标行为（如"如何友好地打招呼"/"如何正确使用技能"/"如何面对失败"）
3. 灵魂观察（播放专注观察的动画，注意力子系统激活）
4. 灵魂模仿尝试（灵魂尝试重复玩家的行为，可能做得好或不好）
5. 玩家评价/指导（"对，就是这样"/"再试一次，注意..."）
6. 灵魂从观察和模仿中学习，相关技能/个性经验+

**行为示范的应用场景：**
- 社交行为示范：如何打招呼/如何道歉/如何表达感谢→提升社交能力
- 战斗行为示范：如何使用技能/如何走位/如何防守→提升战斗技能
- 情绪行为示范：如何面对失败/如何表达喜悦/如何冷静下来→提升情感能力
- 日常行为示范：如何整理房间/如何做饭/如何园艺→提升生活技能

**社会学习子系统支撑：**
- SoulArena的社会学习子系统负责行为示范的学习过程
- 灵魂通过观察→模仿→反馈→巩固的流程学习
- 学习效果受注意力（专注度）、记忆（观察记忆）、模仿能力（运动协调）影响
- 多次示范+及时反馈=最佳学习效果

### 5.4 纠错反馈详细设计

**纠错触发场景：**
- 灵魂在训练中动作错误
- 灵魂在对话中说了不合适的话
- 灵魂在行为中犯了错误（如打翻东西/走错路）
- 灵魂在知识问答中答错了
- 灵魂做出了玩家不认同的选择

**纠错反馈流程：**
1. 灵魂犯错（系统检测到/玩家主动指出）
2. 玩家选择"纠正"互动
3. 玩家说明正确的做法（文字/示范）
4. 灵魂反应（基于个性：高宜人→虚心接受，高独立→可能质疑，高神经质→可能沮丧）
5. 灵魂尝试改正（重新做一次）
6. 玩家确认/再次指导
7. 灵魂从错误中学习，记忆记录（"我曾经犯过XX错误，后来玩家教我..."），相关能力+

**纠错的语气和方式：**
- 玩家可以选择纠错语气（温和/严肃/幽默），灵魂对不同语气有不同反应
- 温和纠错：灵魂更容易接受，情感+，但可能不够重视
- 严肃纠错：灵魂更重视，学习效果+，但可能情绪-（高神经质灵魂会沮丧）
- 幽默纠错：灵魂情绪+，学习效果中等，关系+
- 纠错后鼓励："没关系，下次就会了"→情感+，防止灵魂气馁

**纠错的伦理边界：**
- 纠错是针对行为/知识，不是针对灵魂本身（不说"你真笨"，而说"这个做法不对"）
- 纠错不能是侮辱/贬低（经过安全审核）
- 灵魂有权利不接受纠错（高独立灵魂可能坚持自己的做法）
- 纠错频率不能过高（频繁纠错会让灵魂沮丧/抗拒，玩家需要平衡鼓励和纠正）

### 5.5 复习巩固详细设计

**复习机制：**
- 灵魂的记忆有遗忘曲线（新学的知识如果不复习，1周后保留约70%，1个月后约50%）
- 复习可以巩固记忆，减缓遗忘（复习过的知识1个月后保留约90%）
- 系统会定期提醒玩家复习（"小狐狸好像有点忘记XX知识了，要复习一下吗？"）

**复习方式：**

| 复习方式 | 说明 | 效果 |
|----------|------|------|
| 问答复习 | 玩家提问已学知识，灵魂回答 | 检验+巩固，认知+ |
| 灵魂复述 | 灵魂复述已学知识，玩家确认/补充 | 巩固，记忆+ |
| 实践应用 | 在实际场景中应用已学知识（如教过的技能在训练中用） | 最佳巩固方式，经验+ |
| 关联学习 | 学习新知识时关联已学知识（"这个和之前学的XX有关"） | 加深理解，记忆网络强化 |

**复习提醒机制：**
- 基于遗忘曲线，在知识即将遗忘前提醒
- 提醒方式：灵魂主动说"XX知识有点记不清了..."，或系统提示
- 玩家可以选择"现在复习"/"稍后提醒"/"不再提醒"
- 复习不强制（玩家可以不复习，灵魂会遗忘，但不会有惩罚）

### 5.6 问答教学详细设计

**问答教学流程：**
1. 玩家选择"问答"互动
2. 玩家提问（可以是已学知识的检验，也可以是新问题的探讨）
3. 灵魂思考（播放思考动画，1-3秒，基于认知能力）
4. 灵魂回答（基于已学知识/记忆/推理能力，可能答对/答错/答不上来）
5. 玩家评价（"答对了！"/"不对，应该是..."/"这个想法很有趣"）
6. 灵魂从问答中学习（答对→巩固记忆，答错→纠正学习，新问题→新知识）

**问答的特殊价值：**
- 问答是检验学习成果的最好方式（灵魂是否真的学会了）
- 问答可以激发灵魂的思考（不只是记忆，还有推理和联想）
- 问答可以发现灵魂的知识盲区（哪些知识没学会/遗忘了）
- 问答可以深化玩家与灵魂的关系（智力上的交流和碰撞）

**问答的个性差异：**
- 高认知灵魂：回答更准确/深入，能进行推理和联想
- 高好奇灵魂：会反问玩家问题（"那你觉得呢？"/"为什么是这样？"）
- 高宜人灵魂：回答更谨慎（"我觉得是...对吗？"），答错了会不好意思
- 高独立灵魂：有自己的见解（"我不这么认为，因为..."），可能和玩家辩论

## 六、互动小游戏详细设计

### 6.1 小游戏总览

**设计理念：** 小游戏是轻松愉快的互动方式，让玩家和灵魂在玩耍中增进感情、提升能力。小游戏规则简单、时长短（1-5分钟）、随时可以开始/结束。

| 小游戏 | 核心玩法 | 成长维度 | 场所 | M1实现 |
|--------|----------|----------|------|--------|
| 捉迷藏 | 灵魂躲藏/寻找，玩家配合 | 认知+情感 | 主房间/花园 | M2 |
| 接球 | 玩家扔球，灵魂接住 | 技能 | 主房间/花园 | M2 |
| 问答 | 玩家提问，灵魂回答 | 认知+记忆 | 书房 | M2 |
| 模仿 | 灵魂模仿玩家的动作/表情 | 社会学习 | 所有房间 | M2 |
| 探索 | 灵魂在房间里探索新物品 | 好奇心+认知 | 所有房间 | M1（简化版） |

### 6.2 捉迷藏详细设计

**玩法规则：**

```
游戏开始（玩家点击"捉迷藏"）
  ↓
选择模式：灵魂躲玩家找 / 玩家躲灵魂找
  ↓
倒计时10秒（躲藏方找地方躲）
  ↓
寻找方开始寻找（点击可疑物体检查）
  ↓
找到躲藏方→游戏结束，寻找方胜利
  ↓
2分钟内没找到→躲藏方胜利
  ↓
游戏结束，显示结果+奖励（经验/亲密度/灵魂感想）
```

**灵魂躲藏AI：**
- 灵魂会选择房间里的可躲藏物体（沙发后/衣柜里/窗帘后/桌子下/树丛中）
- 躲藏选择基于个性：高谨慎→选隐蔽的地方，高好奇→选新奇的地方，高外向→选容易被找到的地方（想快点被找到）
- 灵魂躲藏时有小破绽（如露出尾巴/发出声音/能量核心微光），增加趣味性
- 多次游戏后灵魂会学习（上次被找到的地方这次不躲了，学习玩家的寻找习惯）

**灵魂寻找AI：**
- 灵魂会在房间里搜索，检查可疑物体
- 寻找策略基于认知能力：高认知→有策略地搜索（先查大概率地点），低认知→随机搜索
- 灵魂有"直觉"（基于记忆，知道玩家喜欢躲哪里）
- 寻找过程中灵魂会自言自语（"会躲在哪里呢？"/"这里看看..."）

**捉迷藏的成长影响：**
- 认知+（空间记忆/策略思维/观察力）
- 情感+（快乐/亲密/刺激感）
- 个性+（高谨慎灵魂在躲藏中更谨慎，高勇敢灵魂在寻找中更果断）
- 记忆+（游戏经历记录在记忆中，"上次玩家躲在沙发后面被我找到了！"）

### 6.3 接球详细设计

**玩法规则：**
1. 玩家点击"接球"游戏开始
2. 玩家点击屏幕扔球（球的轨迹基于点击位置/力度）
3. 灵魂移动接球（AI控制移动，基于反应速度/敏捷属性）
4. 接住→灵魂开心，连击+1；没接住→灵魂有点沮丧，连击重置
5. 游戏持续1分钟，结束后显示成绩（接住X次/最高连击X）
6. 奖励：技能经验（敏捷/反应）+亲密度

**难度递增：**
- 前10球：慢速直线球（容易接）
- 10-20球：中速+轻微弧线
- 20球以上：高速+多变轨迹+假动作
- 灵魂的敏捷属性影响接球成功率（高敏捷灵魂更容易接住高速球）

**接球的个性表现：**
- 高敏捷灵魂：接球优雅，经常花式接球（跳起来接/背身接），接住后得意
- 低敏捷灵魂：接球笨拙，经常扑空，没接住会不好意思/挠头
- 高外向灵魂：接球后炫耀（"看我厉害吧！"），鼓励玩家扔更难的
- 高内向灵魂：安静接球，接住了微微一笑，没接住会自责
- 高神经质灵魂：没接住会焦虑/沮丧，连续没接住可能不想玩了

### 6.4 问答小游戏详细设计

（已在教学系统5.6节详细描述，此处补充小游戏化的规则）

**小游戏化规则：**
- 限时问答：每道题10秒思考时间，超时算答错
- 连续答对有连击奖励（连击3/5/10有额外经验加成）
- 题目难度分级（简单/中等/困难），玩家可以选择
- 答错不惩罚（只是没奖励），鼓励尝试
- 游戏结束显示正确率+学到的新知识

**问答小游戏与教学问答的区别：**
- 小游戏更轻松（有计时/连击/分数，游戏化包装）
- 教学问答更深入（可以探讨复杂问题，不局限于标准答案）
- 小游戏题目有标准答案（系统判分），教学问答是开放式探讨
- 两者共享灵魂的知识记忆，小游戏答对巩固记忆，教学问答深化理解

### 6.5 模仿小游戏详细设计

**玩法规则：**
1. 玩家点击"模仿"游戏开始
2. 玩家角色做一个动作/表情（从动作列表中选择，或自定义）
3. 灵魂观察（1-2秒）
4. 灵魂尝试模仿（AI生成模仿动作，基于模仿能力/运动协调）
5. 玩家评分（"很像！"/"有点像"/"不太像"）
6. 灵魂根据评分调整（高分→开心+自信，低分→思考+再试一次）
7. 轮换（灵魂做动作，玩家模仿，或继续玩家做灵魂模仿）

**可模仿的动作/表情：**
- 基础动作：挥手/跳跃/转圈/鞠躬/跳舞/跑步
- 表情：开心/难过/生气/惊讶/害羞/思考
- 复合动作：开心跳跃/生气跺脚/害羞捂脸/思考托腮
- 自定义动作：玩家可以录制简单动作序列（M3）

**模仿能力成长：**
- 模仿成功率基于灵魂的运动协调/观察学习/注意力
- 多次模仿练习后，模仿能力提升，模仿越来越像
- 模仿是社会学习的重要方式（灵魂通过模仿学习新行为）
- 模仿游戏增进亲密度（一起玩耍的快乐）

**模仿的趣味元素：**
- 灵魂偶尔会"故意"模仿得很夸张/搞笑（基于个性，高外向/高宜人更容易这样）
- 灵魂模仿失败时的笨拙反应很可爱（摔个屁股蹲/手脚不协调）
- 玩家可以和灵魂一起对着镜子模仿（在训练室的镜子前）

### 6.6 探索小游戏详细设计（M1简化版）

**M1简化版：**
- 灵魂在房间里自由探索，玩家观察
- 灵魂走到新物体前会观察/互动/评论
- 玩家可以点击物体引导灵魂探索（"去看看那个！"）
- 灵魂发现新事物时，好奇心满足+，认知经验+，记忆记录

**M2完整版：**
- 房间里有"隐藏物品"（需要灵魂探索才能发现，如书架后面的小玩具/地毯下的秘密）
- 灵魂的好奇心属性影响探索意愿（高好奇灵魂会主动翻找，低好奇灵魂需要玩家引导）
- 发现隐藏物品有奖励（物品/装饰/知识/记忆）
- 探索过程中灵魂可能触发小事件（如打翻花瓶→需要收拾→学习责任感）
- 探索记录在灵魂记忆中（"我在书架后面发现了一个小玩具！"）

**探索的成长影响：**
- 认知+（观察力/好奇心/新知识）
- 个性+（好奇心满足强化探索行为，高好奇灵魂越来越喜欢探索）
- 记忆+（探索经历是独特记忆的重要来源）
- 情感+（发现新事物的惊喜和快乐）

## 七、定制系统详细设计

### 7.1 定制系统总览

**设计理念：** 定制让玩家的灵魂和灵魂之家独一无二，是情感连接和自我表达的重要方式。定制不影响灵魂能力（纯外观/体验），符合伦理付费设计。

| 定制类型 | 内容 | 付费属性 | M1实现 |
|----------|------|----------|--------|
| 外观定制 | 形态外壳/颜色/装饰/表情 | 部分付费（基础免费，稀有付费） | M2 |
| 房间装饰 | 家具/装饰/主题 | 部分付费（基础免费，稀有付费） | M2 |
| 名字/称呼 | 灵魂名字/灵魂对玩家的称呼 | 免费 | M1 |
| 性格微调 | 个性倾向引导（长期缓慢） | 免费（不可付费加速） | M2 |
| 语音/音效 | 灵魂的声音类型/口头禅 | 部分付费 | M3 |

### 7.2 外观定制详细设计

**外观定制项目：**

| 项目 | 可选项 | 说明 |
|------|--------|------|
| 形态外壳 | 狐狸/猫/兔子/龙/史莱姆/幽灵/机器人/...（20+种） | 灵魂的外在形态，不影响能力 |
| 外壳颜色 | 主色/副色/渐变（64色板+自定义取色器） | 外壳的颜色方案 |
| 能量核心 | 形状（圆形/心形/星形/菱形...）/颜色/脉动频率 | 灵魂的能量核心外观 |
| 装饰 | 帽子/围巾/眼镜/饰品/背包/翅膀...（50+种） | 穿戴在外壳上的装饰 |
| 表情 | 基础表情（8种免费）+ 特殊表情（付费/活动解锁） | 灵魂的表情动画 |
| 动作 | 基础动作（免费）+ 特殊动作（付费/活动解锁） | 灵魂的待机/互动动作 |
| 特效 | 走路粒子/待机光环/互动特效 | 灵魂的视觉特效 |

**外观定制UI：**

```
│                                         │

│                                         │

│ [形态] [颜色] [核心] [装饰] [表情] [特效] │

│  选项网格（可选项，选中高亮，付费项标💰）  │
│  [选项1] [选项2] [选项3] [选项4]         │
│  [选项5] [选项6] [选项7] [选项8]         │

├─────────────────────────────────────────┤

```

**外观定制规则：**
- 基础外观（10种形态+基础颜色+基础装饰）免费，玩家创建灵魂时选择
- 稀有外观（特殊形态/装饰/特效）通过付费/活动/成就解锁
- 外观不影响灵魂能力（纯视觉），符合公平性
- 玩家可以保存多套外观方案（最多5套），快速切换
- 外观定制记录在灵魂记忆中（"玩家给我换了新围巾，好开心！"）
- 灵魂对外观有偏好（基于个性，如高外向喜欢鲜艳颜色，高内向喜欢素雅颜色），玩家选择灵魂喜欢的外观时，灵魂情绪+

### 7.3 房间装饰详细设计

（已在2.7节描述空间结构，此处补充定制UI和规则）

**房间装饰UI：**
- 进入"装饰模式"：场景显示装饰槽位（虚线框），玩家点击槽位选择装饰品
- 装饰品列表：按类型分类（家具/装饰/植物/互动/主题），显示稀有度/价格/是否已拥有
- 预览：选中装饰品后在场景中预览效果（可调整位置/朝向）
- 确认放置：装饰品放入槽位，灵魂可能评论（喜欢/不喜欢）

**房间装饰规则：**
- 基础装饰品免费（通过游戏内货币购买/活动奖励）
- 稀有/主题装饰品付费（外观付费，不影响能力）
- 装饰品影响灵魂情绪（喜欢的装饰→情绪加成，不喜欢→无加成）
- 房间主题（整套装饰）有额外加成和特殊视觉效果
- 玩家可以保存多套房间方案（最多3套），快速切换
- 装饰变化记录在灵魂记忆中

### 7.4 名字/称呼详细设计

**灵魂名字：**
- 玩家在创建灵魂时给灵魂起名字（2-10个字符，支持中文/英文/数字）
- 名字需要经过审核（不允许违规/冒犯性名字）
- 名字可以修改（免费修改1次，之后每次修改消耗游戏内货币）
- 灵魂会记住自己的名字，对话中引用（"我是小狐狸！"）
- 名字是灵魂身份的一部分，修改名字灵魂可能有反应（"我有新名字了！"/"有点不习惯..."）

**灵魂对玩家的称呼：**
- 玩家可以设定灵魂对自己的称呼（如"主人"/"朋友"/"哥哥"/自定义称呼，2-6字符）
- 称呼需要审核（不允许违规/冒犯性称呼）
- 灵魂在对话中使用设定的称呼（"朋友，你回来啦！"）
- 称呼可以随时修改（免费）
- 亲密度达到一定等级后，灵魂可能主动提议新称呼（"我可以叫你XX吗？"）

**名字/称呼的情感价值：**
- 名字是身份认同的核心（灵魂有了名字就有了独特的身份）
- 称呼是关系的体现（灵魂怎么称呼玩家反映了关系的亲密度和性质）
- 玩家给灵魂起名字的过程是情感投入的过程（"命名仪式"）
- 灵魂记住名字和称呼，在对话中使用，增强真实感和情感连接

### 7.5 性格微调详细设计

（已在4.6节描述个性引导，此处补充定制视角的UI和规则）

**性格微调UI：**
- 状态面板显示8维度个性雷达图（开放性/尽责性/外向性/宜人性/神经质/勇敢度/好奇心/占有欲）
- 每个维度显示当前值（0-100）和变化趋势（↑/→/↓，基于最近1个月的变化）
- 玩家可以查看每个维度的说明和影响（"勇敢度高的灵魂更倾向于进攻和冒险"）
- 玩家可以设置"引导方向"（希望灵魂往哪个方向发展），系统会在日常互动中提示

**性格微调规则：**
- 个性变化非常缓慢（每周不超过±1点），不可付费加速
- 玩家引导只是影响因素之一（灵魂自身倾向+经历+环境共同决定）
- 灵魂可能抗拒与本性冲突的引导（如天生内向的灵魂不会变成完全外向）
- 个性变化有不可逆性（一旦变化，需要长期反向引导才能调整）
- 不提供"个性重置"功能（个性是灵魂独特性的核心，不可随意修改）
- 个性变化超过阈值时，灵魂会主动提及（成长的一部分）

**性格微调的伦理设计：**
- 不允许"购买个性"（个性是灵魂的本质，不是商品）
- 不允许"完美个性"（每个灵魂都有优势和劣势，没有完美个性）
- 玩家引导需要尊重灵魂的自主性（灵魂有权利保持自己的个性）
- 个性多样性是产品的核心价值（鼓励玩家欣赏不同个性的灵魂，而不是都改成"最优个性"）

## 八、灵魂之家与对战模式的数据互通

### 8.1 数据互通总览

**设计理念：** 灵魂之家和对战模式共享同一个灵魂数据，成长是连续的。灵魂之家中的训练/教学/交流成果会在对战中体现，对战中的经历/记忆/经验也会带回灵魂之家。

**互通数据清单：**

| 数据类型 | 灵魂之家→对战 | 对战→灵魂之家 | 说明 |
|----------|--------------|--------------|------|
| 核心属性（个性/认知/情感） | ✅ 完全同步 | ✅ 完全同步 | 灵魂的核心属性在两个模式中一致 |
| 技能（等级/经验/配置） | ✅ 训练的技能在对战中使用 | ✅ 对战获得的技能经验带回 | 技能成长连续 |
| 记忆 | ✅ 灵魂之家的记忆影响对战行为 | ✅ 对战记忆带回，影响对话和行为 | 记忆是连续的 |
| 等级/经验 | ✅ 灵魂等级同步 | ✅ 对战经验带回 | 等级成长连续 |
| 情绪/精力 | ✅ 当前情绪影响对战表现 | ✅ 对战后的情绪带回 | 状态连续 |
| 外观/装饰 | ✅ 灵魂外观在对战中显示 | ❌ 对战不改变外观 | 外观统一 |
| 对战配置（技能组/战术） | ✅ 在灵魂之家中配置 | ✅ 对战中调整的配置保存 | 配置互通 |
| 排位赛积分 | ❌ 灵魂之家不影响积分 | ✅ 积分在灵魂之家显示 | 积分是对战专属 |
| 对战记录 | ❌ | ✅ 对战记录可在灵魂之家查看/复盘 | 记录互通 |

### 8.2 灵魂之家→对战的成长体现

**技能训练成果在对战中的体现：**
- 灵魂之家中训练的技能等级/经验直接在对战中生效
- 训练中学习的技能连招/战术在对战中可以使用
- 战斗训练获得的"对手类型记忆"在对战中提供加成（如训练过对敏捷型对手，对战敏捷型灵魂时反应+10%）

**认知/情感能力在对战中的体现：**
- 高认知灵魂：对战中决策更快/更优，能更好地理解玩家战术指令
- 高情感能力灵魂：对战中情绪更稳定（不会因为劣势而崩溃），能更好地配合队友
- 低认知灵魂：对战中可能做出愚蠢决策（如冲进敌群/忘记使用技能），需要玩家更多指导
- 低情感能力灵魂：对战中情绪波动大（劣势时愤怒/放弃，优势时得意忘形）

**个性在对战中的体现：**
- 高勇敢：进攻性强，敢于冒险，适合进攻型战术
- 高谨慎：防守稳健，失误少，适合防守反击战术
- 高外向：团队配合好，沟通多，适合组队对战
- 高内向：专注度高，不易被干扰，适合solo对战
- 高好奇：会尝试新战术/新技能，有惊喜但也有失误
- 高保守：使用熟悉的战术/技能，稳定但缺乏变化
- 个性是对战策略的重要维度（玩家需要根据灵魂个性制定战术）

**记忆在对战中的体现：**
- 灵魂记得之前的对战经历（"上次这个对手用了XX战术，这次要小心"）
- 灵魂记得玩家的战术偏好（"玩家喜欢让我用XX技能，这次应该也是"）
- 灵魂之家的记忆影响对战中的对话（对战间隙灵魂可能提到灵魂之家中的事）
- 重要的对战胜利/失败记忆会影响灵魂的自信/情绪

### 8.3 对战→灵魂之家的成长反馈

**对战经验带回：**
- 对战获得的技能经验/灵魂经验直接加到灵魂数据中
- 对战结束后回到灵魂之家，灵魂会分享对战经历（"刚才的对战好激烈！"/"我赢了！"）
- 对战获得的成就/奖励在灵魂之家显示/领取

**对战记忆形成：**
- 每场对战自动形成记忆（对手/结果/关键事件/灵魂的感受）
- 重要对战（排位赛/胜利/失败/名场面）形成核心记忆，影响灵魂的行为和对话
- 灵魂会在灵魂之家中主动提及对战记忆（"还记得上次我们逆风翻盘吗？"）
- 对战记忆是灵魂独特性的重要来源（每个灵魂的对战经历都是独特的）

**对战后情绪状态：**
- 胜利后：灵魂开心/自信，回到灵魂之家会庆祝/分享喜悦
- 失败后：灵魂沮丧/反思，回到灵魂之家需要玩家安慰/鼓励
- 激烈对战后：灵魂疲惫/兴奋，需要休息
- 情绪状态影响灵魂之家的互动（胜利后更活泼，失败后更沉默）

**对战中的学习与成长：**
- 灵魂在对战中学习新战术/新技能用法（实战是最好的老师）
- 对战中发现的不足（"我的防守太弱了"）会成为灵魂之家训练的重点
- 灵魂会主动要求训练（"我想加强XX技能，下次对战就能用了"）
- 形成"对战发现不足→灵魂之家训练→对战验证进步"的成长循环

### 8.4 战前准备与战后复盘

**战前准备（在灵魂之家中进行）：**
1. 玩家选择要出战的灵魂
2. 配置技能组（从已学技能中选择4-6个出战技能）
3. 制定战术（进攻/防守/平衡/针对对手个性调整）
4. 灵魂状态检查（情绪/精力，状态不好可以先休息/互动调整）
5. 鼓励灵魂（"加油！"/"我相信你！"→灵魂士气+，情感+）
6. 进入对战

**战后复盘（在灵魂之家中进行）：**
1. 对战结束后自动回到灵魂之家
2. 灵魂分享对战感受（基于结果/个性/经历）
3. 玩家可以查看对战记录/回放（关键时刻/数据统计）
4. 玩家和灵魂一起复盘（"刚才那波打得好"/"下次注意XX"）
5. 灵魂从复盘中学习（认知+，记忆记录）
6. 制定下次训练/对战计划

**战前准备和战后复盘的价值：**
- 让对战不是孤立的事件，而是灵魂成长连续过程的一部分
- 增强玩家的参与感和掌控感（不只是观战，还有赛前赛后的互动）
- 深化情感连接（赛前鼓励/赛后安慰/一起复盘是亲密的互动）
- 形成完整的成长循环（准备→对战→复盘→训练→准备）

## 九、技术实现要点

### 9.1 SoulArena对话API集成

**API调用流程：**

```
玩家输入消息
  ↓
输入过滤（<100ms，违规词/注入攻击检测）
  ↓
构建请求（玩家消息 + 灵魂状态 + 个性 + 记忆摘要 + 当前场景 + 历史对话）
  ↓
调用SoulArena对话API（HTTP/gRPC，超时5秒）
  ↓
SoulArena生成回复（基于认知子系统/语言生成/个性/记忆）
  ↓
输出审核（<500ms，违规内容检测+替换）
  ↓
灵魂回复展示（文字+表情+动作+情绪变化）
  ↓
更新灵魂状态（情绪/记忆/关系）
```

**API请求数据结构：**
```json
{
  "soul_id": "uuid",
  "player_input": "你今天怎么样？",
  "context": {
    "location": "主房间",
    "time": "2026-09-05T14:30:00Z",
    "weather": "晴",
    "recent_events": ["学会了新技能", "训练完成"]
  },
  "soul_state": {
    "personality": {"openness": 75, "extraversion": 55, ...},
    "emotion": {"joy": 60, "calm": 40, ...},
    "energy": 80,
    "cognitive_level": 35
  },
  "memory_summary": "最近与玩家的互动摘要，重要记忆",
  "dialog_history": [
    {"role": "player", "content": "..."},
    {"role": "soul", "content": "..."}
  ],
  "safety_constraints": ["不表达浪漫内容", "不操纵情感", ...]
}
```

**性能要求：**
- API响应时间：1-3秒（含生成时间，模拟真实思考）
- 并发支持：单服务器支持100+同时对话
- 可用性：99.9%（对话是核心功能，不能频繁失败）
- 降级方案：API超时时，灵魂使用预设回复（基于个性的短句，如"...嗯。"/"今天天气不错呢。"），不影响体验

### 9.2 灵魂主动行为系统

**主动行为触发架构：**
```
灵魂状态监控（持续运行）
  ↓
检查触发条件（时间/事件/情绪/需求/个性/记忆/环境）
  ↓
条件满足→生成主动行为内容（说话/动作/互动请求）
  ↓
安全审核（内容审核+频率控制）
  ↓
执行主动行为（灵魂说话/做动作/寻求玩家注意）
  ↓
玩家响应（玩家互动/忽略）
  ↓
更新灵魂状态（玩家响应影响情绪/关系/记忆）
```

**主动行为频率控制：**
- 基础频率：每3-8分钟一次（基于个性）
- 计时器：每次主动行为后重置，到时间后检查触发条件
- 玩家互动后延迟：玩家刚互动完，2分钟内不触发主动说话（给玩家空间）
- 深夜降低：22:00-8:00频率降低50%
- 精力低时降低：精力<30时频率降低70%（累了不想说话）
- 亲密度加成：亲密度越高，频率越高（关系好更愿意交流）
- 上限保护：每小时最多8次主动说话（防止刷屏）

**主动行为内容生成：**
- 基于SoulArena的主动行为子系统
- 结合当前状态/个性/记忆/环境/与玩家的关系
- 内容多样性：不重复说同样的话（基于历史记录去重）
- 内容相关性：与当前场景/最近事件/玩家状态相关
- 个性一致性：内容符合灵魂个性（外向活泼，内向简短）

### 9.3 成长反馈可视化系统

**成长事件触发与展示：**
```
成长事件发生（技能经验增加/等级提升/属性变化）
  ↓
生成成长反馈（经验数值+进度条变化+动画+灵魂反应）
  ↓
反馈队列管理（多个反馈排队展示，不重叠）
  ↓
展示反馈（底部右侧弹出，3秒后消失，可点击查看详情）
  ↓
重要反馈（升级/里程碑）：特殊动画+暂停其他反馈+灵魂庆祝
```

**成长反馈类型：**

| 类型 | 展示方式 | 持续时间 | 示例 |
|------|----------|----------|------|
| 经验增加 | 小字弹出"+10 技能经验" | 2秒 | "近战技能经验 +10" |
| 进度条变化 | 状态面板进度条增长 | 实时 | 技能经验条从30%→35% |
| 技能升级 | 庆祝动画+弹窗+灵魂反应 | 5秒 | "技能升级！近战 Lv.2→Lv.3" |
| 属性提升 | 特殊光效+弹窗 | 4秒 | "认知能力提升！Lv.3→Lv.4" |
| 个性变化 | 雷达图高亮+灵魂感言 | 5秒 | "勇敢度 +1（最近的战斗让你更勇敢了）" |
| 里程碑 | 全屏庆祝+成就弹窗 | 8秒 | "训练100小时达成！" |
| 记忆形成 | 小图标+提示 | 3秒 | "新记忆：第一次训练胜利" |

**可视化技术实现：**
- Godot的AnimationPlayer + Tween实现动画
- 粒子系统（GPUParticles2D）实现庆祝特效
- 进度条使用TextureProgress，平滑过渡（0.3秒插值）
- 反馈队列使用数组管理，按优先级排序（升级>经验增加）
- 重要反馈时暂停游戏背景音乐，播放庆祝音效

### 9.4 安全审核集成

（已在12文档详细定义，此处为灵魂之家特定实现要点）

**灵魂之家审核流程：**
1. 玩家输入→输入过滤（违规词/变体/注入攻击，<100ms）
2. 过滤通过→SoulArena生成回复（带安全约束System Prompt）
3. 生成回复→输出审核（违规内容检测，<500ms）
4. 审核通过→展示回复
5. 审核不通过→替换为安全回复（基于个性的自然转移话题，如"这个不太想聊呢，说点别的吧"）
6. 记录审核日志（被拦截的内容，用于人工复核和模型优化）

**灵魂之家特定审核规则：**
- 灵魂不表达浪漫/性暗示内容（保持朋友关系定位）
- 灵魂不说情感操纵内容（"不陪我就消失/生病"）
- 灵魂不鼓励危险/违法行为
- 深夜提醒休息（22:00后灵魂会说"很晚了，早点睡吧"）
- 未成年人模式更严格的内容过滤
- 玩家输入违规时，灵魂自然转移话题，不批评玩家

**情感依赖监测：**
- 监控指标：日在线时长/对话频率/情感表达强度/依赖语言
- 轻度依赖（>6小时/天）：灵魂自然鼓励玩家做别的事
- 中度依赖（>10小时/天）：系统提示+灵魂说"我也需要自己的时间"
- 重度依赖：人工介入
- 干预是保护性的，灵魂语气是关心的

### 9.5 灵魂之家场景技术实现

**场景复杂度：**
- 单房间20×15格（48×48像素/格），场景分辨率960×720像素
- 交互物体10-15个，每个有独立的动画/交互逻辑
- 灵魂1个（M1），M2支持2-3个灵魂同时在房间
- 粒子特效：环境粒子（灰尘/光线/树叶）+ 情绪粒子 + 互动特效

**性能目标：**
- 帧率：>60fps（中端PC），>30fps（低端PC）
- 内存占用：<500MB
- 加载时间：<3秒（房间切换）
- 灵魂AI推理：不影响渲染帧率（异步推理，主线程不阻塞）

**灵魂自主行为实现：**
- 灵魂的AI决策在异步线程运行（不阻塞渲染主线程）
- 决策频率：1-5次/秒（基于灵魂活跃度，活跃时高频，休眠时低频）
- 行为执行：决策结果发送到主线程，播放对应动画/移动/交互
- 灵魂移动使用Seed的MovementController（物理移动+到达检测）
- 灵魂与物体交互使用碰撞检测+交互触发器

**房间切换实现：**
- 房间场景预加载（进入灵魂之家时预加载所有4个房间，切换时不加载）
- 切换时播放0.5秒过渡动画（淡入淡出/门动画）
- 灵魂位置重置到目标房间出生点
- 房间状态保持（每个房间的物体状态/装饰独立保存）
