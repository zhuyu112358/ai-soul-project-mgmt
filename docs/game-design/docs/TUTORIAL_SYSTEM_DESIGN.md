## 一、系统概述

### 1.1 设计目标
- 为新玩家提供清晰、友好的新手引导，快速掌握游戏核心玩法
- 配合已产出的tutorial_ui_skin.png（教程新手引导界面UI皮肤）
- 教程设计遵循"边玩边学"原则，不使用纯文本说明
- 教程可跳过，老玩家不会被强制引导
- 教程进度可保存，玩家可随时重新查看

### 1.2 教程设计原则
- **边玩边学**: 在实际游戏操作中学习，而非纯文本说明
- **循序渐进**: 从基础操作到高级技巧，逐步引导
- **即时反馈**: 玩家操作后立即给予视觉/音效反馈
- **可跳过**: 每个教程步骤都可跳过，不强制玩家
- **可重玩**: 教程完成后可在设置中重新查看
- **视觉引导**: 使用高亮框、箭头、手势图标引导玩家操作
- **数据可视化**: 教程中的数据用图标+进度条展示，不使用纯文本列表

### 1.3 教程类型
| 类型 | 说明 | 触发时机 |
|------|------|----------|
| 首次进入教程 | 游戏首次启动时的完整引导 | 新玩家首次进入游戏 |
| 场景引导 | 进入新场景时的简要引导 | 首次进入主菜单/灵魂选择/RTS竞技场等 |
| 功能解锁引导 | 新功能解锁时的引导 | 等级提升解锁新技能/新功能时 |
| 操作提示 | 游戏中的即时操作提示 | 玩家首次遇到新操作时 |
| 帮助手册 | 完整的游戏帮助文档 | 设置界面中随时查看 |

## 二、首次进入教程（完整流程）

### 2.1 教程流程概览
首次进入教程分为6个阶段，预计5-8分钟完成：

| 阶段 | 场景 | 内容 | 时长 |
|------|------|------|------|
| 1 | 主菜单 | 欢迎界面+基础导航 | 1分钟 |
| 2 | 灵魂选择 | 选择第一个灵魂单位 | 1分钟 |
| 3 | RTS竞技场（基础） | 移动/选中/攻击基础操作 | 2分钟 |
| 4 | RTS竞技场（技能） | 技能释放/冷却/能量管理 | 2分钟 |
| 5 | 战斗结算 | 查看战斗结果/奖励/升级 | 1分钟 |
| 6 | 灵魂之家 | 灵魂成长/互动/训练介绍 | 1分钟 |

### 2.2 阶段1：主菜单欢迎引导

**触发条件**: 新玩家首次进入游戏

**引导内容**:
1. **欢迎弹窗**（居中面板，金色边框，深紫背景）
   - 标题："欢迎来到战策"（金色大号像素字体）
   - 描述："在灵魂对战竞技场中，指挥你的灵魂军团取得胜利！"
   - 灵魂单位展示：一个蓝色灵魂球漂浮在金色基座上
   - 按钮："开始引导"（金色边框）+ "跳过引导"（灰色边框）

2. **主菜单导航引导**（高亮框+箭头）
   - 高亮"开始战斗"按钮，箭头指向，文字："点击这里开始战斗"
   - 玩家点击后，高亮"灵魂选择"按钮，文字："在这里选择和管理你的灵魂"
   - 玩家点击后，高亮"设置"按钮，文字："在这里调整游戏设置"
   - 完成后提示："很好！现在让我们选择你的第一个灵魂。"

**视觉元素**:
- 高亮框：金色发光边框，脉冲动画
- 箭头：金色像素箭头，指向目标
- 手势图标：手指点击图标
- 遮罩：半透明深紫遮罩，突出高亮区域

**音效**:
- 欢迎弹窗打开：ui_panel_open
- 按钮点击：ui_button_click
- 引导完成：battle_victory（简短版）

### 2.3 阶段2：灵魂选择引导

**触发条件**: 首次进入灵魂选择界面

**引导内容**:
1. **灵魂卡片介绍**（高亮第一个灵魂卡片）
   - 高亮火灵魂卡片，文字："这是火元素灵魂，攻击力高，适合进攻"
   - 显示灵魂属性面板（ATK/DEF/SPD图标+数字，HP/MP球形血条）
   - 提示："点击卡片查看详情"

2. **选择灵魂**（高亮确认按钮）
   - 玩家选择一个灵魂后，高亮"确认选择"按钮
   - 文字："确认选择这个灵魂开始战斗"
   - 玩家点击后，灵魂被选中，金光爆发特效

3. **灵魂属性说明**（弹出属性说明面板）
   - ATK（攻击力）：影响技能伤害
   - DEF（防御力）：减少受到的伤害
   - SPD（速度）：影响攻击频率和移动速度
   - HP（生命值）：灵魂的生命值，归零则阵亡
   - MP（能量值）：释放技能消耗能量

**视觉元素**:
- 灵魂卡片高亮：金色发光边框+放大效果
- 属性图标：ATK剑/DEF盾/SPD翅膀/HP心/MP水滴
- 球形血条：HP绿色球/MP蓝色球

**音效**:
- 卡片悬停：ui_button_hover
- 卡片选中：ui_button_click
- 确认选择：battle_start（简短版）

### 2.4 阶段3：RTS竞技场基础操作引导

**触发条件**: 首次进入RTS竞技场，战斗开始前

**引导内容**:
1. **选中单位**（高亮玩家灵魂单位）
   - 高亮玩家蓝色灵魂单位，文字："点击选中你的灵魂单位"
   - 玩家点击后，单位脚下出现金色选中圆圈，右侧显示单位信息面板
   - 提示："选中后可以查看单位属性和状态"

2. **移动单位**（高亮地面目标位置）
   - 高亮地面一个金色标记点，文字："右键点击地面，让单位移动到那里"
   - 玩家右键点击后，单位移动到目标位置，带蓝色移动尾迹
   - 提示："很好！单位会自动寻路移动"

3. **攻击敌人**（高亮AI红色灵魂单位）
   - 高亮AI红色灵魂单位，文字："右键点击敌人，让单位攻击它"
   - 玩家右键点击后，单位移动到攻击范围并自动攻击
   - 命中时显示伤害飘字（白色普通伤害）
   - 提示："单位会自动攻击范围内的敌人"

4. **框选多个单位**（如果有多个单位）
   - 文字："按住左键拖动，可以框选多个单位"
   - 玩家框选后，多个单位脚下出现选中圆圈
   - 提示："框选后可以同时指挥多个单位"

**视觉元素**:
- 选中圆圈：金色发光圆圈，单位脚下
- 移动标记：金色X标记，目标位置
- 攻击范围：金色半透明圆圈，单位周围
- 伤害飘字：白色数字，受击单位上方
- 框选框：金色半透明矩形，拖动时显示

**音效**:
- 单位选中：ui_button_click
- 移动命令：ui_button_hover（简短版）
- 普通命中：hit_normal
- 引导提示：ui_panel_open

### 2.5 阶段4：技能释放引导

**触发条件**: 基础操作引导完成后，战斗进行中

**引导内容**:
1. **技能栏介绍**（高亮底部技能栏）
   - 高亮底部6个技能图标，文字："这是技能栏，按Q/W/E/R/T/Y释放对应技能"
   - 每个技能图标显示：技能图标+冷却遮罩+按键绑定
   - 提示："技能消耗能量（MP），冷却时间内无法释放"

2. **释放第一个技能**（高亮Q键技能）
   - 高亮Q键技能图标（火球），文字："按Q键释放火球技能，对敌人造成火焰伤害"
   - 玩家按Q后，火球从单位射出，命中敌人爆炸，显示伤害飘字
   - 技能图标显示冷却遮罩+倒计时
   - 提示："很好！火球技能造成了大量伤害"

3. **能量管理**（高亮MP球形血条）
   - 高亮顶部MP球形血条，文字："释放技能消耗能量，能量会自动恢复"
   - 显示MP减少和恢复的动画
   - 提示："合理管理能量，不要在关键时刻没有能量释放技能"

4. **治疗技能**（高亮E键技能）
   - 高亮E键技能图标（治疗），文字："按E键释放治疗技能，恢复生命值"
   - 玩家按E后，绿色治愈光环围绕单位，HP恢复，显示绿色+30飘字
   - 提示："治疗技能可以在战斗中恢复生命值"

5. **护盾技能**（高亮R键技能）
   - 高亮R键技能图标（护盾），文字："按R键释放护盾技能，获得护盾吸收伤害"
   - 玩家按R后，蓝色护盾光环围绕单位，显示护盾值
   - 提示："护盾可以吸收敌人的伤害，保护你的灵魂"

**视觉元素**:
- 技能图标：64x64像素图标，金色边框
- 冷却遮罩：灰色扇形遮罩+倒计时数字
- 按键绑定：Q/W/E/R/T/Y金色文字，图标右下角
- 技能特效：火球爆炸/治愈光环/护盾光环（使用particle_texture_sheet.png）
- 伤害飘字：白色普通/金色暴击/绿色治疗
- MP球形血条：蓝色球形，顶部状态栏

**音效**:
- 技能释放（火球）：skill_fireball
- 技能释放（治疗）：skill_heal
- 技能释放（护盾）：skill_shield
- 普通命中：hit_normal
- 暴击命中：hit_critical

## 五、操作提示（即时提示）

### 5.1 提示类型
| 类型 | 触发条件 | 显示方式 | 持续时间 |
|------|----------|----------|----------|
| 操作提示 | 玩家首次遇到新操作 | 底部横幅+图标 | 5秒 |
| 状态提示 | 单位状态变化（眩晕/冰冻/中毒） | 单位头顶图标 | 状态持续 |
| 警告提示 | 单位HP低于30% | 红色边框闪烁+警告图标 | 直到HP恢复 |
| 冷却提示 | 技能冷却完成 | 技能图标闪光+提示音 | 2秒 |
| 能量提示 | MP不足释放技能 | MP条红色闪烁+提示 | 2秒 |

### 5.2 操作提示示例
- "按空格键暂停游戏"
- "按~键打开调试面板"
- "按Tab键切换选中单位"
- "按1-6键快速选中对应单位"

- **位置**: 教程面板底部中央

- **位置**: 教程面板右上角或底部右侧
- **样式**: 灰色边框按钮，文字"跳过"
- **功能**: 点击后跳过当前教程阶段，进入下一阶段或结束教程

## 八、教程进度保存

### 8.1 保存内容
- 教程完成状态（哪些阶段已完成）
- 场景引导显示状态（哪些场景已显示过引导）
- 功能解锁引导显示状态（哪些功能已显示过引导）
- 操作提示显示状态（哪些提示已显示过）
- 帮助手册阅读进度

### 8.2 保存方式
- 使用Godot的`ConfigFile`保存到`user://tutorial_progress.cfg`
- 每次教程状态变化时自动保存
- 游戏启动时加载进度

### 8.3 重置教程
- 在设置界面提供"重置教程"按钮
- 点击后弹出确认面板"确定要重置所有教程进度吗？"
- 确认后清除所有教程进度，下次进入游戏重新开始教程
