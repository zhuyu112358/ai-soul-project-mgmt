## 1. 设计概述

### 1.1 设计目标

战策作为RTS灵魂对战竞技场，社交系统是提升玩家留存和社区活跃度的核心功能。本设计文档涵盖三大社交模块：

- **排行榜系统**：展示玩家竞技成绩，激发竞争欲望
- **邮件系统**：系统通知、奖励发放、玩家私信
- **好友系统**：好友添加、好友对战、好友状态

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **轻量级** | M3阶段先实现核心功能，不做复杂社交网络 |
| **异步优先** | 排行榜/邮件支持离线查看，好友对战先做异步挑战 |
| **风格统一** | 所有UI严格遵循2D像素奇幻+深紫金色风格 |
| **数据可视化** | 排名用徽章+进度条，不用纯文本列表 |
| **奖励驱动** | 排行榜定期发放奖励，邮件承载奖励发放 |

### 1.3 与M2的关系

- M2（当前）：核心玩法闭环（主菜单→灵魂选择→RTS对战→战斗结算→灵魂之家→设置）
- M3（EA后第一个大更新）：社交系统+更多灵魂单位+新地图+平衡性调整
- 本设计文档为M3社交系统提供完整设计规格

## 2. 排行榜系统

### 2.1 排行榜类型

| 排行榜 | 说明 | 更新频率 | 显示数量 |
|--------|------|----------|----------|
| **天梯排行榜** | 按天梯积分排名 | 实时 | 前100名+自己排名 |

| **赛季排行榜** | 按赛季积分排名 | 赛季结束结算 | 前200名 |

### 2.2 天梯积分系统

#### 积分计算

```
基础积分 = 1000（初始）
胜利积分 = +15 ~ +30（根据对手积分差）
失败积分 = -10 ~ -25（根据对手积分差）
连胜加成 = 连胜数 × 2（上限+20）
段位保护 = 段位内前3场失败不扣分
```

### 4.4 好友挑战系统

#### 异步挑战流程

1. 玩家A在好友列表点击"挑战"
2. 选择挑战规则（灵魂阵容/地图/回合时间）
3. 发送挑战请求（通过邮件系统）
4. 玩家B收到挑战邮件，选择接受/拒绝
5. 接受后进入异步对战（玩家B先打，记录操作）
6. 玩家A收到战报邮件，可观看回放
7. 双方获得积分/奖励

#### 挑战规则

| 规则项 | 选项 |
|--------|------|
| 灵魂阵容 | 1v1 / 3v3 / 5v5 |
| 地图 | 随机 / 指定地图 |
| 回合时间 | 30秒 / 60秒 / 90秒 |
| 积分 | 计入天梯 / 不计分（友谊赛） |

## 8. 与现有系统集成

### 8.1 与战斗系统集成

- 对战结束后自动更新排行榜数据（积分/胜场/连胜）
- 异步好友挑战复用现有RTS对战系统
- 战报邮件包含对战回放数据

### 8.2 与灵魂之家集成

- 好友详情显示常用灵魂单位
- 好友状态"灵魂之家"表示在灵魂之家界面
- 可在好友详情查看好友灵魂单位成长情况

### 8.3 与成就系统集成

- 排行榜相关成就（首次上榜/进入前100/进入前10等）
- 好友相关成就（添加首个好友/好友数达到10/好友挑战胜利等）
- 邮件相关成就（领取100封奖励邮件等）

### 8.4 与音频系统集成

- 所有社交UI交互使用现有P0/P1音效
- 新邮件提示使用 ui_tooltip.wav
- 领取奖励使用 coin_gain.wav / exp_gain.wav
- 发送挑战使用 unit_attack.wav
- 排行榜更新可新增专属音效（P2）

### 8.5 与UI主题集成

- 所有社交界面使用现有 battleplan_theme.tres
- 面板样式使用现有 StyleBoxFlat（深紫+金色边框）
- 按钮样式使用现有按钮皮肤
- 字体使用现有 FontLoader.gd 加载的像素字体
