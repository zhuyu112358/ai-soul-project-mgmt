## 一、系统概述

### 1.1 设计目标
- 为战策 Battleplan 提供完整的游戏内商店与物品系统
- 配合已产出的16个物品装备图标和12个资源货币图标
- 提供灵魂单位成长的物品/装备/消耗品系统
- 增强游戏深度和玩家粘性
- 符合2D像素奇幻风格，深紫+金色调

### 1.2 系统组成
| 子系统 | 说明 |
|--------|------|
| 货币系统 | 金币（Gold）、灵魂碎片（Soul Shard）、元素精华（Element Essence） |
| 物品系统 | 消耗品、材料、收藏品 |
| 装备系统 | 武器、防具、饰品 |
| 商店系统 | 普通商店、神秘商店、元素商店 |
| 背包系统 | 物品存储、分类、使用 |
| 掉落系统 | 战斗奖励、宝箱、成就奖励 |

### 1.3 设计原则
- **简单易懂**: 物品分类清晰，用途明确
- **有意义的选择**: 装备和物品提供有意义的build选择
- **渐进式解锁**: 高级物品随游戏进度解锁
- **经济平衡**: 货币获取和消耗平衡，避免通货膨胀
- **视觉统一**: 所有UI遵循2D像素奇幻风格，深紫+金色调

## 二、货币系统

### 2.1 货币类型
| 货币 | 图标 | 获取方式 | 用途 | 稀有度 |
|------|------|----------|------|--------|
| 金币（Gold） | 金色硬币图标 | 战斗胜利、任务、出售物品 | 购买普通物品、装备、消耗品 | 普通 |
| 灵魂碎片（Soul Shard） | 紫色灵魂碎片图标 | 战斗结算、成就、分解装备 | 购买稀有物品、升级技能、灵魂进化 | 稀有 |
| 元素精华（Element Essence） | 四元素精华图标（火/水/土/风） | 元素战斗、分解元素装备、特殊事件 | 购买元素专属装备、元素技能升级 | 史诗 |

### 2.2 货币获取平衡
| 货币 | 新手期（0-5h） | 进阶期（5-20h） | 精通期（20h+） |
|------|----------------|-----------------|----------------|
| 金币/小时 | 200-500 | 500-1500 | 1500-3000 |
| 灵魂碎片/小时 | 5-15 | 15-40 | 40-80 |
| 元素精华/小时 | 0-2 | 2-8 | 8-20 |

### 2.3 货币消耗设计
- **金币消耗**: 普通装备（100-1000）、消耗品（20-200）、技能升级（500-5000）
- **灵魂碎片消耗**: 稀有装备（50-200）、灵魂进化（100-1000）、技能重置（50-200）
- **元素精华消耗**: 元素专属装备（20-100）、元素技能升级（10-50）、元素变换（50-200）

## 六、背包系统

### 6.1 背包容量
- **基础容量**: 30格
- **扩展**: 可通过商店购买背包扩展（+10格，最多扩展到60格）
- **分类标签**: 全部/消耗品/装备/材料/收藏品
- **排序**: 按稀有度/名称/类型排序

### 6.2 背包UI设计
- **布局**: 网格布局，每行6格，共5行（30格）
- **物品格**: 深紫背景#1e1630，金色边框#d4a85c
  - 物品图标（48x48像素）+ 数量（右下角白色数字）
  - 稀有度颜色边框（普通灰/稀有蓝/史诗紫/传说金）
  - 装备已穿戴：绿色勾标记
- **物品详情**: 点击物品后右侧显示详情面板
  - 大图标（96x96）+ 名称+稀有度+描述+属性+使用/装备/出售按钮
- **底部**: 金币显示+整理按钮+关闭按钮

### 6.3 物品操作
| 操作 | 说明 |
|------|------|
| 使用 | 消耗品直接使用，装备穿戴到对应槽位 |
| 装备 | 穿戴到装备槽位，替换已有装备 |
| 卸下 | 将装备放回背包 |
| 出售 | 出售给商店，获得金币（售价为原价的50%） |
| 分解 | 分解装备获得材料（稀有度越高材料越多） |
| 整理 | 自动整理背包，按类型和稀有度排序 |

## 八、经济平衡设计

### 8.1 金币循环
- **获取**: 战斗（主要）、任务、成就、出售物品
- **消耗**: 购买物品/装备、技能升级、背包扩展、复活
- **平衡目标**: 玩家每小时净收入（获取-消耗）为正，但不会快速通货膨胀
- **金币回收**: 技能升级（大量金币）、装备强化、神秘商店高价物品

### 8.2 物品价值曲线
| 物品等级 | 购买价格 | 出售价格（50%） | 战斗掉落率 |
|----------|----------|----------------|-----------|
| 普通 | 100-300 | 50-150 | 15% |
| 稀有 | 300-800 | 150-400 | 5% |
| 史诗 | 800-2000 | 400-1000 | 1% |
| 传说 | 2000-5000 | 1000-2500 | 0.1% |

### 8.3 避免的问题
- ❌ 避免金币过剩（高级物品和技能升级消耗大量金币）
- ❌ 避免装备碾压（装备属性加成控制在30%以内，技术更重要）
- ❌ 避免Pay-to-Win（EA阶段无内购，所有物品游戏内获取）
- ✅ 鼓励多种build（不同装备组合有不同优势）
- ✅ 渐进式难度（高级物品对应高级内容）
