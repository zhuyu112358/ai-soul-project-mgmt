## 一、音效设计原则

### 1.1 整体风格
- **芯片音乐风格（Chiptune）**: 8-bit/16-bit复古游戏音效，与像素美术风格统一
- **奇幻魔法主题**: 带有东方神秘元素的魔法音效，灵魂/能量/符文主题
- **深紫+金色氛围**: 音效色调偏神秘、温暖、金色光辉感，避免冰冷工业感
- **简洁明快**: UI交互音效短促（0.1-0.5秒），不干扰游戏体验
- **层次分明**: 不同交互类型有明显区分度，玩家能通过音效识别操作类型

### 1.2 技术规格
- **格式**: WAV（16-bit, 44100Hz, 立体声）
- **音量规范**: UI音效 -12dB ~ -8dB，战斗音效 -10dB ~ -6dB，背景音乐 -18dB ~ -14dB
- **循环**: 背景音乐循环播放，UI音效单次播放，环境音效可循环
- **声道**: 立体声，UI音效居中，战斗音效根据单位位置左右偏移

### 1.3 音量层级
| 层级 | 类型 | 音量范围 | 说明 |
|------|------|----------|------|
| L1 | 背景音乐 | -18dB ~ -14dB | 底层氛围，不盖过音效 |
| L2 | 环境音效 | -16dB ~ -12dB | 场景氛围，可循环 |
| L3 | UI交互音效 | -12dB ~ -8dB | 界面操作反馈 |
| L4 | 战斗音效 | -10dB ~ -6dB | 战斗动作反馈 |
| L5 | 重要事件音效 | -8dB ~ -4dB | 胜利/失败/升级/成就 |

## 五、背景音乐设计

### 5.1 音乐风格
- **芯片音乐（Chiptune）**: 8-bit/16-bit复古游戏音乐，方波+三角波+噪声为主
- **奇幻魔法主题**: 带有东方神秘元素的旋律，灵魂/能量/符文主题
- **深紫+金色氛围**: 旋律偏神秘、温暖、金色光辉感，避免冰冷工业感
- **循环无缝**: 每首音乐开头和结尾无缝衔接，循环播放无突兀感

### 5.3 音乐层次
- **底层**: 方波低音（bassline），提供节奏和氛围基础
- **中层**: 三角波主旋律（melody），提供情感和记忆点
- **高层**: 三角波/方波装饰音（arpeggio），提供华丽感和金色光辉
- **节奏层**: 噪声鼓点（drums），提供节奏感和动力
- **氛围层**: 持续方波/噪声底噪（pad），提供空间感和深度

## 六、音效实现建议

### 6.1 Godot 4 实现
- 使用 `AudioStreamPlayer` 节点播放UI音效和战斗音效
- 使用 `AudioStreamPlayer2D` 节点播放2D位置相关音效（根据单位位置左右偏移）
- 使用 `AudioStreamPlayer` 节点循环播放背景音乐和环境音效
- 使用 `AudioBus` 分层管理音量（Master / BGM / SFX / UI / Voice）
- 使用 `AudioEffectPitchShift` 实现音调变化（技能等级提升时音调上升）

### 6.2 音效池
- 创建音效对象池，避免频繁创建/销毁AudioStreamPlayer
- 同类型音效最多同时播放3-5个，避免音效叠加过载
- 重要事件音效（胜利/失败/升级）优先播放，可打断普通音效

### 6.3 音量设置
- 在设置界面提供4个音量滑块：主音量、背景音乐、音效、语音
- 音量范围0-100，默认值：主音量80、背景音乐65、音效90、语音75
- 音量变化实时生效，拖动滑块时播放预览音效

## 七、音效优先级与冲突处理

### 7.1 优先级排序
1. **L5 重要事件**: 胜利/失败/升级/成就（最高优先级，可打断其他）
2. **L4 战斗音效**: 技能释放/暴击/死亡（高优先级）
3. **L3 UI交互**: 按钮点击/面板打开（中优先级）
4. **L2 环境音效**: 场景氛围（低优先级，持续循环）
5. **L1 背景音乐**: 底层音乐（最低优先级，持续循环）

### 7.2 冲突处理
- 同类型音效同时触发时，只播放最新的一个（避免叠加）
- 高优先级音效可打断低优先级音效
- 重要事件音效播放时，其他音效音量临时降低30%（闪避效果）
- 战斗激烈时，UI音效音量临时降低20%，突出战斗音效
