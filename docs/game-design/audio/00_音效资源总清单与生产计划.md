## 一、资源生产总览

### 1.1 生产原则

| 原则 | 说明 |
|------|------|
| **版权安全** | 所有音效自行生成（AI生成/代码合成/程序化生成），禁止使用第三方受版权保护的素材 |
| **风格一致** | 音效风格统一为"温暖合成器+自然环境音"，8-bit复古元素点缀，避免刺耳高频 |
| **规格统一** | 统一采样率44100Hz、16bit、WAV格式，音效时长不超过3秒（BGM除外） |
| **优先级驱动** | 按M1（灵魂之家+成长基础）→M2（对战竞技场）→M3（世界探索+社交）的里程碑顺序生产 |
| **可替换** | 早期资源可以是占位符，但必须有明确的规格文档，后续可无缝替换为高品质资源 |
| **灵魂个性** | 每个灵魂有独特的声音特质（音色/音调/语速），通过TTS参数和音效变体实现 |

### 1.2 资源统计（预估）

| 资源类别 | M1需求 | M2需求 | M3需求 | 总计 |
|----------|--------|--------|--------|------|

### 1.3 命名规范

```
{类别}_{名称}_{变体}.wav
```

| 类别前缀 | 说明 | 示例 |
|----------|------|------|
| `ui_` | UI音效 | `ui_button_click.wav` |
| `act_` | 动作音效 | `act_walk_wood.wav` |
| `env_` | 环境音效 | `env_rain_light.wav` |
| `soul_` | 灵魂音效 | `soul_happy_chime.wav` |
| `bat_` | 战斗音效 | `bat_attack_hit.wav` |
| `bgm_` | 背景音乐 | `bgm_home_mainroom.wav` |

### 1.4 技术规格

| 参数 | 值 | 说明 |
|------|-----|------|
| 采样率 | 44100 Hz | CD品质，兼容性好 |
| 位深 | 16 bit | 标准WAV格式 |
| 声道 | 立体声（UI/灵魂/BGM）/ 单声道（动作/环境/战斗，3D空间化） | 空间音效使用单声道源，由引擎3D化 |
| 格式 | WAV（源文件）+ OGG（游戏内压缩） | WAV用于编辑，OGG用于游戏内 |
| 音效时长 | ≤3秒（UI/动作/灵魂），≤5秒（战斗） | 避免过长音效堆积 |
| 环境音效 | 可循环（loop），10-30秒循环段 | 无缝循环 |
| BGM时长 | 2-4分钟（可循环） | 主循环段+引子+尾声 |
| 响度标准 | -16 LUFS（BGM），-20 LUFS（音效） | 避免响度战争，保护听力 |
| 峰值限制 | ≤-1 dBTP | 防止削波失真 |

**BGM动态变化设计：**
- 每首BGM有3个层次：基础层（钢琴/主旋律）+节奏层（鼓点/贝斯）+装饰层（风铃/弦乐）
- 根据灵魂情绪动态增减层次：快乐时增加装饰层，悲伤时减少节奏层，平静时只有基础层
- 房间切换时BGM交叉淡入淡出（2秒过渡）
- 长时间停留（>10分钟）时BGM自然变奏（加入即兴元素，避免听觉疲劳）

## 五、生产方式与工具链

### 5.1 AI音频生成

| 工具 | 用途 | 优势 | 限制 |
|------|------|------|------|
| text_to_audio（文生音频） | UI音效、动作音效、灵魂音效、BGM | 快速生成，风格多样，描述驱动 | 精度有限，需后期处理 |
| audio_to_audio（参考音频生成） | 基于参考音效细化、风格转换 | 保持音色特征，提升品质 | 需参考音频 |

**AI生成工作流：**
1. 编写详细的音效描述（音色/时长/节奏/情绪/场景）
2. text_to_audio生成候选音效（生成2-3个变体）
3. 人工筛选最佳变体
4. 后期处理（Audacity：裁剪/淡入淡出/音量标准化/降噪）
5. 导出为WAV（44100Hz/16bit）
6. Godot中测试播放（3D空间化、音量平衡、触发时机）

### 5.2 代码合成/程序化生成

| 工具 | 用途 | 优势 |
|------|------|------|
| Python (numpy/scipy) | 基础波形合成、音效算法生成 | 精确参数控制，批量生成 |
| Godot AudioStreamGenerator | 实时合成音效（如滑块移动、连续噪音） | 零资源文件，实时参数调整 |
| Web Audio API | 浏览器端音效合成（原型验证） | 快速原型，可视化调试 |

**可代码合成的音效类型：**
- 正弦波/方波/锯齿波基础音
- 频率扫描（上升/下降琶音）
- 噪音生成（白噪/粉噪/棕噪，用于风声/雨声）
- 包络调制（ADSR包络）
- 简单打击乐（kick/snare/hat合成）

### 5.3 TTS语音系统

| 组件 | 说明 | 优先级 |
|------|------|--------|
| TTS引擎 | 混合TTS方案（高效模型+情感参数） | P0 |
| 灵魂声音参数 | 每个灵魂有独特的音色/音调/语速/情感曲线 | P0 |
| 语音情感 | 快乐/悲伤/愤怒/恐惧/平静/兴奋6种基础情感 | P0 |
| 语音速度 | 正常/快速（兴奋）/缓慢（悲伤/疲惫） | P1 |
| 语音停顿 | 自然停顿，思考时的延迟 | P1 |
| 笑声/哭声 | 非语言情感发声 | P2 |

**TTS成本控制：**
- 单灵魂月成本¥0.5-2约束下，TTS使用高效模型
- 缓存常用短语，减少重复生成
- 离线TTS用于高频短语，在线TTS用于复杂对话
- 语音质量目标："足够有表现力"，不追求顶级音质

### 5.4 资源验证清单

每个音效产出后必须验证：

- [ ] 采样率44100Hz，16bit，WAV格式
- [ ] 时长符合规格（UI/动作≤3秒，BGM 2-4分钟）
- [ ] 响度标准化（-16 LUFS BGM / -20 LUFS 音效）
- [ ] 峰值≤-1 dBTP（无削波）
- [ ] 无缝循环（环境音/BGM的循环点无爆音）
- [ ] 风格一致（温暖合成器+自然环境音，无刺耳高频）
- [ ] 命名规范正确（`{类别}_{名称}_{变体}.wav`）
- [ ] 版权状态标注（自行生成，无第三方版权）
- [ ] Godot中测试播放正常（3D空间化、音量平衡、触发时机）
- [ ] 多音效同时播放时无混叠失真（音效混音测试）

## 六、音频技术实现要点

### 6.1 Godot 4音频架构

| 组件 | 说明 |
|------|------|
| AudioStreamPlayer | 2D音效（UI/BGM），非空间化 |
| AudioStreamPlayer2D | 2D空间音效（动作/环境/灵魂），有位置和衰减 |
| AudioStreamPlayer3D | 3D空间音效（世界探索），HRTF支持 |
| AudioBus | 音频总线架构（Master/BGM/SFX/Voice/Ambient） |
| AudioEffect | 音效处理（Reverb/Delay/Compressor/EQ） |
| AudioStreamGenerator | 实时合成音频 |

### 6.2 音频总线布局

```
Master (主输出)
├── BGM (背景音乐，-6dB)
│   ├── BGM_Layer1 (基础层)
│   ├── BGM_Layer2 (节奏层)
│   └── BGM_Layer3 (装饰层)
├── SFX (音效，-3dB)
│   ├── SFX_UI (UI音效)
│   ├── SFX_Action (动作音效)
│   └── SFX_Battle (战斗音效)
├── Voice (语音/TTS，-3dB)
│   ├── Voice_Soul (灵魂语音)
│   └── Voice_Narrator (旁白)
└── Ambient (环境音，-9dB)
    ├── Ambient_Indoor (室内环境)
    └── Ambient_Nature (自然环境)
```

### 6.3 动态音乐系统

| 功能 | 实现方式 |
|------|----------|
| 情绪响应BGM | 根据灵魂情绪调整BGM层次（快乐=全层，悲伤=仅基础层） |
| 场景切换过渡 | 交叉淡入淡出（2秒），AudioStreamPlayer的volume_db动画 |
| 长时间变奏 | 随机触发装饰层即兴元素，避免循环疲劳 |
| 战斗紧张度 | 根据战斗状态调整BGM层次（普通=基础+节奏，激烈=全层+加速） |
