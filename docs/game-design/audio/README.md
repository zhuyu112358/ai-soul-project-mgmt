## 生产规范

- 所有资源严格遵循 `14_声音与音乐设计.md` 和 `00_音效资源总清单与生产计划.md`
- 采样率44100Hz，16bit，WAV格式（源文件）+ OGG（游戏内压缩）
- UI/动作音效≤0.5秒，灵魂音效≤2秒，战斗音效≤2秒
- 环境音效15-30秒可循环，BGM 2-4分钟可循环
- 响度标准：BGM -16 LUFS，音效 -20 LUFS，峰值≤-1 dBTP
- 命名规范：`{类别}_{名称}_{变体}.wav`
- **版权安全：所有资源自行生成，禁止使用第三方受版权保护的素材**
- TTS语音系统：混合TTS方案，单灵魂月成本¥0.5-2，每个灵魂有独特声音参数
