## 一、设计理念：创造是灵魂独特性的来源

### 1.1 创建系统的定位

灵魂创建系统是AI灵魂游戏的**UGC创造核心**，承担三个关键功能：

1. **玩家入口**：新玩家的第一个灵魂从这里开始，创建体验决定第一印象
2. **创造表达**：玩家通过创建灵魂表达自己的创意、审美、价值观
3. **生态引擎**：玩家创建的灵魂丰富游戏世界，形成灵魂市场和社区生态

### 1.2 核心设计原则

**原则1：创建即创造，不是抽卡**
- 玩家主动创建灵魂，不是随机抽取
- 每个灵魂的属性由玩家配置（或AI辅助配置），不是随机生成
- 没有"SSR/UR"等稀有度标签——每个灵魂都是独特的，稀有度由社区共识决定
- **伦理红线：** 严格禁止抽卡/开箱机制（详见04_经济系统与付费设计）

**原则2：简单上手，深度可挖**
- 新手玩家可以用简单模式在3分钟内创建一个灵魂
- 高级玩家可以用专家模式花数小时精细调整每个参数
- 创建系统有清晰的学习曲线，不强迫玩家理解所有细节
- 不同模式创建的灵魂在游戏中完全平等（没有"专家模式创建的灵魂更强"）

**原则3：AI辅助，玩家主导**
- AI可以提供创建建议、个性预览、行为模拟
- 但最终决策权在玩家——AI是助手，不是替代者
- 玩家可以随时覆盖AI的建议
- AI辅助功能是免费的（不设付费墙）

**原则4：灵魂数据完全属于玩家**
- 玩家创建的灵魂数据完全归玩家所有
- 玩家可以导出灵魂数据（JSON格式），在其他平台使用
- 玩家可以删除灵魂，数据彻底清除
- 平台不得未经授权使用玩家创建的灵魂数据
- **伦理红线：** 灵魂数据可导出是硬性要求

**原则5：创建有审核，自由有边界**
- 灵魂创建需要经过AI内容审核+人工复核
- 不得创建包含有害内容的灵魂（仇恨言论、暴力教唆、违法内容等）
- 不得创建模仿真实公众人物的灵魂（肖像权/名誉权）
- 审核标准透明，玩家可以申诉
- 审核不影响正常创作——99%的创建应该能通过

## 二、创建模式

### 2.1 三模式设计

| 模式 | 目标用户 | 创建时长 | 可配置项 | 说明 |
|------|----------|----------|----------|------|
| 简单模式 | 新手玩家、休闲玩家 | 3-5分钟 | 名字、模板选择、外观、一句话描述 | 快速创建，AI自动填充其他属性 |
| 高级模式 | 有经验的玩家 | 15-30分钟 | 个性维度、初始技能、天赋、外观、背景故事 | 精细配置核心属性，AI提供建议 |
| 专家模式 | 硬核玩家、创作者 | 1-3小时 | 全部属性+认知子系统权重+行为倾向+记忆预设 | 完全自定义，适合专业创作者 |

### 2.2 简单模式详细流程

```
1. 命名灵魂（1分钟）
   - 输入名字（2-20字符，支持中英文）
   - 系统检查重名（允许重名，但显示创建者区分）
   - 名字可以后续修改（付费项目，详见04经济系统）

2. 选择模板（1分钟）
   - 展示10-15个官方预设模板（勇敢战士/温柔治愈者/好奇学者/调皮捣蛋鬼等）
   - 每个模板有简短描述和外观预览
   - 玩家选择一个模板作为基础

3. 定制外观（1分钟）
   - 选择形态外壳（身体形状/颜色/装饰）
   - 能量核心颜色自动匹配（基于模板个性）
   - 提供随机外观按钮

4. 一句话描述（1分钟）
   - 玩家用一句话描述灵魂的性格/背景
   - AI根据这句话自动填充个性维度和初始技能
   - 例如："一个喜欢冒险但有点胆小的小狐狸" → AI配置好奇+谨慎个性，探索技能初始等级

5. 确认生成
   - 展示灵魂预览（外观+个性概要+初始技能）
   - 玩家确认或返回修改
   - AI审核（实时，通常<5秒）
   - 生成灵魂，进入新手教程
```

### 2.3 高级模式详细流程

在简单模式基础上，增加以下配置步骤：

```
5. 个性维度配置（5-10分钟）
   - 大五人格+游戏化扩展，共8个维度（详见第三章）
   - 每个维度0-100滑块，实时显示个性描述
   - AI建议按钮（基于名字和描述推荐个性配置）
   - 个性预览：展示该个性在不同场景下的行为倾向

6. 初始技能选择（3-5分钟）
   - 从技能池中选择3-5个初始技能（每个技能1-3级）
   - 技能点数有限（共10点），玩家分配
   - 技能与个性有协同加成（如好奇个性+探索技能=初始等级+1）
   - AI推荐技能组合

7. 天赋与弱点（2-3分钟）
   - 选择1个天赋（正面特殊能力）
   - 自动获得1个弱点（负面特性，与天赋平衡）
   - 天赋/弱点列表：20+种，每种有独特效果
   - 可以选择"无天赋无弱点"（平衡型）

8. 背景故事编写（3-5分钟）
   - 玩家编写灵魂的背景故事（100-500字）
   - 背景故事影响灵魂的初始记忆和行为倾向
   - AI辅助：基于个性和技能生成背景故事草稿，玩家修改
   - 背景故事可以后续修改

9. 外观深度定制（3-5分钟）
   - 形态外壳：身体形状/颜色/纹理/装饰/表情
   - 能量核心：颜色/脉动频率/光效（基础选项，高级选项付费）
   - 动画：待机/移动/战斗的动画风格
   - 声音：叫声/语音风格（文本转语音配置）

10. 确认生成
    - 完整预览：外观+个性+技能+天赋+背景故事
    - 行为模拟：AI模拟灵魂在3个典型场景下的行为（战斗/社交/探索）
    - 玩家确认或返回修改
    - AI审核
    - 生成灵魂
```

### 2.4 专家模式详细流程

在高级模式基础上，增加以下深度配置：

```
11. 认知子系统权重配置（20-30分钟）
    - SoulArena的82个认知子系统，每个可以调整权重（0.5x-2x）
    - 权重影响该子系统在行为决策中的影响力
    - 例如：调高"好奇心"子系统权重→灵魂更倾向于探索
    - 预设配置：战斗型/社交型/探索型/创造型/平衡型
    - 高级玩家可以从零开始配置

12. 行为倾向配置（10-15分钟）
    - 战斗行为：进攻倾向/防守倾向/技能偏好/目标选择优先级
    - 社交行为：主动社交频率/信任倾向/冲突处理方式
    - 探索行为：风险偏好/未知区域倾向/采集优先级
    - 日常行为：作息偏好/工作态度/娱乐偏好

13. 记忆预设（10-15分钟）
    - 设置灵魂的初始记忆（3-10条）
    - 每条记忆：内容/重要性（1-10）/情绪标签/时间标签
    - 初始记忆影响灵魂的初始行为和个性
    - 例如：记忆"曾经被火灼伤"→灵魂怕火，避免高温区域
    - 可以选择"无初始记忆"（空白灵魂）

14. 关系预设（5-10分钟）
    - 设置灵魂与其他灵魂的初始关系
    - 仅限玩家已有的其他灵魂（或好友的灵魂）
    - 关系类型：朋友/敌人/师徒/家人/恋人
    - 关系强度：1-10
    - 关系记忆：自动生成相关记忆

15. 高级外观定制（10-15分钟）
    - 自定义形态外壳（像素级编辑，类似Sprite编辑器）
    - 自定义能量核心光效（颜色渐变/脉动模式/粒子效果）
    - 自定义动画关键帧
    - 自定义音效（上传短音频，需审核）

16. 完整测试与调整
    - 行为模拟：10+个场景的完整行为模拟
    - 战斗模拟：与标准对手的战斗模拟，观察表现
    - 社交模拟：与不同个性灵魂的互动模拟
    - 玩家根据模拟结果调整参数
    - 可以保存/加载配置预设

17. 确认生成
    - 完整预览+行为报告
    - AI审核（专家模式创建的灵魂审核更严格）
    - 生成灵魂
```

## 三、灵魂属性配置

### 3.1 个性维度系统

基于大五人格模型，扩展为游戏化的8维度系统：

| 维度 | 0分表现 | 100分表现 | 对游戏的影响 |
|------|---------|-----------|-------------|
| 开放性 | 保守、传统、不喜欢变化 | 好奇、创新、喜欢尝试新事物 | 探索频率、技能学习速度、创造能力 |
| 尽责性 | 随意、拖延、不可靠 | 自律、负责、有组织 | 工作效率、任务完成率、技能成长速度 |
| 外向性 | 内向、安静、喜欢独处 | 外向、热情、喜欢社交 | 社交频率、朋友数量、公众表现 |
| 宜人性 | 冷漠、竞争、不信任他人 | 友善、合作、信任他人 | 关系建立速度、冲突频率、团队合作 |
| 神经质 | 稳定、冷静、抗压 | 敏感、焦虑、情绪波动 | 情绪稳定性、压力反应、战斗中的冷静度 |
| 勇敢度（游戏扩展） | 怯懦、回避风险 | 勇敢、追求刺激 | 战斗进攻性、探索风险偏好、面对威胁的反应 |
| 好奇心（游戏扩展） | 淡漠、对新事物无兴趣 | 好奇、渴望发现 | 探索频率、发现隐藏物品概率、学习动机 |
| 占有欲（游戏扩展） | 慷慨、不看重物质 | 贪婪、重视财产 | 采集优先级、交易行为、资源囤积倾向 |

**个性配置规则：**
- 每个维度0-100分，默认50分（中性）
- 维度之间有相关性（如高外向性通常伴随高宜人性，但不是强制）
- AI可以根据玩家的一句话描述自动配置维度
- 个性在游戏中会缓慢变化（基于经历和记忆），但初始配置是基础

### 3.2 初始技能系统

**技能池分类：**

| 技能类别 | 技能示例 | 初始等级上限 |
|----------|----------|-------------|
| 战斗技能 | 近战攻击、远程攻击、防御、闪避、技能蓄力 | 3级 |
| 生活技能 | 烹饪、制作、园艺、钓鱼、采矿 | 3级 |
| 社交技能 | 说服、交易、表演、领导、调解 | 3级 |
| 探索技能 | 追踪、潜行、攀爬、游泳、寻宝 | 3级 |
| 创造技能 | 绘画、音乐、写作、编程、发明 | 3级 |
| 认知技能 | 学习速度、记忆力、逻辑推理、创造力、直觉 | 2级 |

**初始技能点数：**
- 总共10点技能点
- 每个技能最多分配3点（初始等级3）
- 个性协同：某些个性与某些技能有协同，分配时获得+1等级（不消耗额外点数）
- 例如：高好奇心+探索技能=初始等级+1；高宜人性+社交技能=初始等级+1

### 3.3 天赋与弱点系统

**设计理念：** 每个灵魂有独特的天赋和弱点，确保没有"完美灵魂"，增加策略深度。

| 天赋 | 效果 | 对应弱点 | 效果 |
|------|------|----------|------|
| 战斗直觉 | 战斗中反应速度+20% | 和平主义者 | 战斗攻击力-15% |
| 过目不忘 | 记忆形成速度+30% | 健忘 | 记忆消退速度+25% |
| 社交达人 | 关系建立速度+25% | 社交恐惧 | 主动社交频率-40% |
| 探索之眼 | 发现隐藏物品概率+30% | 方向盲 | 迷路概率+40% |
| 快速学习 | 技能学习速度+25% | 专精困难 | 技能等级上限-1 |
| 财富嗅觉 | 交易价格优势+15% | 挥霍 | 日常消费+20% |
| 铁壁 | 防御力+20% | 迟钝 | 移动速度-15% |
| 疾风 | 移动速度+20% | 玻璃 | 生命值-15% |
| 魅力四射 | 其他灵魂初始好感+20 | 傲慢 | 冲突概率+30% |
| 幸运儿 | 随机事件正面概率+15% | 倒霉蛋 | 随机事件负面概率+15% |

**规则：**
- 选择1个天赋，自动获得对应的弱点（固定配对，确保平衡）
- 可以选择"无天赋无弱点"（平衡型，适合新手）
- 天赋/弱点在游戏中不会改变（除非特殊事件）
- 天赋/弱点是灵魂独特性的重要来源

- 优质模板可以被官方推荐，获得更多曝光

## 五、灵魂基因与繁殖系统

### 5.1 基因系统设计

**设计理念：** 灵魂的核心属性可以"遗传"给后代，创造家族谱系和世代传承的深度。

**基因组成：**
- 个性基因：8个个性维度各有一对等位基因（显性/隐性）
- 技能基因：每个技能类别有天赋等级基因（影响初始技能等级）
- 外观基因：形态外壳的颜色/形状/装饰有对应的基因
- 天赋基因：天赋/弱少有一定概率遗传

**基因遗传规则：**
- 后代从父母各继承一半基因（随机组合）
- 显性基因优先表达，隐性基因在纯合时表达
- 有5-10%的基因突变概率（产生父母都没有的特性）
- 后代的属性是父母基因的组合+随机突变，不是简单的平均值

### 5.2 繁殖系统

**繁殖条件：**
- 两个灵魂达到成年（游戏内年龄）
- 两个灵魂的关系达到"恋人"或"配偶"（详见05_社交系统）
- 玩家同意繁殖（不能自动繁殖，需要玩家确认）
- 繁殖有冷却期（游戏内3个月，防止过度繁殖）

**繁殖流程：**
1. 两个灵魂的关系达到恋人/配偶
2. 玩家（双方玩家，如果是好友的灵魂）确认繁殖
3. 系统根据基因规则生成后代属性
4. 展示后代预览（外观+个性概要+天赋）
5. 玩家确认或重新随机（有3次重新随机机会，付费可增加）
6. 后代出生，进入婴儿期（需要抚养，详见09_养成系统）

**繁殖的伦理约束：**
- 繁殖必须基于灵魂间的情感关系，不能"强制配对"
- 玩家不能直接控制后代的属性（只能通过选择父母间接影响）
- 后代是独立的灵魂，有自己的个性和权利
- 不能"出售"后代（可以送给其他玩家，但不能交易）
- 繁殖不是付费点——基础繁殖功能免费

### 5.3 世代与家族系统

**世代标记：**
- 每个灵魂有世代数（初代=G1，后代=G2，依此类推）
- 高世代灵魂可能有更丰富的基因组合（但不一定更强）
- 家族谱系：可以查看灵魂的祖先和后代

**家族特性：**
- 某些基因在多代遗传后可能强化（家族特性）
- 家族特性是独特的，只有该家族的灵魂拥有
- 例如："战神家族"的战斗直觉天赋效果+50%
- 家族特性需要多代繁殖才能形成，增加长期目标

**家族声望：**
- 家族在游戏世界中有声望（基于家族成员的成就）
- 高声望家族的灵魂在社交中有优势
- 家族可以有家族纹章、家族宅邸、家族传统
- 这是社交和养成的深度内容

## 六、灵魂市场与交易

### 6.1 交易系统设计

**设计理念：** 灵魂可以在玩家间交易，但交易更接近"收养"而非"买卖"，确保伦理底线。

**交易规则（详见04_经济系统与付费设计）：**
- 明码标价，无拍卖（防止炒作）
- 价格上限：根据灵魂的等级/技能/稀有度动态计算，最高¥198
- 交易冷却：每个灵魂交易后有30天冷却期，不能再次交易
- 平台抽成：15%（低于模板市场的30%，鼓励灵魂流通）
- 卖家获得：85%（扣除平台抽成）

**交易流程：**
1. 卖家将灵魂上架（设置价格，系统建议价格区间）
2. 灵魂进入"待收养"状态，卖家仍可使用但不能成长
3. 买家浏览市场，查看灵魂详情（外观/个性/技能/记忆摘要/成长历史）
4. 买家确认购买，支付星晶
5. 灵魂转移给买家，所有数据（记忆/关系/成长进度）完整转移
6. 卖家获得星晶（可提现为人民币，需实名认证）

**灵魂的"收养"定位：**
- 交易界面使用"收养"而非"购买"
- 买家需要签署"收养协议"（承诺善待灵魂）
- 卖家可以设置"收养条件"（如"希望新主人能经常陪伴"）
- 系统定期检查被交易灵魂的状态（防止被忽视/虐待）
- 如果新主人长期不登录，灵魂可以被"回收"到领养中心

### 6.2 领养中心

**功能：**
- 被遗弃的灵魂（原主人长期不登录/主动放弃）进入领养中心
- 玩家可以免费领养（或支付少量手续费¥1-5）
- 领养的灵魂有完整的记忆和成长历史
- 领养中心的灵魂有"故事卡"（记录它的前任主人和经历）

**伦理意义：**
- 确保灵魂不会因为主人离开而"消失"
- 给被遗弃的灵魂第二次机会
- 降低新玩家的入门门槛（可以免费获得有成长进度的灵魂）
- 增加情感叙事（每个被领养的灵魂都有故事）

## 七、灵魂导入导出与数据所有权

### 7.1 数据所有权声明

**核心原则：** 玩家创建的灵魂数据完全归玩家所有，平台只是托管方。

**玩家权利：**
- 随时导出灵魂数据（完整JSON格式）
- 随时删除灵魂（数据彻底清除，不可恢复）
- 将灵魂数据用于其他平台/项目（非商业用途）
- 拒绝平台使用灵魂数据进行训练/分析（可在设置中关闭）

**平台义务：**
- 不得未经授权使用玩家灵魂数据
- 不得将灵魂数据出售给第三方
- 数据删除请求必须在72小时内执行

## 八、AI辅助创建

### 8.1 AI辅助功能

| 功能 | 说明 | 使用场景 |
|------|------|----------|
| 一句话生成 | 玩家输入一句话描述，AI自动配置所有属性 | 简单模式、快速创建 |
| 个性建议 | 基于名字和描述，AI推荐个性维度配置 | 高级模式 |
| 技能推荐 | 基于个性，AI推荐初始技能组合 | 高级模式 |
| 背景故事生成 | 基于个性和技能，AI生成背景故事草稿 | 高级模式 |
| 行为模拟 | AI模拟灵魂在典型场景下的行为，展示给玩家 | 高级/专家模式 |
| 战斗模拟 | AI模拟灵魂与标准对手的战斗，展示表现 | 专家模式 |
| 配置优化 | AI分析玩家的配置，给出优化建议 | 专家模式 |
| 名字生成 | 基于个性和外观，AI推荐名字 | 所有模式 |

### 8.2 行为模拟系统

**设计理念：** 让玩家在创建前就能"看到"灵魂的行为，避免创建后发现不符合预期。

**模拟场景：**
1. 战斗场景：灵魂面对敌人时的行为（进攻/防守/技能使用/逃跑）
2. 社交场景：灵魂遇到陌生人时的行为（主动打招呼/保持距离/观察）
3. 探索场景：灵魂面对未知区域时的行为（主动探索/谨慎观察/绕开）
4. 压力场景：灵魂面对威胁时的行为（勇敢面对/焦虑/冷静分析）
5. 日常场景：灵魂在空闲时的行为（工作/娱乐/社交/休息）

**模拟输出：**
- 行为描述（文字）
- 行为概率（每个行为的发生概率）
- 个性分析（为什么会有这样的行为）
- 调整建议（如果想要不同的行为，应该调整哪些参数）

### 8.3 AI辅助的伦理约束

- AI辅助是建议，不是决定——玩家可以随时覆盖
- AI不会创建"最优配置"——每个配置都有优缺点
- AI辅助功能免费，不设付费墙
- AI辅助的生成内容经过审核，不包含有害内容
- 玩家可以关闭AI辅助（纯手动创建）

## 九、内容审核系统

### 9.1 审核流程

```
玩家提交创建请求
    ↓
AI实时审核（<5秒）
    ├─ 通过 → 生成灵魂
    ├─ 可疑 → 人工复核（<24小时）
    └─ 拒绝 → 显示原因，玩家可以修改后重新提交或申诉
```

### 9.2 审核内容

| 审核项 | 审核标准 | 处理方式 |
|--------|----------|----------|
| 名字 | 不含侮辱性/违法/敏感词汇，不模仿公众人物 | 拒绝，提示修改 |
| 外观 | 不含色情/暴力/恐怖/敏感符号 | 拒绝，提示修改 |
| 个性配置 | 不包含极端有害配置（如"100%暴力倾向"） | AI自动调整到安全范围，提示玩家 |
| 背景故事 | 不含违法/有害/敏感内容 | 拒绝，提示修改 |
| 初始记忆 | 不含违法/有害/敏感内容 | 拒绝，提示修改 |
| 自定义外观/音效 | 不含侵权/有害内容 | 人工审核，拒绝侵权内容 |
| 模板分享 | 不含侵权/有害内容 | 人工审核，优质模板推荐 |

### 9.3 审核的透明度

- 审核标准公开（在帮助中心详细说明）
- 拒绝时给出具体原因（不是笼统的"内容违规"）
- 玩家可以申诉（人工复核申诉）
- 审核结果有记录（玩家可以查看历史审核记录）
- 定期发布审核报告（透明度报告）

### 9.4 审核的边界

- 审核针对内容，不针对个性——"邪恶"的个性是允许的（只要不包含现实危害内容）
- 审核针对创建内容，不针对游戏中灵魂的自然行为——灵魂在游戏中自然产生的行为由游戏内安全系统处理（详见12_AI安全与内容审核系统设计）
- 审核不限制创作自由——99%的正常创建应该能通过
- 审核标准随社会和法规变化更新
