# 游戏设计调整 v1.1

**调整日期：** 2026-09-05
**调整原因：** 用户在确认进入应用实现阶段前提出三项核心调整
**影响范围：** 核心循环优先级、美术风格、新增独立模式

---

## 调整一：以灵魂成长为核心（而非RTS对战）

### 原设计
- 短期产品定位为"RTS灵魂对战竞技场"，对战是核心玩法
- 成长是对战的副产品（经验/记忆/性格演化）

### 调整后
- **灵魂成长是产品核心**，对战是成长的验证场和竞技场
- 核心循环重新定义：

```
创建灵魂 → 交流与训练 → 灵魂成长 → 对战验证 → 学习与进化 → 更强成长
     ↑                                                        │
     └────────────────── 情感绑定驱动回归 ←───────────────────┘
```

### 具体影响
1. **产品定位调整：** 从"RTS对战游戏"调整为"AI灵魂养成+对战游戏"，养成是核心，对战是玩法之一
2. **新手流程调整：** 新玩家首先进入"灵魂之家"创建和培养第一个灵魂，而不是直接打对战
3. **对战定位调整：** 对战是灵魂展示成长成果、学习新技能、获得战斗记忆的场所，不是唯一的游戏内容
4. **成长维度强化：** 认知/情感/技能/个性/记忆五大成长维度需要在交流训练模式中有直观的体现和反馈
5. **留存机制调整：** 核心留存从"排位冲分"变为"我想看看我的灵魂成长得怎么样了"
6. **付费设计调整：** 付费点围绕成长辅助（外观/训练道具/技能书），而非对战加速

### 与三层产品矩阵的关系
- 短期（0-9月）：灵魂成长核心 + 对战验证场 + 交流训练模式
- 中期（9-18月）：成长核心扩展为虚拟小镇养成 + 直播观察
- 长期（18-36月）：成长核心扩展为社会模拟中的灵魂人生

## 调整二：画面品质升级（精致像素风）

### 原设计
- 阶段一：2D像素风，基础32×32像素/格，角色64×64像素
- 每角色限32色，场景限64色
- 定位为"低成本快速开发"

### 调整后
- **精致像素风（Refined Pixel Art）**，在像素风基础上提升视觉品质：

| 维度 | 原规格 | 调整后规格 |
|------|--------|-----------|
| 角色分辨率 | 64×64像素 | **128×128像素**（细节更丰富） |
| 格子分辨率 | 32×32像素 | **48×48像素** |
| 角色色板 | 32色 | **64色**（渐变和光影更细腻） |
| 场景色板 | 64色 | **128色** |
| 行走动画 | 6帧/8方向 | **8帧/8方向**（更流畅） |
| 待机动画 | 4帧循环 | **6帧循环+呼吸感** |
| 动态光照 | 基础 | **实时光照+阴影投射+法线贴图** |
| 粒子特效 | 基础粒子 | **丰富粒子系统**（技能/环境/灵魂情绪） |
| 后期处理 | 无 | **Bloom+色彩分级+轻微景深** |
| 屏幕震动 | 基础 | **分级震动（轻/中/重）+ 慢放特效** |

### 美术风格定位
- **"精致像素风"**：参考《八方旅人》的HD-2D风格（像素角色+3D光照+粒子特效），但保持纯2D实现降低技术复杂度
- 灵魂角色是视觉焦点：能量核心有实时光晕和粒子环绕，形态外壳有细腻的像素细节和表情动画
- 场景有层次感：视差滚动背景 + 动态光照 + 天气粒子 + 环境动画（水流/火焰/树叶）
- UI保持像素风但更精致：圆角边框、微动画、清晰的图标

### 技术实现
- Godot 4的2D渲染管线完全支持上述规格
- 动态光照使用Godot的Light2D + 法线贴图
- 粒子使用GPUParticles2D
- 后期处理使用CanvasLayer + Shader
- 性能目标：6灵魂同屏+特效时帧率>60fps（中端PC）

### 成本影响
- 美术工作量增加约40-50%（更高分辨率+更多动画帧）
- 但可以通过AI辅助生成+外包关键资源控制成本
- 阶段一美术预算从¥5,000调整为¥8,000-10,000
- 整体EA上线期现金上限从¥10,000调整为¥13,000-15,000

## 调整三：单独的用户与灵魂交流与训练模式

### 新增模式：灵魂之家（Soul Home）

这是独立于对战的核心模式，是玩家与灵魂建立情感绑定的主要场所。

### 模式定位
- **灵魂之家**是灵魂的"家"，玩家可以在这里与灵魂互动、训练、教学、定制
- 这是产品的核心模式之一，与对战模式并列，从M1原型就需要实现
- 情感绑定的主要发生地，长期留存的核心驱动力

### 核心功能

#### 1. 交流系统
| 功能 | 说明 | 技术支撑 |
|------|------|----------|
| 文字聊天 | 玩家与灵魂文字对话，灵魂回复基于性格/记忆/当前状态 | SoulArena对话API |
| 灵魂主动说话 | 灵魂会主动发起对话（如"我今天学到了新东西"） | SoulArena主动行为 |
| 情绪反馈 | 灵魂的情绪通过表情/动作/核心颜色实时反馈 | 情绪可视化系统 |
| 内心独白 | 显示灵魂当前的"想法"（认知状态转自然语言） | 认知子系统状态 |
| 语音（可选） | 灵魂的简单语音回应（类似宝可梦叫声，非完整TTS） | 音效系统 |

#### 2. 训练系统
| 功能 | 说明 | 成长维度 |
|------|------|----------|
| 技能训练 | 教灵魂新技能（通过重复练习+指导） | 技能 |
| 认知训练 | 解谜/推理小游戏，提升灵魂认知能力 | 认知 |
| 情感训练 | 情感识别/共情练习，提升灵魂情感能力 | 情感 |
| 战斗训练 | 与训练假人对战，练习战斗策略 | 技能+记忆 |
| 个性引导 | 通过互动引导灵魂的个性发展（如鼓励勇敢） | 个性 |

#### 3. 教学系统
| 功能 | 说明 |
|------|------|
| 知识传授 | 玩家可以教灵魂知识（世界规则/历史/技能原理），写入灵魂记忆 |
| 行为示范 | 玩家演示正确行为，灵魂观察学习（社会学习子系统） |
| 纠错反馈 | 灵魂犯错时玩家纠正，灵魂从错误中学习 |
| 复习巩固 | 定期复习已学知识，防止遗忘（记忆巩固子系统） |

#### 4. 互动小游戏
| 游戏 | 说明 | 成长维度 |
|------|------|----------|
| 捉迷藏 | 灵魂在房间里躲藏，玩家寻找（或反过来） | 认知+情感 |
| 接球 | 玩家扔球，灵魂接住（反应训练） | 技能 |
| 问答 | 玩家提问，灵魂回答（知识测试） | 认知+记忆 |
| 模仿 | 灵魂模仿玩家的动作/表情 | 社会学习 |
| 探索 | 灵魂在房间里探索新物品，玩家观察 | 好奇心+认知 |

#### 5. 定制系统
| 功能 | 说明 |
|------|------|
| 外观定制 | 灵魂的形态外壳/颜色/装饰/表情（不影响能力） |
| 房间装饰 | 灵魂之家的家具/装饰/主题（影响灵魂情绪） |
| 名字/称呼 | 给灵魂起名字，设定灵魂对玩家的称呼 |
| 性格微调 | 轻微调整性格倾向（效果缓慢，需要长期引导） |

### 灵魂之家的空间设计
- **主房间**：灵魂活动的主要空间，有沙发/桌子/窗户/装饰
- **训练室**：技能训练和战斗训练的场所（有训练假人/器材）
- **书房**：知识传授和认知训练的场所（有书架/书桌）
- **花园/阳台**：休闲互动和情感交流的场所（有植物/风景）
- 房间可以切换，灵魂会在不同房间有不同的行为

### 与对战模式的关系
- 灵魂之家中训练的技能/知识/个性会在对战中体现
- 对战中获得的战斗记忆/经验会带回灵魂之家，影响灵魂的行为和对话
- 玩家可以在灵魂之家中为对战做准备（配置技能/调整性格/制定战术）
- 两个模式共享同一个灵魂数据，成长是连续的

### 技术实现要点
- 灵魂之家的场景比对战场景简单（单房间，少量物体），但需要更多交互细节
- 灵魂在灵魂之家中的行为更自由（没有对战规则约束），需要SoulArena的自主行为能力
- 交流系统需要SoulArena的对话API持续可用，对话内容需要经过安全审核
- 训练系统的成长反馈需要直观可视化（经验条/技能等级/个性变化提示）
- 灵魂之家的美术品质要求更高（玩家会长时间观察，细节很重要）

## 对开发优先级的影响

### M1原型（第1月）调整
原M1：10灵魂在单房间自主对战，玩家可观战
**调整后M1：**
1. **灵魂之家基础版**（核心）：1个灵魂+主房间+文字聊天+基本互动+情绪可视化
2. **简单对战竞技场**（验证）：2灵魂在简单地图中自主对战，玩家可观战
3. **成长系统基础**：灵魂的经验/技能/记忆在交流和对战中增长，有可视化反馈

### M2核心循环验证（第2月）调整
原M2：完整配置→观战→复盘→结算循环
**调整后M2：**
1. 灵魂之家完整功能（训练/教学/小游戏/定制）
2. 对战竞技场完整循环（配置→观战→复盘→结算）
3. 两个模式的成长数据互通验证
4. 50人用户测试

### 美术资源优先级调整
1. 灵魂角色（高优先级，精致像素风128×128）
2. 灵魂之家场景（高优先级，温馨精致）
3. 对战竞技场场景（中优先级，简洁但有氛围）
4. UI/UX（高优先级，精致像素风UI）
5. 特效/粒子（中优先级，灵魂情绪和技能特效）

---

## 总结

这三项调整使产品从"RTS对战游戏"转变为**"以灵魂成长为核心的AI灵魂养成+对战游戏"**，更符合情感绑定的长期留存逻辑，也更贴近"宝可梦级智能"的定位。画面品质提升确保产品在Steam上有足够的视觉吸引力，单独的交流训练模式是情感绑定的核心入口，也是区别于传统RTS游戏的关键差异化。

这些调整不改变技术架构（Godot 4 + SoulArena + Seed），但调整了开发优先级和美术资源投入。M1原型需要同时实现灵魂之家基础版和简单对战竞技场，验证"成长核心"的产品假设。
