# 商业化外观设计体系

**文档版本：** v1.0
**创建日期：** 2026-09-06
**设计原则：** 纯外观付费，不影响竞技平衡，无随机抽取，符合伦理框架

---

## 一、商业化总原则

### 1.1 伦理红线（必须遵守）

1. **纯外观付费**：所有付费内容仅为视觉/听觉外观，不影响游戏数值、竞技平衡、成长速度
2. **无随机抽取**：不设计抽卡、开箱、盲盒等随机付费机制，所有商品明码标价
3. **不操纵情感**：不得利用灵魂的情感表达诱导玩家消费（如"灵魂不开心就需要买礼物"）
4. **精力不可购买**：灵魂成长所需的精力/时间不可用付费加速
5. **竞技公平**：付费外观不得提供任何竞技优势（包括视觉优势、信息优势）
6. **数据归属**：玩家购买的外观数据完全属于玩家，可导出、可转移
7. **透明定价**：所有商品价格透明，无隐藏消费，无"首充陷阱"

### 1.2 付费内容分类

| 分类 | 内容 | 是否影响平衡 | 付费方式 |
|------|------|------------|---------|
| 灵魂皮肤 | 灵魂的视觉外观、形态、特效 | 否 | 直购/赛季通行证 |
| 家园装饰 | 灵魂之家的家具、装饰、环境 | 否 | 直购/建造解锁 |
| 竞技场特效 | 对战中的技能特效、击杀特效、UI皮肤 | 否 | 直购/赛季通行证 |
| 赛季通行证 | 赛季限定外观+装饰+特效 | 否 | 一次性购买 |
| 音乐包 | BGM、音效替换包 | 否 | 直购 |
| 命名权 | 灵魂改名、家园改名 | 否 | 免费次数+付费改名卡 |

## 二、灵魂皮肤系列设计

### 2.1 皮肤体系架构

**皮肤等级：**
- **基础皮肤**：每个灵魂创建时自带，免费
- **进阶皮肤**：通过灵魂成长解锁（免费，成长到特定阶段自动获得）
- **主题皮肤**：付费直购，有完整的主题设计（形态+特效+音效）
- **限定皮肤**：赛季通行证限定，错过需等返场（明码标价返场，不搞饥饿营销）
- **联动皮肤**：与公有领域神话/文化IP联动（如山海经神兽皮肤）

**皮肤不改变：**
- 灵魂的属性、技能、数值
- 灵魂的AI行为、个性、认知能力
- 灵魂的成长速度
- 竞技对战中的任何优势

**皮肤改变：**
- 灵魂的视觉形态（颜色、形状、装饰）
- 灵魂的移动/待机动画
- 灵魂的技能特效（视觉）
- 灵魂的情绪表达特效（视觉）
- 灵魂的专属音效（可选，玩家可开关）

## 三、家园装饰设计

### 3.1 装饰体系架构

**装饰分类：**
- **家具**：桌椅、床、书架、灯具等功能性家具（纯装饰，不影响属性）
- **摆件**：花瓶、画作、雕塑、纪念品等纯装饰
- **环境改造**：地板、墙壁、天花板、灯光、天气效果
- **庭院装饰**：花园、池塘、假山、树木、户外家具
- **互动装饰**：可与灵魂互动的装饰（如灵魂可以弹奏的乐器、可以玩耍的玩具），纯趣味不影响属性

**装饰不改变：**
- 灵魂的属性、成长速度
- 任何游戏数值
- 竞技平衡

**装饰改变：**
- 灵魂之家的视觉外观
- 灵魂在家中的行为（如在花园里玩耍、在书房里看书）
- 环境氛围（灯光、天气、背景音乐）

## 五、赛季通行证设计

### 5.1 通行证架构

**通行证等级：**
- **免费通行证**：所有玩家自动获得，可获取免费档奖励
- **高级通行证**：一次性付费购买（¥68），可获取全部奖励（免费档+付费档）
- **通行证等级包**：可购买等级提升（明码标价，不搞随机），但不强制

**通行证持续时间：** 每个赛季8周（约2个月）

**通行证经验获取：**
- 完成每日任务（免费，不与付费挂钩）
- 完成每周任务（免费）
- 完成赛季任务（免费）
- 参与对战（免费，每场获得少量经验）
- **不可用付费直接购买经验**，只能购买等级提升（明码标价，且有上限）

### 5.2 通行证奖励设计

**免费档奖励（所有玩家可获得）：**
- 赛季限定灵魂皮肤（基础版）×1
- 赛季限定家园装饰×3
- 赛季限定竞技场特效×1
- 游戏内货币（非付费货币）
- 灵魂经验加成（限时，不影响长期成长）
- 头像框×2
- 表情×5

**付费档奖励（购买高级通行证可获得）：**
- 赛季限定灵魂皮肤（豪华版，与免费版同主题但更华丽）×1
- 赛季限定家园装饰×5（含1个互动装饰）
- 赛季限定竞技场特效×3（含1个击杀特效）

### 5.4 通行证伦理设计
