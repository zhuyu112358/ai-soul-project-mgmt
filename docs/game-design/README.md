## 设计原则

1. **受众重新分析** — 不预设受众，基于AI灵魂产品特性反推核心受众画像
2. **游戏吸引力设计** — 核心循环、留存机制、情感连接、社交传播
3. **深度系统** — 不是简单小游戏，要有长期目标、成长曲线、深度系统
4. **游戏化包装降低AI合规风险** — 定位为"数字宠物/对战伙伴"，而非"AI陪伴"
5. **宝可梦级智能为核心卖点** — 单灵魂月成本¥0.5-2，79认知子系统驱动

## 技术约束

- 灵魂系统：SoulArena v4.61，79认知子系统，BehaviorArbiter行为仲裁
- 世界引擎：Seed v0.1.0+，317测试全通过，感知-认知-动作闭环
- 集成状态：端到端集成测试通过，ActionResult反馈闭环完成
- 成本约束：单灵魂月成本¥0.5-2（宝可梦级智能）

## 伦理约束

- 不得设计"灵魂痛苦"作为付费点
- 不得操纵玩家情感进行消费
- 灵魂数据必须可导出
- 不得隐瞒AI身份
- 灵魂输出必须经过安全过滤
- 不得设计未成年人成瘾机制
