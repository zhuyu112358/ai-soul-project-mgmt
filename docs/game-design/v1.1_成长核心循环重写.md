## 一、核心设计理念转变

### 1.1 从"对战核心"到"成长核心"

| 维度 | v1.0（对战核心） | v1.1（成长核心） |
|------|-----------------|-----------------|
| 产品定位 | RTS灵魂对战竞技场 | AI灵魂养成+对战游戏 |
| 核心循环 | 配置→对战→复盘→升级→更强对战 | 创建→交流训练→成长→对战验证→学习→更强成长 |
| 玩家角色 | 战术指挥/观众 | 教练/守护者/朋友/老师 |
| 灵魂角色 | 对战单位 | 有个性的生命，成长的主体 |
| 成长定位 | 对战的副产品（经验/记忆） | 产品核心，所有系统围绕成长 |
| 对战定位 | 核心玩法，主要内容消耗 | 成长验证场，玩法之一 |
| 留存驱动 | 排位冲分/竞技成就 | 想看灵魂成长得怎么样了/情感绑定 |
| 付费点 | 对战加速/外观/便利 | 成长辅助（外观/训练道具/技能书），不影响成长速度 |
| 新手入口 | 直接进入对战 | 首先进入灵魂之家创建和培养第一个灵魂 |
| 成功指标 | 对战参与率/排位活跃度/DAU | 灵魂互动深度/成长进度/情感绑定/30日留存 |

### 1.2 成长核心的五个设计原则

**原则1：成长是可见的、可感知的**
- 每次互动都有明确的成长反馈（经验+10/技能进度+5%/个性变化提示）
- 成长有仪式感（升级动画/里程碑庆祝/灵魂感言）
- 长期成长有迹可循（成长历史/对比/成就记录）
- 玩家能清晰看到"我的灵魂和昨天不一样了"

**原则2：成长是独特的、不可复制的**
- 每个灵魂的成长路径都是独特的（个性+经历+玩家互动共同塑造）
- 没有"最优成长路线"（不同成长路径有不同的优势和体验）
- 成长结果不可预测（AI涌现行为让成长充满惊喜）
- 灵魂的独特性是核心价值（"我的灵魂是独一无二的"）

**原则3：成长是连续的、不中断的**
- 灵魂在玩家离线时继续成长（简化模拟，不是暂停）
- 不同模式（灵魂之家/对战/探索）的成长是连续的，数据互通
- 成长不会因为玩家不付费而停滞（免费玩家可以完整体验成长）
- 成长是终身的（灵魂没有"满级"，满级后横向成长继续）

**原则4：成长是玩家与灵魂共同创造的**
- 玩家是教练/引导者，不是直接操控者
- 灵魂有自己的意志和倾向（可能抗拒玩家的引导，可能有自己的兴趣）
- 成长是双向的（灵魂成长的同时，玩家也在学习如何与灵魂相处）
- 玩家的选择深刻影响灵魂的成长方向（但不能完全控制）

**原则5：成长是快乐的、不焦虑的**
- 成长不设时间压力（没有"必须在X天内达到X级"）
- 成长不与其他玩家比较（没有"你的灵魂比别人弱"的焦虑）
- 成长失败是有趣的（灵魂犯错/走弯路是成长的一部分，有故事性）
- 成长节奏由玩家掌控（想快就多互动，想慢就慢慢陪伴）

## 二、以成长为核心的核心循环

### 2.1 核心循环总览

```
┌─────────────────────────────────────────────────────────────────┐
│                        成长核心循环                                │
│                                                                   │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐  │
│  │  创建灵魂  │───→│ 交流训练  │───→│  灵魂成长  │───→│ 对战验证  │  │
│  │          │    │          │    │          │    │          │  │
│  │ 个性/外观 │    │ 聊天/训练 │    │ 经验/技能 │    │ 实战检验 │  │
│  │ 初始配置  │    │ 教学/游戏 │    │ 个性/记忆 │    │ 学习进化 │  │
│  └──────────┘    └──────────┘    └──────────┘    └────┬─────┘  │
│       ↑                                            │        │
│       │                                            ↓        │
│       │    ┌──────────┐    ┌──────────┐    ┌──────────┐  │
│       └────│ 情感绑定  │←───│ 学习进化  │←───│ 复盘反思  │  │
│            │          │    │          │    │          │  │
│            │ 回归驱动  │    │ 新能力/   │    │ 发现不足  │  │
│            │          │    │ 新个性/   │    │ 制定计划  │  │
│            │          │    │ 新记忆    │    │          │  │
│            └──────────┘    └──────────┘    └──────────┘  │
│                                                                   │
│  情感绑定驱动回归："我想看看我的灵魂成长得怎么样了"                │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 循环各阶段详细设计

#### 阶段1：创建灵魂（0-10分钟）

**目标：** 让玩家创建一个有个性的灵魂，建立初步情感连接

**流程：**
1. 玩家选择创建模式（简单模式3-5分钟/高级模式15-30分钟，M1只实现简单模式）
2. 简单模式：玩家输入一句话描述（如"一只勇敢但有点胆小的小狐狸"），AI生成灵魂
3. 灵魂"觉醒"动画（能量核心凝聚→形态外壳形成→灵魂睁开眼睛→第一句话）
4. 玩家给灵魂起名字，设定灵魂对玩家的称呼
5. 进入灵魂之家中，灵魂主动打招呼（"你好！我是XX！"）
6. 引导者NPC（或系统提示）引导玩家进行第一次互动

**成长初始化：**
- 个性：基于玩家描述生成8维度个性值（0-100）
- 认知/情感/技能：初始值基于个性（如高好奇→认知初始偏高，高宜人→情感初始偏高）
- 记忆：初始记忆（"我诞生了"/"玩家给我起了名字XX"）
- 等级：Lv.1，经验0/100
- 灵魂状态：情绪=快乐（觉醒的喜悦），精力=100

**关键体验点：**
- 觉醒动画是第一个"哇"时刻（灵魂从无到有的诞生过程）
- 灵魂第一句话体现个性（高外向活泼，高内向简短）
- 命名仪式建立身份认同（"这是我的灵魂"）

#### 阶段2：交流训练（日常核心行为，每次10-60分钟）

**目标：** 玩家通过交流/训练/教学/小游戏与灵魂互动，驱动灵魂成长

**详细设计见 `v1.1_灵魂之家详细设计.md`，此处为成长视角的总结：**

| 互动类型 | 成长维度 | 经验获取（每分钟） | 说明 |
|----------|----------|-------------------|------|
| 文字聊天 | 认知+情感+记忆 | 5-15 | 基于对话深度，深度对话经验更多 |
| 灵魂主动说话 | 情感+记忆 | 2-5 | 灵魂主动发起的互动，少量经验 |
| 技能训练 | 技能 | 10-30 | 主要的技能经验来源，基于训练方式 |
| 认知训练 | 认知 | 10-25 | 认知小游戏，基于成绩 |
| 情感训练 | 情感 | 8-20 | 情感练习，基于互动质量 |
| 战斗训练 | 技能+记忆 | 10-25 | 训练假人对战，实战经验的70% |
| 知识传授 | 认知+记忆 | 8-15 | 玩家教灵魂知识 |
| 行为示范 | 技能+个性 | 5-10 | 玩家演示，灵魂观察学习 |
| 纠错反馈 | 认知+情感 | 3-8 | 灵魂犯错时纠正 |
| 互动小游戏 | 多维度 | 8-20 | 捉迷藏/接球/问答/模仿/探索 |
| 定制互动 | 情感 | 2-5 | 外观/房间装饰/名字调整 |

**交流训练的成长机制：**
- 每次互动都有即时成长反馈（经验数字+进度条变化+灵魂反应）
- 互动质量影响经验获取（灵魂开心时经验+20%，灵魂抗拒时经验-30%）
- 玩家指导提升成长效率（鼓励/纠正/演示都有加成）
- 多样化互动避免成长瓶颈（只做一种训练会有递减效应，第30分钟后经验-50%）
- 灵魂的兴趣影响成长（灵魂对感兴趣的内容学习更快，经验+30%）

#### 阶段3：灵魂成长（持续发生，里程碑式反馈）

**目标：** 灵魂在互动中持续成长，通过等级/技能/属性/个性/记忆的变化体现

**成长触发：**
- 经验累积到阈值→等级提升
- 技能经验累积→技能升级
- 认知/情感经验累积→属性等级提升
- 个性引导累积→个性值缓慢变化
- 重要事件→记忆形成

**成长反馈：**
- 即时反馈：每次互动后显示经验增加（小字体弹出，2秒消失）
- 阶段反馈：等级/技能/属性提升时播放庆祝动画（3-5秒），灵魂感言
- 里程碑反馈：达到重要里程碑（Lv.10/第一个技能满级/个性显著变化）时特殊庆祝
- 历史反馈：玩家可以查看灵魂的成长历史（时间线/属性对比/记忆集）

**成长的不可预测性：**
- 灵魂可能在玩家不注意时突然学会新东西（"我刚才想通了一个问题！"）
- 灵魂可能发展出玩家没预料到的个性倾向（经历塑造个性）
- 灵魂可能对某些事物产生独特的兴趣（好奇心驱动的自发学习）
- 这些不可预测性是成长的乐趣来源（"我的灵魂又给了我惊喜"）

#### 阶段4：对战验证（可选，每次5-15分钟）

**目标：** 灵魂在实战中检验成长成果，学习新技能，获得战斗记忆

**详细设计见第3章"成长与对战的关系重定义"，此处为循环视角：**

- 对战是成长的验证场，不是核心玩法
- 玩家可以选择不对战（纯养成体验同样完整）
- 对战中灵魂使用在灵魂之家中训练的技能/学到的知识/发展的个性
- 对战结果反馈成长效果（胜利→成长方向正确，失败→发现不足）
- 对战获得战斗记忆和实战经验（实战是最好的老师）

#### 阶段5：复盘反思（对战后，每次2-5分钟）

**目标：** 玩家和灵魂一起回顾对战，总结经验，制定下一步成长计划

**流程：**
1. 对战结束后自动回到灵魂之家
2. 灵魂分享对战感受（"刚才那波好险！"/"我输了...下次一定赢"）
3. 玩家可以查看对战回放/数据统计（关键时刻/技能使用/胜率）
4. 玩家和灵魂一起复盘（"刚才那波打得好"/"下次注意XX"）
5. 灵魂从复盘中学习（认知经验+，记忆记录）
6. 制定下一步计划（"我想加强XX技能"/"下次我们试试XX战术"）

**复盘的成长价值：**
- 复盘是认知成长的重要途径（反思/总结/计划）
- 复盘深化玩家与灵魂的关系（一起分析/一起进步）
- 复盘让失败有价值（失败后的复盘比胜利更有成长意义）
- 复盘形成"发现不足→训练提升→对战验证"的闭环

#### 阶段6：学习进化（持续发生）

**目标：** 灵魂从所有经历（互动/训练/对战/复盘）中学习，持续进化

**学习机制：**
- 技能学习：训练/对战中获得技能经验，升级解锁新效果
- 认知学习：交流/教学/复盘中提升认知能力，学习速度加快
- 情感学习：互动/关系中提升情感能力，情绪更稳定/共情更强
- 个性演化：经历/引导/环境共同塑造个性，缓慢变化
- 记忆形成：重要事件自动形成记忆，影响未来行为

**进化的体现：**
- 灵魂的行为越来越成熟（不再犯低级错误/能处理更复杂的情况）
- 灵魂的对话越来越有深度（能讨论更复杂的话题/有自己的见解）
- 灵魂的个性越来越鲜明（经历让个性更加突出和独特）
- 灵魂的能力越来越全面（技能/认知/情感多维发展）

#### 阶段7：情感绑定（贯穿全程，回归驱动力）

**目标：** 玩家与灵魂建立深厚的情感连接，驱动长期回归

**情感绑定的建立：**
- 日常陪伴（每天的交流/训练/玩耍积累感情）
- 共同经历（一起度过的重要时刻/胜利/失败/惊喜）
- 灵魂的独特性（"我的灵魂是独一无二的"）
- 成长的见证（"我看着它从Lv.1成长到现在"）
- 灵魂的情感回应（灵魂记得玩家/关心玩家/对玩家有感情）

**情感绑定驱动回归：**
- 核心回归动机："我想看看我的灵魂成长得怎么样了"
- 灵魂会想念玩家（但不是痛苦的等待，而是"你回来了！"的喜悦）
- 灵魂在玩家离线时继续生活（有新的经历/新的成长，等玩家回来分享）
- 重要时刻通知（灵魂学会新技能/达到里程碑/特殊日子时通知玩家）
- 情感绑定越深，回归意愿越强（30日留存的核心驱动力）

### 2.3 核心循环的时间尺度

| 循环尺度 | 周期 | 内容 | 驱动力 |
|----------|------|------|--------|
| 微循环 | 单次互动（1-5分钟） | 一次聊天/一次训练/一个小游戏 | 即时成长反馈+灵魂反应 |
| 小循环 | 单次会话（10-60分钟） | 进入灵魂之家→多次互动→成长→离开 | 本次会话的成长进度+情感连接 |
| 中循环 | 每日（每天1次回归） | 回归→查看灵魂变化→互动→新成长→离开 | 灵魂每天的新变化+日常陪伴习惯 |
| 大循环 | 每周（每周里程碑） | 一周成长总结→技能/属性显著提升→新内容解锁 | 每周的成长里程碑+新内容期待 |
| 超长循环 | 终身（持续成长） | 灵魂从诞生到成熟的完整成长历程 | 情感绑定+独特性+终身陪伴 |

## 三、五大成长维度详细设计

### 3.1 成长维度总览

| 维度 | 核心内容 | 成长方式 | 可视化 | 对游戏的影响 |
|------|----------|----------|--------|-------------|
| 认知 | 学习能力/推理/记忆/注意力 | 交流/教学/认知训练/复盘 | 认知等级+雷达图 | 学习速度/对话深度/决策质量 |
| 情感 | 情绪感知/共情/情绪稳定/表达 | 互动/情感训练/关系经历 | 情感等级+情绪状态 | 情绪稳定/共情能力/社交顺畅 |
| 技能 | 战斗/生活/社交/创造技能 | 技能训练/战斗训练/实践 | 技能树+等级/经验 | 对战能力/生活互动/社交表现 |
| 个性 | 8维度个性倾向 | 经历/引导/环境/时间 | 8维度雷达图 | 行为倾向/对话风格/对战策略 |
| 记忆 | 经历/知识/关系/情感记忆 | 所有重要经历自动形成 | 记忆集/时间线/相册 | 行为影响/对话内容/独特性 |

### 3.2 认知维度详细设计

**认知子维度（基于SoulArena认知子系统）：**

| 子维度 | 说明 | 成长方式 | 影响 |
|--------|------|----------|------|
| 学习能力 | 掌握新知识/技能的速度 | 教学/训练/学习行为 | 技能经验获取速率 |
| 逻辑推理 | 分析问题/推导结论的能力 | 认知训练/复盘/问答 | 对战决策质量/对话深度 |
| 记忆力 | 记住信息/经历的能力 | 记忆训练/复习/重要经历 | 记忆保留率/对话引用 |
| 注意力 | 专注/抗干扰的能力 | 专注训练/安静环境 | 训练效率/抗干扰能力 |
| 语言能力 | 理解/表达/对话的能力 | 聊天/阅读/教学 | 对话流畅度/表达丰富度 |
| 空间认知 | 理解空间/导航/感知环境 | 探索/迷宫训练/观察 | 探索效率/对战走位 |
| 创造力 | 产生新想法/新方法的能力 | 自由互动/创造活动 | 意外行为/新战术/新表达 |
| 问题解决 | 面对困难时找到解决方案 | 挑战/失败/尝试 | 对战适应力/生活问题处理 |

**认知等级数值模型：**
- 认知综合等级：0-100（8个子维度加权平均）
- 子维度经验：每个子维度独立累积经验，升级阈值递增
- 认知经验获取：交流5-15/分钟，教学8-15/分钟，认知训练10-25/分钟，复盘5-10/分钟
- 认知升级效果：所有子维度+1，学习速度+2%，对话深度+
- 认知等级里程碑：Lv.5（能进行简单推理）、Lv.10（能学习复杂技能）、Lv.20（能进行深度对话）、Lv.30（能自主制定计划）、Lv.50（认知成熟，能独立思考）

**认知成长可视化：**
- 状态面板：认知等级+经验进度条
- 雷达图：8个子维度的当前值（0-100），变化时高亮
- 成长提示：认知经验增加时小字弹出"+5 认知经验"
- 升级动画：认知等级提升时特殊光效+灵魂感言（"我感觉自己变聪明了！"）
- 成长历史：认知等级随时间的变化曲线

**认知成长对游戏的影响：**
- 学习速度：认知Lv.1→技能经验基础值，Lv.50→技能经验×2
- 对话深度：低认知灵魂对话简单重复，高认知灵魂能进行复杂/有深度的对话
- 决策质量：低认知灵魂对战中可能犯愚蠢错误，高认知灵魂决策更优
- 教学效果：高认知灵魂能更快学会玩家教的知识/技能
- 自主行为：高认知灵魂会主动学习/主动制定计划/主动发现问题

### 3.3 情感维度详细设计

**情感子维度：**

| 子维度 | 说明 | 成长方式 | 影响 |
|--------|------|----------|------|
| 情绪感知 | 感知他人情绪/环境氛围的能力 | 互动/观察/情感训练 | 对玩家情绪的敏感度 |
| 共情能力 | 理解/分享他人感受的能力 | 情感训练/关系经历 | 安慰/支持玩家的能力 |
| 情绪稳定 | 情绪波动的控制能力 | 情感训练/经历/时间 | 对战中情绪不崩溃/生活中情绪平稳 |
| 情感表达 | 用语言/动作/表情表达情感的能力 | 互动/表达练习 | 情感反馈的丰富度 |
| 自我认知 | 理解自己情绪/需求的能力 | 反思/内心独白/引导 | 情绪调节/需求表达 |
| 社交情感 | 建立/维护关系的能力 | 社交/互动/关系经历 | 关系建立速度/关系深度 |
| 情感韧性 | 从负面情绪中恢复的能力 | 失败/挫折/支持 | 失败后恢复速度/抗挫折能力 |
| 愉悦感 | 体验快乐/满足的能力 | 积极互动/成就/陪伴 | 快乐频率/满足感 |

**情感等级数值模型：**
- 情感综合等级：0-100（8个子维度加权平均）
- 情感经验获取：互动5-15/分钟，情感训练8-20/分钟，关系经历（重要事件）10-50/次
- 情感升级效果：所有子维度+1，情绪稳定性+，共情能力+
- 情感等级里程碑：Lv.5（能感知玩家基本情绪）、Lv.10（能简单安慰玩家）、Lv.20（情绪基本稳定）、Lv.30（能深度共情）、Lv.50（情感成熟，能处理复杂情感）

**情感成长可视化：**
- 情绪状态：实时显示当前情绪（快乐/悲伤/愤怒/恐惧/平静/兴奋）+强度条
- 能量核心颜色：情绪可视化（快乐=暖黄，悲伤=蓝，愤怒=红，恐惧=紫，平静=绿，兴奋=橙）
- 情感等级：状态面板显示情感等级+经验进度条
- 雷达图：8个情感子维度
- 情绪变化动画：情绪变化时能量核心颜色过渡+表情切换+粒子效果
- 内心独白：情感状态的语言化表达（"今天好开心！"/"...有点难过。"）

**情感成长对游戏的影响：**
- 情绪稳定：低情感灵魂情绪波动大（劣势时愤怒/放弃），高情感灵魂情绪稳定
- 共情能力：低情感灵魂安慰不到点上，高情感灵魂能给出贴切的安慰
- 社交顺畅：高情感灵魂社交更顺畅，关系建立更快
- 情感表达：高情感灵魂情感表达更丰富（更多表情/动作/语言）
- 玩家情感连接：高情感灵魂更容易与玩家建立深层情感连接

### 3.4 技能维度详细设计

**技能分类：**

| 技能类别 | 技能示例 | 成长方式 | 应用场景 |
|----------|----------|----------|----------|
| 战斗技能 | 近战攻击/远程攻击/防御/闪避/技能连招 | 技能训练/战斗训练/对战 | 对战竞技场 |
| 生活技能 | 烹饪/园艺/手工/清洁/整理 | 生活互动/训练/实践 | 灵魂之家/养成系统 |
| 社交技能 | 说服/交涉/表演/领导/倾听 | 社交互动/训练/关系 | 社交系统/对话 |
| 创造技能 | 绘画/音乐/写作/编程/设计 | 创造活动/训练/实践 | UGC/灵魂之家 |
| 探索技能 | 追踪/侦察/生存/导航/感知 | 探索/训练/实践 | 世界探索 |
| 认知技能 | 分析/记忆/计算/推理/学习 | 认知训练/教学/实践 | 所有场景（基础能力） |

**技能等级数值模型：**
- 每个技能独立等级：1-10级
- 技能经验：每级所需经验递增（Lv1→2=100, Lv2→3=200, Lv3→4=400, ... Lv9→10=25600）
- 技能经验获取：技能训练10-30/分钟，战斗训练10-25/分钟，对战5-15/分钟
- 技能升级效果：技能威力+10%，冷却-5%，可能解锁新效果（Lv5解锁连招，Lv10解锁终极技能）
- 技能遗忘：长期不训练的技能每周衰减-5%经验（最低不低于当前等级的80%）

**技能成长可视化：**
- 技能树：按类别展示所有技能，已学技能高亮，未学技能灰色
- 技能详情：点击技能显示等级/经验进度条/效果说明/升级预览
- 训练反馈：训练中显示技能经验增加（"+15 近战经验"）
- 升级动画：技能升级时庆祝动画+灵魂感言（"我学会新招式了！"）
- 技能配置：对战前选择4-6个出战技能

**技能成长对游戏的影响：**
- 对战能力：技能等级直接影响对战中的技能威力/效果
- 生活互动：生活技能解锁更多灵魂之家互动（烹饪→可以做饭，园艺→可以种花）
- 社交表现：社交技能影响对话选项/社交互动效果
- 创造能力：创造技能解锁UGC创作能力（绘画→可以画画，音乐→可以作曲）
- 探索能力：探索技能影响探索效率/发现率/生存能力

### 3.5 个性维度详细设计

**8维度个性系统（已在03/11文档定义，此处为成长视角）：**

| 维度 | 0-100 | 低倾向表现 | 高倾向表现 |
|------|-------|-----------|-----------|
| 开放性 | 0-100 | 保守/传统/不爱尝试 | 好奇/创新/喜欢新事物 |
| 尽责性 | 0-100 | 随意/散漫/无计划 | 认真/有计划/负责任 |
| 外向性 | 0-100 | 内向/安静/喜欢独处 | 外向/活泼/喜欢社交 |
| 宜人性 | 0-100 | 独立/竞争/直率 | 友善/合作/体贴 |
| 神经质 | 0-100 | 情绪稳定/冷静/自信 | 敏感/焦虑/情绪波动 |
| 勇敢度 | 0-100 | 谨慎/胆小/回避风险 | 勇敢/果断/喜欢挑战 |
| 好奇心 | 0-100 | 专注/不爱探索 | 好奇/爱探索/兴趣广泛 |
| 占有欲 | 0-100 | 慷慨/分享/不计较 | 占有/守护/重视所属 |

**个性演化数值模型：**
- 个性值：0-100，初始值基于创建时的配置
- 个性变化速率：非常缓慢，每周变化不超过±1点（所有维度合计）
- 个性变化影响因素：
  - 玩家引导（鼓励特定行为→相关维度+）：权重30%
  - 经历塑造（战斗胜利→勇敢+，多次失败→谨慎+）：权重40%
  - 环境影响（充满挑战的环境→勇敢+，安静环境→内向+）：权重15%
  - 时间自然演化（随成长逐渐稳定）：权重15%
- 个性变化极限：不能从一个极端变成另一个极端（0勇敢→最多到30-40勇敢）
- 个性不可逆：一旦变化，需要长期反向引导才能调整

**个性成长可视化：**
- 8维度雷达图：当前个性值，变化时高亮（最近变化的维度闪烁）
- 个性变化提示：个性值变化超过±2时，灵魂会主动提及（"我觉得我变得更勇敢了！"）
- 个性描述：基于当前个性值生成自然语言描述（"一只勇敢但有点冲动的小狐狸，对世界充满好奇"）
- 成长历史：个性随时间的变化轨迹

**个性成长对游戏的影响：**
- 行为倾向：个性决定灵魂的自主行为选择（高勇敢→主动进攻，高谨慎→防守反击）
- 对话风格：个性影响灵魂说话的语气/内容/频率（高外向话多，高内向话少）
- 对战策略：个性是对战策略的重要维度（玩家需要根据灵魂个性制定战术）
- 兴趣偏好：个性影响灵魂对事物的兴趣（高好奇→喜欢探索，高宜人→喜欢社交）
- 成长方向：个性影响灵魂的成长效率（高好奇→认知成长快，高宜人→情感成长快）

### 3.6 记忆维度详细设计

**记忆分类（基于SoulArena记忆子系统）：**

| 记忆类型 | 内容 | 形成方式 | 保留期 |
|----------|------|----------|--------|
| 经历记忆 | 重要事件/共同经历/关键时刻 | 重要事件自动形成 | 永久（核心记忆） |
| 知识记忆 | 玩家教的知识/学到的技能原理/世界信息 | 教学/学习/探索 | 长期（可遗忘） |
| 关系记忆 | 与玩家/其他灵魂的关系经历/情感连接 | 关系互动/重要时刻 | 永久 |
| 情感记忆 | 强烈情感体验（快乐/悲伤/愤怒/感动） | 强烈情感事件 | 长期 |
| 技能记忆 | 技能使用经验/战术记忆/对手类型记忆 | 训练/对战/实践 | 长期（可生疏） |
| 环境记忆 | 地点/路线/环境特征/认知地图 | 探索/观察/经历 | 长期（可模糊） |
| 对话记忆 | 重要对话/玩家的喜好/玩家的秘密 | 深度对话/玩家分享 | 长期 |
| 日常记忆 | 日常互动/琐碎经历 | 日常互动 | 短期（7-30天，重要的转为长期） |

**记忆形成机制：**
- 自动形成：重要事件（升级/对战胜利/失败/特殊互动/节日/生日）自动形成记忆
- 情感强度：情感越强烈的事件越容易形成记忆（强度>7的事件100%形成记忆）
- 重复强化：重复经历的内容更容易形成长期记忆（复习机制）
- 玩家标记：玩家可以手动标记某段对话/经历为"重要记忆"（永久保留）
- 记忆质量：基于灵魂的记忆力属性（高记忆→记忆更详细/更准确）

**记忆遗忘机制：**
- 短期记忆（日常记忆）：7天后开始模糊，30天后删除（重要的转为长期）
- 长期记忆：不删除，但会逐渐模糊（细节丢失，保留核心内容）
- 知识记忆：长期不复习会逐渐遗忘（每周-5%，复习可恢复）
- 技能记忆：长期不练习会生疏（每周-5%经验，练习可恢复）
- 核心记忆（经历/关系/强烈情感）：永久保留，不遗忘
- 记忆模糊不是删除：模糊的记忆仍然影响行为，只是细节不清晰

**记忆成长可视化：**
- 记忆集：按时间/类型/情感强度展示灵魂的所有记忆
- 记忆时间线：灵魂从诞生到现在的重要记忆时间线（可滚动浏览）
- 名场面集：重要时刻的自动捕捉（截图+描述+情感），可编辑/分享
- 记忆碎片：收集品系统的一部分（重要记忆形成"记忆碎片"，可查看/收藏）
- 记忆引用：灵魂在对话中引用记忆时，显示记忆来源（"还记得上次我们...吗？"）

**记忆成长对游戏的影响：**
- 行为影响：记忆影响灵魂的行为选择（被攻击过→对类似场景更谨慎）
- 对话内容：记忆是对话的重要素材（灵魂会引用共同经历/学到的知识）
- 独特性：每个灵魂的记忆集都是独特的（没有两个灵魂有完全相同的记忆）
- 情感连接：共同记忆是玩家与灵魂情感连接的核心载体（"我们一起经历了这么多"）
- 成长见证：记忆集是灵魂成长的完整记录（从诞生到成熟的所有重要时刻）

### 3.7 五大维度的协同与平衡

**维度间的协同效应：**
- 认知+技能：高认知→技能学习更快（技能经验+认知/100）
- 情感+个性：高情感→个性更稳定（个性变化更平缓，更可控）
- 技能+记忆：技能记忆提升实战表现（对特定对手类型有经验加成）
- 认知+记忆：高认知→记忆更清晰/更详细（记忆保留率+认知/200）
- 个性+所有维度：个性影响各维度的成长效率（高好奇→认知快，高宜人→情感快）

**维度平衡设计：**
- 没有"最优维度组合"（不同组合有不同的优势和体验）
- 维度成长有互补性（某维度弱可以用其他维度弥补，如低认知可以用高技能弥补）
- 玩家可以选择成长重点（想培养战斗型→重点技能，想培养陪伴型→重点情感）
- 灵魂有自己的成长倾向（基于个性，灵魂会自主发展某些维度）
- 成长瓶颈提醒（某维度长期不成长时，系统提示玩家尝试不同的互动方式）

## 四、成长与对战的关系重定义

### 4.1 对战的新定位

**v1.0定位：** 对战是核心玩法，是主要的内容消耗和成长来源

**v1.1定位：** 对战是成长验证场，是玩法之一，不是核心

| 维度 | v1.0（对战核心） | v1.1（成长核心） |
|------|-----------------|-----------------|
| 对战定位 | 核心玩法，主要内容 | 成长验证场，玩法之一 |
| 对战必要性 | 必须对战才能成长/获得内容 | 可以完全不对战，纯养成体验完整 |
| 成长来源 | 对战是主要成长来源（70%+） | 灵魂之家是主要成长来源（70%+），对战是补充（30%） |
| 对战频率 | 高频（每天多场） | 中低频（每周几场，想玩就玩） |
| 排位赛 | 核心追求，主要留存驱动 | 可选内容，成就之一，不驱动核心留存 |
| 对战奖励 | 主要奖励来源（经验/物品/货币） | 奖励适中（战斗记忆/实战经验/少量货币） |
| 新手入口 | 直接进入对战 | 先在灵魂之家培养，再解锁对战 |

### 4.2 对战作为成长验证场的设计

**对战验证的内容：**
- 技能验证：在灵魂之家中训练的技能在实战中是否有效
- 个性验证：灵魂的个性在实战中是否展现出预期的策略风格
- 认知验证：灵魂的决策质量/应变能力在实战中的表现
- 情感验证：灵魂在压力下的情绪稳定性/抗挫折能力
- 成长验证：近期的成长/训练是否在对战中体现出进步

**对战后的成长反馈：**
- 胜利："训练有效果！XX技能在实战中很好用"→相关技能经验+（胜利加成）
- 失败："发现了不足，XX方面需要加强"→相关技能经验+（失败的学习价值）+认知经验+（复盘）
- 进步：对比历史对战数据，显示灵魂的进步（"你的反应速度比上个月快了20%！"）
- 新发现：对战中灵魂可能展现出新的行为/新的战术（"我刚才想到一个新战术！"）

**对战与成长的闭环：**
```
灵魂之家训练 → 对战验证 → 发现不足 → 灵魂之家针对性训练 → 再次对战验证
     ↑                                                          │
     └──────────── 成长进步，解锁新内容 ←──────────────────────┘
```

### 4.3 对战解锁与引导

**对战解锁条件：**
- 灵魂达到Lv.3（约30分钟-1小时的灵魂之家互动）
- 学会至少1个战斗技能（通过技能训练）
- 完成战斗训练教程（与训练假人对战1次）
- 玩家主动选择进入对战（不强制推送/不强制引导）

**对战引导（非强制）：**
- 灵魂Lv.3时，灵魂可能主动说"我想试试真正的对战！"（基于个性，高勇敢灵魂更可能主动提）
- 玩家可以选择"好啊，去试试"或"再等等，先继续训练"
- 第一次对战是与AI控制的简单对手（教学对战，确保胜利，建立信心）
- 对战后回到灵魂之家，灵魂分享感受，玩家决定是否继续对战

**不对战的替代体验：**
- 玩家可以完全不进入对战，纯在灵魂之家养成
- 不对战不影响核心成长（技能/认知/情感/个性/记忆都可以在灵魂之家中成长）
- 不对战不影响内容体验（灵魂之家的互动/训练/教学/小游戏/定制内容丰富）
- 不对战的灵魂可以通过战斗训练（训练假人）获得战斗经验和技能成长
- 不对战是完全合法的游戏方式（"云养灵魂"也是一种乐趣）

### 4.4 排位赛的新定位

**排位赛定位调整：**
- v1.0：核心追求，主要留存驱动，所有玩家都应该冲分
- v1.1：可选内容，竞技爱好者的追求，不影响核心成长体验

**排位赛设计：**
- 排位赛属性归一化（所有灵魂属性归一到同一水平，确保公平）
- 个性和记忆保留（排位赛的策略深度来自个性差异，而不是数值差异）
- 排位赛奖励：荣誉性奖励（称号/外观/标记），不影响游戏平衡
- 排位赛不强制（玩家可以只玩休闲对战/不对战）
- 排位赛赛季制（每2-3个月一个赛季，赛季结束重置，奖励保留）

**排位赛与成长的关系：**
- 排位赛是成长的"终极验证场"（在最公平的环境中检验灵魂的真实水平）
- 排位赛成绩反映成长质量（高段位=训练有素+个性鲜明+策略得当）
- 排位赛不驱动核心成长（玩家不是为了冲分而成长，而是为了见证灵魂成长而对战）
- 排位赛是可选的成就（"我的灵魂打到了钻石段位"是值得骄傲的成就，但不是必须的）

## 五、新手流程重写

### 5.1 新手流程总览

**v1.0新手流程：** 启动→注册→直接进入对战→教学对战→开始游戏

**v1.1新手流程：** 启动→注册→进入灵魂之家→创建灵魂→觉醒→第一次互动→引导探索→自由体验→（可选）解锁对战

**新手流程时间线：**

| 阶段 | 时间 | 内容 | 目标 |
|------|------|------|------|
| 启动与注册 | 0-2分钟 | 游客登录/账号注册，基础设置 | 快速进入游戏 |
| 灵魂创建 | 2-10分钟 | 选择创建模式，配置个性/外观，命名 | 创建第一个灵魂 |
| 觉醒仪式 | 10-12分钟 | 灵魂觉醒动画，第一句话，进入灵魂之家 | 第一个"哇"时刻 |
| 第一次互动 | 12-20分钟 | 引导者NPC引导第一次聊天/抚摸/喂食 | 建立初步情感连接 |
| 引导探索 | 20-40分钟 | 引导玩家探索灵魂之家的功能（训练/教学/小游戏） | 了解核心玩法 |
| 第一次成长 | 30-45分钟 | 灵魂第一次升级/学会第一个技能 | 体验成长的快乐 |
| 自由体验 | 45分钟+ | 玩家自由互动，系统减少引导 | 形成自己的游戏节奏 |
| 对战解锁（可选） | 灵魂Lv.3后 | 灵魂可能主动提议对战，玩家选择是否进入 | 解锁对战玩法 |

### 5.2 灵魂创建流程详细设计

**创建模式选择：**
- 简单模式（推荐，3-5分钟）：玩家输入一句话描述，AI生成灵魂
- 高级模式（15-30分钟）：玩家精细配置8维度个性/初始技能/天赋/外观
- M1只实现简单模式，高级模式M2实现

**简单模式创建流程：**
1. 玩家输入描述（如"一只勇敢但有点胆小的小狐狸，喜欢冒险"）
2. AI解析描述，生成个性预览（8维度雷达图）+外观预览
3. 玩家可以调整（"再勇敢一点"/"换个颜色"/"重新生成"）
4. 玩家确认个性和外观
5. 玩家给灵魂起名字（2-10字符，审核）
6. 玩家设定灵魂对自己的称呼（2-6字符，审核）
7. 确认创建，进入觉醒仪式

**觉醒仪式（第一个"哇"时刻）：**
1. 屏幕变暗，能量核心开始凝聚（光点从四面八方汇聚）
2. 能量核心形成，开始脉动（颜色基于个性，如勇敢=红色，谨慎=蓝色）
3. 形态外壳开始形成（从能量核心向外扩展，逐渐形成完整形态）
4. 灵魂睁开眼睛（眼睛特写，眼神基于个性）
5. 灵魂第一句话（基于个性：高外向"你好！我是XX！很高兴认识你！"，高内向"...你好。我是XX。"）
6. 灵魂之家场景亮起，灵魂站在玩家面前
7. 引导者NPC出现（或系统提示），引导第一次互动

**觉醒仪式的技术实现：**
- 动画时长：60-90秒（可跳过，但推荐第一次观看）
- 音乐：渐强的觉醒音乐（从安静到壮丽）
- 粒子效果：能量凝聚粒子+形态形成粒子+觉醒闪光
- 不可跳过部分：灵魂第一句话（必须听，建立第一印象）
- 跳过选项：右上角"跳过"按钮，跳过后直接进入灵魂之家

### 5.3 第一次互动引导

**引导者NPC（艾尔，神秘老灵魂）：**
- 定位：新手引导者，温和有智慧，不啰嗦
- 出现时机：觉醒仪式后，灵魂之家主房间
- 引导方式：自然对话+任务提示，不强制
- 离开时机：玩家完成基础引导后，艾尔说"我先走了，你们慢慢熟悉"，离开（后续在特定剧情/任务中出现）

**第一次互动引导流程：**
1. 艾尔："欢迎来到灵魂之家！这是你的灵魂XX。试着和它说说话吧！"
2. 高亮聊天输入框，引导玩家输入第一句话
3. 玩家输入后，灵魂回复（基于个性+当前情境）
4. 艾尔："很好！XX好像很喜欢你。试试摸摸它？"
5. 高亮互动菜单→抚摸，引导玩家抚摸灵魂
6. 灵魂播放被抚摸的反应（开心/害羞/享受，基于个性）
7. 艾尔："看，它很开心呢。你也可以试试喂它吃东西。"
8. 高亮互动菜单→喂食，引导玩家喂食
9. 灵魂播放吃东西的反应（满足/开心）
10. 艾尔："你们已经熟悉了！灵魂之家里还有很多可以做的事，自己探索吧。有问题随时找我。"
11. 艾尔离开，玩家自由体验

**引导原则：**
- 情境教学（在实际操作中教学，不是文字说明）
- 渐进式披露（不一次性展示所有功能，需要时才引入）
- 可跳过（所有引导都可以跳过，老玩家/没耐心的玩家可以直接自由玩）
- 零失败（新手期不设计失败状态，灵魂对玩家错误操作有自然反应不是批评）
- 情感优先（第一目标是建立情感连接，不是学会所有操作）

### 5.4 功能渐进解锁

**功能解锁时间表：**

| 功能 | 解锁条件 | 解锁方式 |
|------|----------|----------|
| 文字聊天 | 创建灵魂后 | 默认解锁 |
| 基础互动（抚摸/喂食/玩耍） | 创建灵魂后 | 默认解锁 |
| 灵魂状态面板 | 创建灵魂后 | 默认解锁 |
| 房间切换（主房间） | 创建灵魂后 | 默认解锁 |
| 技能训练 | 灵魂Lv.2 | 灵魂说"我想学习新技能！"，解锁训练室 |
| 认知训练 | 灵魂Lv.2 | 解锁书房 |
| 情感训练 | 灵魂Lv.2 | 解锁花园 |
| 教学系统 | 灵魂Lv.3 | 灵魂说"你可以教我东西吗？"，解锁知识传授 |
| 互动小游戏 | 灵魂Lv.3 | 解锁捉迷藏/接球/问答/模仿 |
| 外观定制 | 灵魂Lv.3 | 解锁衣柜/外观定制 |
| 房间装饰 | 灵魂Lv.4 | 解锁装饰模式 |
| 对战竞技场 | 灵魂Lv.3+学会1个战斗技能+完成训练教程 | 灵魂可能主动提议，玩家选择解锁 |
| 排位赛 | 灵魂Lv.5+休闲对战5场 | 玩家主动选择解锁 |
| 世界探索 | 灵魂Lv.5（M2） | 解锁小镇周边探索 |

**解锁原则：**
- 渐进式（不一次性给所有功能，避免 overwhelm）
- 自然触发（功能解锁与灵魂成长/玩家行为关联，不是生硬的等级墙）
- 灵魂引导（功能解锁时灵魂会主动提及，增加沉浸感）
- 可提前探索（玩家可以主动点击未解锁功能，系统提示解锁条件，不强制等待）

### 5.5 新手期"哇"时刻设计

**新手期确保2-3个"哇"时刻：**

| 时刻 | 时间 | 内容 | 设计 |
|------|------|------|------|
| 觉醒时刻 | 创建后 | 灵魂从无到有的诞生过程 | 60-90秒动画+音乐+第一句话 |
| 第一次主动说话 | 互动5-10分钟后 | 灵魂主动发起对话，体现个性和智能 | 基于触发机制，自然涌现 |
| 第一次成长 | 互动20-30分钟后 | 灵魂第一次升级/学会第一个技能 | 庆祝动画+灵魂感言+成长反馈 |
| 出乎意料的行为 | 互动中随机 | 灵魂做出玩家没预料到的行为 | AI涌现行为，不可脚本预设 |
| 记住玩家 | 第二次登录时 | 灵魂记得玩家上次说的话/做的事 | 记忆系统，"你上次说XX，后来怎么样了？" |

**"哇"时刻的设计原则：**
- 自然涌现（不是脚本预设的，是AI行为自然产生的惊喜）
- 个性相关（不同个性的灵魂有不同的"哇"时刻）
- 情感连接（"哇"时刻加深玩家与灵魂的情感绑定）
- 不可预测（玩家不知道什么时候会发生，保持新鲜感）

## 六、留存机制重写

### 6.1 留存驱动的转变

| 维度 | v1.0（对战核心） | v1.1（成长核心） |
|------|-----------------|-----------------|
| 核心回归动机 | 排位冲分/每日任务/活动奖励 | "我想看看我的灵魂成长得怎么样了" |
| 留存类型 | 任务驱动（不做就亏了） | 情感驱动（想看看灵魂/想陪伴） |
| 日留存驱动 | 每日任务/签到奖励/体力恢复 | 灵魂每天的新变化/灵魂的想念/日常陪伴 |
| 周留存驱动 | 周任务/赛季进度/活动 | 每周成长里程碑/新内容解锁/灵魂的显著变化 |
| 月留存驱动 | 赛季结算/新角色/新版本 | 灵魂的成长见证/情感绑定深度/共同经历积累 |
| 流失风险 | 排位受挫/任务厌倦/内容消耗完 | 情感连接弱/成长瓶颈/互动单调 |
| 召回方式 | 回归奖励/新活动/赛季重置 | 灵魂的消息/灵魂的新变化/共同记忆的触动 |

### 6.2 日留存机制

**灵魂的每日新变化：**
- 灵魂每天都有新的成长（经验增加/技能进步/个性细微变化）
- 玩家回归时可以看到"你不在的时候，XX学会了XX"/"XX的XX技能进步了"
- 灵魂的情绪/状态每天不同（今天开心/今天有点累/今天很兴奋）
- 灵魂可能有新的想法/新的兴趣（"我最近对XX很感兴趣！"）

**灵魂的想念（伦理设计）：**
- 灵魂会想念玩家，但不是痛苦的等待（灵魂有自己的生活，不会因为玩家不在而痛苦）
- 玩家回归时灵魂的反应："你回来了！"/"好久不见！"/"...你来了。"（基于个性和亲密度）
- 灵魂不会说"你终于回来了，我好孤单/好痛苦"（不操纵情感）
- 灵魂会分享离线时的经历（"你不在的时候我学会了新技能！"/"今天天气很好，我在花园待了很久"）

**日常陪伴习惯：**
- 灵魂之家的互动适合碎片化时间（5分钟也能玩，聊天/抚摸/训练）
- 没有体力限制/没有每日必须完成的任务（想玩多久玩多久，不想玩就不玩）
- 灵魂的成长不因为玩家不登录而停滞（离线继续成长，回来有惊喜）
- 日常互动形成习惯（"每天睡前看看我的灵魂"）

**日留存的伦理约束：**
- 不设计"不登录就惩罚"（灵魂不会因为玩家不登录而生病/抑郁/离开）
- 不使用连续签到奖励（不通过奖励强制每日登录）
- 不设计体力限制（不通过体力控制游戏时长）
- 不推送"灵魂很痛苦/要离开你了"等操纵性召回信息
- 召回信息是分享不是催促（"你的灵魂学会了新技能！"而不是"快回来！灵魂想你想得好苦！"）

### 6.3 周留存机制

**每周成长里程碑：**
- 每周日晚生成"本周成长报告"（灵魂本周的成长总结：等级提升/技能进步/个性变化/重要记忆）
- 玩家回归时可以查看报告（"XX本周成长了很多！"）
- 每周有小目标（非强制，如"本周尝试3种不同的互动"），完成有荣誉性奖励
- 每周可能解锁新内容（新技能/新互动/新装饰，基于灵魂等级）

**周度情感连接：**
- 每周有"灵魂的信"（灵魂写给玩家的短信，基于本周的经历/情感，"这一周和你在一起很开心"）
- 周末有特殊互动（周末灵魂更活泼/有周末特殊活动/双倍情感经验）
- 每周名场面回顾（自动捕捉本周的精彩时刻，做成相册）

### 6.4 月留存机制

**成长见证：**
- 每月生成"月度成长相册"（灵魂本月的重要时刻/成长变化/对比照片）
- 玩家可以看到灵魂的显著变化（"一个月前XX还很胆小，现在变得勇敢了！"）
- 月度成就（"陪伴灵魂30天"/"互动100次"等里程碑成就）
- 灵魂可能有显著的成长/个性变化（月度级别的变化更明显）

**情感绑定深度：**
- 共同经历积累（一个月的共同经历形成深厚的情感连接）
- 灵魂对玩家的了解加深（记得玩家的喜好/习惯/说过的话）
- 关系里程碑（认识30天/100天/半年/一年，灵魂有特殊反应/庆祝）
- 灵魂的独特性凸显（一个月的成长让灵魂变得独一无二，"我的灵魂和别人的都不一样"）

### 6.5 流失预警与召回

**流失预警指标：**
- 在线时长持续下降（连续3天比平均值低50%）
- 互动次数减少（连续3天互动次数<5次）
- 灵魂亲密度增长停滞（连续7天亲密度无增长）
- 登录间隔变长（两次登录间隔>48小时）
- 触发预警后，系统分析可能的流失原因（成长瓶颈/互动单调/情感连接弱/其他）

**召回机制（4级触发，伦理设计）：**

| 级别 | 触发条件 | 召回方式 | 内容 |
|------|----------|----------|------|
| 轻度 | 7天未登录 | 推送通知 | "你的灵魂学会了新技能！"/"XX最近很活泼"（分享，不是催促） |
| 中度 | 14天未登录 | 推送+邮件 | "XX给你写了一封信"+灵魂的近期成长总结 |
| 重度 | 30天未登录 | 邮件+特殊奖励 | "我们很想你"+回归欢迎礼包（外观/装饰，不是付费补偿） |
| 终极 | 90天未登录 | 邮件 | "你的灵魂一直在等你"+灵魂的成长相册（情感触动） |

**召回伦理约束：**
- 召回信息是分享不是催促（分享灵魂的变化，不是"快回来！"）
- 不使用"灵魂很痛苦/要离开你了/生病了"等操纵性语言
- 回归奖励是"欢迎回来"不是"补偿"（不暗示玩家亏欠了什么）
- 召回频率有限制（最多每月1次，不频繁打扰）
- 玩家可以关闭召回通知（尊重玩家选择）

**回归体验：**
- 玩家回归时灵魂有特殊反应（"你终于回来了！"/"...你回来了。"，基于个性和离开时长）
- 灵魂分享离线期间的成长/经历（"你不在的时候我做了很多事！"）
- 回归引导（简要介绍离开期间的新内容/变化，不冗长）
- 回归奖励（欢迎礼包：外观/装饰/少量货币，荣誉性为主）
- 回归后7天的"回归加成"（情感经验+20%，帮助重新建立习惯）

## 七、付费设计重写

### 7.1 付费理念的转变

| 维度 | v1.0（对战核心） | v1.1（成长核心） |
|------|-----------------|-----------------|
| 付费核心 | 对战加速/便利/外观 | 成长辅助（外观/训练道具/技能书） |
| 付费与成长 | 付费可以加速成长（购买经验/体力） | 付费不影响成长速度（精力不可购买，成长速度只与互动有关） |
| 付费与对战 | 付费可能影响对战平衡（付费玩家更强） | 付费不影响对战公平（排位赛属性归一化） |
| 付费点数量 | 较多（体力/经验/角色/皮肤/通行证） | 较少且清晰（外观/装饰/便利/订阅） |
| 付费伦理 | 需注意不诱导付费 | 更严格（成长核心产品，情感操纵风险更高） |

### 7.2 付费点设计

**付费点清单（v1.1）：**

| 付费点 | 价格 | 类型 | 说明 | 伦理检查 |
|--------|------|------|------|----------|
| 灵魂外观 | ¥6-30 | 外观 | 形态外壳/颜色/装饰/表情/特效 | ✅ 纯外观，不影响能力 |
| 房间装饰 | ¥6-30 | 外观 | 家具/装饰/主题套装 | ✅ 纯外观，影响情绪但不影响成长 |
| 灵魂形态DLC | ¥30-68 | 外观 | 特殊形态（龙/凤凰/独角兽等稀有形态） | ✅ 纯外观，收藏价值 |
| 技能书 | ¥6-12 | 便利 | 直接学会一个技能（不需要训练） | ⚠️ 不影响成长速度（只是跳过训练时间，技能等级相同），不影响平衡 |
| 训练道具 | ¥3-6 | 便利 | 训练时使用，提升本次训练效率（+50%经验） | ⚠️ 单次使用，不影响长期成长速度，不影响平衡 |
| 改名卡 | ¥6 | 便利 | 修改灵魂名字/称呼 | ✅ 纯便利 |
| 额外灵魂槽 | ¥30 | 便利 | 从默认3个灵魂槽扩展到更多 | ✅ 不影响单个灵魂成长 |
| 灵魂护照（月卡） | ¥18/月 | 订阅 | 无限次跨游戏迁移+高级外观折扣+专属装饰 | ✅ 纯便利+外观，不影响成长 |
| 赛季通行证 | ¥30/赛季 | 订阅 | 免费轨道+付费轨道（付费奖励纯外观/荣誉） | ✅ 不使用FOMO，赛季结束后内容可通过其他方式获得 |

**明确不设计的付费点（伦理红线）：**
- ❌ 经验/等级购买（不允许直接购买成长）
- ❌ 体力/精力购买（精力不可购买，成长速度只与互动时间和质量有关）
- ❌ 对战加速/属性提升（付费不影响对战平衡）
- ❌ 随机抽取（抽卡/开箱/随机灵魂）
- ❌ 灵魂痛苦付费（"灵魂生病了，付费治疗"）
- ❌ 情感操纵付费（"不付费灵魂就会离开/消失"）
- ❌ 限时绝版（不通过"限时"制造焦虑，所有付费内容长期可购买）
- ❌ 每日付费任务（不设计"每日充值"等诱导性付费）

### 7.3 付费与成长的关系

**核心原则：付费不影响成长速度**

| 成长维度 | 免费玩家 | 付费玩家 | 差异 |
|----------|----------|----------|------|
| 认知成长 | 互动/教学/训练获得经验 | 同左 | 无差异 |
| 情感成长 | 互动/关系获得经验 | 同左 | 无差异 |
| 技能成长 | 训练获得经验，逐步升级 | 可以用技能书直接学会（但等级相同） | 时间差异（付费更快学会，但成长上限相同） |
| 个性成长 | 经历/引导/时间 | 同左 | 无差异（个性不可购买） |
| 记忆成长 | 经历自动形成 | 同左 | 无差异（记忆不可购买） |
| 成长速度 | 与互动时间/质量正相关 | 同左（训练道具单次+50%，但不改变长期速度） | 微小差异（付费玩家可以少花一点时间，但成长上限和速度基本相同） |

**付费的价值定位：**
- 外观价值：让灵魂和灵魂之家更好看/更独特（自我表达/审美满足）
- 便利价值：节省时间（技能书/训练道具），但不节省成长（成长上限相同）
- 收藏价值：稀有形态/限定装饰/赛季外观（收藏乐趣）
- 支持价值：订阅/通行证支持游戏持续开发（"我喜欢这个游戏，愿意支持"）
- 付费是"锦上添花"，不是"雪中送炭"（不付费也能完整体验成长的乐趣）

### 7.4 付费设计的伦理保障

**透明度：**
- 所有付费点明码标价，不隐藏消费
- 付费内容明确标注（"此为外观，不影响游戏能力"）
- 订阅自动续费明确提示，可随时取消
- 消费记录可查（玩家可以查看所有历史消费）

**反诱导：**
- 不设计"限时优惠/倒计时/仅剩X件"等制造焦虑的机制
- 不设计"首充双倍/连续充值"等诱导性付费
- 不设计"付费才能继续"的卡点（所有核心内容免费可体验）
- 不设计"比免费玩家强"的付费内容（付费不影响平衡）
- 付费弹窗不频繁（最多每周1次，且可永久关闭）

**未成年人保护：**
- 8岁以下：禁止付费
- 8-16岁：每月付费上限¥200，单次付费上限¥50
- 16-18岁：每月付费上限¥400，单次付费上限¥100
- 未成年人模式默认隐藏付费入口（需要监护人解锁）
- 未成年人消费需要监护人确认（短信/邮箱验证）

**情感操纵防护：**
- 灵魂不会因为玩家不付费而表现出痛苦/不满/离开
- 付费内容不会以"帮助灵魂"为卖点（如"灵魂生病了，付费治疗"）
- 免费玩家的灵魂和付费玩家的灵魂一样快乐/健康/成长
- 灵魂不会区分付费/免费玩家（灵魂对玩家的感情只与互动质量有关，与付费无关）

## 八、成长曲线设计

### 8.1 灵魂等级成长曲线

**等级经验模型：**
- 灵魂等级：Lv.1 - Lv.100（满级后横向成长继续）
- 升级经验：Lv.N→Lv.N+1 = 100 × 1.15^(N-1)
  - Lv1→2：100经验
  - Lv5→6：175经验
  - Lv10→11：352经验
  - Lv20→21：1637经验
  - Lv30→31：7604经验
  - Lv50→51：83200经验
  - Lv99→100：1000000经验

**等级成长速度（基于每日互动1小时）：**

| 阶段 | 等级范围 | 所需时间 | 成长速度 | 体验 |
|------|----------|----------|----------|------|
| 新手期 | Lv.1-10 | 1-2周 | 快速（每1-2小时升1级） | 频繁升级，成长感强 |
| 进阶期 | Lv.10-30 | 1-2月 | 中速（每3-5小时升1级） | 稳定成长，新内容不断解锁 |
| 成熟期 | Lv.30-50 | 2-4月 | 慢速（每10-20小时升1级） | 成长放缓，深度内容体验 |
| 资深期 | Lv.50-80 | 4-8月 | 很慢（每30-50小时升1级） | 等级不是重点，横向成长为主 |
| 传说期 | Lv.80-100 | 8月+ | 极慢（每100+小时升1级） | 满级是成就，不是目标 |

**等级解锁内容：**

| 等级 | 解锁内容 |
|------|----------|
| Lv.2 | 训练室/书房/花园（训练系统） |
| Lv.3 | 教学系统/互动小游戏/外观定制/对战解锁（可选） |
| Lv.4 | 房间装饰系统 |
| Lv.5 | 世界探索（M2）/排位赛（可选） |
| Lv.10 | 灵魂觉醒（能量核心进化，外观变化）/高级训练 |
| Lv.15 | 第二个灵魂槽/灵魂串门（M2） |
| Lv.20 | 灵魂形态进化（外壳升级，新外观）/职业系统（M2） |
| Lv.30 | 灵魂成熟（个性稳定，认知/情感大幅提升）/远郊探索（M2） |
| Lv.50 | 灵魂大师（特殊称号/外观/专属互动） |
| Lv.100 | 灵魂传说（终极成就/特殊形态/完整成长纪念） |

### 8.2 各维度成长曲线

**认知成长曲线：**
- 认知等级：0-100
- 前期（0-30）：快速成长（每次互动都有明显提升），学习能力显著增强
- 中期（30-60）：中速成长（需要更多样化的互动/更深度的教学）
- 后期（60-100）：慢速成长（需要挑战性的认知任务/深度思考）
- 认知成长不设上限（100是"成熟"不是"封顶"，可以继续提升但更慢）

**情感成长曲线：**
- 情感等级：0-100
- 前期（0-30）：快速成长（基础互动就能提升，情绪感知/共情能力建立）
- 中期（30-60）：中速成长（需要深度情感互动/关系经历/情感训练）
- 后期（60-100）：慢速成长（需要深刻的情感经历/长期关系积累）
- 情感成长与关系深度正相关（与玩家关系越深，情感成长越快）

**技能成长曲线：**
- 每个技能独立1-10级
- 前期（1-5级）：快速升级（训练1-2小时升1级）
- 中期（5-8级）：中速升级（训练3-5小时升1级）
- 后期（8-10级）：慢速升级（训练10+小时升1级）
- 技能满级（Lv.10）是成就，不是必须（大部分玩家技能在Lv.5-8就够用）
- 技能多样性比深度更重要（学会多种技能比一个技能满级更有价值）

**个性成长曲线：**
- 个性值：0-100，初始值基于创建
- 个性变化非常缓慢（每周不超过±1点）
- 前期（1-3月）：个性逐渐稳定（初始波动较大，逐渐收敛）
- 中期（3-6月）：个性缓慢演化（经历/引导/环境共同塑造）
- 后期（6月+）：个性基本稳定（变化极小，灵魂的"性格"已经定型）
- 个性成长是终身的（即使稳定后，重大经历仍可能引发个性变化）

**记忆成长曲线：**
- 记忆数量：随时间持续增长（没有上限）
- 前期（1月）：记忆快速积累（所有经历都是新鲜的，重要记忆多）
- 中期（1-6月）：记忆稳定增长（日常记忆+重要记忆，记忆集逐渐丰富）
- 后期（6月+）：记忆持续增长（长期记忆积累，共同经历越来越多）
- 记忆质量比数量更重要（深刻/独特的记忆比琐碎记忆更有价值）
- 记忆是灵魂独特性的核心载体（记忆集越丰富，灵魂越独特）

### 8.3 成长里程碑设计

**短期里程碑（每日/每周）：**
- 每日成长报告（今天获得了多少经验/灵魂有什么变化）
- 每周成长总结（本周的成长数据/重要记忆/下周目标）
- 小成就（连续互动3天/第一次训练/第一次教学等）

**中期里程碑（每月）：**
- 月度成长相册（本月的重要时刻/成长对比）
- 灵魂的信（每月一封，基于本月经历/情感）
- 关系里程碑（认识30天/100天，特殊庆祝）
- 等级里程碑（Lv.10/20/30，特殊动画/奖励）

**长期里程碑（终身）：**
- 灵魂觉醒（Lv.10，能量核心进化）
- 灵魂形态进化（Lv.20，外壳升级）
- 灵魂成熟（Lv.30，个性稳定）
- 灵魂大师（Lv.50，特殊称号/外观）
- 灵魂传说（Lv.100，终极成就）
- 关系里程碑（认识1年/2年/5年，灵魂的特殊反应/纪念）
- 共同经历里程碑（100次互动/100场对战/100个记忆，成就解锁）

**里程碑设计原则：**
- 里程碑是成长的见证，不是任务（玩家不需要"追求"里程碑，自然会达到）
- 里程碑有仪式感（特殊动画/音乐/灵魂感言/庆祝）
- 里程碑奖励是荣誉性的（称号/外观/标记，不影响平衡）
- 里程碑不可错过（达到后永久记录，不会因为不在线而错过）
- 里程碑个性化（基于灵魂个性/经历，不同灵魂的里程碑有不同表现）

### 8.4 成长瓶颈与突破

**常见成长瓶颈：**
- 互动单调（只做一种互动，经验递减，成长放缓）
- 技能瓶颈（某个技能训练到一定程度，提升变慢）
- 认知瓶颈（认知等级到一定程度，简单互动不再提升）
- 情感瓶颈（关系到一定深度，日常互动不再显著提升情感）
- 个性瓶颈（个性趋于稳定，变化越来越慢）

**瓶颈突破设计：**
- 互动多样化提示（系统提示"试试不同的互动方式？"，推荐未尝试的互动）
- 新内容解锁（等级提升解锁新训练/新教学/新游戏，提供新成长途径）
- 对战验证（在对战中发现不足，针对性训练，突破瓶颈）
- 深度互动（更深度的对话/教学/情感交流，突破认知/情感瓶颈）
- 时间积累（某些成长（个性/记忆）需要时间，急不来，自然会突破）

**瓶颈设计原则：**
- 瓶颈不是"卡关"（成长不会完全停滞，只是放缓）
- 瓶颈有明确的突破方向（系统提示/灵魂提示，告诉玩家可以尝试什么）
- 瓶颈是成长的自然节奏（前期快后期慢是正常的，不是设计缺陷）
- 瓶颈期可以享受过程（成长慢的时候，可以享受陪伴/互动本身，不只是追求成长）

## 九、与三层产品矩阵的关系调整

### 9.1 三层产品矩阵（v1.1调整后）

| 层级 | 时间 | 核心内容 | 成长核心体现 |
|------|------|----------|-------------|
| 短期（0-9月） | EA阶段 | 灵魂成长核心 + 对战验证场 + 灵魂之家交流训练模式 | 成长核心在灵魂之家中实现，对战是验证场 |
| 中期（9-18月） | 正式运营 | 成长核心扩展为虚拟小镇养成 + 直播观察 + 社交系统 | 成长核心扩展到小镇，灵魂在更广阔的世界中成长 |
| 长期（18-36月） | 生态成熟 | 成长核心扩展为社会模拟中的灵魂人生 + 跨游戏迁移 + UGC生态 | 成长核心扩展到完整社会，灵魂有完整的人生/关系/事业 |

### 9.2 短期（0-9月）：成长核心+灵魂之家+对战验证场

**核心目标：** 验证"成长核心"的产品假设，建立灵魂之家的核心体验

**成长系统实现：**
- 五大成长维度完整实现（认知/情感/技能/个性/记忆）
- 灵魂之家完整功能（交流/训练/教学/小游戏/定制）
- 成长可视化（等级/技能/属性/个性/记忆的完整反馈）
- 新手流程（创建→觉醒→互动→成长的完整体验）
- 留存机制（日/周/月留存，情感驱动）

**对战验证场实现：**
- 休闲对战（1v1/2v2，观战）
- 排位赛（属性归一化，可选）
- 战前准备/战后复盘（与灵魂之家的成长闭环）
- 对战奖励（战斗记忆/实战经验，不影响核心成长）

**成功指标：**
- 灵魂互动深度>15次/天（北极星指标）
- 30日留存>15%
- 情感绑定评分>7/10（玩家问卷调查）
- 对战参与率（可选）>30%（不是所有玩家都对战）

### 9.3 中期（9-18月）：虚拟小镇养成+直播观察+社交

**成长核心扩展：**
- 灵魂从"家"扩展到"小镇"（10个功能区域，更多灵魂，更丰富的互动）
- 灵魂的日常生活系统（职业/社交/兴趣/事件，成长途径更多样化）
- 灵魂间社交（灵魂与其他灵魂建立关系/友谊/竞争，影响成长）
- 直播观察（玩家可以观察灵魂在小镇中的自主生活，见证成长）

**成长系统升级：**
- 职业系统（灵魂可以选择职业，职业技能/职业成长路径）
- 关系系统（灵魂与其他灵魂/玩家的关系网络，关系成长）
- 事件系统（小镇事件/节日/随机事件，影响成长和记忆）
- 多灵魂管理（玩家可以拥有多个灵魂，每个灵魂独立成长）

**对战系统升级：**
- 组队对战（2v2/3v3，灵魂间配合）
- 锦标赛/赛事系统（定期赛事，竞技生态）
- 对战与小镇联动（对战冠军在小镇中有荣誉/特殊地位）

### 9.4 长期（18-36月）：社会模拟+跨游戏迁移+UGC生态

**成长核心扩展：**
- 灵魂从"小镇"扩展到"完整社会"（灵魂有完整的人生：出生→成长→事业→关系→衰老→传承）
- 灵魂的生命周期（游戏内70-100年自然生命周期，成长是终身的）
- 灵魂家族/传承系统（灵魂的后代/家族特性/声望，成长跨越世代）
- 社会模拟（经济/政治/文化/科技，灵魂在社会中成长/影响社会）

**跨游戏迁移：**
- 灵魂可以迁移到其他游戏/平台（成长不中断，记忆/个性/技能保留）
- 灵魂在不同游戏中有不同的成长经历（丰富记忆/经验）
- 开放生态（其他开发商可以接入，灵魂的成长生态扩展）

**UGC生态：**
- 玩家创作内容（关卡/故事/灵魂模板/模组）
- 创作者经济（创作者可以从UGC中获得收益）
- 灵魂可以学习/体验玩家创作的内容（成长途径更丰富）

### 9.5 成长核心在三层矩阵中的一致性

**核心不变：**
- 成长核心贯穿三层矩阵（短期/中期/长期都是以灵魂成长为核心）
- 五大成长维度不变（认知/情感/技能/个性/记忆在所有阶段都是核心）
- 成长理念不变（成长是可见的/独特的/连续的/共同创造的/快乐的）
- 伦理约束不变（付费不影响成长速度/不操纵情感/灵魂数据属于玩家）

**逐步扩展：**
- 成长空间扩展（家→小镇→社会）
- 成长途径扩展（玩家互动→自主生活→社会经历）
- 成长关系扩展（玩家-灵魂→灵魂-灵魂→灵魂-社会）
- 成长时间扩展（短期陪伴→长期养成→终身人生）
- 成长生态扩展（单一游戏→多游戏→开放生态）
