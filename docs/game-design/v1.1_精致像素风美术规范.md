## 一、美术风格总览

### 1.1 风格定义

**风格名称：** 精致像素风（Refined Pixel Art）

**风格定位：** 在经典像素风基础上提升视觉品质，参考《八方旅人》的HD-2D美学（像素角色+3D光照+粒子特效），但保持纯2D实现降低技术复杂度。灵魂角色是视觉焦点，场景有层次感和氛围感，UI精致但不喧宾夺主。

**风格关键词：** 精致、温暖、有灵魂、有光感、有细节、不简陋

**与普通像素风的区别：**

| 维度 | 普通像素风 | 精致像素风（本规范） |
|------|-----------|---------------------|
| 角色分辨率 | 32×32 / 64×64 | **128×128**（细节更丰富） |
| 色板 | 16-32色 | **64色/角色，128色/场景**（渐变和光影更细腻） |
| 光照 | 无/基础平涂 | **实时光照+阴影投射+法线贴图** |
| 动画 | 4-6帧/动作 | **8帧/行走，6帧/待机+呼吸感** |
| 粒子 | 无/基础 | **丰富粒子系统**（技能/环境/情绪/名场面） |
| 后期 | 无 | **Bloom+色彩分级+轻微景深** |
| 场景层次 | 1-2层 | **5层**（背景/装饰/地面/实体/特效） |
| UI | 基础像素UI | **圆角边框+微动画+精致图标** |

### 1.2 技术实现基础

**引擎：** Godot 4.x 2D渲染管线

**核心技术组件：**

| 技术 | 实现方式 | 用途 |
|------|----------|------|
| 像素完美渲染 | Project Settings→Rendering→2D→Use Pixel Snap，CanvasItem.texture_filter=Nearest | 确保像素不模糊 |
| 实时光照 | Light2D + 法线贴图（normal_map） | 角色/场景的动态光照和阴影 |
| 粒子系统 | GPUParticles2D | 技能/环境/情绪/名场面特效 |
| 后期处理 | CanvasLayer + Shader（全屏后处理） | Bloom/色彩分级/景深/屏幕震动 |
| 视差滚动 | 多个CanvasLayer，不同scroll_scale | 场景背景的层次感 |
| 动画系统 | AnimationPlayer + AnimatedSprite2D | 角色/场景/UI动画 |
| 骨骼动画 | 可选：Cutout动画（Godot Skeleton2D） | 复杂角色动画（M2+） |

**像素完美规则：**
- 所有像素艺术资源使用Nearest过滤（texture_filter=0）
- 相机位置取整（camera.position = floor(camera.position)）
- 游戏内缩放使用整数倍（1x/2x/3x），不使用非整数缩放
- UI使用独立的CanvasLayer，不受游戏缩放影响
- 文字使用像素字体或MSDF字体，确保清晰

### 1.3 色彩系统

**全局色板（128色场景色板）：**

| 色系 | 色值范围 | 用途 |
|------|----------|------|
| 暖色系 | #FFB347 - #FF6B6B | 能量核心/火焰/温暖光照/快乐情绪 |
| 冷色系 | #4ECDC4 - #45B7D1 | 水/冰/冷静情绪/悲伤情绪 |
| 自然系 | #96CEB4 - #88D8B0 | 植物/自然/花园/平静情绪 |
| 暗色系 | #2C3E50 - #34495E | 阴影/夜景/深色背景 |
| 中性色 | #ECF0F1 - #BDC3C7 | 地面/墙壁/中性物体 |
| 金色系 | #F39C12 - #E67E22 | 传说物品/成就/特殊标记 |
| 紫色系 | #9B59B6 - #8E44AD | 神秘/魔法/稀有物品 |
| 红色系 | #E74C3C - #C0392B | 危险/愤怒/受击/重要警告 |

**色彩使用原则：**
- 每个场景有主色调（不超过3个主色），辅助色不超过5个
- 能量核心颜色随情绪变化（快乐=暖黄，悲伤=蓝，愤怒=红，恐惧=紫，平静=绿，兴奋=橙）
- 稀有度颜色：普通=白/灰，稀有=蓝，史诗=紫，传说=金
- UI色彩：主色=暖橙(#FF8C42)，辅助=深灰(#2C3E50)，强调=金(#F39C12)，危险=红(#E74C3C)
- 色盲友好：重要信息不仅用颜色区分，还用形状/图标/文字辅助

## 二、角色设计规范

### 2.1 角色模板（128×128像素）

**画布规格：**

| 参数 | 规格 | 说明 |
|------|------|------|
| 画布大小 | 128×128像素 | 标准角色画布 |
| 角色占比 | 高度96-112像素（75-87%画布） | 角色占据画布大部分空间 |
| 安全区域 | 中心96×96像素 | 关键内容（头部/身体）在安全区域内 |
| 出血区域 | 边缘16像素 | 特效/装饰/动作溢出区域 |
| 锚点 | 画布底部中心（64, 128） | 角色站立点，用于定位 |
| 朝向 | 默认朝右（face_right） | 翻转用于朝左 |

**角色结构分层（从下到上）：**

```
Layer 5: 特效层（光环/粒子/情绪特效）
Layer 4: 装饰层（帽子/围巾/眼镜/饰品/背包）
Layer 3: 形态外壳层（身体/头/四肢/尾巴/翅膀）
Layer 2: 能量核心层（核心光效/核心本体/核心脉动）
Layer 1: 阴影层（地面阴影/身体阴影）
```

**角色比例：**
- 头身比：2.5-3头身（Q版比例，可爱友好）
- 头部：40-48像素高（占角色高度40-45%）
- 身体：32-40像素高（占角色高度35-40%）
- 四肢：16-24像素长（占角色高度20-25%）
- 眼睛：8-12像素大（占头部20-25%，大眼睛更有灵魂感）

### 2.2 能量核心设计

**能量核心是灵魂的视觉焦点，是"灵魂感"的核心载体。**

**核心规格：**

| 参数 | 规格 | 说明 |
|------|------|------|
| 核心大小 | 24-32像素直径 | 占据胸部/腹部中心位置 |
| 核心位置 | 角色中心偏上（胸部位置） | 灵魂的"心脏" |
| 核心形状 | 圆形/心形/星形/菱形/水滴形（5种基础形状） | 可定制，影响外观不影响能力 |
| 核心颜色 | 随情绪变化（6种基础情绪色） | 快乐=暖黄#FFD93D，悲伤=蓝#4ECDC4，愤怒=红#FF6B6B，恐惧=紫#9B59B6，平静=绿#88D8B0，兴奋=橙#FF8C42 |
| 核心脉动 | 1.0-2.0Hz（每秒1-2次） | 类似心跳，频率随情绪变化（兴奋时快，平静时慢） |
| 核心光晕 | 半径32-48像素，透明度30-50% | 柔和的光晕，使用Light2D实现 |
| 核心粒子 | 3-5个环绕粒子，缓慢旋转 | 能量核心的粒子环绕效果 |

**核心动画状态：**

| 状态 | 脉动频率 | 亮度 | 粒子效果 | 说明 |
|------|----------|------|----------|------|
| 平静 | 1.0Hz | 100% | 缓慢环绕 | 基础状态 |
| 快乐 | 1.3Hz | 120% | 加速环绕+小光点 | 开心时更亮更快 |
| 兴奋 | 1.8Hz | 150% | 快速环绕+闪光 | 极度兴奋时光芒强烈 |
| 悲伤 | 0.7Hz | 60% | 缓慢下沉+蓝色粒子 | 悲伤时暗淡缓慢 |
| 愤怒 | 2.0Hz | 180% | 剧烈脉动+火星 | 愤怒时剧烈闪烁 |
| 恐惧 | 1.5Hz | 40% | 颤抖+紫色粒子 | 恐惧时暗淡颤抖 |
| 睡眠 | 0.5Hz | 30% | 几乎静止+Z字 | 睡眠时微弱脉动 |

**核心技术实现：**
- 核心本体：Sprite2D（圆形/心形等形状，带渐变）
- 核心光晕：Light2D（color=核心色，energy=0.5-1.5，range=48-64）
- 核心脉动：AnimationPlayer（缩放1.0→1.1→1.0，循环，频率可调）
- 核心粒子：GPUParticles2D（amount=5，lifetime=2.0，orbit_velocity=10-30）
- 颜色变化：Tween（modulate从旧色过渡到新色，0.5秒）
- 性能：核心光效是主要性能消耗之一，同屏最多6个核心光效

### 2.3 形态外壳设计

**形态外壳是灵魂的外在形态，可定制，不影响能力。**

**基础形态列表（M1实现10种）：**

| 形态 | 特征 | 个性倾向关联 | 解锁方式 |
|------|------|-------------|----------|
| 狐狸 | 尖耳/大尾巴/灵动 | 高好奇/高敏捷 | 默认免费 |
| 猫 | 圆耳/长尾巴/优雅 | 高独立/高内向 | 默认免费 |
| 兔子 | 长耳/短尾/可爱 | 高宜人/高谨慎 | 默认免费 |
| 龙 | 角/翅膀/鳞片/威严 | 高勇敢/高外向 | 默认免费 |
| 史莱姆 | 圆滚滚/无定形/软萌 | 高宜人/高开放 | 默认免费 |
| 幽灵 | 半透明/漂浮/神秘 | 高内向/高好奇 | 默认免费 |
| 机器人 | 金属/天线/机械感 | 高尽责/高逻辑 | 默认免费 |
| 鸟 | 翅膀/喙/轻盈 | 高外向/高自由 | 默认免费 |
| 熊 | 壮硕/憨厚/温暖 | 高宜人/高勇敢 | 默认免费 |
| 蝴蝶 | 翅膀/触角/优雅 | 高开放/高情感 | 默认免费 |

**形态外壳分层：**
- 基础层：身体/头/四肢（必须有）
- 特征层：物种特征（耳朵/尾巴/翅膀/角/鳞片等）
- 细节层：纹理/花纹/标记（可选，增加细节）
- 表情层：眼睛/嘴巴/眉毛（独立动画，见2.4表情系统）

**形态外壳配色：**
- 主色：1种（身体主色，64色板中选择）
- 副色：1种（腹部/内侧/细节色，与主色协调）
- 渐变：主色到副色的垂直渐变（上深下浅或上浅下深，增加立体感）
- 高光：1-2个高光点（白色/浅色，增加质感）
- 阴影：1-2个阴影区域（深色，增加立体感）

**形态外壳动画要求：**
- 所有形态使用统一的动画骨架（见第三章动画规格）
- 物种特征（尾巴/翅膀/耳朵）有独立动画（跟随/摆动/扇动）
- 形态切换时播放"变形动画"（2秒，旧形态消散→新形态凝聚）
- 所有形态保持相同的锚点和碰撞体（不影响游戏逻辑）

### 2.4 表情系统（8+基础情绪）

**表情是灵魂情感的核心可视化渠道。**

**基础表情（8种，M1必须实现）：**

| 表情 | 眼睛 | 嘴巴 | 眉毛 | 附加效果 |
|------|------|------|------|----------|
| 开心 | ^_^ 或 弯月眼 | 微笑/张嘴笑 | 放松/上扬 | 核心暖黄+金色粒子 |
| 悲伤 | 下垂眼/泪眼 | 倒八字/撇嘴 | 下垂 | 核心蓝+蓝色雨滴粒子 |
| 愤怒 | 瞪眼/怒目 | 张嘴/咬牙 | 倒八字/紧皱 | 核心红+火星粒子 |
| 恐惧 | 睁大眼/瞳孔缩小 | 张嘴/颤抖 | 高抬/紧皱 | 核心紫+颤抖效果 |
| 惊讶 | 圆睁眼/瞳孔放大 | O型嘴 | 高抬 | 核心橙+闪光 |
| 平静 | 普通眼/半闭眼 | 平嘴/微笑 | 平/放松 | 核心绿+缓慢脉动 |
| 害羞 | 半闭眼/斜视 | 小嘴/抿嘴 | 微垂 | 核心粉+脸红+粉色粒子 |
| 无聊 | 半闭眼/无神 | 平嘴/打哈欠 | 平/微垂 | 核心灰+Z字/气泡 |

**复合表情（M2实现，8种基础的组合）：**
- 兴奋（开心+惊讶）：眼睛闪亮+张嘴+核心橙+闪光
- 焦虑（恐惧+悲伤）：眉头紧皱+咬唇+核心紫蓝+颤抖
- 傲娇（害羞+愤怒）：侧脸+撅嘴+脸红+核心粉橙
- 满足（开心+平静）：闭眼微笑+核心暖黄+柔和光晕
- 困惑（惊讶+平静）：歪头+问号+核心浅黄+问号粒子
- 得意（开心+骄傲）：眯眼+咧嘴+核心金+金色光环
- 心疼（悲伤+关心）：下垂眼+皱眉+核心蓝+安慰光环
- 期待（开心+好奇）：闪亮眼+微笑+核心橙黄+星星粒子

**表情动画规格：**
- 表情切换：0.2-0.3秒过渡（不是瞬间切换，有中间帧）
- 表情保持：情绪持续时表情保持，有微小变化（眨眼/呼吸）
- 眨眼：每3-5秒一次，0.1秒（眼睛从睁开→闭合→睁开）
- 表情强度：情绪强度0-100，表情夸张程度随强度变化（强度<30时表情微妙，>70时表情夸张）
- 说话动画：说话时嘴巴同步开合（基于语音/文字长度，3-5帧循环）

**表情技术实现：**
- 眼睛/嘴巴/眉毛：独立的Sprite2D或AnimatedSprite2D（可独立动画）
- 表情切换：AnimationPlayer（每个表情一个动画，含眼睛/嘴巴/眉毛的关键帧）
- 表情过渡：Tween（modulate/position的平滑过渡，0.2秒）
- 眨眼：Timer（3-5秒随机）+ AnimationPlayer（眨眼动画）
- 性能：表情动画是CPU轻量级，不影响性能

### 2.5 个性与外观关联

**灵魂的个性会微妙地影响外观表现，增强"每个灵魂都是独特的"的感觉。**

| 个性维度 | 高倾向外观表现 | 低倾向外观表现 |
|----------|---------------|---------------|
| 外向性 | 颜色更鲜艳/动作幅度大/表情丰富/粒子效果多 | 颜色更柔和/动作幅度小/表情含蓄/粒子效果少 |
| 神经质 | 核心脉动不稳定/偶尔颤抖/表情变化快 | 核心脉动稳定/动作平稳/表情变化慢 |
| 开放性 | 装饰更奇特/喜欢尝试新外观/颜色更大胆 | 装饰更传统/喜欢经典外观/颜色更保守 |
| 尽责性 | 外观整洁/装饰对称/动作规范 | 外观随意/装饰不对称/动作随性 |
| 宜人性 | 颜色更温暖/表情更友善/装饰更柔和 | 颜色更冷/表情更冷淡/装饰更锐利 |
| 勇敢度 | 姿态挺拔/眼神坚定/颜色更暖 | 姿态微缩/眼神躲闪/颜色更冷 |
| 好奇心 | 眼睛更大/经常四处看/装饰更有趣 | 眼睛正常/专注前方/装饰更简洁 |
| 占有欲 | 装饰更华丽/有"守护"姿态/颜色更深 | 装饰更朴素/姿态放松/颜色更浅 |

**个性外观实现方式：**
- 颜色微调：基于个性值对主色进行HSL偏移（外向+饱和度，神经质+色相抖动）
- 动作幅度：动画播放速度/缩放基于个性值（外向×1.2，内向×0.8）
- 粒子数量：粒子数量基于个性值（外向+50%，内向-30%）
- 这些是微妙的调整（不超过±20%），不是明显的差异，玩家会感觉到"这个灵魂和那个不一样"但不会立刻说出原因

## 三、动画详细规格

### 3.1 动画骨架统一标准

**所有形态外壳使用统一的动画骨架，确保动画资源可复用。**

**骨骼结构（Cutout动画，Godot Skeleton2D）：**

```
Root (锚点，底部中心)
├── Body (身体，旋转+缩放)
│   ├── Head (头部，旋转+位移)
│   │   ├── Eye_L (左眼，缩放+位移)
│   │   ├── Eye_R (右眼，缩放+位移)
│   │   ├── Mouth (嘴巴，缩放+位移)
│   │   └── Brow_L/R (眉毛，旋转+位移)
│   ├── Arm_L (左臂，旋转)
│   │   └── Hand_L (左手，旋转)
│   ├── Arm_R (右臂，旋转)
│   │   └── Hand_R (右手，旋转)
│   ├── Tail (尾巴，旋转+弯曲，多段骨骼)
│   └── Wing_L/R (翅膀，旋转+缩放，可选)
├── Leg_L (左腿，旋转+位移)
│   └── Foot_L (左脚，旋转)
└── Leg_R (右腿，旋转+位移)
    └── Foot_R (右脚，旋转)
```

**骨骼动画规范：**
- 所有骨骼使用2D旋转（rotation），不使用3D
- 关键帧插值：线性（像素动画不使用贝塞尔曲线插值，保持像素感）
- 动画帧率：12fps（每个关键帧间隔1/12秒≈0.083秒）
- 动画根节点：位移只在Root骨骼，其他骨骼只旋转
- 碰撞体：跟随Root骨骼位移，不随身体旋转

### 3.2 基础动作动画规格

**行走动画（8帧/8方向）：**

| 参数 | 规格 | 说明 |
|------|------|------|
| 帧数 | 8帧/方向 | 比普通像素风多2帧，更流畅 |
| 方向 | 8方向（上/下/左/右/左上/右上/左下/右下） | 斜方向可通过水平翻转+垂直翻转减少工作量 |
| 帧率 | 12fps | 8帧循环=0.67秒/步 |
| 位移幅度 | 每循环前进48像素（1格） | 与移动速度匹配 |
| 身体起伏 | ±4像素 | 行走时的上下起伏 |
| 手臂摆动 | ±15度 | 前后摆动 |
| 腿部动作 | 抬起12像素+落地 | 交替迈步 |
| 尾巴/翅膀 | 跟随摆动（±10度） | 物种特征动画 |
| 核心脉动 | 保持基础脉动 | 不受行走影响 |

**待机动画（6帧+呼吸感）：**

| 参数 | 规格 | 说明 |
|------|------|------|
| 帧数 | 6帧循环 | 比普通像素风多2帧 |
| 帧率 | 8fps（慢速） | 6帧循环=0.75秒 |
| 呼吸感 | 身体缩放±2%（吸气放大→呼气缩小） | 模拟呼吸，增加生命感 |
| 身体起伏 | ±2像素 | 轻微的上下浮动 |
| 头部微动 | ±2像素/±3度 | 偶尔的头部调整（不是每帧都动） |
| 眨眼 | 每3-5秒插入眨眼帧 | 独立于待机循环 |
| 尾巴/翅膀 | 缓慢摆动（±5度） | 放松状态的轻微动作 |
| 核心脉动 | 基础脉动1.0Hz | 平静状态的心跳 |

**待机变体（基于个性/情绪，M2实现）：**
- 活泼待机：身体晃动幅度大/偶尔跳一下/尾巴快速摆动（高外向）
- 安静待机：几乎不动/只有呼吸和眨眼/尾巴缓慢摆动（高内向）
- 好奇待机：头四处看/耳朵转动/偶尔向前探（高好奇）
- 谨慎待机：身体微缩/眼神警惕/尾巴夹起（高谨慎/高恐惧）
- 开心待机：偶尔蹦一下/尾巴快速摆动/核心更亮（快乐情绪）
- 悲伤待机：低头/肩膀下垂/尾巴下垂/核心暗淡（悲伤情绪）

### 3.4 动画性能优化

**动画性能规则：**
- 同屏最多6个角色同时播放完整动画（超过6个时，远处角色降低动画帧率）
- 远处角色（距离相机>500像素）使用简化动画（4帧循环，不播放表情动画）
- 不可见角色（屏幕外）暂停动画（AnimationPlayer.active=false）
- 动画资源复用：所有形态共享同一套动画骨架，只替换精灵
- 动画预处理：动画关键帧在加载时预处理，运行时不做计算
- 表情动画与身体动画分离：表情动画独立播放，不影响身体动画性能

**动画LOD（Level of Detail）：**

| 距离 | 动画帧率 | 表情 | 粒子 | 说明 |
|------|----------|------|------|------|
| <300像素 | 12fps | 完整8表情 | 完整 | 近距离，全质量 |
| 300-600像素 | 8fps | 4基础表情 | 简化 | 中距离，中等质量 |
| >600像素 | 4fps | 无（只有身体） | 无 | 远距离，低质量 |
| 屏幕外 | 暂停 | 无 | 无 | 不可见，暂停 |

## 四、场景美术规范

### 4.1 场景基础规格

| 参数 | 规格 | 说明 |
|------|------|------|
| 格子大小 | 48×48像素 | 比普通像素风大，细节更丰富 |
| 场景分辨率 | 1920×1080（基础） | 16:9标准分辨率 |
| 场景大小 | 最小20×15格（960×720像素），最大100×100格 | 灵魂之家房间20×15格，对战地图40×30格 |
| 瓦片大小 | 48×48像素 | 与格子一致 |
| 瓦片集 | 每个场景独立瓦片集，最多256个瓦片 | 包含地面/墙壁/装饰/交互物体 |
| 场景层次 | 5层（背景/装饰/地面/实体/特效） | 见4.2 |

### 4.2 场景层次（5层）

```
Layer 5: 特效层（粒子/光照/后期效果，最上层）
Layer 4: 实体层（角色/可交互物体/移动平台，碰撞层）
Layer 3: 地面层（地板/道路/草地/水面，角色行走层）
Layer 2: 装饰层（植物/家具/墙壁装饰/背景物体，在角色后面）
Layer 1: 背景层（天空/远景/山脉/建筑轮廓，最远层）
```

**各层详细规格：**

| 层次 | 内容 | 滚动速度 | 光照 | 说明 |
|------|------|----------|------|------|
| 背景层 | 天空/云/远山/远景建筑 | 0.2x（视差最慢） | 环境光 | 纯装饰，无碰撞，营造氛围 |
| 装饰层 | 墙壁/窗户/挂画/植物/家具 | 0.5x | 接收光照+投射阴影 | 在角色后面，部分可交互 |
| 地面层 | 地板/草地/道路/水面/地毯 | 1.0x（与角色同步） | 接收光照 | 角色行走层，有碰撞 |
| 实体层 | 角色/可交互物体/门/箱子/移动平台 | 1.0x | 接收光照+投射阴影 | 碰撞层，可交互 |
| 特效层 | 粒子/光照/魔法效果/屏幕特效 | 1.0x | 发光（不接收光照） | 最上层，无碰撞 |

### 4.3 视差滚动背景

**背景层结构（3层视差）：**

```
远景层（0.1x速度）：天空/云/太阳/月亮/星星
中景层（0.3x速度）：远山/建筑轮廓/大树
近景层（0.5x速度）：近树/栅栏/路灯/装饰
```

**视差滚动实现：**
- 使用Godot的ParallaxBackground + ParallaxLayer
- 每个ParallaxLayer设置motion_scale（0.1/0.3/0.5）
- 背景层使用repeat（mirror_repeat=true），确保无限滚动
- 移动设备上视差效果减弱（减少层级，提高性能）

**灵魂之家背景（室内）：**
- 远景层：墙壁纹理/窗户（窗外风景）
- 中景层：墙壁装饰（挂画/架子/灯具）
- 近景层：前景装饰（门框/窗帘/植物）

**对战竞技场背景（室外/半室外）：**
- 远景层：天空/云/远处建筑轮廓
- 中景层：竞技场围墙/观众席/旗帜
- 近景层：竞技场边缘装饰/火把/柱子

### 4.4 动态光照参数

**光照系统规格：**

| 参数 | 规格 | 说明 |
|------|------|------|
| 环境光 | Color(0.3, 0.3, 0.35)，能量0.5 | 基础环境光，偏冷色 |
| 主光源 | DirectionalLight2D或大型Light2D，暖色#FFE4B5，能量1.0 | 模拟阳光/主灯光 |
| 点光源 | Light2D，范围128-256像素，能量0.5-1.0 | 灯具/火把/窗户光 |
| 角色核心光 | Light2D，范围48-64像素，能量0.5-1.5，颜色随情绪 | 每个灵魂的能量核心发光 |
| 阴影 | 启用shadow，shadow_blur=2，shadow_color=Color(0,0,0,0.5) | 柔和阴影 |
| 法线贴图 | 角色/场景物体使用normal_map | 增强光照立体感 |

**光照层级：**
- 环境光：照亮所有层，无阴影
- 主光源：照亮地面/装饰/实体层，投射阴影
- 点光源：局部照亮，投射阴影
- 角色核心光：只照亮角色周围，不投射阴影（性能优化）
- 特效光：只照亮特效层，不影响其他层

**光照性能规则：**
- 同屏最多4个投射阴影的光源（主光源+3个点光源）
- 角色核心光不投射阴影（只发光，性能消耗低）
- 远处光源（距离相机>500像素）关闭阴影投射
- 法线贴图只用于近距离物体（角色/前景装饰），远景不使用法线贴图
- 光照是主要性能消耗之一，需要严格控制数量

**昼夜光照变化（M2，养成系统）：**

| 时间 | 环境光 | 主光源 | 氛围 |
|------|--------|--------|------|
| 清晨(6-8) | 暗蓝(0.2,0.25,0.35) | 橙红(0.8,0.5,0.3)，低 | 清冷温暖交替 |
| 上午(8-12) | 正常(0.3,0.3,0.35) | 暖白(1.0,0.95,0.85)，高 | 明亮温暖 |
| 下午(12-17) | 正常(0.3,0.3,0.35) | 暖白(1.0,0.95,0.85)，高 | 明亮温暖 |
| 黄昏(17-19) | 橙红(0.35,0.25,0.2) | 橙红(0.9,0.5,0.2)，中 | 温暖浪漫 |
| 夜晚(19-6) | 深蓝(0.1,0.1,0.2) | 冷蓝(0.3,0.4,0.6)，低 | 安静神秘 |

### 4.5 瓦片集与场景物体规范

**瓦片集规格：**
- 瓦片大小：48×48像素
- 瓦片集格式：Godot TileSet（.tres），包含atlas纹理+碰撞+导航
- 每个瓦片集最多256个瓦片（16×16网格）
- 瓦片分类：地面（32种）/墙壁（32种）/装饰（64种）/交互物体（64种）/特殊（64种）
- 瓦片碰撞：自动碰撞（基于alpha通道）或手动定义碰撞多边形
- 瓦片导航：定义可行走区域（用于A*寻路）

**交互物体规格：**
- 大小：1-4格（48×48到192×192像素）
- 状态：正常/悬停/激活/禁用（4种状态，每种有独立视觉）
- 动画：可交互物体有idle动画（2-4帧循环）
- 提示：玩家靠近时显示交互提示（图标+文字，如"按E互动"）
- 反馈：交互时有视觉反馈（发光/震动/粒子/音效）
- 碰撞：实体碰撞（角色不能穿过），交互区域比碰撞体大（方便交互）

**场景装饰物体规格：**
- 纯装饰物体无碰撞，无交互
- 有动画的装饰物体（水流/火焰/树叶/旗帜）有2-4帧循环动画
- 装饰物体接收光照和阴影（增加立体感）
- 装饰物体不影响性能（大量装饰时使用批量渲染）

## 六、粒子特效规范

### 6.1 粒子系统总览

**粒子技术：** Godot GPUParticles2D（GPU加速粒子，性能好）

**粒子使用原则：**
- 粒子是"调味"不是"主菜"——增强视觉效果，不喧宾夺主
- 同屏粒子总数不超过500个（性能限制）
- 每个粒子效果有明确的用途（情绪/技能/环境/名场面）
- 粒子效果有生命周期（发射→存续→消散，不无限持续）
- 远处粒子效果降低质量或关闭（LOD）

## 七、后期处理规范

### 7.1 后期处理总览

**后期处理技术：** Godot CanvasLayer + Shader（全屏后处理Shader）

**后期处理原则：**
- 后期处理是"锦上添花"，不改变游戏核心视觉
- 所有后期效果可以单独开关（性能/偏好选项）
- 后期效果强度可调（0-100%）
- 低端设备默认关闭大部分后期效果

### 7.2 Bloom（辉光）

**Bloom效果：** 明亮区域（能量核心/技能特效/光源）向外发光，增加梦幻感和光感。

| 参数 | 规格 | 说明 |
|------|------|------|
| 阈值 | 0.8（亮度>0.8的像素产生辉光） | 只有足够亮的区域才发光 |
| 强度 | 0.3-0.5 | 辉光强度，0.3柔和，0.5明显 |
| 半径 | 8-16像素 | 辉光扩散半径 |
| 迭代次数 | 4次（高斯模糊迭代） | 模糊质量 |
| 色调 | 保持原色（不改变颜色） | 辉光颜色与源颜色一致 |
| 性能消耗 | 中（需要额外的渲染pass） | 中端设备可开启 |

**Bloom使用场景：**
- 灵魂能量核心（核心是主要的发光源）
- 技能特效（火系/雷系/终极技能）
- 场景光源（火把/窗户光/魔法光源）
- UI高亮（重要按钮/通知/成就解锁）
- 名场面（重要时刻增强Bloom强度）

### 7.3 色彩分级（Color Grading）

**色彩分级：** 调整画面整体色调，增强氛围和情感表达。

| 参数 | 规格 | 说明 |

| 对比度 | 1.0-1.2 | 对比度增强，增加层次感 |
| 饱和度 | 1.0-1.1 | 饱和度微调，颜色更鲜艳 |
| 色调 | 场景相关 | 不同场景有不同色调（温暖/清冷/神秘） |
| 阴影色 | 偏蓝(#2C3E50) | 阴影区域偏冷色 |
| 高光色 | 偏暖(#FDEBD0) | 高光区域偏暖色 |

**场景色调预设：**

|------|------|--------|--------|------|

### 7.4 景深（Depth of Field）

**景深效果：** 前景/背景模糊，焦点区域清晰，增加画面层次感和电影感。

| 参数 | 规格 | 说明 |
|------|------|------|
| 焦点距离 | 角色位置（动态跟随） | 焦点跟随主要角色 |
| 焦点范围 | ±100像素 | 焦点范围内清晰 |
| 前景模糊 | 轻度（半径4像素） | 前景物体轻微模糊 |
| 背景模糊 | 中度（半径8像素） | 背景物体明显模糊 |
| 过渡范围 | 50像素 | 清晰到模糊的过渡区域 |
| 性能消耗 | 高（需要深度缓冲+模糊pass） | 中高端设备可开启 |

**景深使用场景：**
- 灵魂之家（角色是焦点，背景装饰模糊，增加温馨感）
- 名场面回放（电影化效果）
- 对话场景（说话角色是焦点，其他模糊）
- 对战中默认关闭（需要清晰看到整个战场）

**景深性能规则：**
- 景深是性能消耗最高的后期效果，低端设备默认关闭
- 对战中强制关闭（影响游戏性）
- 可以在设置中开关，默认关闭（性能优先）
- 开启景深时自动降低其他后期效果强度

### 7.5 屏幕震动（Screen Shake）

**屏幕震动：** 重要事件时屏幕震动，增强打击感和冲击力。

| 震动等级 | 幅度 | 持续 | 频率 | 触发场景 |
|----------|------|------|------|----------|
| 轻微 | 2像素 | 0.1秒 | 20Hz | 轻受击/UI点击 |
| 中等 | 4像素 | 0.2秒 | 15Hz | 重受击/技能命中 |
| 强烈 | 8像素 | 0.3秒 | 10Hz | 暴击/大技能爆炸 |
| 剧烈 | 12像素 | 0.5秒 | 8Hz | 名场面/建筑倒塌/终极技能 |

**屏幕震动实现：**
- 使用Camera2D的offset（随机偏移，模拟震动）
- 震动衰减（幅度随时间线性衰减，不是突然停止）
- 震动方向（受击方向的反向，增强方向感）
- 震动可以叠加（多个震动同时发生时幅度相加，但有上限）
- 玩家可以在设置中关闭屏幕震动（无障碍选项）

### 7.6 慢放特效（Slow Motion）

**慢放效果：** 重要时刻时间变慢，增强戏剧感和操作感。

| 场景 | 慢放速度 | 持续 | 说明 |
|------|----------|------|------|
| 暴击 | 0.3x | 0.5秒 | 暴击瞬间慢放，增强打击感 |
| 对战逆转 | 0.2x | 1.0秒 | 劣势逆转的关键时刻 |
| 终极技能 | 0.1x | 1.5秒 | 终极技能释放的戏剧化效果 |
| 名场面 | 0.3x | 2.0秒 | 名场面自动回放 |
| 灵魂觉醒 | 0.2x | 2.0秒 | 创建灵魂时的觉醒仪式 |
| 等级提升 | 0.5x | 1.0秒 | 等级提升的庆祝时刻 |

**慢放实现：**
- 使用Engine.time_scale（全局时间缩放）
- 慢放时UI不受影响（UI使用独立的process_mode）
- 慢放有缓入缓出（不是突然变慢/恢复，有0.1秒过渡）
- 慢放可以被玩家跳过（按任意键跳过慢放，性能/体验选项）
- 慢放与Bloom/色彩分级配合（慢放时增强后期效果）

### 7.7 后期处理性能预算

| 后期效果 | 性能消耗 | 默认状态 | 低端设备 |
|----------|----------|----------|----------|
| Bloom | 中 | 开启 | 关闭 |
| 色彩分级 | 低 | 开启 | 开启（低质量） |
| 景深 | 高 | 关闭 | 关闭 |
| 屏幕震动 | 极低 | 开启 | 开启 |
| 慢放 | 低（只在特定时刻） | 开启 | 开启 |
| 暗角（Vignette） | 低 | 开启（轻度） | 关闭 |
| 噪点（Grain） | 低 | 关闭 | 关闭 |

**性能规则：**
- 同时开启的后期效果不超过3个（高消耗效果不超过1个）
- 开启景深时自动关闭Bloom（性能优先）
- 对战中只保留Bloom+色彩分级+屏幕震动（关闭景深/暗角）
- 名场面时可以临时增加后期效果（结束后恢复）
- 玩家可以在设置中自定义每个后期效果的开关和强度

## 十、美术资源生产管线

### 10.1 资源分类与优先级

| 资源类型 | 优先级 | 数量（M1） | 生产方式 | 预算占比 |
|----------|--------|-----------|----------|----------|
| 灵魂角色（形态+表情+动画） | P0 | 10种形态×8表情 | AI辅助+外包精修 | 40% |
| 灵魂之家场景（4房间） | P0 | 4场景×瓦片集 | AI辅助+外包 | 20% |
| 对战竞技场场景 | P0 | 1基础+3主题 | AI辅助+外包 | 10% |
| UI（图标+面板+字体） | P0 | 1套完整UI | 外包+采购 | 10% |
| 粒子特效 | P1 | 情绪10+技能20+环境10 | AI辅助+自制 | 5% |
| 音效/音乐 | P1 | BGM5+音效50 | 采购+AI辅助 | 5% |
| 宣传素材（截图/视频/封面） | P2 | 1套 | 自制+外包 | 5% |

### 10.2 AI辅助生成流程

**AI辅助生成工具：**
- 像素艺术生成：使用AI像素艺术生成工具（如Pixel Art AI/Stable Diffusion+像素化后处理）
- 概念设计：AI生成概念图/风格参考，用于指导外包
- 动画辅助：AI辅助生成关键帧/动画参考
- 音效生成：AI生成音效/音乐草稿

**AI辅助生成流程：**
1. **需求定义**：明确资源需求（类型/风格/规格/数量）
2. **Prompt设计**：设计详细的AI生成Prompt（包含风格/颜色/构图/细节描述）
3. **批量生成**：使用AI批量生成候选资源（每个需求生成5-10个候选）
4. **筛选**：从候选中筛选出符合要求的（风格/质量/规格）
5. **精修**：对外包/内部美术进行精修（修正AI生成的缺陷/统一风格/调整细节）
6. **导入**：导入Godot引擎，设置碰撞/动画/材质
7. **验证**：在游戏中验证资源效果（视觉/性能/一致性）

**AI辅助生成的优势：**
- 快速产出概念和候选（缩短生产周期）
- 降低成本（AI生成成本低，精修成本低于从零制作）
- 风格探索（AI可以快速尝试多种风格，找到最佳方向）
- 批量生产（大量重复性资源可以AI批量生成）

**AI辅助生成的限制：**
- 质量不稳定（需要人工筛选和精修）
- 风格一致性差（AI生成的资源风格可能不统一，需要统一处理）
- 复杂动画困难（AI生成动画质量有限，关键动画需要人工制作）
- 版权风险（AI生成资源的版权需要确认，关键资源建议原创）

### 10.3 外包生产流程

**外包类型：**
- 角色美术外包：灵魂角色设计/动画（核心资源，需要高质量）
- 场景美术外包：场景瓦片集/背景/装饰（量大，适合外包）
- UI美术外包：图标/面板/字体（需要统一风格）
- 特效外包：粒子特效/后期Shader（技术美术）

**外包流程：**
1. **需求文档**：编写详细的美术需求文档（参考本文档的规范）
2. **风格参考**：提供AI生成的概念图/参考图，明确风格方向
3. **试稿**：外包先做1-2个试稿，确认风格和质量
4. **批量生产**：试稿通过后批量生产
5. **审核反馈**：每批资源审核，提供反馈修改
6. **最终交付**：最终资源交付（源文件+导出文件）
7. **导入验证**：导入引擎验证效果

**外包质量标准：**
- 符合本文档的所有规格（分辨率/色板/动画帧数/场景层次）
- 风格统一（所有资源风格一致，色彩协调）
- 源文件交付（PSD/AI/Aseprite源文件，方便后续修改）
- 命名规范（统一的文件命名规则）
- 性能达标（资源大小/绘制调用在性能预算内）

### 10.4 资源采购

**采购类型：**
- 像素字体：采购商用像素字体（中文+英文）
- UI素材包：采购像素风UI素材包（作为基础，再定制）
- 音效/音乐：采购商用音效/音乐素材包
- 粒子特效包：采购Godot粒子特效包（作为基础，再定制）

**采购原则：**
- 优先采购可商用授权（CC0/MIT/商用许可）
- 采购后需要定制修改（统一风格，不直接使用）
- 关键资源（灵魂角色/核心场景）原创，不采购
- 采购资源记录来源和授权（避免版权风险）

## 十一、性能目标与优化

### 11.1 性能目标

| 指标 | 目标 | 测试环境 | 说明 |
|------|------|----------|------|
| 帧率 | >60fps | 中端PC（Intel i5+GTX 1060+8GB RAM） | 6灵魂同屏+特效时 |
| 帧率 | >30fps | 低端PC（Intel i3+核显+4GB RAM） | 2灵魂同屏+基础特效 |
| 帧率 | >60fps | 高端PC（Intel i7+RTX 3060+16GB RAM） | 全特效+10灵魂同屏 |
| 加载时间 | <3秒 | 中端PC，SSD | 场景切换/房间切换 |
| 加载时间 | <5秒 | 中端PC，HDD | 场景切换/房间切换 |
| 内存占用 | <1GB | 中端PC | 游戏运行时内存 |
| GPU显存 | <1GB | 中端PC | 显存占用 |
| 绘制调用 | <200 | 中端PC | 同屏绘制调用数 |
| 输入延迟 | <50ms | 中端PC | 从输入到画面响应 |

### 11.2 性能预算分配

| 系统 | CPU预算 | GPU预算 | 说明 |
|------|---------|---------|------|
| 角色动画 | 15% | 10% | 6个角色的动画更新 |
| AI推理 | 30% | — | SoulArena认知推理（主要CPU消耗） |
| 物理/碰撞 | 10% | — | Seed物理模拟 |
| 粒子系统 | 5% | 20% | 500个粒子的更新和渲染 |
| 光照/阴影 | 5% | 15% | 4个光源的阴影计算 |
| 后期处理 | — | 15% | Bloom/色彩分级等 |
| UI渲染 | 5% | 5% | UI绘制 |
| 场景渲染 | 10% | 15% | 瓦片/背景/装饰渲染 |
| 其他 | 5% | 5% | 网络/音频/输入等 |
| **总计** | **100%** | **100%** | |

### 11.3 性能优化措施

**CPU优化：**
- AI推理批处理（多个灵魂的推理合并为一批，提高效率）
- 远处角色降低AI更新频率（距离>500像素，AI更新频率减半）
- 动画LOD（远处角色降低动画帧率）
- 对象池（频繁创建/销毁的对象使用对象池，如粒子/投射物）
- 空间分区（使用Grid/Quadtree进行碰撞检测/可见性剔除）
- 多线程（AI推理/物理计算放在独立线程，不阻塞主线程）

**GPU优化：**
- 批量渲染（相同材质的物体合并绘制，减少draw call）
- 纹理图集（角色/场景/UI使用纹理图集，减少纹理切换）
- 可见性剔除（屏幕外物体不渲染，使用Godot的VisibilityNotifier）
- LOD（远处物体使用低分辨率模型/纹理）
- 粒子限制（严格控制粒子数量，使用GPUParticles2D）
- 光照限制（同屏最多4个投射阴影的光源）
- 后期处理限制（同时开启的后期效果不超过3个）

**内存优化：**
- 纹理压缩（使用ETC2/ASTC压缩纹理，减少显存占用）
- 资源按需加载（场景资源在进入时加载，离开时卸载）
- 动画数据压缩（动画关键帧压缩，减少内存）
- 音频流式播放（长音频流式播放，不全部加载到内存）
- 资源复用（相同资源复用，不重复加载）

**加载优化：**
- 异步加载（资源加载在后台线程，不阻塞主线程）
- 预加载（预加载下一个场景的资源，减少切换时间）
- 加载画面（加载时显示加载画面+进度条+小提示）
- 分块加载（大场景分块加载，先加载可见区域）
- 资源压缩（资源文件压缩，减少磁盘读取时间）

### 11.4 性能设置选项

| 设置项 | 低 | 中 | 高 | 说明 |
|--------|-----|-----|-----|------|
| 分辨率 | 1280×720 | 1920×1080 | 2560×1440 | 游戏渲染分辨率 |
| 粒子数量 | 200 | 500 | 1000 | 同屏粒子总数 |
| 光照质量 | 2光源无阴影 | 4光源软阴影 | 6光源硬阴影 | 光源数量和阴影质量 |
| 后期处理 | 关闭 | Bloom+色彩分级 | 全部开启 | 后期效果开关 |
| 景深 | 关闭 | 关闭 | 开启 | 景深效果 |
| 动画帧率 | 8fps | 12fps | 12fps | 角色动画帧率 |
| 纹理质量 | 低（50%） | 中（100%） | 高（200%） | 纹理分辨率 |
| 垂直同步 | 关闭 | 开启 | 开启 | VSync |
| 帧率限制 | 30fps | 60fps | 144fps | 最大帧率 |

**自动检测：**
- 首次启动时自动检测硬件性能，推荐合适的画质设置
- 运行时动态调整（如果帧率持续低于目标，自动降低画质）
- 玩家可以手动覆盖自动设置
