## 二、逐名详解

### 2.1 灵魂引擎：凌觉

**读音：** líng jué（阳平+阳平，响亮上扬）

**寓意：**
- "觉"=觉知、觉醒、觉悟、觉察
- 是认知/意识的核心隐喻——灵魂的本质是"觉"，能感知、能思考、能觉醒
- "凌觉"=飞越之魂的觉知，灵魂在觉知中成长

**为什么适合灵魂引擎：**
1. **深度足够**："觉"是东方哲学中认知/意识的最高范畴（如"觉悟""觉醒""本觉"），比"知""思""慧"更有深度
2. **温暖光明**："觉"有"天亮""明白"之意，如"觉后知天明"，无任何负面联想，与"渊"的黑暗深渊完全相反
3. **认知隐喻精准**：灵魂引擎的核心是认知子系统（102个），"觉"字直接对应感知-认知-动作循环中的"认知"环节
4. **成长隐喻**："觉"有过程感——从不觉到觉，从小觉到大觉，正好对应灵魂的成长曲线
5. **音韵好听**：líng jué，两个阳平声，响亮上扬，朗朗上口

**视觉联想：**
- 意识的曙光、觉醒的光芒
- 灵魂从混沌中觉醒，光芒照亮内心
- Logo可做："凌"字的笔画中升起一轮朝阳，"觉"字的"见"部化为眼睛形状
- 色调：暖金色+晨曦橙，光明温暖

**出处参考：**
- 《说文解字》："觉，悟也"
- 陶渊明《归去来兮辞》："觉今是而昨非"
- 佛家"本觉""始觉"——众生本有觉知，通过修行显现

---

### 2.2 世界引擎：萌衍

**读音：** méng yǎn（阳平+上声，有起伏，顺口）

**寓意：**
- "萌"=种子发芽、萌发、萌生——种子→生长的起点
- "衍"=繁衍、衍生、衍化、衍变——生长→万千世界的过程
- "萌衍"=种子萌发后繁衍衍生出万千世界

**为什么适合世界引擎：**
1. **核心意象精准**："萌"直接对应种子（Seed），"衍"直接对应万千世界，种子→生长→万千世界的逻辑链完整
2. **组合自然**：萌而后衍，是自然的生长过程，不像"种界"那样生硬拼接
3. **音韵顺口**：méng yǎn，阳平+上声，有起伏，不拗口
4. **无负面联想**："萌"有生机、可爱之意，"衍"有繁衍、丰富之意，都是正面
5. **生态感强**："萌衍"自带生态系统的感觉——一颗种子萌发，繁衍出整个生态世界，正好对应世界引擎的生态生成能力

**视觉联想：**
- 种子在土壤中发芽，根系蔓延，枝叶生长，最终形成万千世界
- Logo可做：一颗种子剖面中长出繁茂的世界树，根系化为"衍"的笔画
- 色调：生命翠绿+嫩芽黄绿，生机盎然

**出处参考：**
- 《礼记·月令》："天地和同，草木萌动"
- 《易·系辞》："生生之谓易"——衍生不息
- "繁衍""衍生"——常用词，无生僻感

### 2.3 游戏应用：凌栖弈录

**读音：** líng qī yì lù（阳平+阴平+去声+去声，有节奏感）

**寓意：**
- "弈"=对弈、棋局——RTS如棋局对弈，策略博弈
- "录"=记录、录闻、录存——对弈的记录、战报、故事
- "凌栖弈录"=在凌栖世界中，灵魂对弈的记录

**为什么适合游戏应用：**
1. **RTS策略本质**："弈"字直接体现RTS的策略博弈本质，比"战""争""竞技"更有文化底蕴和策略感
2. **游戏感强**："录"字有故事感、记录感，如"录闻""录异"，暗示游戏中有丰富的对战故事和战报
3. **与总名呼应**："凌栖"二字直接嵌入，品牌一致性强
4. **不直白**：不用"竞技场""对战"等直白词，"弈录"含蓄有韵味
5. **辨识度高**："弈录"组合独特，市面上没有同名游戏，辨识度强
6. **音韵好听**：líng qī yì lù，四声组合有节奏感，朗朗上口

**视觉联想：**
- 棋盘上两个灵魂对弈，棋局化为战斗场景
- Logo可做：棋盘格背景上，"弈"字的"廾"部化为两个对峙的灵魂，"录"字化为卷轴
- 色调：墨黑+弈金（暗金色），策略感+高级感

**出处参考：**
- 《论语·阳货》："不有博弈者乎？"——博弈是古老的策略游戏
- "录"=记录、记载，如《世说新语》《搜神记》都是"录"体，有故事感

## 三、三个名字的逻辑关联

```
凌觉（灵魂引擎）
  ↓ 觉知
萌衍（世界引擎）
  ↓ 萌发繁衍
凌栖弈录（游戏应用）
```

**逻辑链：**
1. **凌觉**：灵魂的觉知——内在的认知/意识觉醒
2. **萌衍**：觉知的灵魂在世界中萌发繁衍——从内在到外在，从种子到万千世界
3. **凌栖弈录**：在凌栖世界中，觉醒的灵魂们对弈博弈，留下记录——从成长到互动，从个体到群体

**字的关联：**
- "凌"字贯穿灵魂引擎（凌觉）和游戏应用（凌栖弈录），形成品牌家族感
- "觉→萌→弈"是一个从内到外、从静到动的过程：觉知（内）→萌发（外）→对弈（动）
- 三个名字都有东方哲学韵味，风格统一

- **凌觉**："凌"字笔画中升起一轮朝阳，"觉"字的"见"部化为眼睛形状，寓意"觉知"

### 4.3 UI风格

- 统一使用东方美学元素：水墨晕染、留白、印章、书法字体
- 凌觉偏暖金光明、萌衍偏翠绿生机、弈录偏墨黑策略
- 三个子项目共享设计语言，但各有调性
