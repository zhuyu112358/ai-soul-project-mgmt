## 二、v3.1新命名方案

### 2.1 灵魂引擎：Ember / 灵火

**英文名：Ember**（已确认，余烬微光，灵魂之火）
**中文名：灵火**（v3.1新增，与Ember意合）

**寓意：**
- 灵=灵魂，火=火焰
- 灵火=灵魂之火，是灵魂最本质的能量与温度
- 与Ember（余烬微光）意合，都是微小但温暖的火焰
- "灵火"也有"灵魂之火虽微，但可以温暖整个灵魂之家，可以在对战中燃烧"的成长隐喻
- 符合灵魂之家的温暖治愈调性，也符合竞技场的战斗激情

**为什么切合游戏主题：**
1. **灵魂本质**：灵火直接对应"AI灵魂"的核心，是灵魂的能量本源
2. **温暖治愈**：火有温暖的意象，符合灵魂之家中交流训练的治愈调性
3. **成长隐喻**：灵火从微弱余烬到熊熊燃烧，对应灵魂的认知/情感/技能成长
4. **对战激情**：火有战斗的意象，灵火在竞技场中燃烧，对应RTS对战
5. **跨世界迁移**：灵火可以在不同世界/载体间传递燃烧，对应Sojourn的寄居迁移
6. **精致像素风**：火焰在像素风中表现力极强（粒子效果、光影变化）

**音韵：**
- 灵火：líng huǒ，阳平+上声，响亮有力
- Ember：/ˈɛmbər/，两个音节，柔和温暖

**英文名关联：**
- Ember=余烬、微光、将燃未燃的火焰
- 灵火=灵魂之火
- 二者意合，都是微小但温暖的火焰，都有"可以燎原"的成长潜力
- 中文名"灵火"比直接翻译"余烬"更温暖、更有力量，避免了"余烬"的冷却/将灭的负面联想

**视觉联想：**
- 一团温暖的灵魂之火，在黑暗中微微燃烧，火焰中有灵魂的形态
- 火焰的颜色随灵魂的情绪变化：开心时金黄，悲伤时蓝紫，愤怒时橙红
- Logo可做："灵"字的笔画化为火焰，"火"字化为灵魂形态
- 色调：暖金 #F5C842 + 余烬橙 #FF6B35

**版权查重结果：**
- Steam搜索：未发现知名同名游戏叫"灵火"
- "灵火"作为词汇有一些小说/动漫使用，但作为游戏名无知名同名RTS/养成游戏
- Ember已有一些游戏/品牌使用（如Ember Online、Ember Sword），但用户已确认Ember，中文名"灵火"无冲突
- **结论：灵火无版权冲突，可安全使用**

### 2.2 游戏应用：灵泉 / Soulspring

**中文名：灵泉**
**英文名：Soulspring**（Soul+spring的组合，灵魂之泉）

**寓意：**
- 灵=灵魂，泉=泉水、源泉
- 灵泉=灵魂之泉，是灵魂成长、交流、对战的源泉
- 泉水从源头涌出，源源不断，对应灵魂的持续成长
- 泉水流淌到不同地方，对应灵魂在不同世界/载体间迁移寄居（Sojourn）
- 泉水有温柔的一面（灵魂之家的治愈），也有力量的一面（竞技场的对战）
- 泉水在像素风中表现力极强（水面反光、波纹、粒子效果）

**为什么切合游戏主题：**
1. **灵魂成长**：泉水涌出=灵魂成长，源源不断=持续成长，泉水越深=灵魂越强
2. **温暖治愈**：泉水有温暖治愈的意象，符合灵魂之家中交流训练的治愈调性
3. **策略对战**：泉水有力量的意象，灵泉的力量可以在竞技场中释放，RTS对战如泉水般流动变化
4. **跨世界迁移**：泉水流淌=灵魂在不同世界间流动迁移，对应Sojourn的寄居主题
5. **精致像素风**：泉水是像素风游戏中最经典的视觉元素之一（水面、波纹、倒影、瀑布），表现力极强
6. **长期跨游戏**：灵泉可以流淌到不同游戏中，对应跨游戏AI灵魂系统的长期愿景
7. **灵魂之家**：灵魂之家可以建在灵泉之畔，泉水是灵魂之家的核心景观

**与其他命名的逻辑关联：**
- Sojourn（寄居）→ 灵泉（灵魂寄居在灵泉之畔）
- Ember/灵火（灵魂之火）→ 灵泉（灵魂之泉）：火与水，灵魂的两个本质能量，火代表激情/对战，水代表温柔/治愈
- Arboreus/建木（世界树）→ 灵泉（灵魂之泉）：建木生长在灵泉之畔，泉水滋养世界树，世界树衍生万千世界
- 逻辑链：灵火（灵魂之火）→ 灵泉（灵魂之泉）→ 建木（世界树）→ 万千世界

**音韵：**
- 灵泉：líng quán，阳平+阳平，响亮流畅
- Soulspring：/ˈsoʊlsprɪŋ/，两个音节组合，简短好记

**英文名关联：**
- Soul=灵魂
- spring=泉水、春天、跳跃、涌现、源泉
- Soulspring=灵魂之泉、灵魂的源泉
- 与Sojourn（/ˈsoʊdʒɜːrn/）、Ember（/ˈɛmbər/）、Arboreus（/ɑːrˈbɔːriəs/）风格协调，都是英文/拉丁词源的优雅词汇
- Soulspring是组合词，独特性强，无同名游戏

**视觉联想：**
- 一汪清澈的灵魂之泉，泉水微微发光，水面有灵魂的倒影
- 泉水从源头涌出，流淌到灵魂之家（温暖），也流淌到竞技场（力量）
- 泉水的颜色随灵魂的情绪变化
- Logo可做："灵"字化为泉水的波纹，"泉"字化为泉水涌出的形态
- 色调：清泉蓝 #4A90D9 + 治愈绿 #2D9B5E + 暖金 #F5C842

**为什么否决涿鹿/Dominion：**
- 涿鹿偏历史战役，与"灵魂成长+温暖治愈+跨世界迁移"的游戏主题契合度不够
- Dominion偏统治/战争，缺少温暖治愈感
- 游戏主题是"AI灵魂的成长与对战"，不是单纯的历史战争，需要更有灵魂感、温暖感的名字
- 灵泉/Soulspring同时包含了温暖治愈（泉水）、成长（涌出）、对战（力量）、跨世界迁移（流淌）四个维度，更切合游戏主题

**版权查重结果：**
- Steam搜索：未发现知名同名游戏叫"灵泉"或"Soulspring"
- "灵泉"作为地名/寺名有一些使用，但作为游戏名无知名同名
- Soulspring作为组合词，独特性强，未发现知名同名游戏/品牌
- **结论：灵泉/Soulspring无版权冲突，可安全使用**

## 三、四个名字的逻辑关联

```
Sojourn / 凌栖（项目总名，灵魂寄居）
  ↓ 寄居在
Ember / 灵火（灵魂引擎，灵魂之火）
  ↓ 火与水
Soulspring / 灵泉（游戏应用，灵魂之泉）
  ↓ 泉水滋养
Arboreus / 建木（世界引擎，世界树）
  ↓ 生长出
万千世界
```

**逻辑链：**
1. **Sojourn / 凌栖**：灵魂寄居，暂住迁移——项目总名，定义灵魂的存在状态
2. **Ember / 灵火**：灵魂之火，余烬微光——灵魂的本质能量，火代表激情/对战
3. **Soulspring / 灵泉**：灵魂之泉，温暖源泉——灵魂的成长/交流/对战场所，水代表温柔/治愈
4. **Arboreus / 建木**：世界树，种子→生长→万千世界——灵魂寄居的世界载体，泉水滋养世界树

**五行呼应：**
- 灵火（火）→ 灵泉（水）：火水既济，灵魂的两个本质能量平衡
- 灵泉（水）→ 建木（木）：水生木，泉水滋养世界树生长
- 建木（木）→ 万千世界：世界树衍生万千世界

**风格统一：**
- 四个英文名：Sojourn / Ember / Soulspring / Arboreus，都是英文/拉丁词源的优雅词汇
- 四个中文名：凌栖 / 灵火 / 灵泉 / 建木，都有灵魂/自然意象，温暖治愈
- 整体风格：东方灵魂意象 + 西方优雅命名 + 精致像素风

### 4.2 Logo设计方向

- **Sojourn / 凌栖**：灵魂光球寄居在树洞中，"凌"字化为灵魂光芒，"栖"字化为树洞
- **Ember / 灵火**：一团温暖的灵魂之火，火焰中有灵魂形态，"灵"字化为火焰，"火"字化为灵魂

- **Arboreus / 建木**：种子剖面中长出世界树，根系化为"建"字笔画，树冠化为"木"字

### 4.3 UI风格

- 统一使用东方灵魂美学元素：水墨晕染、祥云、水波纹、火焰纹、书法字体
- 灵火偏暖金光明、灵泉偏清泉蓝治愈、建木偏翠绿生机、凌栖偏紫金神秘
- 四个子项目共享设计语言，但各有调性
