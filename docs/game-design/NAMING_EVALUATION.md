# 项目命名最终方案 v3.2

**项目总名：凌栖 / Sojourn**（凌=飞越之魂，栖=寄居之所；Sojourn=暂住寄居，灵魂在不同载体间迁移）

**命名日期：** 2026-09-06
**命名版本：** v3.2（用户澄清产品定位：凌栖/Sojourn是游戏平台/生态，RTS灵魂对战竞技场只是平台上的第一个游戏；游戏名只需要体现RTS对战主题，不需要带"灵魂"字样，不需要承载整个生态主题）
**命名原则：** 切合游戏主题，RTS策略对战，精致像素风，版权查重

---

## 一、产品定位澄清（v3.2关键变更）

**凌栖/Sojourn是游戏平台/生态，不是单一游戏。**

- 灵魂可以派去不同世界探索，获得新的成长和记忆
- 灵魂之家（家园）独立于具体游戏之外，是平台级功能
- 后续允许第三方开发新世界（类似Minecraft模组），做成生态
- 当前开发的RTS灵魂对战竞技场只是平台上的**第一个游戏**

**因此：具体游戏的命名只需要考虑自己的主题和特点（RTS对战），不需要承载整个灵魂生态的主题，不需要带"灵魂"字样。**

## 三、v3.2新命名方案

### 3.1 灵魂引擎：Ember / 灵火

**英文名：Ember**（已确认，余烬微光，灵魂之火）
**中文名：灵火**（v3.1新增，v3.2继续使用，与Ember意合）

**寓意：**
- 灵=灵魂，火=火焰
- 灵火=灵魂之火，是灵魂最本质的能量与温度
- 与Ember（余烬微光）意合，都是微小但温暖的火焰
- "灵火"也有"灵魂之火虽微，但可以温暖整个灵魂之家，可以在对战中燃烧"的成长隐喻
- 符合灵魂之家的温暖治愈调性，也符合竞技场的战斗激情

**为什么切合灵魂引擎：**
1. **灵魂本质**：灵火直接对应"AI灵魂"的核心，是灵魂的能量本源
2. **温暖治愈**：火有温暖的意象，符合灵魂之家中交流训练的治愈调性
3. **成长隐喻**：灵火从微弱余烬到熊熊燃烧，对应灵魂的认知/情感/技能成长
4. **对战激情**：火有战斗的意象，灵火在竞技场中燃烧，对应RTS对战
5. **跨世界迁移**：灵火可以在不同世界/载体间传递燃烧，对应Sojourn的寄居迁移
6. **精致像素风**：火焰在像素风中表现力极强（粒子效果、光影变化）

**音韵：**
- 灵火：líng huǒ，阳平+上声，响亮有力
- Ember：/ˈɛmbər/，两个音节，柔和温暖

**英文名关联：**
- Ember=余烬、微光、将燃未燃的火焰
- 灵火=灵魂之火
- 二者意合，都是微小但温暖的火焰，都有"可以燎原"的成长潜力
- 中文名"灵火"比直接翻译"余烬"更温暖、更有力量，避免了"余烬"的冷却/将灭的负面联想

**视觉联想：**
- 一团温暖的灵魂之火，在黑暗中微微燃烧，火焰中有灵魂的形态
- 火焰的颜色随灵魂的情绪变化：开心时金黄，悲伤时蓝紫，愤怒时橙红
- Logo可做："灵"字的笔画化为火焰，"火"字化为灵魂形态
- 色调：暖金 #F5C842 + 余烬橙 #FF6B35

**版权查重结果：**
- Steam搜索：未发现知名同名游戏叫"灵火"
- Steam上有《Soulfire》（灵魂之火，2020年，类魂系大逃杀）和《Soulflame》（即将推出，动作冒险），但中文名"灵火"无直接同名
- Ember已有一些游戏/品牌使用，但用户已确认Ember，中文名"灵火"无冲突
- **结论：灵火无版权冲突，可安全使用**

### 3.2 第一个游戏（RTS灵魂对战竞技场）：战策 / Battleplan

**中文名：战策**
**英文名：Battleplan**（Battle+plan的组合，作战计划）

**寓意：**
- 战=战斗、对战，策=策略、计谋、策划
- 战策=战斗策略，是RTS实时策略对战的核心
- RTS对战就是实时制定战斗策略、执行战斗策略的过程
- "战策"也有"战斗策略博弈"的意象，符合RTS策略博弈的特点
- 不带"灵魂"字样，符合平台定位（灵魂是平台级概念，游戏名只体现游戏主题）

**为什么切合RTS对战主题：**
1. **实时对战**：战=战斗，直接体现RTS实时对战的核心玩法
2. **策略博弈**：策=策略/计谋，直接体现RTS策略博弈的核心玩法
3. **竞技场**：战策是在竞技场中制定和执行的战斗策略，符合竞技场定位
4. **精致像素风**：战策有古典兵法的意象，符合精致像素风的文化调性
5. **不直白**：战策比"竞技场""对战"等直接词更有文化感和辨识度
6. **平台第一个游戏**：战策只体现RTS对战主题，不承载整个灵魂生态主题，符合平台定位

**与平台的关系：**
- 战策是凌栖/Sojourn平台上的第一个游戏
- 玩家在灵魂之家中培养灵魂（平台级功能），然后带到战策竞技场中进行RTS对战
- 战策中的战斗策略会影响灵魂的成长和记忆
- 后续平台上的其他游戏（如探索游戏、养成游戏等）会有各自的命名

**音韵：**
- 战策：zhàn cè，去声+去声，响亮有力
- Battleplan：/ˈbætəlplæn/，两个音节组合，简短好记

**英文名关联：**
- Battle=战斗、对战
- plan=计划、策略、策划
- Battleplan=作战计划、战斗策略
- 与"战策"意合（战=Battle，策=Plan）
- 与Sojourn（/ˈsoʊdʒɜːrn/）、Ember（/ˈɛmbər/）、Arboreus（/ɑːrˈbɔːriəs/）风格协调，都是英文/拉丁词源的优雅词汇
- Battleplan是组合词，独特性强，无知名同名RTS游戏

**视觉联想：**
- 战场地图上的作战计划，箭头和标记指示部队的移动和攻击方向
- 像素风的战场，士兵和建筑在地图上移动，战斗特效闪烁
- Logo可做："战"字化为盾牌和刀剑，"策"字化为地图和箭头
- 色调：战旗红 #C0392B + 铠甲银 #BDC3C7 + 策略金 #F1C40F

**为什么否决之前的方案：**
- 涿鹿/Dominion（v3.0）：偏历史战役，与"灵魂成长+温暖治愈+跨世界迁移"的游戏主题契合度不够；且用户澄清平台定位后，游戏名不需要承载整个生态主题
- 灵泉/Soulspring（v3.1）：偏温暖治愈，缺少RTS对战的竞技感和策略感；且带"灵"字，不符合平台定位（游戏名不需要带"灵魂"字样）
- 弈境/Stratagem（v3.2候选）：版权查重不通过，Steam有《永恒弈境》（包含"弈境"）和《Three Kingdoms Stratagem》《Stratagem Lost》（包含"Stratagem"）
- 弈阵/Phalanx（v3.2候选）：版权查重不通过，TapTap有《弈阵》（同名回合制兵棋）和Steam有《Phalanx of Resistance》（包含"Phalanx"）

**版权查重结果：**
- Steam搜索：未发现知名同名游戏叫"战策"或"Battleplan"
- "战策"作为词汇有一些使用，但作为游戏名无知名同名RTS/策略游戏
- Battleplan作为组合词，独特性强，未发现知名同名RTS游戏（有一些桌游/军事模拟使用，但无知名电子游戏）
- **结论：战策/Battleplan无版权冲突，可安全使用**

## 四、四个名字的逻辑关联

```
平台层：
  Sojourn / 凌栖（平台总名，灵魂寄居生态）
    ├── 灵魂引擎：Ember / 灵火（灵魂之火，平台级灵魂AI引擎）
    ├── 世界引擎：Arboreus / 建木（世界树，平台级世界生成引擎）
    └── 灵魂之家（平台级家园功能，独立于具体游戏）

游戏层（平台上的第一个游戏）：
  Battleplan / 战策（RTS灵魂对战竞技场）
```

**逻辑链：**
1. **Sojourn / 凌栖**：平台总名，灵魂寄居生态，定义灵魂的存在状态
2. **Ember / 灵火**：灵魂引擎，灵魂之火，平台级灵魂AI引擎，驱动所有游戏中的灵魂
3. **Arboreus / 建木**：世界引擎，世界树，平台级世界生成引擎，生成所有游戏中的世界
4. **Battleplan / 战策**：平台上的第一个游戏，RTS灵魂对战竞技场，玩家用培养的灵魂进行实时策略对战

**平台与游戏的关系：**
- 平台（凌栖/Sojourn）提供灵魂引擎（Ember/灵火）、世界引擎（建木/Arboreus）、灵魂之家（家园）等基础能力
- 游戏（战策/Battleplan）是平台上的具体应用，使用平台提供的灵魂和世界进行RTS对战
- 后续平台上会有更多游戏（探索游戏、养成游戏等），每个游戏有自己的命名
- 灵魂可以在不同游戏间迁移，获得不同的成长和记忆

**风格统一：**
- 四个英文名：Sojourn / Ember / Arboreus / Battleplan，都是英文/拉丁词源的优雅词汇
- 中文名：凌栖 / 灵火 / 建木 / 战策，都有文化意象，不直白
- 整体风格：东方文化意象 + 西方优雅命名 + 精致像素风
