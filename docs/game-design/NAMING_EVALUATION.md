## 二、v3.0新命名方案

### 2.1 世界引擎：建木 / Arboreus

**中文名：建木**
**英文名：Arboreus**（拉丁语"树"，与建木意合）

**寓意：**
- 建木是中国神话中的**世界树**，连接天地，是众神上下的通道
- 一颗种子长成参天大树，根系蔓延，枝叶繁茂，衍生出万千世界
- 完美对应"种子→生长→万千世界"的核心意象
- 建木本身就包含了从种子到世界树的完整生长过程

**神话出处：**
- 《山海经·海内经》："有木，青叶紫茎，玄华黄实，名曰建木，百仞无枝，有九欘，下有九枸，其实如麻，其叶如芒，大暤爰过，黄帝所为。"
- 《淮南子·地形训》："建木在都广，众帝所自上下。"
- 建木是上古神话中连接天地的神树，伏羲、黄帝等众神通过建木上下于天地

**音韵：**
- 建木：jiàn mù，去声+去声，短促有力
- Arboreus：/ɑːrˈbɔːriəs/，拉丁语源，四音节，优雅有神话感

**英文名关联：**
- Arboreus源自拉丁语"arbor"（树），与建木（世界树）意合
- 与Sojourn（/ˈsoʊdʒɜːrn/）、Ember（/ˈɛmbər/）风格协调，都是拉丁/日耳曼语源的优雅短词
- Arboreus有"树木的、如树的"之意，暗示世界引擎如大树般生长、分支、衍生万千世界

**视觉联想：**
- 一颗种子破土而出，长成参天大树，根系蔓延至地底，枝叶触及天空
- 树冠中孕育着万千世界，每一片叶子都是一个小世界
- Logo可做：种子剖面中长出世界树，根系化为"建"字的笔画，树冠化为"木"字
- 色调：生命翠绿+神木金，生机盎然+神圣感

**与其他命名的逻辑关联：**
- Ember（灵魂之火）→ Arboreus（世界之树）：木火相生，五行呼应。灵魂之火点燃，世界之树生长
- Sojourn（寄居）→ Arboreus（建木世界）：灵魂寄居在建木衍生的万千世界中
- 建木是Ember灵魂的栖息之所，是Sojourn寄居的世界载体

**版权查重结果：**
- Steam搜索：无直接叫"建木"或"Jianmu"的游戏
- 《义闻录：轮回》中有"建木神树"作为剧情元素，但不是游戏名
- 《匠木》是榫卯主题益智手游，名字不同（匠木 vs 建木）
- Arboreus：无知名同名游戏；Arborea是Alley Cat Games Ltd的桌游商标（2025年注册，玩具类），但Arboreus与Arborea不同名
- **结论：建木/Arboreus无版权冲突，可安全使用**

### 2.2 游戏应用：涿鹿 / Dominion

**中文名：涿鹿**
**英文名：Dominion**（统治、控制权，与涿鹿争夺天下意合）

**寓意：**
- 涿鹿之战是中国神话中**规模最大、最著名的战役**，黄帝 vs 蚩尤
- 涉及多方势力（黄帝、炎帝、蚩尤、九黎）、各种神兽（应龙、女魃、风伯、雨师）、法术斗法
- 是中国神话中的"世界大战"，完美契合RTS大规模实时策略对战
- "涿鹿"作为游戏名，有历史厚重感和神话感，暗示神话级别的大规模对战

**神话出处：**
- 《山海经·大荒北经》："蚩尤作兵伐黄帝，黄帝乃令应龙攻之冀州之野。应龙畜水，蚩尤请风伯雨师，纵大风雨。黄帝乃下天女曰魃，雨止，遂杀蚩尤。"
- 《史记·五帝本纪》："蚩尤作乱，不用帝命。于是黄帝乃征师诸侯，与蚩尤战于涿鹿之野，遂禽杀蚩尤。"
- 涿鹿之战是上古神话中最关键的战役，决定了华夏文明的走向

**音韵：**
- 涿鹿：zhuō lù，阴平+去声，短促有力，有战斗感
- Dominion：/dəˈmɪniən/，三音节，重音在第二音节，有力量感和庄严感

**英文名关联：**
- Dominion意为"统治、控制权、领地"，RTS的核心就是争夺战场控制权
- 与涿鹿（争夺天下统治权）意合——涿鹿之战就是黄帝与蚩尤争夺天下统治权
- 与Sojourn、Ember、Arboreus风格协调，都是拉丁/日耳曼语源的有力词汇
- Dominion有"统治权"之意，暗示游戏中玩家争夺战场统治权

**视觉联想：**
- 神话战场上，多方势力对峙，神兽翱翔，法术交织
- 黄帝的应龙与蚩尤的风伯雨师在空中斗法，地面上九黎部落与华夏部落激战
- Logo可做：两个对峙的神兽剪影（应龙 vs 蚩尤），中间是战场，化为"涿"字的笔画
- 色调：战火红+神话金，战斗感+史诗感

**与其他命名的逻辑关联：**
- Arboreus（建木世界）→ Dominion（涿鹿之战）：在建木衍生的世界中，灵魂们进行涿鹿之战
- Ember（灵魂之火）→ Dominion（涿鹿之战）：灵魂之火在战场上燃烧，Ember是战士，Dominion是战场
- Sojourn（寄居）→ Dominion（涿鹿之战）：灵魂寄居在战场中，通过对战成长
- 涿鹿是建木世界中的终极战场，是Ember灵魂的成长验证场

**为什么不用Conquest：**
- 初拟英文名Conquest（征服），但Steam已有《Conquest!》（GreenLion Gaming，2021年，多人策略RPG）同名游戏
- 为避免版权混淆，改用Dominion
- Dominion与涿鹿的意合更精准（争夺统治权 vs 单纯征服），且更有RTS策略感

**版权查重结果：**
- Steam搜索：无直接叫"涿鹿"或"Zhuolu"的独立游戏
- 《三国志-群雄涿鹿》含"涿鹿"二字但是组合名，非独立游戏名
- 《逐鹿》《逐鹿汉末》是同音字（逐鹿 vs 涿鹿），不同字，不构成同名
- Dominion：有桌游《Dominion》（皇舆争霸，Rio Grande Games），但作为电子RTS游戏名可区分；无知名同名RTS电子游戏
- **结论：涿鹿/Dominion无直接版权冲突，可安全使用（建议注册商标时注意桌游类区分）**

## 三、四个名字的逻辑关联

```
Sojourn（凌栖，灵魂寄居）
  ↓ 寄居在
Ember（灵魂引擎，余烬之火）
  ↓ 点燃生长
Arboreus（世界引擎，建木世界树）
  ↓ 在世界中对战
Dominion（游戏应用，涿鹿之战）
```

**逻辑链：**
1. **Sojourn（凌栖）**：灵魂寄居，暂住迁移——项目总名，定义灵魂的存在状态
2. **Ember（灵魂引擎）**：余烬微光，灵魂之火——灵魂的本质，是寄居的主体
3. **Arboreus（世界引擎）**：建木世界树，种子→生长→万千世界——灵魂寄居的世界载体，木火相生
4. **Dominion（游戏应用）**：涿鹿之战，争夺统治权——灵魂在建木世界中对战成长的战场

**五行呼应：**
- Ember（火）→ Arboreus（木）：木火相生，灵魂之火点燃世界之树
- 建木（木）生长出万千世界，Ember（火）灵魂寄居其中，通过Dominion（战）成长

**风格统一：**
- 四个英文名：Sojourn / Ember / Arboreus / Dominion，都是拉丁/日耳曼语源的优雅有力词汇
- 两个中文名（有中文名的）：凌栖 / 建木 / 涿鹿，都有古代神话/文学底蕴
- 整体风格：东方神话内核 + 西方优雅命名外壳
