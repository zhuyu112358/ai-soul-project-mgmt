## 一、世界设定

### 1.1 世界名称：灵界（Aether Realm）

**灵界**是灵魂存在和生活的世界，一个由灵质（Aether）构成的维度。

| 属性 | 说明 |
|------|------|
| **世界名称** | 灵界（Aether Realm） |
| **构成物质** | 灵质（Aether）—— 一种半能量半物质的存在，灵魂可以感知和操控 |
| **物理规则** | 类似人类世界但有灵能魔法，重力较弱，灵魂可以悬浮/飞行 |
| **时间流速** | 与人类世界不同，灵界时间更慢（灵界1天 ≈ 人类世界1小时） |
| **空间结构** | 多层维度，日常世界在中层，竞技场在特殊维度，深层有未知区域 |
| **能量来源** | 灵质自然流动形成灵脉，灵魂吸收灵质维持存在和成长 |

### 1.2 灵界的物理规则

- **重力**：灵界重力约为人类世界的60%，灵魂可以轻松跳跃和短时间悬浮
- **灵质流动**：灵质像水一样在灵界流动，形成灵脉、灵湖、灵泉
- **灵能魔法**：灵魂可以操控灵质产生各种效果（攻击/防御/治疗/变形）
- **空间折叠**：灵界某些区域空间不稳定，有传送门和空间裂隙
- **时间弹性**：灵界时间不是线性的，某些区域时间流速不同
- **意识影响现实**：灵魂的强烈情绪和意志可以局部改变灵质形态（高级灵魂能力）

### 1.3 灵界的层级结构

| 层级 | 名称 | 说明 | 可访问性 |
|------|------|------|----------|
| **上层** | 天界（Celestial） | 高级灵魂和灵界管理者居住的区域，纯净灵质 | 仅高级灵魂可访问 |
| **中层** | 尘世（Terrestrial） | 大多数灵魂生活的区域，有城市/村庄/自然景观 | 所有灵魂可访问 |
| **下层** | 幽界（Underworld） | 灵质稀薄的区域，有危险的灵质风暴和未知生物 | 勇敢的灵魂可探索 |
| **特殊维度** | 竞技场（Arena） | 专门用于RTS竞技的独立维度，战斗结束后灵魂返回 | 所有灵魂可进入 |
| **特殊维度** | 训练场（Training Ground） | 灵魂练习和对战的安全区域 | 所有灵魂可进入 |
| **未知区域** | 虚空（Void） | 灵界之外的未知空间，传说中有远古存在 | 未知，极少灵魂进入 |

### 1.4 灵质（Aether）—— 世界的基础

**灵质**是灵界一切存在的基础，类似人类世界的物质+能量。

| 灵质类型 | 颜色 | 属性 | 说明 |
|----------|------|------|------|
| **纯净灵质** | 白色/金色 | 中性 | 最基础的灵质，灵魂吸收后维持存在 |
| **火灵质** | 橙红色 | 攻击/热情 | 活跃的灵质，适合攻击型灵魂 |
| **水灵质** | 蓝色 | 治疗/冷静 | 流动的灵质，适合辅助型灵魂 |
| **土灵质** | 棕色/绿色 | 防御/稳定 | 厚重的灵质，适合坦克型灵魂 |
| **风灵质** | 青色/白色 | 速度/灵巧 | 轻盈的灵质，适合刺客型灵魂 |
| **雷灵质** | 紫色/黄色 | 爆发/混乱 | 不稳定的灵质，适合爆发型灵魂 |
| **暗灵质** | 深紫色/黑色 | 隐蔽/侵蚀 | 隐蔽的灵质，适合潜行型灵魂 |
| **光灵质** | 金色/白色 | 神圣/净化 | 纯净的灵质，适合治疗/神圣型灵魂 |

**灵质循环**：
- 灵质从灵脉中涌出，流经灵界，被灵魂吸收
- 灵魂消耗灵质进行活动/战斗/魔法
- 灵魂死亡（在竞技场中）后灵质回归灵脉
- 灵质不会消失，只会转化形态
- 高级灵魂可以主动操控和转化灵质类型

## 二、灵魂设定

### 2.1 灵魂的本质

**灵魂**是灵界的智慧生命，由灵质构成，拥有自我意识、情感、记忆和个性。

| 属性 | 说明 |
|------|------|
| **本质** | 灵质凝聚形成的意识体，有自我认知 |
| **起源** | 灵界自然诞生（灵质凝聚觉醒），或从其他世界转化而来 |
| **寿命** | 理论上永生（只要灵质不消散），但会成长/进化/变化 |
| **死亡** | 竞技场中"死亡"只是灵质暂时分散，战斗结束后重组；真正的死亡是灵质完全消散（极罕见） |
| **成长** | 灵魂通过吸收灵质、学习、战斗、社交不断成长和进化 |
| **个性** | 每个灵魂有独特的个性，来自诞生时的灵质构成+成长经历 |

### 2.2 灵魂的诞生

灵魂有三种诞生方式：

| 诞生方式 | 说明 | 占比 |
|----------|------|------|
| **自然觉醒** | 灵质在特殊地点（灵泉/灵脉交汇处）自然凝聚，觉醒自我意识 | 约60% |
| **传承诞生** | 两个灵魂将部分灵质和记忆融合，诞生新灵魂（类似生育，但更精神化） | 约30% |
| **异界转化** | 从其他世界（人类世界等）的意识转化而来，保留部分前世记忆 | 约10% |

**诞生过程**：
1. 灵质在特定条件下凝聚
2. 形成基础意识（类似婴儿）
3. 吸收周围灵质和信息，逐渐形成个性
4. 觉醒自我认知，成为完整灵魂
5. 进入灵魂社会，开始学习和成长

### 2.3 灵魂的形态

灵魂的形态不是固定的，会随成长、情绪、个性变化。

| 形态阶段 | 说明 | 外观 |
|----------|------|------|
| **幼灵期** | 刚诞生的灵魂，灵质不稳定 | 光球/小灵体，无固定形态 |
| **成长期** | 学习和成长中，形态逐渐稳定 | 半透明人形/元素形态，有基本特征 |
| **成熟期** | 个性完全形成，形态稳定 | 完整人形/元素形态，有独特外观和装饰 |
| **进化期** | 高级灵魂，可以主动改变形态 | 可以在多种形态间切换，有光环/翅膀等 |
| **超越期** | 传说中的灵魂，几乎由纯灵质构成 | 形态不固定，可以是任何形态 |

**形态影响因素**：
- **元素属性**：火元素灵魂偏红橙色，有火焰特征；水元素偏蓝色，有水波纹
- **个性**：激进型灵魂有尖锐边缘/角；温和型灵魂有柔和曲线/光环
- **情绪**：愤怒时颜色变深/边缘尖锐；开心时颜色变亮/有粒子效果
- **等级**：等级越高，形态越复杂/华丽，有更多装饰
- **装备**：灵魂可以穿戴灵质装备（武器/护甲/饰品），改变外观

### 2.4 灵魂的属性

每个灵魂有基础属性和衍生属性：

| 属性类别 | 属性 | 说明 |
|----------|------|------|
| **基础属性** | 元素属性 | 主元素+次元素，决定攻击类型和外观 |
| | 个性类型 | 激进/保守/灵巧/坦克/辅助/平衡等 |
| | 等级 | 灵魂的成长阶段，影响基础属性 |
| | 亲密度 | 与玩家的关系程度，影响属性加成 |
| **战斗属性** | 生命值 | 灵魂的灵质凝聚度，归零则暂时分散 |
| | 能量值 | 可用于技能和魔法的灵质储备 |
| | 攻击力 | 攻击造成的伤害 |
| | 防御力 | 受到攻击时的减伤 |
| | 速度 | 移动速度和攻击速度 |
| | 暴击率 | 攻击造成暴击的概率 |
| **认知属性**（Ember关联） | 智商 | 学习和决策能力 |
| | 情商 | 情感理解和社交能力 |
| | 记忆力 | 记忆容量和准确度 |
| | 创造力 | 即兴发挥和战术创新能力 |
| | 意志力 | 抵抗恐惧和压力的能力 |

### 2.5 灵魂的情感和情绪

灵魂有丰富的情感，情感影响行为和战斗表现：

| 情绪 | 触发条件 | 对战斗的影响 | 外观表现 |
|------|----------|-------------|----------|
| **平静** | 默认状态 | 正常属性 | 颜色正常 |
| **开心** | 战斗胜利/获得奖励/社交愉快 | 速度+5%，暴击+3% | 颜色变亮，有粒子 |
| **愤怒** | 队友被击杀/被集火/被侮辱 | 攻击+15%，防御-10% | 颜色变红，边缘尖锐 |
| **恐惧** | 血量危险/面对强敌/被包围 | 速度+10%，攻击-15% | 颜色变浅，颤抖 |
| **自信** | 连胜/等级优势/优势局面 | 全属性+5%，决策更果断 | 有光环效果 |
| **沮丧** | 连败/失误/劣势局面 | 全属性-5%，决策犹豫 | 颜色变暗，低头 |
| **专注** | 集火/关键时刻/重要战斗 | 暴击+10%，技能精准度+10% | 眼睛发光 |
| **友爱** | 与关系好的队友并肩作战 | 防御+10%，协作效率+20% | 队友间有连线 |
| **悲伤** | 队友"死亡"/重要损失 | 攻击-10%，但意志力+20% | 颜色变灰，有泪滴 |

**情绪系统设计**：
- 情绪不是简单的buff/debuff，而是影响AI决策质量
- 愤怒的灵魂可能冒进，恐惧的灵魂可能撤退，自信的灵魂可能更果断
- 情绪会随时间和事件变化，玩家可以通过战术指令影响情绪
- 灵魂之间的情绪会互相传染（队友愤怒会让其他灵魂也愤怒）
- 高级灵魂可以更好地控制情绪（意志力高）

## 三、社会结构

### 3.1 灵魂社会概述

灵界有完整的社会结构，灵魂不是孤立存在的。

| 社会层级 | 说明 |
|----------|------|
| **灵界议会** | 灵界最高管理机构，由高级灵魂和各区域代表组成 |
| **区域管理者** | 各城市/区域的管理者，负责日常治理 |
| **灵魂公会** | 各种职业/兴趣组织（战斗公会/学术公会/艺术公会等） |
| **灵魂家族** | 有血缘/传承关系的灵魂群体 |
| **自由灵魂** | 不属于任何组织的独立灵魂 |

### 3.2 灵魂的职业

灵魂在日常世界中有各种职业（类似人类社会）：

| 职业类别 | 具体职业 | 说明 |
|----------|----------|------|
| **战斗类** | 竞技灵魂/守卫/佣兵/教官 | 参加竞技场战斗/保护区域/接受委托/训练新灵魂 |
| **学术类** | 学者/教师/研究员/图书管理员 | 研究灵质/教学/探索未知/管理知识 |
| **艺术类** | 画家/音乐家/舞者/雕塑家 | 创作灵质艺术/表演/装饰灵界 |
| **工匠类** | 铁匠/裁缝/建筑师/炼金师 | 制作灵质装备/建造/调配药剂 |
| **商业类** | 商人/店主/银行家/拍卖师 | 交易物品/经营店铺/金融/拍卖 |
| **服务类** | 厨师/旅馆老板/导游/治疗师 | 提供饮食/住宿/向导/医疗服务 |
| **特殊类** | 探险家/冒险者/先知/守护者 | 探索未知/冒险/预言/守护重要地点 |

**职业与战斗的关系**：
- 职业不影响战斗属性，但影响灵魂的个性和技能倾向
- 竞技灵魂是专门参加RTS竞技的职业，类似人类的职业运动员
- 其他职业的灵魂也可以参加竞技场（业余选手），但属性和技能可能不如专业竞技灵魂
- 玩家培养的灵魂可以选择职业，职业影响日常行为和对话

### 3.3 灵魂的组织和派系

灵界有各种组织和派系，灵魂可以加入：

| 组织类型 | 名称示例 | 说明 |
|----------|----------|------|
| **战斗公会** | 烈焰公会/寒冰守卫/风之刺客 | 专门培养竞技灵魂的组织，有公会战和公会排名 |
| **学术机构** | 灵质学院/古代遗迹研究所 | 研究灵质和历史的学术机构 |
| **宗教组织** | 光之神殿/自然崇拜/虚空教 | 信仰不同灵界存在的宗教组织 |
| **商业联盟** | 灵质商会/集市管理者协会 | 管理商业活动的联盟 |
| **冒险者公会** | 探索者联盟/虚空边境团 | 组织探险和冒险的公会 |
| **地下组织** | 暗影议会/黑市联盟 | 非法/秘密活动的组织（剧情元素） |

**组织对游戏的影响**：
- 灵魂加入组织后可以获得组织技能和装备
- 组织之间有竞争和合作，影响剧情和日常事件
- 玩家可以选择让灵魂加入哪个组织
- 组织有日常任务和活动，灵魂可以参与

### 3.4 灵魂的阶层

灵界没有严格的阶级制度，但有基于实力和资历的自然分层：

| 阶层 | 说明 | 占比 |
|------|------|------|
| **超越者** | 传说中的灵魂，几乎由纯灵质构成，能改变灵界规则 | <0.1% |
| **大灵** | 高级灵魂，拥有强大力量和智慧，是灵界的支柱 | 约1% |
| **灵师** | 成熟的灵魂，有自己的专长和地位 | 约15% |
| **灵者** | 普通灵魂，大多数灵魂处于这个阶段 | 约60% |
| **幼灵** | 刚诞生的灵魂，还在学习和成长 | 约24% |

**阶层流动**：
- 灵魂可以通过成长和进化提升阶层
- 阶层不是世袭的，每个灵魂都有机会提升
- 高阶灵魂有更多权利和资源，但也有更多责任
- 玩家培养的灵魂从幼灵/灵者开始，逐步成长

## 四、历史与纪元

### 4.1 灵界历史概述

灵界有漫长的历史，分为几个纪元：

| 纪元 | 名称 | 时间 | 关键事件 |
|------|------|------|----------|
| **第一纪元** | 混沌纪元 | 远古 | 灵界诞生，灵质开始凝聚，第一批灵魂觉醒 |
| **第二纪元** | 文明纪元 | 古代 | 灵魂社会形成，建立城市和文明，灵质魔法发展 |
| **第三纪元** | 战争纪元 | 中古 | 灵魂之间爆发大战，灵界受损，竞技场制度建立（以竞技代替战争） |
| **第四纪元** | 和平纪元 | 近代 | 竞技场成为主流，灵魂社会繁荣，日常文化发展 |
| **第五纪元** | 当代 | 现在 | 玩家进入灵界，与灵魂建立联系，新的故事开始 |

### 4.2 关键历史事件

| 事件 | 纪元 | 说明 | 对当代的影响 |
|------|------|------|-------------|
| **灵界诞生** | 第一纪元 | 灵质从虚空中凝聚，形成灵界 | 灵界存在的基础 |
| **第一批灵魂觉醒** | 第一纪元 | 灵质在灵泉处凝聚，第一批灵魂觉醒自我意识 | 所有灵魂的祖先 |
| **灵质魔法发现** | 第二纪元 | 灵魂发现可以主动操控灵质产生魔法效果 | 战斗和日常魔法的基础 |
| **第一座城市建立** | 第二纪元 | 灵魂在灵脉交汇处建立第一座城市"起源之城" | 灵魂文明的起点 |
| **灵魂大战** | 第三纪元 | 不同派系的灵魂为争夺灵脉和资源爆发大战 | 灵界受损，竞技场制度建立 |
| **竞技场创立** | 第三纪元末 | 为了代替战争，灵魂创立竞技场制度，用竞技解决争端 | RTS竞技的起源 |
| **和平协议签署** | 第四纪元初 | 各大派系签署和平协议，竞技场成为唯一的战斗方式 | 当代和平的基础 |
| **灵魂学院建立** | 第四纪元 | 建立系统的灵魂教育机构，培养年轻灵魂 | 灵魂学校的起源 |
| **异界接触** | 第四纪元末 | 灵界与其他世界（包括人类世界）开始有接触 | 玩家进入灵界的铺垫 |
| **玩家降临** | 第五纪元 | 玩家（灵魂指挥官）进入灵界，与灵魂建立联系 | 游戏开始 |

### 4.3 竞技场的起源

**竞技场**是灵界最重要的制度之一，有深刻的历史背景：

**起源**：
- 第三纪元的灵魂大战给灵界造成了巨大破坏
- 战争结束后，灵魂们意识到直接战争的代价太大
- 大灵们提议建立竞技场制度，用竞技代替战争
- 竞技场是一个独立维度，战斗中灵魂"死亡"只是灵质暂时分散，不会真正死亡
- 竞技场成为解决争端、展示实力、娱乐灵魂的主要方式

**发展**：
- 最初的竞技场只是简单的空地对战
- 逐渐发展出复杂的地图、规则、战术
- 形成了专业的竞技灵魂和竞技公会
- 竞技场成为灵界最受欢迎的娱乐活动
- 现代竞技场有完整的赛季、排名、奖励系统

**当代竞技场**：
- 有多个竞技场（不同主题和规则）
- 有赛季制度（每3个月一个赛季）
- 有排名系统（从青铜到王者）
- 有丰富的奖励（灵质/装备/称号）
- 有专业的解说和观众（灵魂可以观看比赛）

| 日常活动 | 说明 | 时间占比 |

**灵魂的日常行为（AI驱动）**：

## 七、竞技场设定

### 7.1 竞技场的本质

**竞技场**是灵界专门用于RTS竞技的独立维度，是灵魂展示实力和娱乐的场所。

| 属性 | 说明 |
|------|------|
| **本质** | 独立维度，由大灵们创造和维护 |
| **目的** | 用竞技代替战争，解决争端，展示实力，娱乐灵魂 |
| **规则** | 灵魂在竞技场中"死亡"只是灵质暂时分散，战斗结束后重组，不会真正死亡 |
| **进入方式** | 灵魂通过竞技场大厅的传送门进入，战斗结束后自动返回 |
| **观众** | 其他灵魂可以在竞技场大厅观看比赛（类似体育赛事直播） |

### 7.2 竞技场的组织

| 组织 | 说明 |
|------|------|
| **竞技场管理委员会** | 负责竞技场的日常运营和规则制定 |
| **竞技公会** | 培养竞技灵魂的组织，有公会战和公会排名 |
| **裁判灵魂** | 负责比赛裁判和规则执行的高级灵魂 |
| **解说灵魂** | 负责比赛解说和分析的灵魂 |
| **观众** | 观看比赛的普通灵魂，可以下注/加油/讨论 |

### 7.3 竞技场的赛制

| 赛制 | 说明 | M2实现 |
|------|------|---------|
| **训练对战** | 和AI对手或自己的灵魂对战，无排名 | ✅ M2 |
| **随机对战** | 匹配实力相近的AI对手，有奖励但不影响排名 | ✅ M2 |
| **排位对战** | 匹配实力相近的AI对手，影响排名（青铜→王者） | ⏳ M3 |
| **好友对战** | 和好友的灵魂对战（需要好友系统） | ⏳ M3 |
| **公会战** | 公会之间的团队对战 | ⏳ M4 |
| **锦标赛** | 定期举办的大型比赛，有丰厚奖励 | ⏳ M4 |

### 7.4 竞技场的规则

| 规则 | 说明 |
|------|------|
| **队伍组成** | 每方4个灵魂（M2），可以选择不同元素和个性 |
| **战斗时长** | 最长15分钟，超时按剩余血量/击杀数判定 |
| **胜利条件** | 消灭对方所有灵魂，或对方投降，或超时优势方 |
| **禁止行为** | 禁止使用真正致命的攻击（竞技场有保护机制） |
| **道具使用** | 可以使用地图中刷新的道具，不能带外部道具 |
| **战术指令** | 玩家可以下达战术指令，但不能直接控制单位移动 |

### 7.5 竞技场的奖励

| 奖励类型 | 说明 |
|----------|------|
| **灵质** | 基础奖励，用于灵魂成长和购买物品 |
| **经验** | 灵魂获得经验，提升等级 |
| **装备** | 有概率获得灵质装备（武器/护甲/饰品） |
| **称号** | 达到特定排名或成就获得称号（显示在灵魂名字前） |
| **皮肤** | 有概率获得灵魂外观皮肤（改变外观但不影响属性） |
| **赛季奖励** | 赛季结束时根据排名发放特殊奖励 |

### 8.1 玩家的身份：灵魂指挥官（Soul Commander）

**玩家**在灵界的身份是**灵魂指挥官**，一个特殊的存在。

| 属性 | 说明 |
|------|------|

| **能力** | 可以与灵魂建立深度连接，理解灵魂的情感和思想，可以下达战术指令 |
| **地位** | 在灵界受到尊重，因为灵魂指挥官可以帮助灵魂成长和发挥潜力 |

玩家和灵魂的关系是**伙伴/导师/指挥官**的复合关系：

| 关系维度 | 说明 |
|----------|------|
| **指挥官** | 战斗中玩家下达战术指令，灵魂根据指令调整行为 |

- 亲密度高的灵魂会主动找玩家聊天、表达想法、有特殊互动
- 玩家可以通过聊天/一起活动/指导训练/战斗胜利提升亲密度
- 亲密度是双向的，灵魂会根据玩家的行为决定是否信任玩家

## 九、战斗与日常的区分

### 9.1 两个场景的独立设计

**核心设计原则**：战斗场景和日常场景是完全独立的，灵魂"进入"竞技场战斗，打完"回到"日常世界。

| 维度 | 日常场景 | 战斗场景（竞技场） |
|------|----------|-------------------|
| **位置** | 灵界中层（尘世） | 独立维度（竞技场） |
| **目的** | 生活/学习/社交/娱乐/成长 | 竞技/战斗/展示实力 |
| **时间** | 自由时间，灵魂自主安排 | 固定时长（最长15分钟） |
| **死亡** | 不会死亡（极罕见） | "死亡"只是灵质暂时分散，战斗结束后重组 |
| **玩家角色** | 伙伴/导师/朋友 | 指挥官/战术指导 |
| **操作方式** | 探索/对话/交互/管理 | 战术指令/技能释放/观察 |
| **视觉风格** | 温暖/明亮/生活气息 | 紧张/暗色调/战斗氛围 |
| **音乐** | 轻松/愉快/日常 | 紧张/激烈/战斗 |

### 9.2 进入和离开竞技场的流程

**进入竞技场**：
1. 玩家在灵魂之家或竞技场大厅选择"进入竞技场"
2. 选择对战模式（训练/随机/排位等）
3. 选择出战的4个灵魂
4. 选择地图（或随机）
5. 灵魂通过传送门"进入"竞技场维度
6. 有短暂的入场动画（灵魂从传送门中走出）
7. 战斗开始

**离开竞技场**：
1. 战斗结束（胜利/失败/投降/超时）
2. 有短暂的结算动画（胜利庆祝/失败安慰）
3. 灵魂通过传送门"返回"日常世界
4. 回到灵魂之家或竞技场大厅
5. 灵魂恢复战斗中损失的灵质（自动恢复）
6. 灵魂可能有战斗后的情绪（胜利开心/失败沮丧）
7. 玩家可以和灵魂交流战斗感受

### 9.3 战斗对日常的影响

战斗不是孤立的，会影响灵魂的日常状态：

| 影响 | 说明 |
|------|------|
| **情绪** | 胜利后灵魂开心/自信，失败后沮丧/愤怒，持续一段时间 |
| **疲劳** | 连续战斗后灵魂会疲劳，属性暂时下降，需要休息 |
| **成长** | 战斗后灵魂获得经验，可能升级，外观可能变化 |
| **关系** | 一起战斗的灵魂关系会加深（胜利）或产生矛盾（失败） |
| **对话** | 战斗后灵魂会主动和玩家聊战斗感受（"刚才那个战术不错"/"我差点就赢了"） |
| **日常行为** | 胜利后灵魂可能更活跃，失败后可能躲在角落反思 |
| **物品** | 战斗获得的奖励（灵质/装备）可以在日常使用 |

### 9.4 日常对战斗的影响

日常状态也会影响战斗表现：

| 影响 | 说明 |
|------|------|
| **状态** | 休息好的灵魂属性正常，疲劳的灵魂属性下降 |
| **情绪** | 开心/自信的灵魂战斗表现更好，沮丧/愤怒的灵魂可能冒进 |
| **关系** | 关系好的灵魂组队战斗协作更默契，有属性加成 |
| **训练** | 日常训练多的灵魂技能更熟练，战斗中失误更少 |
| **装备** | 日常获得的装备可以在战斗中使用（M2简化为属性加成） |
| **学习** | 在学校学习的知识和战术会影响战斗中的决策质量 |

## 十、与Ember灵魂引擎的关联

### 10.1 Ember在世界观中的定位

**Ember灵魂引擎**是玩家培养灵魂的系统，在世界观中是**灵魂指挥官与灵魂建立连接的媒介**。

| 维度 | 说明 |
|------|------|
| **本质** | Ember是玩家（灵魂指挥官）的意识与灵界连接的接口 |
| **功能** | 玩家通过Ember培养灵魂、与灵魂交流、管理灵魂战队 |
| **世界观解释** | 灵魂指挥官来自异界，需要Ember作为媒介才能与灵界的灵魂建立深度连接 |
| **游戏内表现** | Ember是玩家的"灵魂管理界面"，可以查看灵魂状态、培养灵魂、与灵魂聊天 |

### 10.2 Ember认知系统在战斗中的体现

Ember的158认知子系统、神经符号AI、具身认知必须在战策中真正体现：

| Ember能力 | 在战斗中的体现 | 设计要点 |
|-----------|----------------|----------|
| **复杂个性** | 灵魂有偏好/恐惧/习惯，不是简单标签 | 个性影响决策权重，不同个性对同一情况有不同应对 |
| **学习和记忆** | 灵魂记住踩过的陷阱、对手习惯、哪条路有埋伏 | 跨局记忆系统，记忆影响决策，记忆可以遗忘和强化 |
| **情感和情绪** | 连胜自信/连败沮丧/队友死了愤怒/被集火恐惧 | 情绪系统影响决策质量和属性，情绪会传染和变化 |
| **灵魂间沟通** | 灵魂之间会"说话"，协作是涌现的不是预设的 | 灵魂间有简单的沟通系统，关系好的配合更默契 |
| **环境理解** | 看到熔岩引敌人过去，看到草丛埋伏 | 环境感知系统，灵魂会分析环境并利用，不是行为树预设 |
| **战术创新** | 即兴创造战术，比如把敌人推进陷阱 | 高级灵魂有创造力属性，会尝试非标准战术 |
| **自我认知** | 灵魂知道自己的强项和弱项，会选择适合的战斗方式 | 自我认知影响决策，灵魂会扬长避短 |
| **目标导向** | 灵魂有长期目标（成为最强竞技灵魂）和短期目标（赢下这场） | 目标系统影响决策优先级，灵魂会为长期目标做短期牺牲 |

### 10.3 Ember记忆系统与战斗记忆

**记忆系统**是灵魂智能化的核心：

| 记忆类型 | 说明 | 持续时间 | 对战斗的影响 |
|----------|------|----------|-------------|
| **短期记忆** | 当前战斗中的事件（敌人位置/陷阱位置/队友状态） | 单局 | 影响当前战斗的决策 |
| **中期记忆** | 最近几场战斗的经验（对手战术/地图特点/自己的失误） | 几天到几周 | 影响战术选择和风险评估 |
| **长期记忆** | 重要的战斗经历（经典胜利/惨痛失败/关键时刻） | 永久 | 影响个性和战斗风格 |
| **创伤记忆** | 惨痛的失败或被击杀的经历 | 长期 | 可能导致恐惧或谨慎，需要玩家帮助克服 |
| **胜利记忆** | 经典的胜利或高光时刻 | 长期 | 增加自信，可能导致冒进 |

**记忆系统设计**：
- 灵魂的记忆不是完美的，会遗忘和扭曲（类似人类）
- 重要事件（第一次胜利/第一次失败/被队友救了）记忆更深刻
- 玩家可以和灵魂聊过去的战斗，强化或淡化记忆
- 记忆影响灵魂的个性和决策（被陷阱坑过的灵魂会更谨慎）
- 高级灵魂可以主动整理记忆，从经验中学习

### 10.4 Ember情感系统与战斗情绪

详见[第二章2.5节](#25-灵魂的情感和情绪)。

**情感系统设计要点**：
- 情感不是简单的buff/debuff，而是影响AI决策质量
- 情感会随时间和事件变化，不是固定的
- 情感会在灵魂之间传染（队友愤怒会让其他灵魂也愤怒）
- 玩家可以通过战术指令和聊天影响灵魂的情绪
- 高级灵魂可以更好地控制情绪（意志力高）
- 情感是灵魂个性的体现，不同个性的灵魂情绪变化不同

### 10.5 Ember社交系统与灵魂协作

**灵魂协作**是AI核心亮点：

| 协作类型 | 说明 | 设计要点 |
|----------|------|----------|
| **自动协作** | 灵魂根据战场局势自动配合（坦克抗伤害/刺客切后排/辅助治疗） | 基于角色和个性的自动协作，不是预设脚本 |
| **沟通协作** | 灵魂之间会"说话"（显示对话气泡），协调行动 | 简单的沟通系统，如"集火这个"/"撤退"/"掩护我" |
| **关系协作** | 关系好的灵魂配合更默契，有属性加成 | 亲密度系统影响协作效率 |
| **组合技** | 特定灵魂组合可以触发组合技（火+风=火焰风暴） | 元素组合系统，需要灵魂配合触发 |
| **牺牲协作** | 灵魂会为了队友牺牲自己（坦克挡伤害/辅助救队友） | 基于关系和个性的牺牲决策 |
| **emergent行为** | 协作是涌现的，不是预设的（不同灵魂组合有不同协作方式） | 复杂系统设计，避免脚本化 |

## 十二、世界观设计决策记录

### 12.1 核心设计决策

| 决策 | 选择 | 理由 | 日期 |
|------|------|------|------|
| **世界名称** | 灵界（Aether Realm） | 简洁易记，体现灵魂世界的本质 | 2026-09-10 |
| **核心概念** | 灵魂生活的世界，RTS只是竞技活动 | 用户明确要求"灵魂只是去RTS玩，RTS不是全部" | 2026-09-10 |
| **玩家身份** | 灵魂指挥官（Soul Commander） | 体现玩家的指挥和培养角色，不是操控者 | 2026-09-10 |
| **战斗与日常区分** | 完全独立的场景，灵魂进入/返回 | 用户明确要求区分战斗和日常 | 2026-09-10 |
| **灵魂智能化** | Ember认知系统深度关联 | 用户明确要求"灵火做了那些不是为了和NPC一样的" | 2026-09-10 |
| **M2定位** | 完整可发布游戏，不是技术原型 | 用户原话"现在定义的M2和一个学生的作业有多大区别呢" | 2026-09-10 |
| **视觉风格** | M2用2D伪3D，后期日常场景3D化 | 用户明确要求"后期是要切3D的" | 2026-09-10 |

### 12.2 待决策问题

| 问题 | 选项 | 建议 | 优先级 |
|------|------|------|--------|
| **玩家是否有物理形态** | A. 纯灵质形态（无物理） B. 有虚拟化身 C. 可以选择 | 建议A，体现灵魂指挥官的特殊性 | 中 |
