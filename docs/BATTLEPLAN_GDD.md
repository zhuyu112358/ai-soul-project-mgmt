## 一、核心理念

**战策是一个"灵魂竞技场"策略游戏。** 玩家不直接操控单位，而是培养和指挥自己的灵魂在竞技场中战斗。灵魂拥有自主意识和战斗风格，会自己移动、攻击、躲避和释放技能。玩家的角色是"指挥官"——通过战术指令、技能调度和战前配置来影响战斗走向，而不是像传统RTS那样点击移动每个单位。

**一句话体验：** 培养你的灵魂，指挥它在充满地形互动的竞技场中与对手灵魂对决，你的策略决策决定胜负。

**与传统RTS的区别：**
- 传统RTS：玩家直接控制单位移动/攻击，考验操作和APM
- 战策：灵魂自主战斗，玩家通过战术指令和技能释放影响战局，考验策略和决策

---

## 二、核心玩法循环

### 单局战斗循环
1. **战前配置**（30秒-1分钟）：选择灵魂、配置技能组、设定战术倾向、选择地图
2. **战斗进行**（2-5分钟）：灵魂自主战斗，玩家实时释放技能+下达战术指令
3. **战斗结算**（15秒）：展示胜负、伤害统计、灵魂获得经验和奖励

### 长期成长循环
1. 战斗胜利 → 灵魂获得经验 → 灵魂升级 → 属性提升+解锁新技能
2. 收集不同元素/个性的灵魂 → 组建灵魂队伍 → 应对不同对手和地图
3. 解锁新地图、新技能、新战术 → 游戏深度增加

## 三、玩家参与方式（非直接控制）

### 3.1 技能释放（核心操作）
- 每个灵魂有4个技能槽，玩家在战斗中点击或按快捷键(1-4)释放
- 技能有冷却时间，需要把握释放时机
- 技能类型：伤害技、治疗技、防御技、控制技、增益技、召唤技
- 技能释放是玩家最直接的战斗干预方式

### 3.2 战术指令（宏观操控）
- 玩家可以给灵魂下达战术倾向指令，改变灵魂的AI行为模式：
  - **激进**：主动追击敌人，优先攻击，较少躲避
  - **保守**：保持距离，优先防御和治疗，等待时机
  - **灵巧**：频繁移动躲避，利用地形，打游击战
  - **集火**：优先攻击指定目标（玩家点击敌方灵魂标记集火）
  - **撤退**：暂时脱离战斗，回血/回蓝后重新加入
- 战术指令不是直接控制移动，而是改变灵魂的决策权重

### 3.3 战场互动
- 玩家可以触发地图上的机关/道具（如治疗泉、伤害陷阱、增益buff点）
- 利用地形：指挥灵魂占据高地、躲入草丛、引敌人到熔岩区
- 战场互动增加策略深度

### 3.4 战前策略
- 灵魂选择：不同灵魂有不同属性/技能/战斗风格
- 技能配置：从灵魂的技能池中选择4个带入战斗
- 战术预设：设置开场战术倾向
- 地图选择：不同地图有不同地形和互动元素

## 四、灵魂自主战斗AI系统

### 4.1 灵魂个性→战斗风格映射
每个灵魂有个性属性（来自Ember灵魂引擎），映射到战斗AI：
- **高攻击性** → 追击距离远，攻击频率高，较少躲避
- **高谨慎性** → 保持安全距离，频繁躲避，优先防御
- **高社交性** → （多单位时）倾向配合队友，集火
- **高好奇心** → 探索地图，主动触发互动元素
- **高情绪稳定性** → 行为一致，不冲动
- **低情绪稳定性** → 行为波动大，有时激进有时保守

### 4.2 AI决策层级
1. **战略层**（战术指令影响）：决定整体行为模式（激进/保守/灵巧等）
2. **战术层**（每秒决策）：决定当前目标（攻击谁/去哪里/用什么技能）
3. **操作层**（每帧执行）：移动、攻击、躲避、技能释放的具体执行

### 4.3 自主行为
- 灵魂会自己寻找目标、移动到攻击范围、执行攻击
- 灵魂会自己躲避敌方技能（根据个性和谨慎度）
- 灵魂会自己使用部分技能（AI判断时机），但核心大招由玩家控制
- 灵魂会利用地形（躲障碍、占高地）

## 五、地图与场景设计

### 5.1 地图要素
- **可通行区域**：灵魂可以自由移动的地面
- **障碍物**：石头、树木、水晶柱等，有碰撞（灵魂不能穿过）
- **地形效果区**：
  - 水域：移动速度降低30%
  - 熔岩：每秒受到伤害
  - 草丛：进入后隐身（敌方看不到）
  - 高地：攻击范围+10%，闪避+5%
  - 沙地：移动速度+10%但闪避-5%
- **可互动物**：
  - 治疗泉：靠近后回血，有冷却
  - 伤害陷阱：踩到后受到伤害，可被玩家触发
  - 增益点：拾取后获得临时buff（攻击/防御/速度）
  - 宝箱：打破后获得随机奖励

### 5.2 伪3D效果
- 所有灵魂和物体有投影阴影（根据光源方向）
- 物体有层级：背景（最远）→ 地面装饰 → 障碍物 → 灵魂 → 前景（最近）
- 灵魂被障碍物遮挡时半透明显示
- 高度感：灵魂站在地面上，有上下层的视觉区分

### 5.3 碰撞系统
- 灵魂与障碍物碰撞：不能穿过，绕行
- 灵魂与灵魂碰撞：不能重叠，互相推开
- 灵魂与地图边界碰撞：不能走出竞技场
- 技能与障碍物碰撞：部分技能被阻挡，部分可以越过

### 5.4 M2可用地图（从现有90+概念图中选）
待设计任务评估后选定3-5张，建议优先：
- 暗森林（dark_forest）：树木障碍+草丛隐蔽
- 熔岩洞穴（lava_cave）：熔岩伤害区+石头障碍
- 水晶神殿（crystal_temple）：水晶柱障碍+增益点
- 冰封平原（ice_plain）：水域减速+开阔地形
- 废墟竞技场（ruins_arena）：多种障碍物+宝箱

## 六、灵魂与玩家关联系统

### 6.1 灵魂来源
- 玩家在Ember灵魂引擎中培养的灵魂，可以导入战策作为战斗单位
- 灵魂的属性（元素、个性、技能、等级）直接映射到战斗中
- 玩家也可以在战策中解锁/招募新灵魂

### 6.2 属性映射
| Ember灵魂属性 | 战策战斗属性 |
|---|---|
| 元素类型 | 决定精灵外观、技能属性、元素克制 |
| 个性特质 | 决定AI战斗风格（激进/保守/灵巧等） |
| 认知能力 | 影响技能释放判断、躲避能力 |
| 情绪状态 | 影响战斗中的行为波动 |
| 等级/经验 | 决定基础属性（HP/攻击/防御/速度） |
| 技能/能力 | 映射为战斗技能（4个技能槽） |

### 6.3 精灵外观
- 精灵外观由元素类型+个性特征决定
- 利用现有100+元素精灵图（new_soul_unit_*_sprite_sheet.png）
- 不同个性的同元素灵魂有颜色/装饰差异
- 精灵有idle/move/attack/hurt/death动画

## 七、完整游戏流程

### 7.1 主菜单
- 开始战斗
- 灵魂管理（查看/培养/配置灵魂）
- 商店/收集
- 设置
- 退出

### 7.2 灵魂选择
- 展示玩家拥有的所有灵魂（卡片式）
- 显示灵魂属性、技能、个性、等级
- 选择一个灵魂出战

### 7.3 战斗配置
- 技能配置：从灵魂技能池中选4个
- 战术预设：设置开场战术倾向
- 地图选择：选择战斗地图
- 对手选择：AI对手（不同难度）或匹配玩家

### 7.4 战斗
- 倒计时3秒 → 战斗开始
- 灵魂自主战斗，玩家释放技能+战术指令
- 一方HP归零 → 战斗结束
- 时间限制：5分钟，超时按剩余HP比例判定

### 7.5 战斗结算
- 胜负展示
- 伤害统计（输出/承受/治疗）
- 灵魂获得经验
- 奖励（金币/道具/新技能碎片）
- 灵魂升级/成长提示

### 7.6 灵魂成长
- 升级：属性提升
- 技能解锁：达到特定等级解锁新技能
- 个性发展：战斗行为影响个性变化
- 外观进化：特定条件下精灵外观变化

## 九、视觉风格

- **整体风格**：2D像素风+深紫金色调
- **灵魂精灵**：半写实像素角色，256x256，带动画
- **地图**：手绘风场景，1920x1080，有层次感
- **UI**：深紫底+金色描边+像素字体，M2已有138项UI组件
- **特效**：粒子特效（攻击/受击/技能/死亡），利用现有资源
- **光影**：暗色调+点光源（灵魂发光），营造竞技场氛围
