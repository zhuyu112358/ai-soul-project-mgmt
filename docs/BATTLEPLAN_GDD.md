## 一、核心理念

### 1.1 这是什么游戏？

**战策 Battleplan 是一款"灵魂指挥官"策略对战游戏。**

玩家不直接操控单位移动，而是作为**灵魂指挥官**，指挥自己培养的灵魂战队在魔法竞技场中进行自主战斗。玩家通过**战术指令、技能释放、战前配置**影响战斗走向，而灵魂单位则根据自身的**个性、元素属性、AI行为**自主移动、攻击、躲避和使用技能。

**一句话描述游戏体验：**
> "你是灵魂的指挥官，不是傀儡师。你的灵魂会自己战斗，而你决定它们如何战斗。"

### 1.2 核心设计哲学

| 原则 | 说明 |
|------|------|
| **灵魂自主** | 灵魂单位有自己的个性和战斗风格，会自主决策移动/攻击/躲避/技能 |
| **玩家策略** | 玩家通过战术指令（进攻/防守/集火/撤退）和技能释放影响战斗，不直接点选移动 |
| **战前深度** | 战斗前的灵魂选择、技能配置、战术预设是核心策略深度 |
| **战中紧张** | 战斗中玩家需要观察局势、适时释放技能、切换战术指令，有参与感和紧张感 |
| **成长反馈** | 战斗后灵魂获得经验和成长，玩家能看到自己培养的灵魂变强 |

### 1.3 玩家与灵魂的关系

玩家不是"操控者"，而是"指挥官"和"培养者"：

- **培养关系**：玩家在Ember灵魂引擎中培养灵魂，灵魂有自己的个性、元素属性、技能树
- **指挥关系**：战斗中玩家下达战术指令，灵魂根据指令调整行为倾向，但不被精确控制
- **信任关系**：玩家需要了解每个灵魂的个性和战斗风格，合理配置战队，信任灵魂的自主战斗
- **成长关系**：灵魂在战斗中获得经验，个性和能力会随成长变化

### 1.4 与传统RTS的区别

| 维度 | 传统RTS（星际/魔兽） | 战策 Battleplan |
|------|----------------------|-----------------|
| 单位控制 | 玩家直接点选移动/攻击 | 灵魂自主移动/攻击，玩家下达战术指令 |
| 操作密度 | 高APM，精确微操 | 低操作密度，策略决策为主 |
| 单位个性 | 无个性，同类型单位行为一致 | 每个灵魂有独特个性，影响战斗表现 |
| 战前配置 | 种族/建筑/科技选择 | 灵魂选择/技能配置/战术预设 |
| 战中操作 | 造兵/升级/微操/多线 | 技能释放/战术切换/战场互动 |
| 核心技巧 | 操作速度+多线能力 | 策略判断+灵魂理解+时机把握 |

### 1.5 目标玩家

- 喜欢策略游戏但不喜欢高强度微操的玩家
- 喜欢收集/培养角色的玩家
- 喜欢看"自己的队伍"战斗的玩家（类似自走棋但有更多参与感）
- 喜欢奇幻魔法主题的玩家

## 二、核心玩法循环

### 2.1 战斗中玩家做什么？

玩家在战斗中**不直接控制单位移动**，而是通过以下方式参与战斗：

#### 2.1.1 战术指令系统（核心）

玩家可以对**全体灵魂**或**单个灵魂**下达战术指令，改变AI行为倾向：

| 指令 | 效果 | 适用场景 |
|------|------|----------|
| **进攻 Aggressive** | 灵魂主动寻找敌人，优先攻击，冒进倾向高 | 优势局、需要快速推进 |
| **防守 Defensive** | 灵魂保持距离，优先躲避，防守反击 | 劣势局、需要拖时间 |
| **集火 Focus** | 灵魂优先攻击玩家标记的目标 | 需要击杀关键目标 |
| **撤退 Retreat** | 灵魂向后撤退，脱离战斗 | 血量危险、需要重整 |
| **跟随 Follow** | 灵魂跟随玩家指定的友方单位 | 保护核心单位 |
| **自由 Free** | 灵魂完全自主决策，不干预 | 默认状态 |

**操作方式**：底部战术栏有6个指令按钮，点击后选择目标（全体/单个灵魂），指令会在灵魂头顶显示图标。

#### 2.1.2 技能释放系统

玩家可以在战斗中**主动释放灵魂的技能**（类似MOBA的技能栏）：

- 每个灵魂有1-2个主动技能
- 技能有冷却时间和能量消耗
- 玩家点击技能图标，然后选择目标位置/目标单位
- 技能释放有视觉特效和音效

**M2简化**：每个灵魂1个主动技能，4个灵魂共4个技能，底部技能栏4个图标。

#### 2.1.3 战场互动

地图上有可互动元素，玩家可以触发：

| 互动元素 | 效果 | 操作 |
|----------|------|------|
| 魔法机关 | 触发区域伤害/治疗/增益 | 点击机关 |
| 补给点 | 恢复附近灵魂的生命/能量 | 灵魂走到补给点自动触发 |
| 可破坏物 | 破坏后获得增益/打开通路 | 灵魂攻击可破坏物 |
| 地形机关 | 升降桥/闸门，改变通路 | 点击开关 |

#### 2.1.4 观察与决策

玩家需要持续观察战场：

- 观察灵魂血量/能量状态
- 观察敌方灵魂位置和意图
- 观察技能冷却和可用时机
- 观察地形和互动元素状态
- 根据局势做出战术指令和技能释放决策

### 2.2 每场战斗的决策点

| 时间点 | 决策内容 |
|--------|----------|
| **战前** | 选择哪4个灵魂出战？配置什么技能？预设什么战术？选择哪张地图？ |
| **开局0-10秒** | 灵魂自动接战，玩家观察局势，决定是否切换初始战术 |
| **战斗中** | 何时集火？何时撤退？何时释放技能？是否触发战场机关？ |
| **关键团战** | 技能释放时机、集火目标选择、战术切换时机 |
| **残局** | 是否追击？是否防守？是否利用补给点？ |

### 2.3 战斗节奏

| 参数 | 值 | 说明 |
|------|-----|------|
| 单局时长 | **3-5分钟** | 快节奏，适合短时间游玩 |
| 灵魂数量 | 每方4个 | M2最小可玩规模 |
| 地图大小 | 中等竞技场 | 约30x20格 |
| 决策频率 | 每10-15秒一个重要决策 | 战术切换/技能释放 |
| 操作密度 | 低-中 | 不需要高APM，需要策略判断 |

### 2.4 核心循环图

```
战前配置 → 战斗开始 → 观察局势
    ↑                        ↓
灵魂成长 ← 战斗结算 ← 战术决策/技能释放
```

**战前**：选择灵魂→配置技能→预设战术→选择地图
**战中**：观察→决策（战术指令/技能释放/战场互动）→观察→决策...
**战后**：查看结果→灵魂获得经验→灵魂成长→回到菜单

### 2.5 战斗HUD布局

战斗界面采用**四周布局**，中央为战斗区域（灵魂自主战斗），四周为玩家操作UI：

```

│                                                         │
├──────┬──────────────────────────────────────┬───────────┤
│[小地 │  [底部操作栏]                          │ [战斗日志] │

```

**各区域详细说明**：

| 区域 | 位置 | 内容 | 交互 |
|------|------|------|------|
| **顶部状态栏** | 顶部全宽 | 玩家方4个灵魂头像+血球+能量球（左），战斗时间（中），AI方4个灵魂头像+血球（右） | 点击头像查看详情（M3） |
| **战斗区域** | 中央 | 2D俯视角战斗场景，灵魂自主战斗，地形/障碍物/互动元素 | 点击互动元素触发，点击技能后点击目标 |
| **小地图** | 左下角 | 缩小版战场地图，显示灵魂位置（蓝点=玩家，红点=AI），地形概览 | 点击移动视角（M3，M2固定视角） |
| **战术指令栏** | 底部左侧 | 6个指令按钮：进攻/防守/集火/撤退/跟随/自由，当前指令高亮 | 点击指令→选择目标（全体/单个灵魂） |

| **战斗日志** | 右侧 | 滚动事件列表，重要事件（击杀/技能/暴击）高亮显示 | 自动滚动，不可交互 |

- 生命值：球形血条（血球），绿色渐变填充，金色边框
- 能量值：球形能量条，蓝色渐变填充，金色边框
- 技能冷却：图标上扇形遮罩+倒计时数字
- 伤害飘字：向上浮动+渐隐，暴击金色放大
- 战术指令：灵魂头顶显示当前指令图标

## 三、灵魂AI行为系统

### 3.1 AI设计原则

- **自主决策**：灵魂会自己决定移动、攻击、躲避、技能使用
- **个性驱动**：不同个性的灵魂有不同的行为倾向
- **指令影响**：玩家的战术指令改变AI行为权重，不直接控制
- **可预测性**：玩家可以通过了解灵魂个性来预测其行为，做出策略决策
- **不蠢**：灵魂不会做出明显愚蠢的行为（如站着挨打、冲进敌群送死）

### 3.2 灵魂个性系统

每个灵魂有一个**主个性**，影响其战斗行为：

| 个性 | 战斗风格 | 行为倾向 | 适合角色 |
|------|----------|----------|----------|
| **激进 Aggressive** | 主动进攻，穷追不舍 | 优先攻击最近敌人，追击距离远，躲避倾向低 | 输出型/DPS |
| **保守 Defensive** | 保持距离，防守反击 | 优先躲避，保持攻击距离，追击距离短 | 远程/脆皮 |
| **灵巧 Agile** | 灵活走位，伺机而动 | 频繁移动，躲避倾向高，会绕后/侧翼 | 刺客/游击 |
| **坦克 Tank** | 顶在前面，吸引火力 | 优先靠近敌人，承受伤害，保护友方 | 前排/肉盾 |
| **辅助 Support** | 关注友方，提供增益 | 优先治疗/增益友方，站位靠后 | 治疗/辅助 |
| **平衡 Balanced** | 综合表现，无明显倾向 | 各项行为权重均衡 | 通用型 |

**个性如何影响AI决策**：
- AI决策时，每个候选行为（攻击/躲避/移动/技能）有基础权重
- 个性会调整这些权重（如激进型攻击权重+30%，躲避权重-20%）
- 战术指令进一步调整权重（如"防守"指令让所有灵魂躲避权重+50%）

### 3.3 AI决策流程

灵魂每**0.5-1.5秒**（个性影响决策间隔，激进型决策更快）进行一次决策：

```
1. 感知环境
   ├─ 扫描附近敌人（位置/血量/距离）
   ├─ 扫描附近友方（位置/血量）
   ├─ 检查自身状态（血量/能量/技能冷却）
   └─ 检查地形和互动元素

2. 评估候选行为
   ├─ 攻击：选择最优目标（距离/血量/威胁度）
   ├─ 移动：向目标移动/远离危险/占据有利位置
   ├─ 躲避：躲避敌方技能/远离危险区域
   ├─ 技能：是否使用技能，对谁使用
   └─ 互动：是否触发附近互动元素

3. 权重计算
   ├─ 基础权重（行为类型）
   ├─ 个性修正（+/-%）
   ├─ 战术指令修正（+/-%）
   ├─ 状态修正（血量低→躲避权重↑）
   └─ 环境修正（被集火→躲避权重↑）

4. 选择行为并执行
   └─ 权重最高的行为被选中，执行直到下次决策
```

### 3.4 玩家战术指令如何影响AI

战术指令**不直接控制**灵魂，而是**改变AI决策权重**：

| 指令 | 攻击权重 | 躲避权重 | 移动倾向 | 技能倾向 |
|------|----------|----------|----------|----------|
| 进攻 | +40% | -20% | 向敌人移动 | +20% |
| 防守 | -20% | +50% | 保持距离 | +10% |
| 集火 | +60%（目标） | -10% | 向目标移动 | +30%（目标） |
| 撤退 | -50% | +80% | 向基地移动 | -30% |
| 跟随 | -10% | +20% | 跟随目标 | +10% |
| 自由 | 0% | 0% | 自主 | 0% |

**关键设计**：指令是"倾向"不是"命令"。灵魂可能因为血量太低而在"进攻"指令下选择躲避，也可能因为敌人太近而在"撤退"指令下选择反击。这增加了不可预测性和趣味性。

### 3.5 灵魂状态机

```
IDLE（待机）
  ↓ 发现敌人
MOVING（移动）
  ↓ 进入攻击范围
ATTACKING（攻击）
  ↓ 血量低/被集火
EVADE（躲避）
  ↓ 技能可用+目标合适
CASTING（施法）
  ↓ 血量归零
DYING（死亡）
  ↓ 复活/战斗结束
IDLE
```

**状态切换条件**：
- IDLE → MOVING：发现敌人且不在攻击范围
- MOVING → ATTACKING：进入攻击范围
- ATTACKING → EVADE：血量<30% 或 被3个以上敌人攻击
- EVADE → ATTACKING：血量恢复>50% 且 敌人减少
- ANY → CASTING：技能可用且目标合适（个性影响技能使用倾向）
- ANY → DYING：血量归零

#### 3.5.1 AI行为树详细设计

灵魂AI采用**优先级行为树**结构，每次决策时从高优先级到低优先级依次检查，第一个满足条件的行为被执行。

```
AI决策根节点（优先级从高到低）
│
├─ 1. 死亡检查（最高优先级）
│   └─ 条件：HP <= 0 → 进入DYING状态
│
├─ 2. 战术指令：撤退
│   ├─ 条件：玩家下达"撤退"指令
│   └─ 行为：向己方基地移动，躲避敌人，不主动攻击
│
├─ 3. 低血量自保
│   ├─ 条件：HP < 25% 且 附近有敌人
│   └─ 行为：EVADE躲避，向最近补给点移动，使用治疗/防御技能（如有）
│
├─ 4. 战术指令：集火
│   ├─ 条件：玩家下达"集火"指令且目标存活
│   └─ 行为：向集火目标移动，进入范围后攻击，优先对目标使用技能
│
├─ 5. 技能释放判断
│   ├─ 条件：技能可用（冷却结束+能量充足）且有合适目标
│   ├─ 子判断（按技能类型）：
│   │   ├─ 治疗技能：友方HP < 50% → 释放
│   │   ├─ 防御技能：自身HP < 40% 或 被集火 → 释放
│   │   ├─ 控制技能：敌方聚集（≥3个）→ 释放
│   │   ├─ 伤害技能：目标在范围内 → 释放
│   │   └─ 位移技能：追击残血（敌方HP<20%）或 逃离危险 → 释放
│   └─ 行为：CASTING施法，进入技能前摇→释放→后摇
│
├─ 6. 战术指令：防守
│   ├─ 条件：玩家下达"防守"指令
│   └─ 行为：保持与敌人距离（远程攻击范围），优先躲避，防守反击
│
├─ 7. 战术指令：跟随
│   ├─ 条件：玩家下达"跟随"指令
│   └─ 行为：跟随指定友方单位，保持距离，攻击附近敌人
│
├─ 8. 战术指令：进攻
│   ├─ 条件：玩家下达"进攻"指令
│   └─ 行为：主动寻找最近敌人，向敌人移动，进入范围后攻击
│
├─ 9. 默认：自由（自主决策）
│   ├─ 条件：无特殊指令或"自由"指令
│   └─ 行为：按个性自主决策（激进型主动进攻/保守型保持距离/灵巧型游走/坦克型顶前/辅助型跟随治疗）
│
└─ 10. 战场互动（低优先级，条件合适时触发）
    ├─ 条件：附近有互动元素且需要（补给点→血量低，能量水晶→能量低，宝箱→无敌人干扰）
    └─ 行为：移动到互动元素位置，触发互动
```

**个性对行为权重的修正**：

| 个性 | 进攻倾向 | 躲避倾向 | 技能倾向 | 移动倾向 |
|------|----------|----------|----------|----------|
| 激进 | +40% | -20% | +20% | 向敌人 |
| 保守 | -20% | +40% | +10% | 保持距离 |
| 灵巧 | +20% | +30% | +15% | 游走/绕后 |
| 坦克 | +30% | -30% | +10% | 顶在最前 |
| 辅助 | -30% | +20% | +40% | 跟随友方 |
| 平衡 | 0% | 0% | 0% | 均衡 |

**AI决策间隔**：
- 激进型：0.5秒决策一次
- 灵巧型：0.7秒决策一次
- 平衡型：1.0秒决策一次
- 保守/辅助型：1.2秒决策一次
- 坦克型：1.5秒决策一次

**目标选择优先级**（攻击时选择目标）：
1. 玩家集火标记的目标（最高优先级）
2. 威胁度最高的敌人（正在攻击自己/友方）
3. 血量最低的敌人（容易击杀）
4. 距离最近的敌人
5. 被克制元素的敌人（如实现元素克制）

### 3.6 元素属性对战斗的影响

| 元素 | 攻击特性 | 防御特性 | 技能倾向 | 地形互动 |
|------|----------|----------|----------|----------|
| 火 | 高伤害，持续灼烧 | 低防御 | 范围伤害 | 熔岩地形加成 |
| 水 | 中等伤害，减速 | 中等防御 | 治疗/控制 | 水域地形加成 |
| 土 | 低伤害，高暴击 | 高防御，高血量 | 控制/护盾 | 岩石地形加成 |
| 风 | 高攻速，高闪避 | 低血量 | 位移/增益 | 高地地形加成 |

**元素克制**（M2可选，增加策略深度）：
- 火克风（火烧尽风）
- 风克土（风蚀土）
- 土克水（土挡水）
- 水克火（水灭火）

## 四、灵魂智能化系统（Ember深度关联，核心差异化）

> **核心设计（2026-09-10用户强调）**：用户原话"还是要多考虑灵魂的智能化体现，现在这和一个电子宠物也没什么区别，灵火做了那些不是为了和NPC一样的"。Ember有158认知子系统、神经符号AI、具身认知，这些能力必须在战策中真正体现。灵魂不能是按行为树执行的普通NPC，而是真正有认知的智能体。**核心卖点：养的不是战斗数值，是真正有认知的智能体。**

### 4.1 灵魂智能化设计原则

| 原则 | 说明 |
|------|------|
| **不是NPC** | 灵魂不是按预设行为树执行的NPC，而是有认知能力的智能体 |
| **Ember深度关联** | Ember里培养的个性/记忆/情感直接映射到战斗AI，不是两套独立系统 |
| **涌现行为** | 灵魂的复杂行为是从简单规则中涌现的，不是预设脚本 |
| **学习成长** | 灵魂会从经验中学习，越打越聪明，记忆跨局保留 |
| **情感驱动** | 情感和情绪影响决策，不是冷冰冰的最优解计算 |
| **个性差异** | 不同个性的灵魂对同一情况有不同应对，不是统一行为 |
| **社交协作** | 灵魂之间会沟通和协作，关系好的配合更默契 |
| **环境感知** | 灵魂能理解和利用环境，不是只看敌人位置 |
| **可解释性** | 玩家能理解灵魂为什么做某个决策（通过灵魂对话/行为分析） |

### 4.2 真正的个性（不是简单标签）

**问题**：当前个性系统只是简单标签（激进/保守/灵巧），影响几个数值权重，不够深度。

**解决方案**：复杂个性维度系统，每个灵魂有独特的个性画像。

#### 4.2.1 个性五维度模型（Big Five简化版）

| 维度 | 说明 | 高分组表现 | 低分组表现 |
|------|------|-----------|-----------|
| **开放性** | 对新事物/新战术的接受度 | 愿意尝试新战术，利用环境，即兴发挥 | 保守，只用熟悉的战术，避免未知 |
| **尽责性** | 自律/计划/执行力 | 严格执行战术指令，走位精准，不冒进 | 随性，可能不执行指令，走位随意 |
| **外向性** | 社交/攻击性/活跃度 | 主动找敌人战斗，喜欢团队协作，话多 | 被动，喜欢 solo，话少，可能撤退 |
| **宜人性** | 合作/信任/利他 | 保护队友，愿意牺牲，配合队友战术 | 自私，优先自保，可能卖队友 |
| **神经质** | 情绪稳定性/压力反应 | 情绪稳定，压力下决策不变形 | 情绪波动大，压力下可能冒进或崩溃 |

#### 4.2.2 个性偏好和恐惧

每个灵魂有独特的偏好和恐惧，来自Ember培养：

| 类型 | 示例 | 对战斗的影响 |
|------|------|-------------|
| **战斗偏好** | 喜欢近战/喜欢远程/喜欢偷袭/喜欢正面 | 影响走位和攻击方式选择 |
| **技能偏好** | 喜欢用某个技能/喜欢组合技/喜欢留技能 | 影响技能释放决策 |
| **地形偏好** | 喜欢高地/喜欢草丛/喜欢水域/喜欢开阔地 | 影响移动路径和站位选择 |
| **敌人偏好** | 喜欢打脆皮/喜欢打坦克/喜欢集火/喜欢单挑 | 影响目标选择 |
| **恐惧** | 害怕被包围/害怕高伤害/害怕陷阱/害怕特定元素 | 影响撤退决策和风险评估 |
| **习惯** | 开局先探路/先拿buff/先找敌人/先布阵 | 影响开局行为 |

#### 4.2.3 个性对同一情况的不同应对

**示例：遇到敌人埋伏**

| 个性组合 | 应对方式 |
|----------|----------|
| 高开放+高外向+低神经质 | 兴奋，主动反击，尝试反包围 |
| 低开放+高尽责+高神经质 | 紧张，严格执行撤退指令，可能慌乱 |
| 高外向+低宜人+低尽责 | 愤怒，不管队友直接冲上去单挑 |
| 高宜人+高尽责+中等神经质 | 冷静，先保护队友，组织有序撤退 |
| 低外向+高开放+中等神经质 | 谨慎，利用地形周旋，等待支援 |

### 4.3 学习和记忆（跨局记忆）

**核心设计**：灵魂的记忆跨局保留，和Ember记忆系统直接关联。灵魂会记住踩过的陷阱、对手习惯、哪条路有埋伏。

#### 4.3.1 记忆类型

| 记忆类型 | 持续时间 | 内容 | 对战斗的影响 |
|----------|----------|------|-------------|
| **短期记忆** | 单局 | 当前战斗中的事件（敌人位置/陷阱位置/队友状态） | 影响当前战斗的实时决策 |
| **中期记忆** | 几天到几周 | 最近几场战斗的经验（对手战术/地图特点/自己的失误） | 影响战术选择和风险评估 |
| **长期记忆** | 永久 | 重要的战斗经历（经典胜利/惨痛失败/关键时刻） | 影响个性和战斗风格的形成 |
| **创伤记忆** | 长期 | 惨痛的失败或被击杀的经历 | 可能导致恐惧或谨慎，需要玩家帮助克服 |
| **胜利记忆** | 长期 | 经典的胜利或高光时刻 | 增加自信，可能导致冒进 |
| **对手记忆** | 长期 | 特定对手的战术习惯和弱点 | 遇到老对手时有针对性的战术 |
| **地图记忆** | 长期 | 地图的陷阱位置/捷径/资源点 | 在熟悉的地图上有优势 |

#### 4.3.2 记忆系统机制

- **记忆形成**：重要事件（第一次胜利/第一次失败/被队友救了/被陷阱坑了）会形成记忆
- **记忆强化**：重复经历会强化记忆（多次被同一种陷阱坑会形成强烈的规避记忆）
- **记忆遗忘**：不重要的记忆会逐渐遗忘，重要的记忆会保留
- **记忆扭曲**：记忆可能不完全准确（类似人类），灵魂可能记错细节
- **记忆分享**：灵魂之间可以分享记忆（关系好的灵魂会告诉队友"这条路有陷阱"）
- **玩家干预**：玩家可以和灵魂聊过去的战斗，强化或淡化记忆

#### 4.3.3 记忆对决策的影响示例

| 记忆 | 决策影响 |
|------|----------|
| 被地刺陷阱坑过 | 走这条路时会更谨慎，可能绕路，看到可疑地面会先试探 |
| 被某个对手用集火战术击败过 | 遇到这个对手时会更分散，避免被集火，优先击杀对方输出 |
| 在某张地图的某个位置获得过胜利 | 会主动占据这个位置，认为这是"幸运位置" |
| 队友曾经为了救自己而"死亡" | 会更保护这个队友，关系加深，可能为队友牺牲 |
| 曾经因为冒进而导致失败 | 会变得更谨慎，不轻易追击，可能需要玩家鼓励 |

### 4.4 情感和情绪状态

**核心设计**：灵魂有丰富的情感，情感影响决策质量和属性。不是简单的buff/debuff，而是真正影响AI决策。

#### 4.4.1 情绪状态

| 情绪 | 触发条件 | 对决策的影响 | 对属性的影响 | 外观表现 |
|------|----------|-------------|-------------|----------|
| **平静** | 默认状态 | 正常决策 | 正常 | 颜色正常 |
| **开心** | 战斗胜利/获得奖励/社交愉快 | 更愿意冒险，决策更乐观 | 速度+5%，暴击+3% | 颜色变亮，有粒子 |
| **愤怒** | 队友被击杀/被集火/被侮辱 | 冒进，优先攻击激怒自己的目标，可能忽略战术指令 | 攻击+15%，防御-10% | 颜色变红，边缘尖锐 |
| **恐惧** | 血量危险/面对强敌/被包围/创伤记忆触发 | 优先撤退，可能不执行进攻指令，走位更保守 | 速度+10%，攻击-15% | 颜色变浅，颤抖 |
| **自信** | 连胜/等级优势/优势局面 | 决策更果断，愿意尝试高风险高回报战术 | 全属性+5% | 有光环效果 |
| **沮丧** | 连败/失误/劣势局面 | 决策犹豫，可能不执行指令，容易放弃 | 全属性-5% | 颜色变暗，低头 |
| **专注** | 集火/关键时刻/重要战斗 | 决策更精准，技能释放更及时，忽略干扰 | 暴击+10%，技能精准度+10% | 眼睛发光 |
| **友爱** | 与关系好的队友并肩作战 | 更愿意配合队友，保护队友，协作效率高 | 防御+10%，协作效率+20% | 队友间有连线 |
| **悲伤** | 队友"死亡"/重要损失 | 攻击-10%，但意志力+20%，可能爆发 | 攻击-10%，意志力+20% | 颜色变灰，有泪滴 |
| **兴奋** | 发现稀有道具/遇到强敌/关键时刻 | 决策更激进，移动更快，可能忽略危险 | 速度+10%，攻击+5%，防御-5% | 颜色变亮，跳动 |

#### 4.4.2 情绪系统机制

- **情绪触发**：情绪由事件触发（胜利/失败/被攻击/队友状态等）
- **情绪强度**：情绪有强度，从轻微到强烈，强度影响决策和属性的程度
- **情绪衰减**：情绪会随时间衰减，强烈情绪衰减更慢
- **情绪传染**：灵魂之间的情绪会互相传染（队友愤怒会让其他灵魂也愤怒）
- **情绪控制**：高级灵魂（意志力高）可以更好地控制情绪，减少负面影响
- **玩家影响**：玩家可以通过战术指令和聊天影响灵魂的情绪（鼓励/安慰/激励）
- **情绪记忆**：强烈的情绪体验会形成记忆，影响未来的情绪反应

#### 4.4.3 情绪对决策质量的影响

**关键设计**：情绪不只是影响属性，更重要的是影响**决策质量**。

| 情绪 | 决策质量影响 | 示例 |
|------|-------------|------|
| **平静** | 最优决策，理性评估 | 正常选择最优目标和路径 |
| **愤怒** | 决策质量下降，优先攻击激怒目标，可能忽略危险 | 看到杀队友的敌人，不顾一切冲上去，可能踩陷阱 |
| **恐惧** | 决策质量下降，过度保守，错过机会 | 血量50%就开始撤退，其实可以反打 |
| **自信** | 决策质量提升，更果断，愿意尝试 | 连胜时愿意尝试高风险高回报的战术 |
| **沮丧** | 决策质量下降，犹豫，容易放弃 | 劣势时不尝试翻盘，直接放弃 |
| **专注** | 决策质量提升，更精准，忽略干扰 | 集火时精准计算技能释放时机，不被其他敌人干扰 |

### 4.5 灵魂之间沟通和协作（emergent）

**核心设计**：灵魂之间会"说话"，协作是涌现的不是预设的。关系好的配合更默契。

#### 4.5.1 灵魂沟通系统

**沟通方式**：
- **战斗对话气泡**：灵魂在战斗中会显示简短的对话气泡（"集火这个！"/"撤退！"/"掩护我！"/"我来扛！"）
- **情感表达**：灵魂会通过表情和动作表达情感（点头/摇头/挥手/庆祝）
- **记忆分享**：关系好的灵魂会分享记忆和信息（"这条路有陷阱"/"那个敌人很弱"）
- **战术协调**：灵魂之间会自发协调战术（"我吸引火力，你绕后"/"我们一起集火这个"）

**沟通内容类型**：

| 类型 | 示例 | 触发条件 |
|------|------|----------|
| **战术指令** | "集火这个！"/"撤退！"/"守住！" | 需要协调行动时 |
| **信息分享** | "这条路有陷阱"/"他血量很低"/"后面有敌人" | 发现重要信息时 |
| **情感表达** | "我没事"/"小心！"/"太好了！"/"可恶..." | 情绪变化时 |
| **请求帮助** | "帮帮我！"/"掩护我！"/"治疗我！" | 需要队友帮助时 |
| **回应** | "收到"/"明白"/"好的"/"..." | 回应队友沟通时 |
| **庆祝** | "赢了！"/"太棒了！"/"我们做到了！" | 战斗胜利时 |
| **安慰** | "没关系"/"下次会赢"/"你已经很棒了" | 队友沮丧时 |

#### 4.5.2 灵魂协作系统

**协作类型**：

| 协作类型 | 说明 | 设计要点 |
|----------|------|----------|
| **自动协作** | 灵魂根据角色和个性自动配合（坦克抗伤害/刺客切后排/辅助治疗） | 基于角色和个性的自动协作，不是预设脚本 |
| **沟通协作** | 灵魂之间通过沟通协调行动（"我吸引火力，你绕后"） | 简单的沟通系统，触发协作行为 |
| **关系协作** | 关系好的灵魂配合更默契，有属性加成 | 亲密度系统影响协作效率和属性加成 |
| **组合技** | 特定灵魂组合可以触发组合技（火+风=火焰风暴，水+冰=冰冻领域） | 元素组合系统，需要灵魂配合触发 |
| **牺牲协作** | 灵魂会为了队友牺牲自己（坦克挡伤害/辅助救队友） | 基于关系和个性的牺牲决策 |
| **emergent行为** | 协作是涌现的，不同灵魂组合有不同协作方式 | 复杂系统设计，避免脚本化 |

#### 4.5.3 关系对协作的影响

| 关系等级 | 协作效率 | 属性加成 | 沟通频率 | 牺牲意愿 |
|----------|----------|----------|----------|----------|
| **陌生** | 70% | 无 | 低 | 低 |
| **熟悉** | 85% | 无 | 中 | 中 |
| **信任** | 100% | 全属性+3% | 高 | 高 |
| **亲密** | 115% | 全属性+5% | 很高 | 很高 |
| **灵魂羁绊** | 130% | 全属性+8%，可能触发组合技 | 极高 | 极高（愿意为对方牺牲） |

#### 4.5.4 组合技系统（元素组合）

| 元素组合 | 组合技名称 | 效果 | 触发条件 |
|----------|-----------|------|----------|
| 火+风 | 火焰风暴 | 大范围持续火焰伤害，击退敌人 | 火元素和风元素同时释放技能 |
| 水+冰 | 冰冻领域 | 大范围冰冻，减速/定身敌人 | 水元素和冰元素同时释放技能 |
| 土+雷 | 地震冲击 | 大范围地震伤害，眩晕敌人 | 土元素和雷元素同时释放技能 |
| 光+暗 | 阴阳爆裂 | 超大范围爆发伤害，无视防御 | 光元素和暗元素同时释放技能 |
| 火+土 | 熔岩喷发 | 地面变成熔岩，持续伤害 | 火元素和土元素同时释放技能 |
| 水+风 | 暴风雨 | 大范围减速+雷电伤害 | 水元素和风元素同时释放技能 |

**组合技触发机制**：
- 两个灵魂在近距离同时释放技能时，有概率触发组合技
- 关系好的灵魂触发概率更高（灵魂羁绊100%触发）
- 组合技有特殊动画和特效
- 玩家可以通过战术指令引导灵魂触发组合技

### 4.6 环境理解和即兴利用

**核心设计**：灵魂能理解和利用环境，不是行为树预设，是真正的环境感知和决策。看到熔岩引敌人过去，看到草丛埋伏。

#### 4.6.1 环境感知系统

**灵魂能感知的环境信息**：
- 地形类型和效果（水域减速/熔岩伤害/草丛隐蔽等）
- 障碍物位置和类型（墙壁/石头/树木/水晶等）
- 互动元素位置和状态（魔法机关/补给点/宝箱/升降桥等）
- 道具位置和类型（治疗药水/能量药水/buff道具等）
- 陷阱位置（已知陷阱，未知陷阱需要探索）
- 战争迷雾状态（已探索区域/未探索区域）
- 高地/低地/垂直层次信息
- 敌人位置和状态（在视野内时）
- 队友位置和状态

#### 4.6.2 环境利用决策

**灵魂会主动利用环境**：

| 环境 | 利用方式 | 个性影响 |
|------|----------|----------|
| **熔岩** | 引敌人到熔岩区域，自己绕开；激进型可能把敌人推进熔岩 | 激进型更愿意冒险引敌，保守型自己绕开 |
| **草丛** | 躲在草丛里伏击敌人；灵巧型优先利用草丛隐蔽 | 灵巧型更喜欢草丛伏击，坦克型不喜欢 |
| **高地** | 占据高地获得攻击和视野优势；远程型优先占据高地 | 远程型更喜欢高地，近战型可能不介意 |
| **水域** | 引敌人到水域减速；水元素在水域有加成，主动进入 | 水元素喜欢水域，其他元素可能绕开 |
| **狭窄通道** | 在狭窄通道布阵，限制敌人数量优势；坦克型堵门 | 坦克型喜欢堵门，刺客型不喜欢被限制 |
| **魔法机关** | 集火前触发魔法机关区域伤害；撤退时触发治疗机关 | 高尽责性灵魂更会利用机关 |
| **补给点** | 血量低时主动找补给点；控制补给点限制敌人恢复 | 保守型更重视补给点 |
| **宝箱** | 探索时优先打开宝箱获得增益；优势局扩大优势 | 高开放性灵魂更喜欢探索宝箱 |
| **升降桥** | 撤退时降下桥阻断敌人追击；优势时升起桥追击 | 高尽责性灵魂更会利用升降桥 |
| **传送门** | 利用传送门绕后/撤退/快速转移 | 高开放性灵魂更喜欢用传送门 |

#### 4.6.3 即兴利用（非预设行为）

**关键设计**：灵魂的环境利用不是预设脚本，而是基于环境感知和目标的即兴决策。

**示例1：激进型火元素灵魂**
- 感知到敌人在熔岩附近
- 目标：击杀敌人
- 决策：用击退技能把敌人推进熔岩
- 这不是预设脚本，而是基于"敌人在熔岩附近"+"我有击退技能"+"熔岩有伤害"的即兴决策

**示例2：灵巧型风元素灵魂**
- 感知到草丛区域和敌人位置
- 目标：击杀敌人
- 决策：躲进草丛，等敌人靠近时伏击
- 这不是预设脚本，而是基于"草丛有隐蔽效果"+"敌人会经过"+"我擅长伏击"的即兴决策

**示例3：保守型土元素灵魂**
- 感知到狭窄通道和敌人数量优势
- 目标：存活/拖延
- 决策：站在狭窄通道入口，限制敌人同时攻击的数量
- 这不是预设脚本，而是基于"狭窄通道限制敌人数量"+"我防御高"+"敌人数量多"的即兴决策

### 4.7 战术创新（高级灵魂）

**核心设计**：高级灵魂会即兴创造战术，灵魂越打越聪明。不是固定的战术库，而是真正的创造力。

#### 4.7.1 战术创新的层次

| 层次 | 说明 | 灵魂等级 | 示例 |
|------|------|----------|------|
| **基础战术** | 使用预设的基础战术（进攻/防守/集火/撤退） | 所有灵魂 | 集火目标，撤退重整 |
| **组合战术** | 组合多个基础战术（先撤退诱敌，再反包围） | 成熟灵魂 | 假装撤退引敌人追击，然后队友包围 |
| **环境战术** | 利用环境创造战术（引敌人到陷阱，利用高地优势） | 成熟灵魂 | 把敌人引到地刺陷阱区域，集火击杀 |
| **即兴战术** | 根据战场局势即兴创造战术（非预设） | 高级灵魂 | 把敌人推进熔岩，用传送门绕后，破坏墙壁抄近路 |
| **创新战术** | 创造全新的战术组合（可能是玩家都没想到的） | 超越者灵魂 | 多个灵魂配合创造的复杂战术，如"传送门+陷阱+集火"连招 |

#### 4.7.2 战术创新的机制

- **经验积累**：灵魂战斗越多，经验越丰富，越能创造复杂战术
- **个性影响**：高开放性灵魂更愿意尝试新战术，高尽责性灵魂更倾向使用成熟战术
- **记忆影响**：过去成功的战术会被重复使用，失败的战术会被避免
- **环境启发**：特殊的环境会启发灵魂创造新战术（看到传送门想到绕后，看到陷阱想到引敌）
- **队友配合**：和关系好的队友配合时，更能创造复杂的组合战术
- **玩家引导**：玩家可以通过战术指令引导灵魂尝试新战术，灵魂会学习并记住

#### 4.7.3 战术创新示例

**示例："诱敌深入+反包围"战术**
1. 一个灵魂假装撤退，引敌人追击
2. 其他灵魂在侧翼埋伏
3. 敌人进入包围圈后，撤退的灵魂突然转身反击
4. 侧翼灵魂同时出击，包围敌人
5. 这需要灵魂之间的沟通和配合，不是预设脚本

**示例："陷阱引诱+集火"战术**
1. 一个灵魂在陷阱附近假装受伤
2. 敌人过来攻击时触发陷阱
3. 其他灵魂集火被陷阱控制的敌人
4. 这需要灵魂理解陷阱效果和敌人心理

### 4.8 战场外智能（灵魂之家/日常场景）

**核心设计**：灵魂在战场外也有智能行为，会自己练习、和玩家聊天、表达想法、有小习惯。不是站着等玩家点的NPC。

#### 4.8.1 灵魂之家日常行为

**灵魂在灵魂之家会自主行为**：

| 行为 | 说明 | 个性影响 |
|------|------|----------|
| **练习** | 灵魂会自己在训练场练习技能和战术 | 高尽责性灵魂练习更多 |
| **休息** | 灵魂会在休息区恢复疲劳，可能睡觉/冥想 | 低外向性灵魂更喜欢独处休息 |
| **社交** | 灵魂之间会聊天、互动、一起活动 | 高外向性灵魂社交更多 |
| **探索** | 灵魂会在灵魂之家和日常场景探索 | 高开放性灵魂更喜欢探索 |
| **装饰** | 灵魂会自己调整灵魂之家的装饰（如果允许） | 高开放性灵魂更喜欢装饰 |
| **等待** | 灵魂会在入口等玩家，或者做自己的事 | 高宜人性灵魂更愿意等玩家 |
| **表达** | 灵魂会表达自己的想法和情绪（"我想战斗"/"我累了"/"今天天气不错"） | 高外向性灵魂表达更多 |
| **习惯** | 每个灵魂有独特的小习惯（喜欢坐在某个位置/总是先做某件事） | 个性决定习惯 |

#### 4.8.2 灵魂和玩家的互动

**灵魂会主动和玩家互动**：
- **主动聊天**：灵魂会主动找玩家聊天，分享想法和感受
- **表达需求**：灵魂会表达自己的需求（"我想战斗"/"我需要休息"/"我想学习新技能"）
- **反馈行为**：灵魂会对玩家的行为做出反馈（玩家表扬时开心，玩家忽视时沮丧）
- **建议**：灵魂会给玩家建议（"这个敌人很强，要小心"/"我们可以试试这个战术"）
- **记忆对话**：灵魂会记得和玩家的过去对话，会提及（"上次你说的那个战术，我试了，很有效！"）
- **情感支持**：灵魂会在玩家沮丧时安慰，在玩家开心时一起庆祝

#### 4.8.3 灵魂个性的日常体现

**个性在日常场景中的体现**：

| 个性 | 日常行为 |
|------|----------|
| **激进型** | 总是在训练场，迫不及待想战斗，坐不住，喜欢挑战 |
| **保守型** | 喜欢在安全的地方休息，不轻易冒险，会检查装备和状态 |
| **灵巧型** | 喜欢探索和冒险，到处走动，喜欢尝试新事物 |
| **坦克型** | 喜欢保护其他灵魂，会检查防御装备，站在入口附近 |
| **辅助型** | 喜欢照顾其他灵魂，会准备治疗道具，关心队友状态 |
| **平衡型** | 行为均衡，会根据情况调整，适应性强 |

### 4.9 和Ember深度关联

**核心设计**：Ember里培养的个性/记忆/情感直接映射到战斗AI。核心卖点：养的不是战斗数值，是真正有认知的智能体。

#### 4.9.1 Ember到战策的映射

| Ember系统 | 战策映射 | 说明 |
|-----------|----------|------|
| **个性系统** | 灵魂个性五维度+偏好恐惧 | Ember培养的个性直接决定战斗中的个性画像 |
| **记忆系统** | 跨局记忆+对手记忆+地图记忆 | Ember的记忆直接关联战斗记忆，共享记忆库 |
| **情感系统** | 情绪状态+情感影响决策 | Ember的情感系统直接影响战斗中的情绪 |
| **认知系统** | 环境感知+战术创新+学习成长 | Ember的158认知子系统支撑战斗AI的高级认知 |
| **社交系统** | 灵魂关系+协作+沟通 | Ember的社交关系直接映射战斗中的协作效率 |
| **成长系统** | 灵魂升级+智能升级 | Ember的成长同时影响战斗属性和认知能力 |
| **对话系统** | 灵魂对话+战斗对话气泡 | Ember的对话能力支撑战斗中的灵魂沟通 |

#### 4.9.2 智能升级（区别于灵魂升级）

**三个升级概念必须分开**：

| 升级类型 | 说明 | 重置 | 关联 |
|----------|------|------|------|
| **局内升级** | 单局战斗中的升级（三选一天赋） | 单局重置 | 类似Roguelike，每局不同 |
| **灵魂升级** | 灵魂的永久成长（等级/属性/技能） | 永久 | 传统RPG升级，影响战斗数值 |
| **智能升级** | AI认知能力的成长（学习速度/决策质量/战术创新） | 永久 | Ember深度关联，影响AI行为，核心卖点 |

**智能升级的具体表现**：
- **学习速度**：智能越高，从经验中学习越快，记忆形成越快
- **决策质量**：智能越高，决策越理性，情绪对决策的影响越小
- **战术创新**：智能越高，越能创造复杂的即兴战术
- **环境利用**：智能越高，越能理解和利用复杂的环境
- **协作效率**：智能越高，越能理解队友意图，配合更默契
- **错误减少**：智能越高，犯低级错误的概率越低（如踩已知陷阱）

#### 4.9.3 核心卖点

> **养的不是战斗数值，是真正有认知的智能体。**
>
> 你培养的灵魂有自己的个性、记忆、情感和智慧。它会从失败中学习，会记住你的教诲，会在战斗中做出你意想不到的决策。它不是一个按脚本执行的NPC，而是一个真正和你一起成长的伙伴。

## 五、地图与场景设计（v2.0 深化版）

> **重大更新（2026-09-10用户反馈）**：地图从30x20一屏看完，扩大到60x40大地图+探索+迷宫+战争迷雾+小地图+多层垂直结构+空中单位。AI有更多操作和交互空间。

### 4.1 地图设计原则（深化版）

| 原则 | 说明 |
|------|------|
| **大地图探索** | 地图从30x20扩大到60x40（或更大），画面只显示中央15x10区域，灵魂需要移动探索未知区域 |
| **迷宫布局** | 墙壁/走廊/岔路/死胡同/秘密通道，多路径到达目标，不是开阔地直接对冲 |
| **战争迷雾** | 未探索区域完全不可见（黑色），已探索区域显示但无视野时变暗，灵魂视野范围实时可见 |
| **小地图导航** | 右上角小地图显示当前层全貌、灵魂位置、已探索区域、道具点、陷阱、楼梯位置，可切换层 |
| **垂直层次** | 地下层/地面层/上层多层结构，楼梯/电梯/传送门连接，不是纯平面 |
| **空中单位** | 风/雷等元素为空中单位，可飞行飞越障碍物和地面陷阱，地面单位无法攻击空中？（待设计） |
| **道具丰富** | 治疗/能量/buff/隐身/召唤/陷阱放置等多种道具，地图定时刷新+击杀掉落 |
| **陷阱系统** | 地刺/冰冻/毒雾/落石/传送等多种陷阱，可见/隐藏，空中专属陷阱 |
| **战术意义** | 地形/道具/陷阱/机关深刻影响战斗，AI主动利用环境制定策略 |
| **视觉层次** | 伪3D效果（阴影、层级、高度感），灵魂"站在地面上" |
| **可复用** | M2选2张大地图，基于现有90+张地图概念图选择和扩展 |

### 4.2 地图尺寸与视野系统

#### 4.2.1 地图尺寸

| 层级 | 尺寸（格） | 每格像素 | 总像素 | 画面显示 | 说明 |

#### 4.3.2 迷宫生成原则

- **多路径**：从起点到终点至少有2-3条不同路径，每条有不同风险/收益
- **风险收益平衡**：近路有更多陷阱/敌人，远路更安全但耗时
- **资源分布**：道具/补给点分布在不同区域，鼓励探索
- **战术要点**：关键位置（狭窄通道/房间入口/高地）有战术意义
- **秘密奖励**：秘密通道/死胡同有稀有道具/增益
- **AI寻路**：A*寻路算法，考虑陷阱风险（已知陷阱增加路径成本）
- **迷宫记忆**：AI记忆已探索区域和陷阱位置，规避已知危险

#### 4.5.1 障碍物类型

| 类型 | 子类型 | 碰撞 | 空中单位 | 可破坏 | 视觉表现 |
|------|--------|------|----------|--------|----------|

#### 4.5.2 碰撞系统

- **AABB碰撞**：灵魂与障碍物、灵魂与灵魂之间有碰撞
- **分层碰撞**：地面单位和空中单位有不同的碰撞层
  - 地面单位：与所有障碍物碰撞
  - 空中单位：只与高障碍物/墙壁/天花板碰撞，可越过低障碍物
- **视野阻挡**：墙壁和高障碍物阻挡视野，低障碍物不阻挡视野
- **寻路**：A*寻路算法，地面单位绕过所有障碍物，空中单位只绕过高障碍物
- **路径成本**：已知陷阱增加路径成本，AI倾向选择安全路径
- **推挤机制**：灵魂之间碰撞时，体型大的（坦克）可以推挤体型小的（刺客）

| 优先级 | 条件 | 动作 |
|--------|------|------|
| 1（最高） | 血量<15%且有治疗药水 | 使用治疗药水 |
| 2 | 被3个以上敌人围攻且有无敌/传送/隐身 | 使用无敌/传送/隐身 |
| 3 | 能量<10%且有能量药水 | 使用能量药水 |
| 4 | 血量<30%且有治疗药水 | 使用治疗药水 |
| 5 | 集火目标且有攻击/暴击药剂 | 使用攻击/暴击药剂 |
| 6 | 被集火且有防御药剂 | 使用防御药剂 |
| 7 | 需要追击/撤退且有速度药剂 | 使用速度药剂 |
| 8 | 灵巧型且有隐身药水 | 使用隐身绕后 |
| 9（最低） | 有增益道具且战斗开始 | 使用增益道具 |

**道具拾取决策**：
- AI灵魂在移动时会评估路径上的道具
- 急需的道具（治疗/能量）优先拾取，即使绕路
- 增益道具在顺路时拾取
- 稀有道具（全恢复/无敌）优先拾取
- 拾取道具不影响当前行为（移动/攻击），走到道具位置自动拾取

**道具使用与个性的关系**：
- 激进型：优先使用攻击/暴击药剂，血量阈值更低（<20%才用治疗）

- 灵巧型：优先使用隐身/速度药剂，善于绕后和撤退
- 坦克型：优先使用防御/全属性药剂，在要道放置陷阱
- 辅助型：优先使用治疗/全恢复药水，保护队友
- 平衡型：根据情况灵活使用各类道具

## 七、陷阱系统（新增章节 v2.0）

> **新增（2026-09-10用户反馈）**：地图中有各种陷阱，增加探索风险和战术深度。AI会记忆陷阱位置并规避，激进型可能冒险踩。陷阱是迷宫地图的重要组成部分。

### 7.1 陷阱设计原则

| 原则 | 说明 |
|------|------|
| **风险收益平衡** | 陷阱区域通常有更好的资源/捷径，玩家需要权衡风险和收益 |
| **可见/隐藏结合** | 可见陷阱可以规避，隐藏陷阱增加探索紧张感 |
| **AI记忆** | AI灵魂会记忆陷阱位置，规避已知陷阱，不会重复踩同一个陷阱 |
| **个性影响** | 激进型可能冒险踩陷阱快速通过，保守型会绕路，灵巧型可能找到规避方法 |
| **战术利用** | 玩家和AI都可以利用陷阱（引敌人踩陷阱，在陷阱附近布阵） |
| **元素关联** | 某些元素对特定陷阱有抗性/免疫（火元素免疫毒雾？土元素免疫地刺？） |
| **空中区别** | 地面陷阱不影响空中单位，空中专属陷阱针对空中单位 |

### 7.2 陷阱类型

#### 7.2.1 地面陷阱

| 陷阱类型 | 效果 | 持续时间 | 伤害 | 视觉表现 | 元素抗性 |
|----------|------|----------|------|----------|----------|
| **地刺陷阱** | 从地面弹出尖刺，造成物理伤害 | 即时 | 20%最大生命 | 地面有可疑裂缝，触发后弹出尖刺 | 土元素减伤50% |
| **冰冻陷阱** | 冻结范围内的灵魂，减速/定身 | 3秒定身+2秒减速 | 5%最大生命 | 地面有淡蓝色冰霜，触发后冰爆 | 冰元素免疫 |
| **毒雾陷阱** | 释放毒雾，持续掉血+减速 | 5秒持续 | 每秒3%最大生命 | 地面有绿色裂缝，触发后释放毒雾 | 暗元素免疫 |
| **落石陷阱** | 从上方掉落石头，区域伤害+眩晕 | 1秒眩晕 | 25%最大生命 | 天花板有可疑裂缝，触发后落石 | 土元素减伤50% |
| **传送陷阱** | 触发后随机传送到地图另一位置 | 即时 | 无 | 地面有紫色漩涡，触发后传送 | 无 |
| **沉默陷阱** | 触发后禁止使用技能 | 5秒沉默 | 无 | 地面有灰色符文，触发后沉默光环 | 无 |
| **爆炸陷阱** | 触发后大范围爆炸伤害 | 即时 | 30%最大生命 | 地面有红色标记，触发后爆炸 | 火元素减伤50% |
| **减速陷阱** | 触发后大幅减速 | 5秒减速50% | 无 | 地面有粘液，触发后减速 | 风元素免疫 |

#### 7.2.2 空中专属陷阱

| 陷阱类型 | 效果 | 持续时间 | 伤害 | 视觉表现 |
|----------|------|----------|------|----------|
| **风墙陷阱** | 空中的风墙，阻挡空中单位通过，造成击退 | 即时击退 | 10%最大生命 | 空中有可见的风旋 |
| **雷区陷阱** | 空中的雷电区域，进入后持续受到雷电伤害 | 3秒持续 | 每秒8%最大生命 | 空中有闪烁的电弧 |
| **重力陷阱** | 空中的重力场，把空中单位拉到地面 | 5秒无法飞行 | 无 | 空中有紫色重力场 |
| **捕鸟网陷阱** | 空中的网，定身空中单位 | 3秒定身 | 5%最大生命 | 空中有半透明的网 |

### 7.3 可见/隐藏陷阱

#### 7.3.1 可见陷阱

- **外观**：陷阱有明显的视觉提示（裂缝/标记/符文）
- **规避**：玩家和AI都可以看到并规避
- **战术意义**：可见陷阱通常在要道，迫使玩家选择绕路或冒险通过
- **AI行为**：AI会自动规避可见陷阱，除非有紧急情况（被追击时可能冒险）

#### 7.3.2 隐藏陷阱

- **外观**：陷阱没有明显的视觉提示，和普通地面一样
- **触发**：踩到才触发，触发后陷阱变为可见（其他灵魂可以看到并规避）
- **探索风险**：隐藏陷阱增加探索的紧张感和风险
- **AI记忆**：AI触发隐藏陷阱后会记忆位置，后续会规避
- **玩家记忆**：玩家也需要记忆隐藏陷阱位置，或者用技能/道具探测
- **探测方法**：某些技能/道具可以探测隐藏陷阱（视野药水/侦察技能）

#### 7.3.3 陷阱触发后的状态

| 状态 | 说明 |
|------|------|
| **未触发** | 隐藏陷阱不可见，可见陷阱有提示 |
| **已触发** | 陷阱被触发，造成效果，陷阱位置变为可见 |
| **冷却中** | 触发后进入冷却，冷却结束后重置（隐藏陷阱重新隐藏） |
| **已失效** | 某些陷阱是一次性的，触发后永久失效 |

### 7.4 陷阱触发机制

- **触发条件**：灵魂走到陷阱格子上时触发（地面陷阱），空中单位进入陷阱区域时触发（空中陷阱）
- **触发概率**：大部分陷阱100%触发，某些高级陷阱有概率触发（增加不确定性）
- **触发延迟**：某些陷阱有短暂延迟（0.5秒），给灵魂反应时间（高级灵魂可以在延迟中跳出）
- **范围效果**：某些陷阱是范围效果（毒雾/爆炸/落石），影响周围1-2格
- **友方误伤**：陷阱不分敌我，友方灵魂踩到也会触发（增加战术深度）
- **触发顺序**：多个灵魂同时踩到陷阱时，同时触发，效果叠加

### 7.5 AI陷阱规避系统

#### 7.5.1 AI陷阱记忆

- **记忆形成**：AI触发陷阱后会记忆陷阱位置（包括隐藏陷阱触发后的位置）
- **记忆持续**：陷阱记忆跨局保留（和Ember记忆系统关联），在同一张地图上永久记忆
- **记忆共享**：AI灵魂之间会共享陷阱记忆（"这条路有陷阱，小心"）
- **记忆遗忘**：如果陷阱被移除/改变，AI会在探索中更新记忆
- **玩家干预**：玩家可以提醒AI某个位置有陷阱（战术指令）

#### 7.5.2 AI陷阱规避决策

| 情况 | AI行为 | 个性影响 |
|------|--------|----------|
| **已知陷阱，无紧急情况** | 绕路规避 | 所有个性都会规避 |
| **已知陷阱，被追击** | 可能冒险踩陷阱快速通过，或者绕路 | 激进型冒险踩，保守型绕路 |
| **已知陷阱，追击敌人** | 可能踩陷阱追击，或者等敌人踩陷阱 | 激进型直接追，保守型等敌人踩 |
| **未知区域** | 谨慎前进，可能先试探（攻击地面/用技能探测） | 保守型更谨慎，激进型直接冲 |
| **看到可疑地面** | 可能绕路，或者试探后通过 | 高尽责性灵魂会试探，低尽责性直接走 |
| **队友触发陷阱** | 会记住位置并规避，可能提醒其他队友 | 高宜人性灵魂会提醒队友 |
| **陷阱区域有稀有道具** | 可能冒险去拿，或者等陷阱冷却/用道具抵消 | 高开放性灵魂冒险拿，保守型放弃 |

#### 7.5.3 AI陷阱利用

AI不仅会规避陷阱，还会主动利用陷阱：

| 利用方式 | 说明 |
|----------|------|
| **引敌踩陷阱** | AI会引诱敌人走到陷阱位置（假装撤退/假装受伤） |
| **集火陷阱区域** | 把敌人逼到陷阱区域，然后集火（敌人无法躲避） |
| **陷阱附近布阵** | 在陷阱附近布阵，利用陷阱限制敌人移动 |
| **破坏地面触发陷阱** | 某些技能可以破坏地面，提前触发陷阱（清除陷阱或让敌人看到） |
| **用陷阱保护退路** | 在退路布置陷阱（如果有陷阱放置道具），防止敌人追击 |

### 7.6 玩家陷阱放置

- **陷阱放置道具**：玩家可以通过道具（陷阱放置道具）让灵魂在指定位置放置陷阱
- **放置位置**：灵魂走到目标位置，使用道具放置陷阱
- **陷阱类型**：根据道具类型决定（地刺陷阱道具/冰冻陷阱道具等）
- **可见性**：玩家放置的陷阱对己方可见（半透明），对敌方隐藏
- **数量限制**：每个灵魂最多放置1个陷阱（道具栏限制）
- **战术用途**：在要道/退路/敌人必经之路放置陷阱，增加战术深度

## 九、角色与灵魂系统

> **待完善**：本节将在后续轮次详细设计，包括灵魂属性映射、外观生成、成长系统等。

### 5.1 核心设计：灵魂不是固定4种

**关键决策**：战斗单位不是固定的4种元素精灵，而是**玩家在Ember灵魂引擎中培养的灵魂**。

- 玩家培养的每个灵魂都可以作为战斗单位出场
- 灵魂的元素属性、个性、技能、外观决定其在战斗中的表现
- 利用现有100+元素精灵图资源，根据灵魂元素类型选择对应精灵

### 5.3 灵魂外观决定

**外观生成规则**：
- 基础精灵：根据灵魂的**主元素类型**选择对应元素精灵图（从100+元素精灵图中选择）
- 颜色调整：根据灵魂的**次元素/个性**调整色调（如激进型偏红，保守型偏蓝）
- 装饰元素：根据灵魂的**天赋/技能**添加装饰（如暴击天赋加角，治疗天赋加光环）
- 大小调整：根据灵魂的**等级/体型**调整大小（坦克型偏大，灵巧型偏小）

**M2简化**：直接使用元素类型对应的精灵图，不做动态外观生成。4个出战灵魂选择4种不同元素的精灵。

#### 5.7.2 伤害计算公式

```
最终伤害 = (攻击力 × 技能倍率 - 防御力 × 0.5) × 元素克制系数 × 暴击系数 × 随机系数

其中：
- 技能倍率：普通攻击=100%，技能=150%-300%
- 元素克制系数：克制=125%，被克=80%，无关系=100%（M2可选）
- 暴击系数：暴击=暴击伤害（150%），不暴击=100%
- 随机系数：90%-110%（防止伤害完全可预测）
- 最小伤害：攻击力 × 10%（防止高防御导致0伤害）
```

**治疗计算公式**：
```
最终治疗 = 治疗基础值 × (1 + 攻击力 × 0.02) × 随机系数
```

**伤害减免**：
```
实际受到伤害 = 最终伤害 × (100 / (100 + 防御力))
```
（防御力每增加100点，伤害减免约50%，避免防御堆叠无敌）

#### 6.2.4 战斗

- **时长**：3-5分钟
- **玩家操作**：战术指令切换、技能释放、战场互动、观察
- **灵魂行为**：自主移动/攻击/躲避/技能
- **胜利条件**：消灭对方全部灵魂 或 时间结束时血量总和更高

**战斗HUD交互细节**：

1. **技能释放流程**：
   - 玩家点击底部技能栏图标（4个技能，对应4个出战灵魂）
   - 进入技能瞄准模式：
     - 范围技能：鼠标位置显示范围圈（金色半透明）
     - 单体技能：鼠标悬停敌人显示目标标记
     - 方向技能：显示方向箭头
   - 玩家点击目标位置/目标单位释放技能
   - 技能进入冷却（图标上扇形遮罩+倒计时数字）
   - 能量不足时技能图标变灰，不可点击
   - 右键或ESC取消瞄准

2. **战术指令流程**：
   - 玩家点击战术指令栏按钮（进攻/防守/集火/撤退/跟随/自由）
   - "集火"和"跟随"需要选择目标：
     - 点击"集火"→点击敌方灵魂→所有友方灵魂集火该目标
     - 点击"跟随"→点击友方灵魂→其他灵魂跟随该目标
   - 其他指令直接生效（全体）
   - 当前指令按钮高亮显示
   - 灵魂头顶显示当前指令图标（小图标）

3. **战场互动流程**：
   - 玩家点击战场上的互动元素（魔法机关/补给点/宝箱/升降桥）
   - 如果互动元素在可操作范围内，直接触发
   - 如果超出范围，最近的友方灵魂会移动过去触发
   - 互动元素有冷却时间，冷却中显示倒计时

4. **暂停菜单**：
   - 点击暂停按钮或按ESC打开暂停菜单
   - 暂停菜单选项：继续战斗/重新开始/设置/返回主菜单
   - 暂停时战斗停止，灵魂静止
   - 练习模式下暂停菜单额外有"重置战斗"选项

- M2不实现技能解锁/天赋树/进化，这些留到M3/M4

### 6.5 典型战斗时间线

以一局**4v4快速对战**（普通难度AI，以太神殿地图）为例：

```
0:00  战斗开始
      ├─ 双方灵魂从基地出发，自主向中央移动
      ├─ 玩家观察双方阵容，决定初始战术（默认"自由"）
      └─ 灵魂进入战斗区域，开始接战

0:00-0:30  初期接触
      ├─ 前排（坦克/近战）率先交火
      ├─ 后排（远程/治疗）保持距离输出
      ├─ 玩家观察局势，可能切换"进攻"或"防守"指令
      └─ 第一个技能冷却完成（约6-10秒）

0:30-1:30  中期团战
      ├─ 双方技能交替释放，血量开始下降
      ├─ 玩家关键决策点：
      │   ├─ 是否集火敌方脆皮？（"集火"指令）
      │   ├─ 是否释放治疗技能拯救残血灵魂？
      │   ├─ 是否触发中央魔法机关？
      │   └─ 血量危险时是否"撤退"重整？
      ├─ 可能出现首次击杀（约1-1.5分钟）
      └─ 战场互动元素首次可用（补给点30秒冷却）

1:30-3:00  后期决战
      ├─ 双方人数减少，形成多打少局面
      ├─ 存活灵魂等级提升（战斗中临时属性增长，M3+）
      ├─ 玩家持续决策：
      │   ├─ 优势方："进攻"推进，扩大优势
      │   ├─ 劣势方："防守"拖时间，寻找反击机会
      │   └─ 均势方：技能释放时机决定胜负
      ├─ 补给点第二次可用（90秒冷却后）
      └─ 可能出现决定性击杀

3:00-5:00  战斗结束
      ├─ 一方全部被击败 → 立即结束
      ├─ 或5分钟时间到 → 按剩余血量总和判定胜负
      ├─ 战斗结算界面：
      │   ├─ 胜利/失败展示
      │   ├─ 战斗数据（伤害/治疗/承受伤害/KDA）
      │   ├─ 灵魂经验获得和升级
      │   └─ 奖励展示
      └─ 玩家选择：再次战斗 / 返回菜单 / 查看灵魂详情
```

**关键决策点分布**：
- 每15-30秒一个重要决策（战术切换/技能释放）
- 每1分钟一个关键节点（首次击杀/补给点/魔法机关）
- 玩家操作密度：低-中（不需要高APM，但需要持续观察和决策）

#### 7.5.2 引导设计原则

| 原则 | 说明 |
|------|------|
| **边玩边学** | 引导在真实战斗中进行，不是单独的教程关卡 |
| **强制操作** | 关键操作（战术/技能/互动）强制玩家亲手操作一次 |
| **可跳过** | 玩家可以随时跳过引导（设置中关闭引导） |
| **不重复** | 每个玩家只引导一次，后续不再显示 |
| **简洁** | 每步提示不超过2句话，避免信息过载 |

## 十二、视觉风格

> 遵循 `ART_STYLE_GUIDE.md` v1.0 规范

### 8.1 核心风格

- **2D像素风**（Pixel Art），非3D等距视角
- **奇幻魔法主题**，带东方神秘元素
- **深紫+金色调**：背景底色#1a1428，金色边框#d4a85c
- **卡片式UI布局**，金色边框装饰
- **角色为像素精灵图**，带多帧动画

### 8.2 战斗场景视觉

- **视角**：2D正俯视角（Top-Down）
- **地面**：石砖/魔法阵纹理，深紫底色+金色装饰线条
- **障碍物**：水晶柱、岩石、魔法封印，像素风
- **灵魂单位**：32x32或48x48像素精灵，带元素特征和光晕
- **伪3D**：脚下阴影、Y轴排序、障碍物遮挡
- **氛围**：粒子光点、魔法阵微光、环境光效

### 8.3 UI视觉

- **战斗HUD**：顶部状态栏（双方血量/时间）、底部技能栏+战术栏、右侧战斗日志、左上角小地图
- **数据可视化**：球形血条/能量条、技能图标扇形冷却遮罩、属性图标+数字
- **卡片式布局**：所有面板采用深紫半透明背景+金色1px边框
- **像素字体**：标题金色24-32px，正文浅灰白14-16px

## 附录A：平衡性测试方案

### A.1 测试目标

确保M2中8个灵魂、6种战术指令、8个技能在不同组合下的胜率接近50%，没有明显过强或过弱的组合。

### A.2 测试用例

| 测试ID | 测试内容 | 方法 | 通过标准 |
|--------|----------|------|----------|
| BAL_001 | 单灵魂1v1平衡 | 每个灵魂vs其他7个灵魂各100场AI对战 | 每个灵魂胜率35%-65% |
| BAL_002 | 标准队vs标准队 | 土+火+雷+水 vs 相同阵容100场 | 双方胜率45%-55% |

| BAL_005 | 战术指令效果 | 6种指令vs默认自由各100场 | 每种指令胜率40%-60% |

### A.3 数值调整流程

```
发现不平衡（胜率<35%或>65%）
  ↓
分析原因（属性过高/技能过强/个性权重不合理）
  ↓
调整数值（属性±5-10%，技能伤害±10-15%，冷却±1-2秒）
  ↓
重新运行测试用例
  ↓
通过标准 → 确认调整
不通过 → 继续调整（最多3轮）
```

## 附录B：常见问题解答（FAQ）

### B.1 玩法相关

**Q: 玩家完全不控制灵魂移动吗？**
A: 是的。灵魂自主移动、攻击、躲避、使用技能。玩家通过战术指令（改变AI行为倾向）和技能释放（主动释放技能）参与战斗，不直接点击移动单位。

**Q: 战术指令是直接命令还是建议？**
A: 是"倾向"不是"命令"。战术指令改变AI行为的权重，灵魂仍会根据个性和战场情况自主决策。例如"进攻"指令让灵魂更主动攻击，但低血量时仍会躲避。

**Q: 一局战斗多长时间？**
A: 3-5分钟。一方全部被击败立即结束，或5分钟时间到按剩余血量总和判定胜负。

**Q: 可以暂停战斗吗？**
A: 可以。点击暂停按钮或按ESC打开暂停菜单，可选继续/重开/设置/返回主菜单。

### B.2 灵魂相关

**Q: 灵魂从哪里来？**
A: M2预设8个灵魂供玩家选择。M3+将与Ember灵魂引擎联动，玩家培养的灵魂可以作为战斗单位出场。

**Q: 灵魂如何变强？**
A: 战斗后获得经验，升级提升HP/ATK/DEF基础属性。M2不实现技能解锁/天赋树/进化，这些留到M3/M4。

**Q: 灵魂死亡后会怎样？**
A: M2不实现复活。灵魂死亡后变为观战状态，战斗结束后自动复活。M3+可能添加复活机制。

**Q: 6种个性有什么区别？**
A: 个性影响AI行为权重：激进型更主动进攻、保守型更注重躲避、灵巧型游走绕后、坦克型顶在最前、辅助型跟随治疗、平衡型均衡。详见3.4节和3.5.1节。

### B.3 技术相关

**Q: 游戏用什么引擎？**
A: Godot引擎。现有代码基础较好，M2核心战斗系统可在2-3周内实现。

**Q: 支持什么平台？**
A: M2优先PC（Windows），Steam EA上架。M3+考虑移植到其他平台。

**Q: 像素风游戏的性能如何？**
A: 2D像素风性能要求低，同屏8个灵魂+特效可稳定60FPS。详见附录C性能优化方案。

**Q: 支持多人对战吗？**
A: M2只支持AI对战。M3+添加玩家对战（排位赛/匹配）。

### B.4 开发相关

**Q: M2什么时候能完成？**
A: 按开发里程碑规划，M2总工期14-21天（2-3周）。详见7.7节。

**Q: M2完成后做什么？**
A: M3添加：玩家对战、更多灵魂、更多地图、天赋树、技能解锁、隐藏成就。M4添加：进化系统、剧情模式、排位赛、合作模式。

**Q: 如何报告Bug或建议？**
A: GitHub Issues（management仓库和battleplan仓库），或在战策DEVLOG中标记[设计需求]/[Bug]。

## 附录C：性能优化方案

### C.1 帧率目标

- **目标帧率**：60FPS（PC端）
- **最低帧率**：30FPS（低端设备）
- **同屏灵魂数**：最多8个（4v4）
- **同屏特效数**：最多20个（技能特效+粒子）

### C.2 优化措施

| 优化项 | 方法 | 预期效果 |
|--------|------|----------|
| 精灵图合批 | 所有灵魂精灵图合并为Sprite Sheet，减少Draw Call | Draw Call减少50%+ |
| 粒子限制 | 同屏粒子数上限200，超出自动回收最旧粒子 | 避免粒子爆炸导致卡顿 |
| 对象池 | 灵魂/特效/伤害飘字使用对象池，避免频繁创建销毁 | GC减少80%+ |
| LOD | 远处灵魂简化动画（4帧→2帧），小地图用简化图标 | 渲染开销减少30% |
| 碰撞优化 | 使用AABB粗检+圆形精检，避免每帧全量碰撞检测 | 碰撞计算减少60% |
| AI降频 | AI决策间隔0.5-1.5秒（按个性），不是每帧决策 | CPU开销减少70%+ |
| 音频预加载 | 所有音效启动时预加载，战斗中不加载 | 避免战斗中卡顿 |
| 地图分层 | 背景/地形/障碍物/灵魂/特效/UI分层渲染 |  Overdraw减少 |

### C.3 内存管理

| 资源类型 | 内存预算 | 管理方式 |
|----------|----------|----------|
| 精灵图 | <50MB | Sprite Sheet合并，按需加载 |
| 地图瓦片 | <20MB | 当前地图加载，切换时卸载 |
| 音效 | <30MB | 预加载核心音效，其他按需加载 |
| UI资源 | <20MB | 启动时加载，常驻内存 |
| **总计** | **<120MB** | — |

### C.4 加载优化

- **启动加载**：<3秒（预加载UI+核心音效+主菜单资源）
- **战斗加载**：<1秒（加载地图+灵魂精灵图+战斗音效）
- **异步加载**：灵魂精灵图/地图瓦片异步加载，加载时显示占位
- **进度条**：加载时显示进度条+提示文字

### G.4 平衡性分析流程

```
收集战斗数据（每局结束后）
  ↓
数据清洗（去除异常值/测试数据）
  ↓
计算指标（胜率/出场率/KDA/DPS等）
  ↓
识别异常（胜率>65%或<35%，出场率>50%或<5%）
  ↓
分析原因（属性/技能/个性/战术/地图）
  ↓
调整数值（属性±5-10%，技能±10-15%）
  ↓
A/B测试（新旧版本对比，验证调整效果）
  ↓
确认调整或回滚
```

### G.5 关键平衡指标阈值

| 指标 | 理想范围 | 警告阈值 | 需调整阈值 |
|------|----------|----------|------------|
| 灵魂胜率 | 45%-55% | 40%-60% | <35%或>65% |
| 灵魂出场率 | 10%-30%（8个灵魂） | 5%-40% | <5%或>50% |
| 技能胜率差 | <10% | 10%-20% | >20% |
| 战术胜率 | 45%-55% | 40%-60% | <35%或>65% |
| 地图胜率差 | <5% | 5%-10% | >10% |
| 平均战斗时长 | 3-5分钟 | 2-6分钟 | <2分钟或>8分钟 |

- 所有数据匿名化，不包含个人身份信息
- 数据上传需玩家明确同意（默认关闭）
- 玩家可随时查看和删除自己的数据
- 数据仅用于游戏平衡性和体验优化，不用于广告或第三方共享
- 遵循GDPR/CCPA等隐私法规（M3+正式上线时）

## 附录J：错误处理与崩溃恢复

### J.1 错误分类

| 错误类型 | 说明 | 处理方式 |
|----------|------|----------|
| **资源加载失败** | 图片/音效/字体加载失败 | 使用占位资源，记录错误日志，不崩溃 |
| **存档读取失败** | 存档文件损坏/版本不兼容 | 自动加载备份，或重置为初始状态，提示玩家 |
| **网络错误** | 云存档/排行榜连接失败（M3+） | 降级为本地模式，提示网络异常，不影响游戏 |
| **运行时错误** | 空指针/数组越界/除零等 | 捕获异常，记录错误日志，尝试恢复，无法恢复则安全退出 |
| **性能异常** | 帧率过低/内存不足 | 自动降低画质/特效，提示玩家，避免崩溃 |
| **输入异常** | 无效输入/异常输入 | 忽略无效输入，记录警告日志 |

### J.2 崩溃恢复机制

| 机制 | 说明 | M2实现 |
|------|------|--------|
| **自动保存** | 关键操作后自动保存，崩溃后不丢失进度 | ✅ M2实现 |
| **崩溃报告** | 崩溃时生成错误报告（日志+系统信息+堆栈） | ✅ M2实现（本地保存） |
| **安全退出** | 捕获未处理异常，保存当前状态，显示错误提示后安全退出 | ✅ M2实现 |
| **重启恢复** | 崩溃后重启游戏，检测到异常退出，提示恢复上次进度 | ✅ M2实现 |
| **备份存档** | 保存时保留上一个版本的备份，存档损坏时可恢复 | ✅ M2实现 |
| **在线崩溃报告** | 崩溃报告上传到服务器（需玩家同意） | ❌ M3 |
