## 一、核心理念

### 1.1 这是什么游戏？

**战策 Battleplan 是一款"灵魂指挥官"策略对战游戏。**

玩家不直接操控单位移动，而是作为**灵魂指挥官**，指挥自己培养的灵魂战队在魔法竞技场中进行自主战斗。玩家通过**战术指令、技能释放、战前配置**影响战斗走向，而灵魂单位则根据自身的**个性、元素属性、AI行为**自主移动、攻击、躲避和使用技能。

**一句话描述游戏体验：**
> "你是灵魂的指挥官，不是傀儡师。你的灵魂会自己战斗，而你决定它们如何战斗。"

### 1.2 核心设计哲学

| 原则 | 说明 |
|------|------|
| **灵魂自主** | 灵魂单位有自己的个性和战斗风格，会自主决策移动/攻击/躲避/技能 |
| **玩家策略** | 玩家通过战术指令（进攻/防守/集火/撤退）和技能释放影响战斗，不直接点选移动 |
| **战前深度** | 战斗前的灵魂选择、技能配置、战术预设是核心策略深度 |
| **战中紧张** | 战斗中玩家需要观察局势、适时释放技能、切换战术指令，有参与感和紧张感 |
| **成长反馈** | 战斗后灵魂获得经验和成长，玩家能看到自己培养的灵魂变强 |

### 1.3 玩家与灵魂的关系

玩家不是"操控者"，而是"指挥官"和"培养者"：

- **培养关系**：玩家在Ember灵魂引擎中培养灵魂，灵魂有自己的个性、元素属性、技能树
- **指挥关系**：战斗中玩家下达战术指令，灵魂根据指令调整行为倾向，但不被精确控制
- **信任关系**：玩家需要了解每个灵魂的个性和战斗风格，合理配置战队，信任灵魂的自主战斗
- **成长关系**：灵魂在战斗中获得经验，个性和能力会随成长变化

### 1.4 与传统RTS的区别

| 维度 | 传统RTS（星际/魔兽） | 战策 Battleplan |
|------|----------------------|-----------------|
| 单位控制 | 玩家直接点选移动/攻击 | 灵魂自主移动/攻击，玩家下达战术指令 |
| 操作密度 | 高APM，精确微操 | 低操作密度，策略决策为主 |
| 单位个性 | 无个性，同类型单位行为一致 | 每个灵魂有独特个性，影响战斗表现 |
| 战前配置 | 种族/建筑/科技选择 | 灵魂选择/技能配置/战术预设 |
| 战中操作 | 造兵/升级/微操/多线 | 技能释放/战术切换/战场互动 |
| 核心技巧 | 操作速度+多线能力 | 策略判断+灵魂理解+时机把握 |

### 1.5 目标玩家

- 喜欢策略游戏但不喜欢高强度微操的玩家
- 喜欢收集/培养角色的玩家
- 喜欢看"自己的队伍"战斗的玩家（类似自走棋但有更多参与感）
- 喜欢奇幻魔法主题的玩家

## 二、核心玩法循环

### 2.1 战斗中玩家做什么？

玩家在战斗中**不直接控制单位移动**，而是通过以下方式参与战斗：

#### 2.1.1 战术指令系统（核心）

玩家可以对**全体灵魂**或**单个灵魂**下达战术指令，改变AI行为倾向：

| 指令 | 效果 | 适用场景 |
|------|------|----------|
| **进攻 Aggressive** | 灵魂主动寻找敌人，优先攻击，冒进倾向高 | 优势局、需要快速推进 |
| **防守 Defensive** | 灵魂保持距离，优先躲避，防守反击 | 劣势局、需要拖时间 |
| **集火 Focus** | 灵魂优先攻击玩家标记的目标 | 需要击杀关键目标 |
| **撤退 Retreat** | 灵魂向后撤退，脱离战斗 | 血量危险、需要重整 |
| **跟随 Follow** | 灵魂跟随玩家指定的友方单位 | 保护核心单位 |
| **自由 Free** | 灵魂完全自主决策，不干预 | 默认状态 |

**操作方式**：底部战术栏有6个指令按钮，点击后选择目标（全体/单个灵魂），指令会在灵魂头顶显示图标。

#### 2.1.2 技能释放系统

玩家可以在战斗中**主动释放灵魂的技能**（类似MOBA的技能栏）：

- 每个灵魂有1-2个主动技能
- 技能有冷却时间和能量消耗
- 玩家点击技能图标，然后选择目标位置/目标单位
- 技能释放有视觉特效和音效

**M2简化**：每个灵魂1个主动技能，4个灵魂共4个技能，底部技能栏4个图标。

#### 2.1.3 战场互动

地图上有可互动元素，玩家可以触发：

| 互动元素 | 效果 | 操作 |
|----------|------|------|
| 魔法机关 | 触发区域伤害/治疗/增益 | 点击机关 |
| 补给点 | 恢复附近灵魂的生命/能量 | 灵魂走到补给点自动触发 |
| 可破坏物 | 破坏后获得增益/打开通路 | 灵魂攻击可破坏物 |
| 地形机关 | 升降桥/闸门，改变通路 | 点击开关 |

#### 2.1.4 观察与决策

玩家需要持续观察战场：

- 观察灵魂血量/能量状态
- 观察敌方灵魂位置和意图
- 观察技能冷却和可用时机
- 观察地形和互动元素状态
- 根据局势做出战术指令和技能释放决策

### 2.2 每场战斗的决策点

| 时间点 | 决策内容 |
|--------|----------|
| **战前** | 选择哪4个灵魂出战？配置什么技能？预设什么战术？选择哪张地图？ |
| **开局0-10秒** | 灵魂自动接战，玩家观察局势，决定是否切换初始战术 |
| **战斗中** | 何时集火？何时撤退？何时释放技能？是否触发战场机关？ |
| **关键团战** | 技能释放时机、集火目标选择、战术切换时机 |
| **残局** | 是否追击？是否防守？是否利用补给点？ |

### 2.3 战斗节奏

| 参数 | 值 | 说明 |
|------|-----|------|
| 单局时长 | **3-5分钟** | 快节奏，适合短时间游玩 |
| 灵魂数量 | 每方4个 | M2最小可玩规模 |
| 地图大小 | 中等竞技场 | 约30x20格 |
| 决策频率 | 每10-15秒一个重要决策 | 战术切换/技能释放 |
| 操作密度 | 低-中 | 不需要高APM，需要策略判断 |

### 2.4 核心循环图

```
战前配置 → 战斗开始 → 观察局势
    ↑                        ↓
灵魂成长 ← 战斗结算 ← 战术决策/技能释放
```

**战前**：选择灵魂→配置技能→预设战术→选择地图
**战中**：观察→决策（战术指令/技能释放/战场互动）→观察→决策...
**战后**：查看结果→灵魂获得经验→灵魂成长→回到菜单

### 2.5 战斗HUD布局

战斗界面采用**四周布局**，中央为战斗区域（灵魂自主战斗），四周为玩家操作UI：

```

├──────┬──────────────────────────────────────┬───────────┤
│[小地 │  [底部操作栏]                          │ [战斗日志] │

```

**各区域详细说明**：

| 区域 | 位置 | 内容 | 交互 |
|------|------|------|------|
| **顶部状态栏** | 顶部全宽 | 玩家方4个灵魂头像+血球+能量球（左），战斗时间（中），AI方4个灵魂头像+血球（右） | 点击头像查看详情（M3） |
| **战斗区域** | 中央 | 2D俯视角战斗场景，灵魂自主战斗，地形/障碍物/互动元素 | 点击互动元素触发，点击技能后点击目标 |
| **小地图** | 左下角 | 缩小版战场地图，显示灵魂位置（蓝点=玩家，红点=AI），地形概览 | 点击移动视角（M3，M2固定视角） |
| **战术指令栏** | 底部左侧 | 6个指令按钮：进攻/防守/集火/撤退/跟随/自由，当前指令高亮 | 点击指令→选择目标（全体/单个灵魂） |
| **技能栏** | 底部中央 | 4个技能图标（对应4个出战灵魂），显示冷却扇形遮罩+能量消耗 | 点击技能→进入瞄准→点击目标释放 |
| **暂停/设置** | 底部右侧 | 暂停按钮、设置按钮 | 点击打开暂停菜单/设置 |
| **战斗日志** | 右侧 | 滚动事件列表，重要事件（击杀/技能/暴击）高亮显示 | 自动滚动，不可交互 |

**数据可视化规范**（遵循ART_STYLE_GUIDE.md）：
- 生命值：球形血条（血球），绿色渐变填充，金色边框
- 能量值：球形能量条，蓝色渐变填充，金色边框
- 技能冷却：图标上扇形遮罩+倒计时数字
- 伤害飘字：向上浮动+渐隐，暴击金色放大
- 战术指令：灵魂头顶显示当前指令图标

## 三、灵魂AI行为系统

### 3.1 AI设计原则

- **自主决策**：灵魂会自己决定移动、攻击、躲避、技能使用
- **个性驱动**：不同个性的灵魂有不同的行为倾向
- **指令影响**：玩家的战术指令改变AI行为权重，不直接控制
- **可预测性**：玩家可以通过了解灵魂个性来预测其行为，做出策略决策
- **不蠢**：灵魂不会做出明显愚蠢的行为（如站着挨打、冲进敌群送死）

### 3.2 灵魂个性系统

每个灵魂有一个**主个性**，影响其战斗行为：

| 个性 | 战斗风格 | 行为倾向 | 适合角色 |
|------|----------|----------|----------|
| **激进 Aggressive** | 主动进攻，穷追不舍 | 优先攻击最近敌人，追击距离远，躲避倾向低 | 输出型/DPS |
| **保守 Defensive** | 保持距离，防守反击 | 优先躲避，保持攻击距离，追击距离短 | 远程/脆皮 |
| **灵巧 Agile** | 灵活走位，伺机而动 | 频繁移动，躲避倾向高，会绕后/侧翼 | 刺客/游击 |
| **坦克 Tank** | 顶在前面，吸引火力 | 优先靠近敌人，承受伤害，保护友方 | 前排/肉盾 |
| **辅助 Support** | 关注友方，提供增益 | 优先治疗/增益友方，站位靠后 | 治疗/辅助 |
| **平衡 Balanced** | 综合表现，无明显倾向 | 各项行为权重均衡 | 通用型 |

**个性如何影响AI决策**：
- AI决策时，每个候选行为（攻击/躲避/移动/技能）有基础权重
- 个性会调整这些权重（如激进型攻击权重+30%，躲避权重-20%）
- 战术指令进一步调整权重（如"防守"指令让所有灵魂躲避权重+50%）

### 3.3 AI决策流程

灵魂每**0.5-1.5秒**（个性影响决策间隔，激进型决策更快）进行一次决策：

```
1. 感知环境
   ├─ 扫描附近敌人（位置/血量/距离）
   ├─ 扫描附近友方（位置/血量）
   ├─ 检查自身状态（血量/能量/技能冷却）
   └─ 检查地形和互动元素

2. 评估候选行为
   ├─ 攻击：选择最优目标（距离/血量/威胁度）
   ├─ 移动：向目标移动/远离危险/占据有利位置
   ├─ 躲避：躲避敌方技能/远离危险区域
   ├─ 技能：是否使用技能，对谁使用
   └─ 互动：是否触发附近互动元素

3. 权重计算
   ├─ 基础权重（行为类型）
   ├─ 个性修正（+/-%）
   ├─ 战术指令修正（+/-%）
   ├─ 状态修正（血量低→躲避权重↑）
   └─ 环境修正（被集火→躲避权重↑）

4. 选择行为并执行
   └─ 权重最高的行为被选中，执行直到下次决策
```

### 3.4 玩家战术指令如何影响AI

战术指令**不直接控制**灵魂，而是**改变AI决策权重**：

| 指令 | 攻击权重 | 躲避权重 | 移动倾向 | 技能倾向 |
|------|----------|----------|----------|----------|
| 进攻 | +40% | -20% | 向敌人移动 | +20% |
| 防守 | -20% | +50% | 保持距离 | +10% |
| 集火 | +60%（目标） | -10% | 向目标移动 | +30%（目标） |
| 撤退 | -50% | +80% | 向基地移动 | -30% |
| 跟随 | -10% | +20% | 跟随目标 | +10% |
| 自由 | 0% | 0% | 自主 | 0% |

**关键设计**：指令是"倾向"不是"命令"。灵魂可能因为血量太低而在"进攻"指令下选择躲避，也可能因为敌人太近而在"撤退"指令下选择反击。这增加了不可预测性和趣味性。

### 3.5 灵魂状态机

```
IDLE（待机）
  ↓ 发现敌人
MOVING（移动）
  ↓ 进入攻击范围
ATTACKING（攻击）
  ↓ 血量低/被集火
EVADE（躲避）
  ↓ 技能可用+目标合适
CASTING（施法）
  ↓ 血量归零
DYING（死亡）
  ↓ 复活/战斗结束
IDLE
```

**状态切换条件**：
- IDLE → MOVING：发现敌人且不在攻击范围
- MOVING → ATTACKING：进入攻击范围
- ATTACKING → EVADE：血量<30% 或 被3个以上敌人攻击
- EVADE → ATTACKING：血量恢复>50% 且 敌人减少
- ANY → CASTING：技能可用且目标合适（个性影响技能使用倾向）
- ANY → DYING：血量归零

### 3.6 元素属性对战斗的影响

| 元素 | 攻击特性 | 防御特性 | 技能倾向 | 地形互动 |
|------|----------|----------|----------|----------|
| 火 | 高伤害，持续灼烧 | 低防御 | 范围伤害 | 熔岩地形加成 |
| 水 | 中等伤害，减速 | 中等防御 | 治疗/控制 | 水域地形加成 |
| 土 | 低伤害，高暴击 | 高防御，高血量 | 控制/护盾 | 岩石地形加成 |
| 风 | 高攻速，高闪避 | 低血量 | 位移/增益 | 高地地形加成 |

**元素克制**（M2可选，增加策略深度）：
- 火克风（火烧尽风）
- 风克土（风蚀土）
- 土克水（土挡水）
- 水克火（水灭火）

## 四、地图与场景设计

> **待完善**：本节将在后续轮次详细设计，包括具体地图选择、地形效果、碰撞系统、伪3D实现等。

### 4.1 地图设计原则

- **不是张贴图**：地图有互动元素、地形效果、碰撞、可破坏物
- **战术意义**：地形影响战斗，玩家需要利用地形制定策略
- **视觉层次**：伪3D效果（阴影、层级、高度感），灵魂"站在地面上"
- **可复用**：M2选3-5张地图，基于现有90+张地图概念图选择

### 4.2 地形效果系统

| 地形 | 效果 | 视觉表现 |
|------|------|----------|
| 水域 | 移动速度-30%，水元素+20%防御 | 蓝色水面波纹 |
| 熔岩 | 每秒损失2%生命，火元素+20%攻击 | 橙红熔岩冒泡 |
| 草丛 | 隐蔽（敌人视野-50%），风元素+20%闪避 | 绿色草丛摆动 |
| 高地 | 攻击+15%，视野+20% |  elevated地面+阴影 |
| 低地 | 攻击-10%，被暴击率+10% | 凹陷地面 |

### 5.1 核心设计：灵魂不是固定4种

**关键决策**：战斗单位不是固定的4种元素精灵，而是**玩家在Ember灵魂引擎中培养的灵魂**。

- 玩家培养的每个灵魂都可以作为战斗单位出场
- 灵魂的元素属性、个性、技能、外观决定其在战斗中的表现
- 利用现有100+元素精灵图资源，根据灵魂元素类型选择对应精灵

### 5.2 灵魂属性到战斗的映射

| Ember灵魂属性 | 战斗中映射 | 说明 |
|---------------|-----------|------|
| 元素类型 | 攻击/防御/技能特性 | 火/水/土/风等100+元素 |
| 个性 | AI行为倾向 | 激进/保守/灵巧/坦克/辅助/平衡 |

| 技能 | 战斗中可释放的主动技能 | 每个灵魂1-2个主动技能 |
| 天赋 | 被动增益 | 暴击率/闪避率/吸血等 |
| 亲密度 | 属性加成 | 亲密度越高，战斗中属性+% |
| 心情 | 临时属性波动 | 心情好属性+%，心情差属性-% |

### 5.3 灵魂外观决定

**外观生成规则**：
- 基础精灵：根据灵魂的**主元素类型**选择对应元素精灵图（从100+元素精灵图中选择）
- 颜色调整：根据灵魂的**次元素/个性**调整色调（如激进型偏红，保守型偏蓝）
- 装饰元素：根据灵魂的**天赋/技能**添加装饰（如暴击天赋加角，治疗天赋加光环）
- 大小调整：根据灵魂的**等级/体型**调整大小（坦克型偏大，灵巧型偏小）

**M2简化**：直接使用元素类型对应的精灵图，不做动态外观生成。4个出战灵魂选择4种不同元素的精灵。

### 5.7 数值平衡系统

#### 5.7.1 核心属性

| 属性 | 缩写 | 说明 | 基础值（1级） |

| 能量恢复 | MP_REGEN | 每秒能量恢复 | 5/秒 |

#### 5.7.2 伤害计算公式

```
最终伤害 = (攻击力 × 技能倍率 - 防御力 × 0.5) × 元素克制系数 × 暴击系数 × 随机系数

其中：
- 技能倍率：普通攻击=100%，技能=150%-300%
- 元素克制系数：克制=125%，被克=80%，无关系=100%（M2可选）
- 暴击系数：暴击=暴击伤害（150%），不暴击=100%
- 随机系数：90%-110%（防止伤害完全可预测）
- 最小伤害：攻击力 × 10%（防止高防御导致0伤害）
```

**治疗计算公式**：
```
最终治疗 = 治疗基础值 × (1 + 攻击力 × 0.02) × 随机系数
```

**伤害减免**：
```
实际受到伤害 = 最终伤害 × (100 / (100 + 防御力))
```
（防御力每增加100点，伤害减免约50%，避免防御堆叠无敌）

## 六、完整游戏流程

### 6.1 流程总览

```
主菜单
  ↓
灵魂管理（查看/培养灵魂）
  ↓
战斗配置（选择出战灵魂/技能/战术/地图）
  ↓
匹配对手（AI/玩家）
  ↓
战斗（灵魂自主+玩家策略）
  ↓
战斗结算（经验/奖励/灵魂成长）
  ↓
回到主菜单
```

### 6.2 各阶段详细设计

#### 6.2.1 主菜单

- **功能**：开始战斗、灵魂管理、设置、商店（M3）、成就（M3）
- **视觉**：奇幻魔法主题背景，灵魂球漂浮动画，金色标题
- **玩家操作**：点击"开始战斗"进入战斗配置

#### 6.2.2 灵魂管理

- **功能**：查看所有灵魂、灵魂详情、技能配置、天赋（M3）、进化（M4）
- **视觉**：灵魂卡片列表，点击查看详情
- **玩家操作**：浏览灵魂、查看属性、配置技能（M2简化为查看）

#### 6.2.3 战斗配置

**这是核心策略阶段**，玩家需要做出以下决策：

1. **选择出战灵魂**（4个）：从灵魂库中选择4个灵魂出战
   - 考虑元素搭配（是否有元素克制/互补）
   - 考虑个性搭配（是否有坦克/输出/辅助的平衡）
   - 考虑技能搭配（技能是否有组合效果）

2. **配置技能**（M2简化为默认技能）：每个灵魂选择1个主动技能
3. **预设战术**：选择开局战术指令（进攻/防守/自由）
4. **选择地图**：从3-5张可用地图中选择
5. **选择对手**：AI难度（简单/普通/困难）或玩家匹配（M3）

#### 6.2.4 战斗

- **时长**：3-5分钟
- **玩家操作**：战术指令切换、技能释放、战场互动、观察
- **灵魂行为**：自主移动/攻击/躲避/技能
- **胜利条件**：消灭对方全部灵魂 或 时间结束时血量总和更高

#### 6.2.5 战斗结算

- **内容**：胜利/失败、战斗数据（伤害/治疗/承受伤害）、经验获得、灵魂升级、奖励
- **视觉**：胜利金色光效/失败暗红色调，数据统计卡片
- **玩家操作**：查看数据、确认返回、再次战斗

### 6.3 灵魂成长循环

```
战斗 → 获得经验 → 升级 → 属性提升 → 更强的战斗 → 更多经验
```

- 每个出战灵魂获得经验（胜利×2，失败×1）
- 升级提升血量/攻击/防御基础属性
- M2不实现技能解锁/天赋树/进化，这些留到M3/M4

### 6.4 游戏模式

#### M2游戏模式（3种）

| **自定义对战** | 玩家选择AI难度、地图、出战灵魂 | 默认解锁 | 标准经验（无金币） |

**AI难度（3级）**：

### 6.5 典型战斗时间线

以一局**4v4快速对战**（普通难度AI，以太神殿地图）为例：

```
0:00  战斗开始
      ├─ 双方灵魂从基地出发，自主向中央移动
      ├─ 玩家观察双方阵容，决定初始战术（默认"自由"）
      └─ 灵魂进入战斗区域，开始接战

0:00-0:30  初期接触
      ├─ 前排（坦克/近战）率先交火
      ├─ 后排（远程/治疗）保持距离输出
      ├─ 玩家观察局势，可能切换"进攻"或"防守"指令
      └─ 第一个技能冷却完成（约6-10秒）

0:30-1:30  中期团战
      ├─ 双方技能交替释放，血量开始下降
      ├─ 玩家关键决策点：
      │   ├─ 是否集火敌方脆皮？（"集火"指令）
      │   ├─ 是否释放治疗技能拯救残血灵魂？
      │   ├─ 是否触发中央魔法机关？
      │   └─ 血量危险时是否"撤退"重整？
      ├─ 可能出现首次击杀（约1-1.5分钟）
      └─ 战场互动元素首次可用（补给点30秒冷却）

1:30-3:00  后期决战
      ├─ 双方人数减少，形成多打少局面
      ├─ 存活灵魂等级提升（战斗中临时属性增长，M3+）
      ├─ 玩家持续决策：
      │   ├─ 优势方："进攻"推进，扩大优势
      │   ├─ 劣势方："防守"拖时间，寻找反击机会
      │   └─ 均势方：技能释放时机决定胜负
      ├─ 补给点第二次可用（90秒冷却后）
      └─ 可能出现决定性击杀

3:00-5:00  战斗结束
      ├─ 一方全部被击败 → 立即结束
      ├─ 或5分钟时间到 → 按剩余血量总和判定胜负
      ├─ 战斗结算界面：
      │   ├─ 胜利/失败展示
      │   ├─ 战斗数据（伤害/治疗/承受伤害/KDA）
      │   ├─ 灵魂经验获得和升级
      │   └─ 奖励展示
      └─ 玩家选择：再次战斗 / 返回菜单 / 查看灵魂详情
```

**关键决策点分布**：
- 每15-30秒一个重要决策（战术切换/技能释放）
- 每1分钟一个关键节点（首次击杀/补给点/魔法机关）
- 玩家操作密度：低-中（不需要高APM，但需要持续观察和决策）

## 十一、设计决策记录

### 2026-09-10 决策记录

| 决策 | 选择 | 理由 | 备选方案 |
|------|------|------|----------|
| **核心玩法** | 灵魂自主战斗+玩家战术指令 | 用户明确否决传统RTS直接操控，要求灵魂自主战斗 | 传统RTS直接操控（已否决）、自走棋（玩家参与太少） |
| **玩家操作** | 战术指令+技能释放+战场互动 | 不直接控制移动，但有策略参与感 | 纯观察（自走棋式）、完全控制（传统RTS） |
| **灵魂个性** | 6种个性影响AI权重 | 增加灵魂独特性和策略深度 | 无个性（同类型行为一致）、更多个性（M3+） |
| **战术指令** | 6种指令改变AI权重 | 指令是"倾向"不是"命令"，增加不可预测性 | 直接命令（灵魂必须执行） |
| **单局时长** | 3-5分钟 | 快节奏，适合短时间游玩 | 10-15分钟（传统RTS时长） |
| **出战灵魂数** | 4个 | M2最小可玩规模，管理复杂度适中 | 3个（太少）、6个（太复杂） |
| **M2地图数** | 1-2张 | 最小可玩，集中精力做核心玩法 | 3-5张（M3） |
| **灵魂成长** | 经验/升级/属性提升 | M2简化，不做技能解锁/天赋树 | 完整成长系统（M3+） |
