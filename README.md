# AI灵魂项目 — 项目管理中心

> 跨游戏AI灵魂系统的项目管理、进展跟踪、计划与卡点管理

## 项目愿景

打造一个跨游戏、跨平台的AI灵魂系统。用户培养的"灵魂"是带有持久记忆和个性的数字伙伴，可以在不同游戏间迁移使用，在对战中成长，在虚拟社会中进化，最终走向实体机器人。

## 更新机制

本仓库由定时监控任务定期更新：
- 每次监控触发时，读取两个子项目的最新进展
- 更新 PROJECT_STATUS.md（进展报告）
- 更新 PROJECT_PLAN.md（计划调整）
- 更新 BLOCKERS.md（卡点与建议）
- 提交并推送到GitHub

## 商业计划摘要

采用三层产品矩阵，共享同一套灵魂引擎：
1. **短期（0-9月）：** RTS灵魂对战竞技场 — 快速变现
2. **中期（9-18月）：** 养成+直播观察 — 扩大用户
3. **长期（18-36月）：** 社会模拟+模型评测平台 — 建壁垒

核心优势：宝可梦级智能（单灵魂月成本¥0.5-2）、游戏化合规包装、跨游戏迁移网络效应。
